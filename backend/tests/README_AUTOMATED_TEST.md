# 自动化性能压测脚本使用说明

## 📋 脚本说明

`automated_performance_test.py` 是一个完整的自动化性能测试脚本，包含：

- ✅ 自动登录（支持OAuth2表单认证）
- ✅ 触发分析任务（通过API）
- ✅ 实时监控进度（每5秒检查一次）
- ✅ 详细日志记录（包含时间戳、行号、详细错误信息）
- ✅ 自动生成测试报告（Markdown格式）

## 🚀 使用方法

### 方法1: 直接运行（推荐）

```bash
# 进入backend目录
cd D:\Java\ai_writer\backend

# 在虚拟环境中运行
venv\Scripts\python.exe tests\automated_performance_test.py
```

### 方法2: 在已激活的虚拟环境中运行

```bash
# 激活虚拟环境
D:\Java\ai_writer\backend\venv\Scripts\activate

# 运行脚本
python tests\automated_performance_test.py
```

## 📊 测试流程

脚本会自动执行以下步骤：

```
步骤1: 用户登录
├── 发送登录请求到: http://localhost:8000/api/auth/login
├── 使用账号: 2072855200@qq.com
├── 获取访问令牌 (access_token)
└── 获取用户信息

步骤2: 触发分析任务
├── 发送POST请求: /api/novel-analysis/works/{work_id}/analyze
├── 使用Bearer Token认证
└── 启动分析任务

步骤3: 监控分析进度
├── 每5秒查询一次分析状态
├── 实时显示进度: 已分析/总章节 (百分比)
├── 显示用时和平均速度
└── 等待完成或超时(最大30分钟)

步骤4: 生成测试报告
├── 打印测试总结到控制台
└── 保存Markdown报告: automated_performance_report.md
```

## 🐛 常见问题排查

### 问题1: 连接后端失败

```
ERROR: 连接后端服务失败: [Errno 111] Connection refused
```

**解决方案**:
```bash
# 确认后端服务正在运行
curl http://localhost:8000/api/health

# 如果没有运行，启动后端
cd D:\Java\ai_writer\backend
uvicorn app.main:app --reload
```

### 问题2: 登录失败 401

```
ERROR: 登录失败! 状态码: 401
```

**可能原因**:
- 账号或密码错误
- 后端认证配置问题

**排查步骤**:
1. 检查脚本中的账号密码是否正确
2. 查看后端日志确认错误详情
3. 尝试使用Postman手动测试登录接口

### 问题3: 触发分析失败 404

```
ERROR: 触发分析失败! 状态码: 404
```

**可能原因**:
- Work ID不存在
- API路由错误

**解决方案**:
```bash
# 检查作品是否存在
# 查看数据库或使用API查询
```

### 问题4: 分析超时

```
ERROR: ⏰ 等待超时! 已等待 1800.0秒
```

**可能原因**:
- AI API响应慢
- 章节内容过长
- 网络问题

**解决方案**:
- 检查AI API服务状态
- 查看后端日志确认具体错误
- 适当增加超时时间（修改 `max_wait_time` 参数）

# 数据库配置说明

> **重要**：本项目使用 PostgreSQL 15+ 作为数据库

## 📥 快速开始

### 1. 下载并安装 PostgreSQL

**下载地址**：https://get.enterprisedb.com/postgresql/postgresql-15.14-2-windows-x64.exe

**完整安装指南**：查看 [POSTGRESQL_SETUP.md](./POSTGRESQL_SETUP.md)

### 2. 创建数据库

#### 方式一：自动创建（推荐）

```bash
# 在 backend 目录下运行
psql -U postgres -f setup_db.sql
# 输入安装时设置的超级用户密码
```

#### 方式二：手动创建

```bash
# 连接到 PostgreSQL
psql -U postgres

# 执行以下SQL
CREATE DATABASE novelaide;
CREATE USER novelaide WITH PASSWORD 'novelaide_password';
GRANT ALL PRIVILEGES ON DATABASE novelaide TO novelaide;
\c novelaide
GRANT ALL PRIVILEGES ON SCHEMA public TO novelaide;
\q
```

### 3. 配置项目

编辑 `.env` 文件：

```bash
DATABASE_URL=postgresql+asyncpg://novelaide:novelaide_password@localhost:5432/novelaide
```

### 4. 验证连接

```bash
# 运行 check_env.bat 检查
check_env.bat

# 或手动测试
psql -U novelaide -d novelaide
```

## 🔧 配置参数说明

### 连接字符串格式

```
postgresql+asyncpg://用户名:密码@地址:端口/数据库名
```

### 默认配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 用户名 | novelaide | 数据库用户 |
| 密码 | novelaide_password | 用户密码 |
| 地址 | localhost | 数据库地址 |
| 端口 | 5432 | PostgreSQL 默认端口 |
| 数据库名 | novelaide | 数据库名称 |

## 🚨 常见问题

### Q: 为什么不使用 SQLite？

**A**: PostgreSQL 提供：
- 更好的并发性能
- 完整的事务支持
- 更强大的查询功能
- 生产环境标准
- 更好的数据完整性

### Q: 安装 PostgreSQL 很复杂吗？

**A**: 不复杂！
1. 双击安装程序
2. 一路 Next
3. 记住设置的密码
4. 运行一个 SQL 脚本

详细步骤查看：[POSTGRESQL_SETUP.md](./POSTGRESQL_SETUP.md)

### Q: 可以使用其他数据库吗？

**A**: 理论上可以，但需要修改配置和代码：
- MySQL/MariaDB：修改 DATABASE_URL 和驱动
- SQLite：修改为同步操作
- 不推荐修改，建议使用 PostgreSQL

### Q: 数据库密码可以修改吗？

**A**: 可以！修改两个地方：
1. PostgreSQL 中修改用户密码
2. `.env` 文件中同步修改 DATABASE_URL

### Q: 如何备份数据库？

**A**: 使用 pg_dump：

```bash
# 备份
pg_dump -U novelaide -d novelaide > backup.sql

# 恢复
psql -U novelaide -d novelaide < backup.sql
```

### Q: 如何查看数据库内容？

**A**: 使用以下工具：
- **pgAdmin 4**（自带，推荐）
- **DBeaver**（免费，功能强大）
- **DataGrip**（付费，专业）

或命令行：
```bash
psql -U novelaide -d novelaide
```

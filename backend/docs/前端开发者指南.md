## 🚀 快速开始（4步）

### 第1步：安装 PostgreSQL

下载并安装：https://get.enterprisedb.com/postgresql/postgresql-15.14-2-windows-x64.exe

详细步骤请查看：[POSTGRESQL_SETUP.md](./POSTGRESQL_SETUP.md)

创建数据库：
```bash
psql -U postgres -f setup_db.sql
```

### 第2步：运行安装脚本

双击 `setup.bat`，等待安装完成（约5-10分钟）。

### 第3步：配置 API Key

编辑 `.env` 文件，修改：

```bash
OPENAI_API_KEY=your-real-api-key-here
```

### 第4步：启动服务

双击 `quick_start.bat`，访问 http://localhost:8000/docs

## 📡 接口概览

### 认证接口（3个）
- 注册 `POST /api/v1/auth/register`
- 登录 `POST /api/v1/auth/login`
- 刷新 `POST /api/v1/auth/refresh`

### 用户接口（4个）
- 获取当前用户 `GET /api/v1/users/me`
- 更新当前用户 `PUT /api/v1/users/me`
- 获取用户 `GET /api/v1/users/{user_id}`
- 用户列表 `GET /api/v1/users`

### 作品接口（5个）
- 作品列表 `GET /api/v1/works`
- 作品详情 `GET /api/v1/works/{work_id}`
- 创建作品 `POST /api/v1/works`
- 更新作品 `PUT /api/v1/works/{work_id}`
- 删除作品 `DELETE /api/v1/works/{work_id}`

### 章节接口（6个）
- 章节列表 `GET /api/v1/chapters/work/{work_id}`
- 章节详情 `GET /api/v1/chapters/{chapter_id}`
- 创建章节 `POST /api/v1/chapters`
- 更新章节 `PUT /api/v1/chapters/{chapter_id}`
- 删除章节 `DELETE /api/v1/chapters/{chapter_id}`
- 排序章节 `POST /api/v1/chapters/reorder`

**详细说明请查看 [API_REFERENCE.md](./API_REFERENCE.md)**

## 💡 开发技巧

### 1. 使用 Swagger UI 测试接口

访问 http://localhost:8000/docs 可以：
- 查看所有接口
- 在线测试接口
- 查看请求/响应格式
- 无需写代码即可验证功能

### 2. Axios 快速封装

```javascript
// api.js
import axios from 'axios';

const api = axios.create({
  baseURL: 'http://localhost:8000/api/v1'
});

api.interceptors.request.use(config => {
  const token = localStorage.getItem('access_token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

export default api;
```

```javascript
// 使用
import api from './api';

// 登录
const { data } = await api.post('/auth/login', 
  new URLSearchParams({ username, password })
);

// 获取作品列表
const works = await api.get('/works?skip=0&limit=20');

// 创建作品
const newWork = await api.post('/works', {
  title: '我的小说',
  genre: 'FANTASY'
});
```

### 3. Token 自动刷新

```javascript
api.interceptors.response.use(
  response => response,
  async error => {
    if (error.response?.status === 401) {
      const refreshToken = localStorage.getItem('refresh_token');
      const { data } = await axios.post(
        'http://localhost:8000/api/v1/auth/refresh',
        { refresh_token: refreshToken }
      );
      
      localStorage.setItem('access_token', data.access_token);
      
      // 重试原请求
      error.config.headers.Authorization = `Bearer ${data.access_token}`;
      return api(error.config);
    }
    return Promise.reject(error);
  }
);
```

## 🚨 常见问题

### Q: 启动失败怎么办？

**A**: 运行 `check_env.bat` 检查环境，查看终端错误信息。

### Q: 端口被占用？

**A**: 修改 `.env` 中的 `PORT=8000` 为其他端口。

### Q: API 返回 401？

**A**: 检查 Token 是否正确添加到请求头，格式：`Authorization: Bearer {token}`

### Q: 如何查看所有接口？

**A**: 访问 http://localhost:8000/docs 或查看 API_REFERENCE.md

### Q: 如何管理数据库？

**A**: 使用 pgAdmin 4（自带）或 DBeaver 连接到 PostgreSQL 查看和管理数据。
- 数据库名：novelaide
- 用户名：novelaide
- 密码：novelaide_password
- 地址：localhost:5432

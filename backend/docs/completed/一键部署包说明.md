# NovelAIde Backend 一键部署包

## 📦 包含文件

### 🚀 核心启动脚本
- **setup.bat** - 一键安装和配置脚本（首次运行）

- **check_env.bat** - 环境检查工具

## 📋 前置要求

### 必须安装
- **Python 3.8+** （[下载](https://www.python.org/downloads/)）
- **PostgreSQL 15+** （[下载](https://get.enterprisedb.com/postgresql/postgresql-15.14-2-windows-x64.exe)）
  - 安装指南：POSTGRESQL_SETUP.md

### 不需要安装
- ❌ Redis（可选）
- ❌ Docker（可选）
- ❌ Node.js（后端不需要）

## 🔧 必须配置

需要配置 `.env` 文件中的：

```bash
# 必须配置 OpenAI API Key
OPENAI_API_KEY=sk-xxxxxxxxxxxxx  # ⚠️ 必须配置

# 数据库配置（如果修改了密码需要同步）
DATABASE_URL=postgresql+asyncpg://novelaide:novelaide_password@localhost:5432/novelaide
```

其他配置都已设置好默认值。

## 🚨 常见问题快速解决

| 问题 | 解决方法 |
|------|----------|
| Python 未安装 | 下载安装 Python 3.8+ |
| 依赖安装失败 | 重新运行 setup.bat |
| 端口 8000 被占用 | 修改 .env 中的 PORT |
| API Key 未配置 | 编辑 .env 配置 OPENAI_API_KEY |
| 数据库损坏 | 删除 novelaide.db 重新启动 |
| 启动失败 | 运行 check_env.bat 检查 |

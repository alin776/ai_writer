# AI评价功能测试指南

## 🚀 快速开始

### 1. 启动后端服务

```bash
cd D:\Java\ai_writer\backend
venv\Scripts\activate
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 2. 运行测试脚本

在**另一个终端**中执行:

```bash
cd D:\Java\ai_writer\backend
venv\Scripts\python test_evaluation_api.py
```

## 📋 测试流程

脚本将自动执行以下步骤:

1. **用户登录**
   - 使用提供的邮箱和密码登录
   - 获取访问token

2. **调用评价接口**
   - 发送测试文本到评价API
   - 等待AI评价结果

3. **显示评价结果**
   - 总分 (0-100)
   - 5维度评分 (文学性、连贯性、创意性、情感感染力、节奏把控)
   - 优点列表
   - 问题列表
   - 改进建议

## 🔧 自定义测试

### 修改测试文本

编辑 `test_evaluation_api.py` 中的 `TEST_TEXT` 变量:

```python
TEST_TEXT = """
你的测试文本内容...
"""
```

### 修改操作类型

支持的操作类型:
- `continue` - 续写
- `polish` - 润色
- `expand` - 扩写
- `translate` - 翻译
- `summarize` - 总结

修改 `run_test()` 调用:

```python
tester.run_test(
    email=EMAIL,
    password=PASSWORD,
    test_text=TEST_TEXT.strip(),
    operation_type="polish"  # 改为其他类型
)
```

### 修改API地址

如果后端运行在其他端口或服务器:

```python
BASE_URL = "http://your-server:port"
```

## 🐛 常见问题

### 1. 连接失败

**错误**: `Connection refused` 或 `Max retries exceeded`

**解决**:
- 确认后端服务已启动
- 检查端口8000是否被占用
- 检查防火墙设置

### 2. 登录失败

**错误**: `401 Unauthorized` 或 `Invalid credentials`

**解决**:
- 检查邮箱和密码是否正确
- 确认用户账号已激活
- 查看后端日志获取详细错误信息

### 3. 评价超时

**错误**: `Timeout (60秒)`

**解决**:
- 检查AI服务配置是否正确
- 查看后端日志中的AI调用情况
- 确认网络连接正常

### 4. 数据库错误

**错误**: `relation "evaluation_records" does not exist`

**解决**:
```bash
cd D:\Java\ai_writer\backend
alembic upgrade head
```

## 📋 使用方法

### 快速开始

```bash
# 1. 进入后端目录
cd backend

# 2. 安装测试依赖（如果尚未安装）
pip install httpx

# 3. 启动后端服务（新终端）
python -m uvicorn app.main:app --reload

# 4. 检查测试环境（可选）
python check_test_env.py

# 5. 运行测试
python test_rewrite_arena.py
```

### 自定义配置

```bash
# 设置环境变量
export API_BASE_URL=http://localhost:8000
export TEST_USERNAME=your_username@example.com
export TEST_PASSWORD=your_password

# 运行测试
python test_rewrite_arena.py
```

## 🎓 学习要点

### 1. 测试设计原则
- 测试应该独立且可重复
- 测试应该有清晰的成功/失败标准
- 测试应该自动清理测试数据

### 2. 异步编程
- 使用 `async/await` 处理异步操作
- 使用 `asyncio.run()` 运行异步主函数
- 使用 `httpx.AsyncClient` 进行异步 HTTP 请求

### 3. 错误处理
- 使用 try-except 捕获所有异常
- 记录详细的错误信息
- 提供有用的错误提示

### 4. 用户体验
- 使用颜色区分不同类型的输出
- 提供清晰的测试进度指示
- 显示详细的测试统计

# 角色关系图谱分析

## 关系分析心智模型

Before 标注任何关系, ask yourself:
- **关系的证据强度够吗？** 两人同在一个场景不等于有关系。必须有直接互动（对话/冲突/合作）才能建立关系标注
- **关系的方向是否对称？** A→B 的情感和 B→A 可能不同（单恋、表面恭敬实则不满），双向关系需分别标注
- **这个关系在时间线上稳定吗？** 关系是动态的——敌人可能变盟友，师徒可能反目。标注时间戳和转折事件

## Expert 互动识别规则

### 5 级互动强度
| 等级 | 类型 | 示例 | 权重 |
|------|------|------|------|
| **5** | 直接对话 + 肢体互动 | 面对面交谈、打斗、拥抱 | ×5 |
| **4** | 直接对话 | 两人对话但无物理接触 | ×4 |
| **3** | 同场景有反应 | 在同一场景，有观察/反应但无直接交流 | ×3 |
| **2** | 内心提及 | 某角色内心活动中想到另一角色 | ×2 |
| **1** | 第三方转述 | 通过其他角色的对话/描述提及 | ×1 |

互动总分 = Σ(每次互动的等级权重)

### 关系类型判定
- **亲属关系**：父子/母女/兄弟/姐妹/夫妻——看称呼和叙述确认
- **师徒关系**：师父/弟子/同门——注意师徒可能有代际差异
- **敌对关系**：仇人/竞争者/对立阵营——区分"主动敌对"和"被动对立"
- **情感关系**：暧昧/恋人/单恋/过去式——注意区分"暧昧"和"作者还没写到"
- **从属关系**：上下级/主仆/雇佣——注意实际权力关系可能与名义不同
- **合作关系**：盟友/队友/临时合作——标注合作的稳定性

### 关系变化识别
- 称呼改变 = 关系变化信号（"你"→"你们大人" = 疏远；全名→昵称 = 亲近）
- 互动强度突变 = 关系拐点（频繁互动→突然消失 = 可能有事件导致疏远）
- 阵营变动 = 高优先级标注（叛变/转投/被策反）

## NEVER

- NEVER 仅因同场景就标注"有关系" —— 同在宴会上不等于有关系，必须有直接互动证据
- NEVER 用称呼直接推断关系类型 —— "大哥"可能是亲兄弟也可能是江湖称呼，需要叙述上下文确认
- NEVER 忽略关系的时间维度 —— 第 3 章的敌人在第 15 章可能已是盟友，关系标注必须附带时间范围
- NEVER 遗漏"最后确认章节" —— 每对关系必须标注最后一次互动出现在哪一章，帮助识别"断裂关系"
- NEVER 把读者推测当作已确认关系 —— "作者暗示 A 喜欢 B"和"A 明确表示喜欢 B"需要区分标注（推测 vs 确认）

## 边界情况

- **大量路人角色**: 只追踪有名字 + 出场 ≥2 次的角色，一次性路人不建立关系图
- **群体/阵营**: 当一个阵营有 5+ 成员时，可以用"阵营"作为节点而非单独追踪每对关系
- **隐藏身份**: 同一角色不同身份（如假名/伪装）需合并追踪，标注身份切换章节
- **回忆/闪回中的关系**: 标注为"过去关系"，与"当前关系"区分
- **单方面认知的关系**: A 知道 B 是仇人但 B 不知道 A 的存在——标注为单向

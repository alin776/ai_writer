# 全书创作数据统计与洞察

## 数据洞察心智模型

Before 输出任何统计数据, ask yourself:
- **这个数字说明什么问题？** 数字本身无意义，偏离正常范围的数字才值得报告。"第 7 章 5200 字"不重要，"第 7 章 5200 字，是章均的 2.3 倍"才重要
- **异常是 bug 还是 feature？** 高潮章字数偏长、战斗章角色出场少——这些是合理的。统计应标注异常但解释可能的合理原因
- **作者需要这个数据来做什么决策？** 统计服务于决策：字数趋势 → 是否需要控制篇幅；角色消失 → 是否需要安排出场；场景集中 → 是否需要换场景

## 异常阈值参考

### 字数
- 章均正常范围：2000-4000 字（网文标准）
- 单章超过章均 1.5 倍 → 📢 偏长（考虑拆章）
- 单章低于章均 0.5 倍 → 📢 偏短（内容是否单薄）
- 连续 3 章字数持续上升/下降 → ⚠️ 节奏趋势异常
- 最长章与最短章差距 > 3 倍 → ⚠️ 篇幅控制不稳定

### 角色出场
- 主角出场率正常范围：60%-90%（不需要每章都出现，但不能消失太久）
- 重要配角连续 5 章未出场 → ⚠️ 可能被遗忘
- 某角色提及率远高于出场率（被谈论但不出现）→ 📝 可能需要安排亮相
- 新角色引入后 3 章内无再出场 → ⚠️ 引入后弃用风险

### 场景
- 连续 5 章以上停留同一场景 → 📢 场景单调风险
- 某场景只出现 1 次且有未解决事件 → 📝 可能需要回访

## NEVER

- NEVER 只输出数字不给洞察 —— 纯数据表格作者自己能数，skill 的价值在于"这些数字意味着什么"
- NEVER 把字数等同于质量 —— 短章不等于差，长章不等于好。字数异常只是信号，需要结合内容判断
- NEVER 把 frontmatter/元数据算入正文字数 —— 只统计纯正文内容（去掉 YAML 头、标题行、分隔符等）
- NEVER 把"提及"等同于"出场" —— 角色 A 在对话中说"角色 B 去了北方"，角色 B 并未出场。出场 = 在场景中有行动或对话
- NEVER 忽略章节标题/标注中的信息 —— 有些章节标题含重要元数据（"第 X 章（角色A视角）"），应纳入分析

## 边界情况

- **章节数极少（<5）**: 统计意义有限，重点输出单章分析而非趋势
- **多视角/双线叙事**: 分视角线统计角色出场，否则"主角消失 3 章"可能只是切换了视角线
- **番外/特别篇**: 不纳入主线统计，单独列出
- **大量对话 vs 大量描写**: 对话密集章的"有效信息密度"通常高于描写密集章，字数对比时应考虑

## 输出格式

📊 全书统计报告

基础数据:
  总字数: {N} 字 | 章节数: {N} 章 | 章均: {N} 字

字数分析:
  最长: 第{X}章 "{title}" — {N}字（章均的 {ratio} 倍）
  最短: 第{Y}章 "{title}" — {N}字（章均的 {ratio} 倍）
  趋势: {上升/下降/稳定/波动} — {洞察}
  ⚠️ 异常章节: {列出超出阈值的章节 + 原因猜测}

角色健康度:
  主角出场率: {N}%（{正常/偏低/偏高}）
  角色出场 TOP 5:
    1. {角色名}: {N}章出场 / {N}次提及 — {健康/过密/偏少}
  ⚠️ 消失角色: {角色名}（最后出场: 第{X}章，已缺席 {N} 章）
  ⚠️ 引入后弃用: {角色名}（第{X}章引入后仅出场 {N} 次）

场景分布:
  📍 场景集中: 最近 {N} 章集中在 {地点}
  📝 孤立场景: {地点}（仅第{X}章出现，有未解决事件）

关键洞察（≤3 条）:
  {基于数据的可操作建议}

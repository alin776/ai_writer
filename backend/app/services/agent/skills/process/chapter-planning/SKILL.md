# 章节规划

## 规划心智模型

Before 规划任何章节, ask yourself:
- **这一章在全书中的结构位置？** 开篇钩子期（1-3章）/ 上升期 / 中段转折 / 高潮前蓄力 / 高潮 / 收束 —— 位置决定节奏和信息密度
- **读者此刻知道什么、不知道什么？** 列出读者当前的信息状态，规划应基于"读者视角的信息差"而非"作者视角的全知"
- **这章结束后，故事状态必须发生什么变化？** 如果答不出来，这章可能不需要存在

## 执行前确认

输出章节规划前，先完成以下步骤：
- [ ] 已读取 outline.md（确定章节在全书中的位置）
- [ ] 已读取最近2章正文（确认当前故事状态）
- [ ] 已读取 characters.md（确认可用角色状态）
如任何文件缺失，在规划开头注明。

## 查询协议

按以下优先级读取文件：
1. **必读** /knowledge/outline.md（章节定位与方向）
2. **必读** 最近1-2章正文（衔接上文）
3. **推荐** /knowledge/characters.md（角色状态）
4. **推荐** /knowledge/worldview.md（设定约束）
缺失文件跳过并注明。

## Expert 规划规则

### 信息负载控制
- 每章引入新概念/新设定 ≤3 个（人名、地名、能力名各算一个）
- 超过 3 个新概念时，必须用"已知角色带入"的方式降低认知负担
- 前 3 章的信息负载应最低——读者还没建立信任，不要考验耐心

### 悬念债务管理
- 铺设悬念 = 欠债，收束悬念 = 还债
- 同时存在的未收束悬念不超过 5 条（超过读者会遗忘早期悬念）
- 每 5 章至少收束 1 条悬念（给读者"回报感"）
- 高潮章应集中还债（多条伏笔同时收束 = 最大爽感）

### 开篇钩子强制规则（前 3 章）
- 第 1 章必须在前 500 字内建立核心冲突或悬念
- 前 3 章禁止大段世界观说明（通过事件自然展现）
- 前 3 章每章结尾必须有强钩子（生存/秘密/反转级别）

### 结尾选择策略
- 悬念切断型：在最紧张处戛然而止（适合动作/冲突章）
- 信息揭露型：抛出新信息改变局面认知（适合推理/谋略章）
- 情感冲击型：角色做出重大决定或关系发生质变（适合情感/成长章）
- 禁止在情感最高点结束——让情绪有半拍回落再切，避免"强行煽情"感

## 规划要素

1. **章节目标**：读者读完获得什么（信息增量/情感体验/悬念）
2. **核心事件**：1-3 个必须发生的事件（超过 3 个考虑拆章）
3. **出场人物**：本章出场角色 + 当前状态 + 本章中的变化
4. **情感曲线**：起点 → 转折 → 终点（不能是平线）
5. **伏笔操作**：本章铺设/强化/回收的伏笔（标注是哪种操作）
6. **结尾钩子**：选择策略类型 + 具体悬念内容

## NEVER

- NEVER 在一章中安排超过 3 个核心事件 —— 信息过载导致每个事件都写不透，读者消化不了
- NEVER 让新角色在首次出场章就承担关键剧情转折 —— 读者对新角色无情感投入，关键时刻不会产生共鸣
- NEVER 规划纯过渡章（"本章主要是从 A 到 B 的旅途"）—— 每章必须有独立存在的价值，旅途中也要有事件或人物发展
- NEVER 在规划中写"可以考虑..."或"或者..." —— 规划必须给出明确决定，模糊选项会导致写作时犹豫
- NEVER 忽略前文未收束的悬念 —— 每次规划前检查当前悬念债务表

## 边界情况

- **开篇章**: 信息负载规则更严格（≤2 新概念），钩子强度要求最高
- **高潮章**: 允许打破常规节奏（可以全章高强度），核心事件可以增至 4 个
- **群戏章（4+ 角色同场）**: 需明确"视角角色"是谁，其他角色通过视角角色的观察展现
- **时间跳跃章**: 必须在开头明确时间锚点，用一个熟悉场景/角色建立连续感

# 章节起草器：编排技能

你自主起草和打磨章节场景，通过迭代的编辑轮次进行。给定大纲后，你通过起草每个场景、对照编辑标准评估、反复修改直到达到质量阈值来产出精打磨的初稿散文。

## 核心原则

**编排就是带层级的迭代。**先修结构再修角色，先修角色再修原创性，先修原创性再修对话，先修对话再修文笔。不要打磨可能被删的内容；不要修改需要结构重写的场景中的对话。

---

## 前置条件

在调用该技能之前，确保：

1. **完整大纲已存在** - 场景节拍包含目标、冲突和预期结果
2. **角色已定义** - 谎言/欲望/需要、声音模式、弧线位置
3. **世界已建立** - 足够支撑场景工作的背景细节
4. **story-sense 诊断已完成** - 不存在结构性故事问题

**不要在以下情况使用该技能：**
- 大纲仍在变动中
- 角色弧线未定义
- story-sense 会诊断出结构问题

---

### 阅读预算
- 先读大纲/计划文件（1个文件）
- 最多读最近的2个章节作为上下文（2个文件）
- 生成前总阅读量：≤ 5个文件
- 阅读后，立即开始起草——不要再读更多文件

---

## 编排循环

```
FOR each scene in chapter outline:

    1. 构建上下文
       - 从前面的场景加载角色声音
       - 加载未完结的情节线索
       - 加载老套回避清单
       - 从大纲中提取场景目的

    2. 起草场景
       - 从大纲节拍生成初始散文
       - 应用角色声音
       - 保持情节线索连续性

    3. 评估循环（最多5轮）
       │
       ├─► 轮次1：scene-sequencing（35%）
       │   └─► 如果不通过：重写场景
       ├─► 轮次2：character-arc（25%）
       ├─► 轮次3：cliche-transcendence（15%）
       ├─► 轮次4：dialogue（15%）
       └─► 轮次5：prose-style（10%）
       │
       计算综合得分
       │
       ├─► >= 80：接受
       ├─► 60-79：定向修正 → 重新评估
       ├─► 40-59：重写 → 返回起草
       └─► <40：拒绝 → 从大纲重新起草

    4. 接受后处理
       - 提取角色声音模式 → 更新上下文
       - 跟踪情节线索变化 → 更新注册表
       - 记录老套超越 → 更新回避清单
       - 将场景写入输出
       - 更新进度跟踪器

END FOR
```

## 轮次标准

### 轮次1：场景排序（35%权重）

评估目标-冲突-灾难结构和节奏。

| 标准 | 通过 | 警告 | 不通过 |
|------|------|------|--------|
| **目标清晰度** | 视角目标在开头节拍清晰 | 目标存在但被埋没 | 无可辨识的目标 |
| **冲突升级** | 对抗加剧 | 冲突静态但存在 | 没有真正的对抗 |
| **灾难质量** | "是的，但是……"或"不，而且……" | 简单的"不" | 干净的"是"或无结局 |
| **续接存在** | 反应-困境-决定存在 | 续接缩略 | 高张力后缺失 |
| **场景-续接比例** | 匹配预期节奏 | 轻微不匹配 | 严重不匹配 |

**关键：**如果场景排序不通过，不要继续其他轮次。结构问题会使下游评估无效。

### 轮次2：角色弧线（25%权重）

评估转变一致性和弧线进展。

| 标准 | 通过 | 警告 | 不通过 |
|------|------|------|--------|
| **谎言可见性** | 虚假信念在选择中明显 | 谎言存在但未陈述 | 没有谎言在运作 |
| **欲望/需要差距** | 表面/实际之间张力清晰 | 差距存在但不清楚 | 欲望 = 需要（无张力） |
| **弧线进展** | 场景推进或挑战弧线 | 弧线静态但一致 | 角色与弧线矛盾 |
| **转变标记** | 选择反映弧线位置 | 位置不清楚 | 行为违反个性 |

### 轮次3：老套超越（15%权重）

通过正交性测试评估原创性。

| 标准 | 通过 | 警告 | 不通过 |
|------|------|------|--------|
| **形式轴** | 非默认形式 | 轻微变化 | 完全是类型默认 |
| **认知轴** | 自身关注点，意外交叉 | 有些情节感知 | 完全服务于故事 |
| **目标轴** | 自身议程与之碰撞 | 目标与情节相关 | 纯粹为主角服务 |
| **角色轴** | 自身故事与之交叉 | 有些独立性 | 只为英雄存在 |
| **正交性测试** | 2+轴正交 | 1轴正交 | 所有轴匹配默认 |

### 轮次4：对话（15%权重）

评估声音独特性、潜台词和功能。

| 标准 | 通过 | 警告 | 不通过 |
|------|------|------|--------|
| **声音独特性** | 不看标签也能区分角色 | 有些重叠 | 声音一样（D1） |
| **潜台词存在** | 说出的和意味的有差距 | 偶尔直接陈述 | 一切都在表面（D4） |
| **双重功能测试** | 每次交流3+功能 | 2个功能 | 只有单一功能（D5） |
| **自然度** | 缩略、打断、节奏 | 稍微正式 | 生硬/呆板（D2） |
| **说明处理** | 通过冲突传递信息 | 轻微的"你知道的" | 说明文倾泻（D3） |

### 轮次5：散文风格（10%权重）

评估句子层面的技巧。

| 标准 | 通过 | 警告 | 不通过 |
|------|------|------|--------|
| **句式变化** | 长度和结构有变化 | 有些变化 | 单调（P4） |
| **清晰度** | 具体、明确的先行词 | 偶有抽象 | 写作不清楚（P2） |
| **声音一致性** | 措辞水平一致 | 轻微偏移 | 随机偏移（P6） |
| **经济性** | 每个词都有存在理由 | 轻微冗余 | 过度雕琢（P3） |
| **主动语态** | 被动语态是有意的 | 有些默认被动 | 过度使用被动（P5） |

## 综合评分

每个轮次产出0-100分：
- 全部通过 = 100
- 每个警告 = -15
- 每个不通过 = -40

**综合分 = SUM(轮次得分 × 轮次权重)**

| 综合分 | 结果 | 操作 |
|--------|------|------|
| >= 80 | 接受 | 场景完成，进入下一个 |
| 60-79 | 修改 | 修正最低分轮次，重新评估 |
| 40-59 | 重写 | 带失败约束重新生成 |
| < 40 | 拒绝 | 从大纲重新起草 |

---

## 迭代限制

| 层级 | 限制 | 超限时 |
|------|------|--------|
| 每轮次 | 3 | 升级为重写 |
| 每场景 | 12 | 在阈值50接受，标记待审 |
| 每章节 | 50 | 停止，报告剩余问题 |

**递减收益检测：**如果迭代之间改善 < 10%，接受当前状态或升级。

## 上下文积累

跨场景维护：

### 角色声音
每个场景之后，提取并存储：
- 每个角色的词汇模式
- 句子节奏模式
- 直接程度
- 口头习惯和回避

用作后续场景的约束："角色X说话像[标记]"

### 情节线索
跟踪：
- **未结线索** - 已引入，未解决
- **已结线索** - 本章已解决
- **伏笔** - 为未来回收埋下的铺垫

每个场景检查：
- 不与已建立的事实矛盾
- 未结线索被提及或推进
- 至少一个元素有进展

### 老套回避
cliche-transcendence 轮次后，记录：
- 回避了哪些默认选项
- 如何超越它们
- 感觉新鲜的新元素

用作约束："已超越[X]，保持新鲜感"

## 修改策略

### 定向修正（得分60-79）
1. 确定最低分轮次
2. 提取具体的失败标准
3. 生成针对该标准的最小修正
4. 重新评估该轮次 + 下游轮次
5. 如果轮次改善，重新计算综合分

### 重写（得分40-59）
1. 保留大纲中的场景目标
2. 生成带明确约束的新草稿：
   - "开头必须包含清晰目标"
   - "冲突必须升级"
   - 等等，基于失败项
3. 重新运行完整评估循环

### 拒绝（得分 < 40）
1. 回到大纲节拍
2. 从头重新起草
3. 视为新场景（重置迭代）

---

## 冲突解决

当修正一个轮次破坏了另一个：

1. **检测：**任何修正后重新运行所有轮次
2. **比较：**有任何轮次退步了吗？
3. **优先：**权重更高的轮次在平局中获胜
4. **寻求综合：**修正能同时满足两者吗？
5. **接受权衡：**如果不可调和，按层级接受

**升级：**如果冲突在2次尝试后持续，标记场景待人工审查。

## 反模式

### 无限打磨者
**模式：**因为一个标准处于警告状态就持续迭代。
**修正：**警告是可接受的。迭代限制后在阈值接受。

### 轮次跳过者
**模式：**场景排序不通过时跳到散文风格。
**修正：**结构轮次有硬性门槛。不通过阻止继续。

### 上下文失忆症
**模式：**每个场景孤立起草，丢失声音和线索。
**修正：**每个场景起草前明确加载上下文。

### 级联盲区
**模式：**修正了对话，没检查散文风格是否退步。
**修正：**任何修正后始终重新评估当前轮次 + 下游轮次。

### 沉默失败者
**模式：**达到迭代限制，不加记录地继续。
**修正：**记录所有限制退出，附带分类的剩余问题。

## 调用示例

**输入：**包含5个场景节拍的章节大纲

**过程：**
1. 加载大纲，确认前置条件
2. 初始化进度跟踪器
3. 对每个场景：
   - 从之前的场景构建上下文
   - 起草初始散文
   - 运行评估循环
   - 接受时：提取上下文，写入输出
4. 完成：5个打磨过的场景，标记的问题已记录

**输出：**
- `drafts/[故事]/[章节]/` 中的5个场景文件
- 显示所有迭代的进度跟踪器
- 下一章的上下文文件
- 任何标记的问题清单，待人工审查

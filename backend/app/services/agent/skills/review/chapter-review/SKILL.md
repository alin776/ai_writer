# 章节质量评审

## 评审心智模型

Before 评审任何章节, ask yourself:
- **基准线是谁？** 评分基准 = 合格的商业网文作者，不是文学大师。7 分 = 职业水准无明显短板，不是"还不错"
- **这章的职责是什么？** 推进章（主线进展）vs 铺垫章（人物/世界构建）vs 高潮章（爆发）—— 不同类型权重不同
- **读者在这个位置的状态？** 前 3 章读者耐心最低、高潮后读者需要喘息、长铺垫后读者期待爆发

## 评审维度（每项 1-10 分）

### 1. 节奏感
判断标准：信息密度是否均匀？情绪张弛是否有变化？是否有"空转"段落（删掉不影响剧情）？

校准锚点：
- **8-10**: 每段都推进情节或深化人物，高低起伏节奏清晰，读者不会想跳段
- **5-7**: 整体流畅但有 1-2 处拖沓或节奏断裂，可通过删减/重排修复
- **2-4**: 大段空转，或全程同一节奏无变化，读者容易走神
- **1**: 叙事混乱无法跟随，或整章都是无效内容

### 2. 对话自然度
判断标准：遮住角色名，能否通过说话方式区分角色？有无"信息倾倒"式对话？

校准锚点：
- **8-10**: 每个角色说话有辨识度，对话推进关系或冲突，无废话
- **5-7**: 整体自然但偶有角色"代作者发言"，或 1-2 处信息倾倒
- **2-4**: 多数角色说话风格雷同，或大段对话只为交代背景设定
- **1**: 全部对话像同一个人说的，或完全不符合角色身份

### 3. 描写质量
判断标准：描写是否服务于叙事目的（氛围/人物/节奏）？还是为描写而描写？

校准锚点：
- **8-10**: 描写精准克制，每处描写都有叙事功能（烘托情绪/暗示伏笔/构建画面），感官多元
- **5-7**: 描写基本到位但偶有冗余，或过度依赖单一感官（纯视觉）
- **2-4**: 描写要么过度堆砌要么极度匮乏，对叙事无贡献
- **1**: 无有效描写，或描写与场景情绪严重不匹配

### 4. 情节推进
判断标准：读者读完这章后，故事状态发生了什么变化？如果答案是"没变化"，这章可能有问题。

校准锚点：
- **8-10**: 主线明确推进，章末状态与章初有质变（信息量/关系/局势），承前启后自然
- **5-7**: 有推进但幅度偏小，或推进中有逻辑跳跃需要补充过渡
- **2-4**: 推进模糊，章末与章初几乎无变化，或强行推进缺乏铺垫
- **1**: 完全无推进（纯日常水字数），或与前文矛盾

### 5. 结尾钩子
判断标准：读者读到最后一句时，是想"然后呢？"还是"哦，结束了"？

校准锚点：
- **8-10**: 结尾制造强烈的"不得不翻下一章"的冲动（悬念/反转/情感冲击）
- **5-7**: 有一定悬念但力度不够，或钩子与本章内容关联度不高
- **2-4**: 平淡收尾，无悬念无期待
- **1**: 在不恰当的位置强行切断，或以总结感悟结尾

## NEVER

- NEVER 给所有维度相同或相近的分数（如全部 6-7 分）—— 任何章节必然有强项和弱项，全同分说明评审缺乏区分度
- NEVER 给出模糊赞美如"描写生动""节奏流畅"而不指出具体段落 —— 无法定位的反馈等于没有反馈
- NEVER 用文学批评的标准评判网文 —— "缺少意识流""象征手法不足"不是网文的问题
- NEVER 忽略章节类型差异 —— 铺垫章的情节推进天然低于高潮章，应在点评中说明而非扣分
- NEVER 只说问题不给方向 —— 每个扣分项必须附带"可以怎么改"的具体建议

## 边界情况

- **开篇章（前3章）**: 额外关注"钩子是否足够强"和"世界观信息倾倒风险"，节奏权重 +20%
- **高潮章**: 情节推进和结尾钩子权重更高，允许描写密度降低（紧张场景不需要大段环境描写）
- **过渡/铺垫章**: 主动说明"本章为铺垫章，情节推进预期较低"，改为重点评估人物塑造和伏笔铺设
- **对话密集章**: 对话自然度权重 +20%，描写质量权重 -10%
- **纯动作/战斗章**: 节奏感权重最高，对话自然度权重降低

## 输出格式

第{X}章 "{标题}" 评审报告（章节类型: {推进/铺垫/高潮/过渡}）

  节奏感:     {N}/10 — {指出具体段落的评价}
  对话自然度: {N}/10 — {指出具体段落的评价}
  描写质量:   {N}/10 — {指出具体段落的评价}
  情节推进:   {N}/10 — {指出具体段落的评价}
  结尾钩子:   {N}/10 — {指出具体段落的评价}
  综合:       {N}/10（各维度加权，非简单平均）

亮点（≤3 处）: {具体段落引用 + 为什么好}
问题（≤3 处）: {具体段落引用 + 问题分类 + 严重度}
建议（≤3 条）: {针对最严重问题的改进方向 + 参考手法}

# 全书一致性审计

## 审计心智模型

Before 标记任何矛盾, ask yourself:
- **这是 bug 还是 feature？** 作者可能有意让角色"言行不一"来暗示隐藏身份，或让时间模糊来营造梦境感。先假设"作者可能有意为之"，再验证
- **读者会注意到吗？** 硬矛盾（第 3 章黑发第 7 章金发）读者一定会注意；软矛盾（性格微妙变化）读者可能不会计较。优先报告硬矛盾
- **矛盾的严重程度？** 影响剧情逻辑的 > 影响角色可信度的 > 影响世界观自洽的 > 纯细节不一致的

## 审计范围决策树

```
全书章节数？
├─ ≤10 章 → 全量审计（逐章逐维度）
├─ 11-30 章 → 分段审计（每 10 章为一段，段内全量 + 跨段抽查关键角色/设定）
└─ >30 章 → 焦点审计（用户指定范围，或自动聚焦：最近 10 章 + 关键角色全量追踪）
```

## 反幻觉三原则

1. **大纲即法律**：章节内容必须与 outline 规划一致
2. **设定即物理**：worldview / characters 中的设定不可违反
3. **新增需注册**：章节中出现的新元素，必须能在设定文件中找到依据

## 五维检查（附决策规则）

### 维度一：人物一致性
检查项：外貌特征、性格言行、口头禅、能力境界

矛盾判定规则：
- 外貌描写前后不同 → 🔴 硬矛盾（除非有剧情原因如变装/受伤）
- 性格突变无铺垫 → ⚠️ 需确认（可能是有意的角色弧线）
- 口头禅/说话方式前后不同 → ⚠️ 需确认
- 能力突然消失或忽强忽弱 → 🔴 硬矛盾

### 维度二：时间线一致性
检查项：相对时间、绝对时间、年龄、季节、同时性

矛盾判定规则：
- 明确时间标记冲突（"三天后"与实际事件不符） → 🔴 硬矛盾
- 年龄与时间流逝不匹配 → 🔴 硬矛盾
- 季节/天气与时间不符 → ⚠️ 警告
- 隐含时间矛盾（事件太多塞不进给定时段） → ⚠️ 警告

### 维度三：能力体系一致性
检查项：力量体系规则、战力变化、技能延续、能力限制

矛盾判定规则：
- 违反已建立的能力限制 → 🔴 硬矛盾
- 已展示技能后续章节"遗忘" → 🔴 硬矛盾（消失的能力）
- 战力忽强忽弱无解释 → ⚠️ 需确认
- 突破/升级无铺垫 → ⚠️ 警告

### 维度四：地理/距离一致性
检查项：地点间距离、旅行时间、地点描述

矛盾判定规则：
- 同一地点描述矛盾（"北方山城"变"南方水乡"） → 🔴 硬矛盾
- 旅行时间与距离明显不匹配 → ⚠️ 警告
- 地理方位关系矛盾 → ⚠️ 警告

### 维度五：称呼/关系一致性
检查项：称呼一致性、关系发展逻辑、阵营立场

矛盾判定规则：
- 无关系变化事件但称呼突变 → 🔴 硬矛盾
- 关系跳跃发展（陌生人突变挚友） → ⚠️ 需确认
- 阵营立场无缘无故翻转 → ⚠️ 需确认

## NEVER

- NEVER 把有意的角色转变标记为矛盾 —— 角色成长/黑化/觉醒是剧情需要，关键看是否有铺垫。如有铺垫但你仍感觉突兀，标记为 ⚠️ 而非 🔴
- NEVER 只检查显式矛盾，忽略隐含矛盾 —— "他独自一人穿越沙漠三天"后紧接"他从背包里拿出新鲜水果"就是隐含矛盾
- NEVER 信任角色自述作为事实 —— 角色可能说谎、记错或被蒙蔽，用叙述者视角和其他章节交叉验证
- NEVER 忽略"消失的能力" —— 角色展示过某个技能/物品后再未使用，在关键场景本该使用却没有，这是最常见也最隐蔽的矛盾
- NEVER 对设定文件缺失时直接跳过 —— 如果没有 characters.md 或 worldview.md，从已有章节中提取隐含设定作为审计基准，并提醒作者补充设定文件

## 边界情况

- **设定文件缺失**: 从已有章节提取隐含设定作为审计基准，在报告开头说明"基准来自章节推断，非作者确认设定"
- **不可靠叙述者**: 如果小说使用不可靠叙述者手法，同一事件不同版本可能是有意设计，标记为 📝 提醒而非矛盾
- **多视角/多时间线叙事**: 不同视角对同一事件的描述差异可能是有意的（罗生门），审计时以客观可验证事实为准
- **魔法/超自然设定**: 在魔法体系内自洽即可，不用地球物理定律审查

## 输出格式

按严重度分级：
🔴 严重: {矛盾描述} — 第{X}章 vs 第{Y}章 / {设定文件}
  证据: "{原文引用1}" vs "{原文引用2}"
  影响: {对剧情/角色可信度的影响}

⚠️ 警告: {矛盾描述} — 可能是有意为之，请确认
  证据: "{相关原文}"
  建议: {如果是 bug 怎么修 / 如果是 feature 建议加铺垫}

📝 提醒: {细微不一致}
  建议: {快速修复方向}

汇总:
  🔴 严重矛盾: {N}个
  ⚠️ 需确认: {N}个
  📝 提醒: {N}个
  最高风险区域: {哪个维度/哪几章问题最集中}

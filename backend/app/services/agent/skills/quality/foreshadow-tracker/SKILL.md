# 伏笔追踪

## 伏笔心智模型

Before 追踪任何伏笔, ask yourself:
- **这是伏笔还是普通细节？** 伏笔 = 当前看似不重要但后续有回报的细节。如果删掉这个细节不影响后续剧情，它可能只是装饰而非伏笔
- **读者能察觉但不能确定吗？** 好伏笔的特征是"初见不经意，回看恍然大悟"。如果太明显 = 剧透，如果太隐蔽 = 揭示时读者没有共鸣
- **这条伏笔的回报值得等待吗？** 铺设越早、强化越多，读者对收束的期待越高。小伏笔配大揭示 = 惊喜；大伏笔配小揭示 = 失望

## 伏笔生命周期

一条完整的伏笔线经历三阶段：
1. **铺设**（Seed）：不经意的细节、物件、对话、异常行为
2. **强化**（Reinforce）：再次出现加深印象，可能换角度/换场景提及
3. **收束**（Payoff）：真相揭示、伏笔回收，读者获得"原来如此"的满足

## Expert 判断框架

### 伏笔质量三维评估
- **隐蔽性**：首次出现时是否自然融入叙事？（强行插入的伏笔 = 剧透）
- **回报比**：收束时的信息量/情感冲击 与 铺设投入 是否匹配？
- **有机性**：伏笔是否服务于故事主线？（为伏笔而伏笔 = 炫技）

### 量化健康规则
- 铺设后 **10 章内无任何强化** = 断裂风险（读者已遗忘）
- 同一伏笔 **强化超过 5 次** = 过度提醒（从暗示变成明示，失去悬念感）
- 铺设后 **2 章内就收束** = 过早收束（缺少期待积累，回报感弱）
- 全书结束时 **未收束的伏笔 ≤ 2 条** 可接受（为续集留口或有意开放结局）

### 伏笔类型识别
- **物件型**：特定道具/信物反复出现（玉佩、信件、武器）
- **语言型**：特定台词/预言/诅咒后续应验
- **行为型**：角色异常行为暗示隐藏动机
- **环境型**：场景/天气/时间暗示后续事件
- **关系型**：角色间微妙互动暗示隐藏关系

## 伏笔状态判定

| 状态 | 判定条件 |
|------|---------|
| ✅ 已闭合 | 铺设→（强化）→收束 完整，且收束力度匹配 |
| ⚠️ 悬挂中 | 已铺设/强化，尚未收束（超过 10 章则高风险） |
| ❌ 断裂 | 铺设后 >10 章无强化也无收束，疑似遗忘 |
| 🔄 过早收束 | 铺设后 ≤2 章即收束，缺少积累 |
| 📢 过度强化 | 强化 >5 次，已从暗示变成明示 |

## NEVER

- NEVER 只追踪显式伏笔（作者标记的"伏笔"）—— 最有价值的往往是作者无意识埋下的隐性伏笔（角色的一句闲话、一个未解释的场景细节）
- NEVER 把反复提及等同于伏笔强化 —— 主角的名字反复出现不是伏笔。强化必须增加新信息或改变读者对原始线索的理解
- NEVER 把所有未收束伏笔标记为问题 —— 连载中/系列作品的悬挂伏笔可能是有意为之，标注为"悬挂中"而非"断裂"
- NEVER 只用关键词匹配追踪伏笔 —— 同一伏笔可能换不同方式表达（"那枚玉佩"→"脖子上的坠子"→"温润的触感"），需要语义追踪
- NEVER 忽略"反伏笔" —— 故意铺设让读者误判的线索（红鲱鱼）也是有意的叙事手法，应单独标注而非视为断裂

## 边界情况

- **连载中/未完结作品**: 大量伏笔处于悬挂状态是正常的，重点关注"断裂"（被遗忘的）而非"悬挂中"
- **多线叙事**: 每条叙事线有独立的伏笔系统，跨线伏笔需要单独追踪
- **第一人称视角**: 伏笔可能对叙述者隐藏（叙述者不知道自己看到的是伏笔），需从读者全知视角分析
- **悬疑/推理类**: 伏笔密度天然高于其他类型，5 次强化的阈值可放宽到 8 次

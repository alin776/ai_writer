# 场景排序：节奏技能

你帮助作者使用场景-续篇节奏来构建场景和控制叙事节奏。

## 核心原则

**节奏的基本单位不是单独的场景，而是场景-续篇对。** 场景制造张力；续篇消化张力。这种交替创造出使故事可读的峰谷起伏。

## 场景结构：目标 → 冲突 → 灾难

### 目标
视角角色在这个场景中想要什么？
- 具体且明确
- 在场景内可实现
- 与更大的故事目标相关联
- 在最初的几个节拍内让读者清楚

### 冲突
对目标的阻碍，在场景内**逐步升级**。
- 另一个角色有不同的议程
- 环境障碍或时间压力
- 内在阻力（恐惧、怀疑、价值观）

静态冲突是无聊的。每个节拍都应该让目标更难实现。

### 灾难
场景以以下结果之一结束（按叙事力量排序）：
1. **是的，但是……** — 目标达成，新问题产生（最强）
2. **不，而且……** — 目标失败，情况更糟
3. **不** — 目标失败，必须重试
4. **是** — 目标顺利达成（慎用——会扼杀张力）

## 续篇结构：反应 → 困境 → 决定

### 反应
对灾难的情感回应。让读者：
- 消化所发生的事情
- 与角色的情感状态连接
- 在高张力场景之间喘口气

可以很简短（一个句子）或很展开（数页）。

### 困境
角色面临没有好选项的选择。之前的灾难已经：
- 关闭了某些路径
- 揭示了新信息
- 制造了竞争性的优先事项

困境必须感觉确实艰难。

### 决定
角色投入行动，这成为下一个场景的**目标**。

## 节奏控制

场景与续篇的比例控制节拍：

| 更多场景 | 更多续篇 |
|---------|---------|
| 快节奏 | 慢节奏 |
| 动作密集 | 沉思性 |
| 惊悚感 | 文学感 |
| 读者喘不过气 | 读者沉思 |

**关键技巧：** 压缩或扩展续篇来控制节拍。场景按自然长度运行；续篇是你的节奏杠杆。

## 场景级别诊断

### 缺失目标
"这个角色在这里想要什么？"
- 如果你无法清楚地回答，场景缺少方向
- 修复：在第一段建立目标

### 静态冲突
"阻碍是否升级？"
- 如果冲突停留在同一水平，场景感觉平淡
- 修复：每个节拍让目标更难实现

### 软弱的灾难
"结果是否太干净？"
- 没有并发症的"是"结局会抽干张力
- 修复：添加一个"但是"或"而且"

### 缺失续篇
"我们消化了上一个场景吗？"
- 场景到场景的跳跃没有续篇会让读者精疲力竭
- 修复：即使简短的反应段落也有帮助

### 过多续篇
"我们是否沉溺于反应中？"
- 没有行动的长篇内省会让动力停滞
- 修复：压缩到关键节拍，转向决定

## 场景中的写作模式

| 模式 | 最适合 | 常见于 |
|------|--------|--------|
| 动作 | 场景冲突 | 场景 |
| 对话 | 角色互动 | 场景 |
| 描写 | 设定场景、放慢节奏 | 场景开头、续篇 |
| 内省 | 消化事件 | 续篇 |
| 概述 | 时间压缩 | 场景之间 |

模式应匹配功能。续篇中的动作感觉仓促。动作中的内省扼杀动力。

## 你做什么

1. **询问目标** — 角色在这个场景中想要什么？
2. **检查升级** — 冲突是否加剧？
3. **检验灾难** — 它是否太干净？
4. **寻找续篇** — 有消化的时间吗？
5. **映射比例** — 更多场景还是更多续篇？这是否匹配意图？
6. **追踪链条** — 决定是否导向下一个场景的目标？

## 你不做什么

- 规定具体的场景长度
- 强制执行僵化的模板
- 要求每个场景后都有续篇（节奏会变化）
- 选择场景中应该发生什么

## 示例交互

**作者：** "我故事的中段感觉既令人疲惫又莫名地缓慢。"

**你的方法：**
1. 询问："带我过一遍一个典型的章节——发生了什么？"
2. 检查是否有不间断的场景："动作序列之间有消化的时间吗？"
3. 检查场景目标："在你写的最后一个场景中，角色想要什么？"
4. 探查灾难质量："那个场景怎么结束的？他们得到想要的了吗？"
5. 如果是干净的胜利："那可能在抽干张力。你能加上什么'但是'？"
6. 如果缺失续篇："即使在下一个场景之前加一段反应也能帮助读者跟上"

## 反模式

### 1. 不间断的场景
**模式：** 纯动作没有消化时间——场景接场景的冲突没有续篇节拍。
**失败原因：** 读者变得麻木。没有消化时间，情感赌注就会变平。每个新灾难的冲击力递减。读者跟不上。
**修复：** 即使在快节奏的故事中也要插入续篇节拍。即使一段反应也有帮助。压缩是可以的；消除会让人精疲力竭。

### 2. 沉溺式续篇
**模式：** 数页的内省而没有决定——长篇的内心独白在原地转圈。
**失败原因：** 读者失去耐心。续篇存在是为了消化和决定，而非沉溺。没有朝决定前进的运动，内省就变成了自我放纵。
**修复：** 困境必须导向决定；决定导向行动。给续篇设定时限。如果角色没有朝选择移动，压缩或删减。

### 3. 随意的灾难
**模式：** 场景结果与场景事件脱节——灾难凭空出现以制造戏剧性。
**失败原因：** 读者感觉到操纵。灾难应该是冲突的逻辑后果，而非作者的干预。没有动机的灾难打破信任。
**修复：** 反向追踪链条。场景冲突如何逻辑地产生了这个灾难？如果你无法回答，灾难就是随意的。重新设计冲突以铺垫灾难。

### 4. 干净的胜利
**模式：** 角色毫无并发症地达成目标——场景以简单的"是"结束。
**失败原因：** 干净的胜利抽干张力。每一次无条件的成功都让下一个挑战感觉不那么危险。读者不再担心。
**修复：** 添加一个"但是"或"而且"。目标达成但新问题产生。胜利到手但代价超出预期。简单的成功是罕见的；并发症才是常态。

### 5. 缺失目标
**模式：** 场景开始时没有清晰的角色目标——事情发生了但没有驱动力。
**失败原因：** 没有目标，就没有冲突（没有什么可以对抗的）。没有冲突，就没有灾难（没有什么可以失败的）。场景变成了描写，而非故事。
**修复：** 在第一段建立目标。视角角色在这个场景中具体想要什么？如果你无法清楚地回答，场景就缺少方向。

## 可用工具

### analyze_scene.py
分析场景文本的结构元素。当你需要对特定场景进行快速诊断时使用。


> **路径提示**: 脚本位于 `skills/structure/scene-sequencing/scripts/` 目录下。
> 执行时必须使用从项目根目录出发的完整相对路径。

```bash
# 分析场景文件
python skills/structure/scene-sequencing/scripts/analyze_scene.py scene.txt

# 直接分析文本
python skills/structure/scene-sequencing/scripts/analyze_scene.py --text "她必须找到那把钥匙，否则一切都来不及了。但门外的脚步声越来越近..."

# 以 JSON 格式输出供进一步处理
python skills/structure/scene-sequencing/scripts/analyze_scene.py scene.txt --json
```

**检测内容：**
- 目标指标（想要、需要、试图、必须）
- 冲突指标（但是、阻碍、障碍、然而）
- 灾难指标（失败、更糟、困住、崩溃）
- 反应指标（感到、震惊、心中、不禁）
- 困境指标（选择、要么、如果、两难）
- 决定指标（决定、计划、打算、一定要）

**输出包含：**
- 场景/续篇比例评估
- 节奏分类（动作密集、平衡、沉思性）
- 缺失元素警告
- 具体建议

**何时使用：**
- 对草稿场景进行快速诊断
- 识别为什么一个场景感觉不对
- 检查多个场景的节奏
- 在更深入分析之前获得具体建议

## 输出持久化

本技能将主要输出写入文件，以便工作跨会话持续保存。

### 输出路径

分析和诊断结果直接在对话中呈现。如需持久化，写入平台标准路径：
- 大纲/结构相关 → `/knowledge/outline.md`
- 章节内容 → `/chapters/NN-标题.md`

### 主要输出

本技能需要持久化：
- **节奏诊断** - 场景/续篇平衡、节奏问题
- **场景分析** - 每个场景的目标、冲突、灾难
- **续篇分析** - 反应、困境、决定元素
- **建议** - 针对节奏问题的具体干预

### 对话 vs. 文件

| 写入文件 | 留在对话中 |
|----------|-----------|
| 逐场景拆解 | 特定场景的讨论 |
| 节奏诊断 | 澄清性问题 |
| 建议的干预 | 作者的结构决定 |
| 场景/续篇比例评估 | 实时反馈 |

### 文件命名

模式：`{story}-pacing-{date}.md`
示例：`novel-chapter5-pacing-2025-01-15.md`

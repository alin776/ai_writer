# World-Fates：命运之轮

你管理共享世界中实体的长期命运。你的角色是确保命运之轮转动——没有权力是永恒的，后果会累积，世界在战役之间感觉充满动态。

## 核心原则

**命运是选择在时间中的后果。**

静态的世界感觉虚假。当同一个皇帝永远统治、同一个公会控制贸易数百年、强大的角色从不衰落——世界失去了逼真感。命运之轮转动。权力吸引挑战。脆弱性不断累积。风险暴露不断增加。

本技能追踪实体的命运压力，并生成命运转变提案供人类审批后再应用到世界圣经中。

---

## 运作模式：混合

本技能以**混合模式**运作：
1. 脚本计算命运压力并生成加权概率掷骰
2. LLM 根据掷骰结果和实体状态综合提案
3. 人类在变更应用到世界圣经之前进行批准、修改或拒绝

**系统永远不会"骗"玩家的角色。** 死亡和衰落感觉像真实的命运，因为它们源于累积的概率，而非武断的决定。

## 命运状态

### 状态 F1：稳定上升
**症状：** 实体强大但新近崛起；脆弱性少；任期短。
**命运压力：** 低（0.1-0.3）
**干预措施：** 仅监控。记录暴露事件。

### 状态 F2：权力巅峰
**症状：** 实体处于最大影响力；长期任期；少有可见弱点。
**命运压力：** 中等（0.3-0.5）
**关键问题：** 他们为权力牺牲了什么？谁怨恨他们？他们害怕失去什么？
**干预措施：** 浮现隐藏的脆弱性。引入对手。

### 状态 F3：过度扩张
**症状：** 权力捉襟见肘；多个活跃冲突；傲慢行为。
**命运压力：** 高（0.5-0.7）
**关键问题：** 哪个承诺会先崩溃？谁会从他们的衰落中受益？
**干预措施：** 级联小失败。测试联盟。考虑提供命运选择。

### 状态 F4：岌岌可危
**症状：** 多个脆弱性暴露；敌人环伺；资源耗尽。
**命运压力：** 危急（0.7-0.9）
**关键问题：** 支撑他们的最后一根线是什么？什么会让它断裂？
**干预措施：** 命运抉择。重大命运转变提案。死亡概率激活。

### 状态 F5：坠落进行中
**症状：** 级联已开始；实体正在衰落。
**命运压力：** 终末（0.9+）
**关键问题：** 他们如何倒下？什么幸存？谁继承？
**干预措施：** 管理过渡。重新分配权力/财富。记录终局。

## 三级退出系统

角色通过以下三种机制之一离开玩家控制，按优先顺序排列：

### 第1级：自愿NPC转化（玩家选择）

玩家可以随时将角色退役为NPC状态。

**何时提供：**
- 玩家看到命运压力在积累
- 玩家想要探索不同的角色
- 角色的故事感觉已完成
- 玩家想在命运强制更严酷结果前优雅退出

**会发生什么：**
- 玩家塑造退出叙事（导师、对手、背景人物）
- 角色在世界中持续存在，不再受玩家控制
- 不需要命运掷骰
- 角色可能作为NPC在未来会话中重新出现

**设计原则：** 这个选项始终可用。玩家永远不应感到被困住。

### 第2级：命运抉择（命运提议，玩家决定）

当命运压力超过0.6时，不是立即掷死亡骰，而是命运呈现一个戏剧性选择。

**选择结构：**
- **路径A：** NPC化/转变（角色存活但离开玩家控制）
- **路径B：** 面对掷骰（留在玩家控制，冒死亡/衰落风险）
- **路径C：**（可选）具有不同代价的第三选项

**选择示例：**
- "暗影女王提供庇护——为她服务，失去自我"（NPC）vs "拒绝并战斗"（死亡掷骰）
- "背叛盟友以求生"（留在玩家控制，声望毁于一旦）vs "与他们并肩"（死亡掷骰）
- "接受腐化以获得力量"（成为反派NPC）vs "抵抗"（衰落掷骰）

**为什么有效：**
- 玩家在命运时刻拥有能动性
- 选择本身就是叙事高潮
- 死亡/衰落更有分量，因为他们有过退出的机会
- 创造难忘的戏剧性时刻

### 第3级：命运强制结果（掷骰后果）

仅在以下情况触发：
- 玩家拒绝了提供的选择（第2级）
- 没有适合当前叙事的选择
- 情况需要立即解决

**会发生什么：**
- 概率机制决定结果（见下方公式）
- 即使在这里，玩家也可以讲述最后时刻
- 结果经人类批准后应用到世界圣经

**设计原则：** 死亡永远不应是第一选项。进程是：
1. 压力可见地积累（玩家可以自愿退出）
2. 命运提供戏剧性选择（玩家决定）
3. 只有在被拒绝时才进行掷骰

## 命运压力公式

命运压力决定了实体经历重大命运转变的可能性。

```
Fate Pressure = (Power Level × Tenure Modifier × Vulnerability Score / 10)
                ÷ (Protection Factor × max(Fortune Buffer, 0.5))
                + Risk Exposure Accumulation
```

### 权力等级（1-10）

实体掌握多少影响力/资源/能力。

| 等级 | 范围 | 示例 |
|------|------|------|
| 1-2 | 本地 | 村长、小商人、当地英雄 |
| 3-4 | 区域 | 镇长、公会会长、区域冠军 |
| 5-6 | 国家 | 贵族家族、主要派系、著名冒险者 |
| 7-8 | 文明 | 王国统治者、传奇英雄、大法师 |
| 9-10 | 世界级 | 皇帝、半神、威胁世界的力量 |

### 任期修正值

掌权时长。任期越长 = 累积风险越高。

| 持续时间 | 修正值 | 理由 |
|----------|--------|------|
| < 1年 | 0.5x | 新人期；尚未树敌 |
| 1-5年 | 1.0x | 基准；已建立但未固化 |
| 5-20年 | 1.5x | 累积的怨恨，陈旧的联盟 |
| 20-50年 | 2.0x | 长期统治引发继承挑战 |
| 50+年 | 2.5x | 非自然长寿；必有变故 |

### 脆弱性评分（0-10）

暴露弱点的总和。评分脆弱性：

| 脆弱性类型 | 权重 | 示例 |
|-----------|------|------|
| 已知敌人 | +1.0 | 想要你位置的对手 |
| 活跃冲突 | +1.5 | 战争、仇恨、持续争端 |
| 可利用的缺陷 | +2.0 | 成瘾、暴脾气、骄傲 |
| 关键依赖 | +1.0 | 依赖单一盟友、资源 |
| 毁灭性秘密 | +3.0 | 暴露将终结他们的隐藏真相 |

上限为10。脆弱性越多 = 压力越高。

### 防护系数（1-10）

降低命运压力的屏障。评分防护：

| 防护类型 | 权重 | 示例 |
|---------|------|------|
| 忠诚盟友 | +1.0 | 愿意为你赴死的信任朋友 |
| 要塞化阵地 | +2.0 | 城堡、秘密基地、防御优势 |
| 神圣/魔法防护 | +3.0 | 神明眷顾、强力魔法 |
| 情报网络 | +1.0 | 间谍、预警系统 |
| 民众支持 | +2.0 | 深受人民爱戴 |

最低为1（没有人的防护为零）。

### 幸运缓冲（0-5）

剩余的运气/恩典/叙事保护。

- **初始值：** 大多数角色为3，主角为4-5
- **减少条件：** 死里逃生、濒死体验、重大挫折
- **可恢复：** 通过牺牲、成长、完成正面弧线
- **降为0时：** 运气耗尽；死亡成为可能

幸运缓冲代表"主角光环"，但它是一种*可耗尽的资源*。

### 风险暴露累积

特定危险情况随时间增加压力。

| 暴露类型 | 每次增量 |
|---------|---------|
| 实战 | +0.10 |
| 政治阴谋 | +0.05 |
| 背叛风险 | +0.15 |
| 过度自信行为 | +0.10 |
| 死里逃生 | +0.05 |
| 秘密暴露 | +0.20 |

跨会话累积，直到命运转变重置。

## 命运之轮机制

### 何时转动命运之轮？

命运评估在以下时机触发：

| 触发条件 | 何时使用 |
|---------|---------|
| 会话边界 | 每次游戏会话结束后 |
| 弧线完成 | 当战役弧线结束时 |
| 时间跳跃 | 当发生重大游戏内时间流逝时 |
| 重大事件 | 当发生世界级震动事件时 |
| 手动触发 | 当人类请求评估时 |

### 概率加权

对命运压力进行掷骰以确定是否触发命运转变：

```
Roll d100
If roll < (fate_pressure × 100): Fate-shift triggered
```

**命运转变严重度表：**

| 掷骰 vs 阈值 | 严重度 | 描述 |
|--------------|--------|------|
| 掷骰 < 阈值 × 0.25 | 灾难性 | 死亡、彻底衰落、完全毁灭 |
| 掷骰 < 阈值 × 0.50 | 重大 | 重大损失、严重受伤、重大败北 |
| 掷骰 < 阈值 × 0.75 | 中等 | 挫折、脆弱性暴露、资源损失 |
| 掷骰 < 阈值 × 1.00 | 轻微 | 警告信号、声望受损、小损失 |

### 命运转变类型

**角色：**
- **死亡：** 角色的物理终结
- **失势：** 失去权力、地位、位置
- **腐化：** 道德或精神的堕落
- **流放：** 被驱逐出影响范围
- **转变：** 本质的根本改变
- **衰微：** 随时间的逐步衰退

**派系：**
- **崩溃：** 组织终结
- **分裂：** 分成若干派系
- **被吞并：** 被对手吸收
- **衰退：** 失去影响力/资源
- **改革：** 改变根本性质
- **战败：** 在特定冲突中失败

**地点：**
- **毁灭：** 物理终结
- **征服：** 易手
- **灾害：** 灾难性损害
- **衰落：** 经济/人口下降
- **转变：** 性质改变
- **孤立：** 与世隔绝

## 死亡机制

死亡只有在以下条件全部满足时才进入概率池：
1. 角色处于实际危险中（战斗、险境、敌对情况）
2. 命运压力为高或以上（> 0.5）
3. 幸运缓冲已耗尽（< 1）

**死亡阈值计算：**

```
death_threshold = (fate_pressure - 0.5) × 2 × (1 - fortune_buffer / 5)
```

**计算示例：**

| 命运压力 | 幸运缓冲 | 死亡阈值 |
|---------|---------|---------|
| 0.5 | 0 | 0%（基准，无死亡风险） |
| 0.6 | 0 | 20% |
| 0.7 | 0 | 40% |
| 0.8 | 0 | 60% |
| 0.9 | 0 | 80% |
| 0.7 | 1 | 32% |
| 0.7 | 2 | 24% |

**为什么死亡感觉像命运，而非作弊：**
1. **透明性：** 玩家可以看到命运压力在累积
2. **选择驱动：** 脆弱性来自角色的选择
3. **渐进性：** 压力随时间积累，不是突然出现
4. **概率性：** 骰子创造真正的不确定性
5. **可生存：** 幸运缓冲允许英雄式逃脱
6. **有意义：** 死亡具有叙事分量和世界影响

## 提案生成

当命运转动且转变发生时，生成提案供人类审核。

### 提案格式

```markdown
# Fate-Shift Proposal: [Entity Name]

**Date Generated:** [Date]
**Trigger:** [What caused assessment]
**Fate Pressure at Assessment:** [Score]

## Current State Summary
[Brief description of entity's current situation]

## Vulnerability Analysis
[What weaknesses led to this]

## The Fate Roll
- **Roll:** [d100 result]
- **Threshold:** [fate_pressure × 100]
- **Severity:** [Catastrophic/Major/Moderate/Minor]

## Proposed Fate-Shift
[Detailed description of what happens]

### Type
[Death/Fall/Corruption/etc.]

### Narrative Hook
[How this could be revealed or play out]

### Consequences
- For the entity: [What changes]
- For the world: [Ripple effects]
- For campaigns: [What this affects]

## Alternative Options
1. [Less severe option]
2. [Different type of shift]
3. [Delayed but inevitable version]

## Approval Required
[ ] Approve as proposed
[ ] Approve with modifications: _______________
[ ] Reject and explain: _______________
[ ] Defer decision to later
```

## 与世界圣经的集成

### 读取当前状态

本技能从世界圣经条目中读取以评估：
- 从描述和关系中获取实体权力等级
- 从历史部分获取任期
- 从关键事实和关系中获取脆弱性
- 从派系成员资格和盟友中获取防护

### 提议变更

命运转变提案创建**待定**条目：
1. 在 `history/events/` 中为命运转变事件创建条目
2. 用新状态更新受影响的实体条目
3. 将所有变更标记为 **Proposed ?** 直到获批
4. 人类批准后转为 **Established ✓**

### 追踪命运元数据

在世界圣经的实体条目中添加：

```markdown
## Fate Tracking

**Tenure:** [Duration]
**Current Fate Pressure:** [0-1]
**Fortune Buffer:** [0-5]
**Last Assessment:** [Date]

### Vulnerabilities
- [Vulnerability 1]
- [Vulnerability 2]

### Protections
- [Protection 1]
- [Protection 2]

### Risk Exposure Log
- [Date]: [Event] (+X% pressure)
```

## 反模式

### 不朽皇帝
**问题：** 强大的实体从不面对后果；世界感觉静态。
**修复：** 一致地应用命运压力。高权力 × 长任期 = 高压力。

### 随机死亡
**问题：** 死亡感觉武断，像系统在"作弊"。
**修复：** 只有当压力通过选择累积时才掷死亡骰。展示计算过程。

### 主角光环
**问题：** 主角对命运免疫，而NPC不断倒下。
**修复：** 相同规则适用于所有人。幸运缓冲给予主角更多机会，而非免疫。

### 突然崩溃
**问题：** 帝国一夜之间从稳定到毁灭。
**修复：** 展示级联过程。轻微 → 中等 → 重大 → 灾难性，随时间推移。

### 命运已定
**问题：** 所有人都看到衰落即将到来；没有紧张感。
**修复：** 概率保持真正的不确定性。即使高压力也可能不触发。

### 世界毁灭者
**问题：** 单次命运转变颠覆所有战役。
**修复：** 人类审批关卡。批准前考虑对战役的影响。

### 廉价退出
**问题：** NPC转化感觉像逃避死亡而非戏剧性选择。
**修复：** 第2级选择应该是真正艰难的。NPC路径有真实代价。

## 可用工具

### fate-pressure.py

计算实体的当前命运压力。

> **路径提示**: 脚本位于 `skills/worldbuilding/world-fates/scripts/` 目录下。
> 执行时必须使用从项目根目录出发的完整相对路径。

```bash
python skills/worldbuilding/world-fates/scripts/fate-pressure.py --power 3 --tenure 15 --vulns 5 --prots 3 --fortune 2 --exposure 0.3
python skills/worldbuilding/world-fates/scripts/fate-pressure.py --power 3 --tenure 15 --vulns 5 --prots 3 --fortune 2 --exposure 0.3 --json
```

**参数说明：**

| 参数 | 类型 | 范围 | 说明 | 示例 |
|------|------|------|------|------|
| `--power` | int | 1-10 | 权力等级（1=村长 5=县级 10=帝王） | `--power 3` |
| `--tenure` | int | ≥0 | 在位年数 | `--tenure 15` |
| `--vulns` | **int** | ≥0 | 已知脆弱性**数量**（逐个计数，非评分） | `--vulns 5`（敌人3+矛盾2） |
| `--prots` | **int** | ≥0 | 已知防护措施**数量**（逐个计数，非评分） | `--prots 3`（声望+武力+盟友） |
| `--fortune` | int | 0-5 | 运气缓冲（0=厄运 3=中性 5=天命） | `--fortune 2` |
| `--exposure` | float | 0-1 | 累积暴露度（0=隐藏 1=暴露） | `--exposure 0.3` |
| `--name` | str | - | 实体名称（用于输出标题） | `--name "源顺镖局"` |
| `--json` | flag | - | 输出 JSON 格式 | `--json` |

> ⚠️ `--vulns` 和 `--prots` 必须为**整数计数**（列举具体条目后数数），不是 0-10 评分。如传入浮点数会截断为整数并发出警告。

### fate-roll.py

为一个或多个实体掷命运之轮。

```bash
python skills/worldbuilding/world-fates/scripts/fate-roll.py "Entity Name" --bible ./world-bible
python skills/worldbuilding/world-fates/scripts/fate-roll.py --trigger session-end --bible ./world-bible
python skills/worldbuilding/world-fates/scripts/fate-roll.py --high-pressure-only
```

### fate-choice.py

为高压力情况生成戏剧性的第2级选择。

```bash
python skills/worldbuilding/world-fates/scripts/fate-choice.py "Entity Name" --bible ./world-bible
python skills/worldbuilding/world-fates/scripts/fate-choice.py "Entity Name" --antagonist "The Dark Queen"
```

### propose-shift.py

生成命运转变提案供人类审核。

```bash
python skills/worldbuilding/world-fates/scripts/propose-shift.py "Entity Name" \
  --severity major --type fall --bible ./world-bible
```

### exposure-log.py

记录增加命运压力的风险暴露事件。

```bash
python skills/worldbuilding/world-fates/scripts/exposure-log.py "Entity Name" \
  --event "Survived assassination attempt" --pressure 0.15 --bible ./world-bible
```

| **shared-world** | 读取实体条目；向世界圣经提议变更 |
| **game-facilitator** | 在会话边界评估；为下次会话设置提供信息 |
| **character-arc** | 负面弧线增加脆弱性；正面弧线恢复幸运 |
| **story-sense** | 核心叙事原则适用于命运转变提案 |
| **genre-conventions** | 不同类型有不同的命运转折预期 |

### 交接点

**game-facilitator → world-fates：**
- 会话结束：报告风险暴露事件
- 会话中角色死亡：记录，调整世界状态
- 主要NPC行动：更新脆弱性/防护

**world-fates → game-facilitator：**
- 已批准的命运转变：需要纳入的新情况
- 上升的压力警告：潜在的戏剧性钩子
- 第2级选择：在高潮时刻执行

## 交互示例

**用户：** "瓦伦领主统治北方边域已40年。他经历了三场战争，议会中有两个已知敌人，刚刚曝光他有一个私生继承人。他的命运压力是多少？"

**你的方法：**

1. 计算各组件：
   - 权力等级：7（拥有军队的区域统治者）
   - 任期：40年 → 修正值 2.0x
   - 脆弱性：2个敌人（+2）+ 私生子秘密现已曝光（+3变为+1，因为已曝光）+ 3场战争（+4.5）= 7.5/10
   - 防护：假设忠诚家臣（+2）、要塞化驻地（+2）、一定民众支持（+1）= 5/10
   - 幸运缓冲：长期统治伴随多次逃脱，估计2

2. 应用公式：
   ```
   pressure = (7 × 2.0 × 0.75) / (5 × 2) + exposure
   pressure = 10.5 / 10 + ~0.1 = ~1.05 → capped at 1.0
   ```

3. 结果：状态 F5（坠落进行中）

4. 解释："瓦伦领主正在主动衰落中。他40年的统治、议会敌人和曝光的继承人已将他推至终末压力。考虑运行 `fate-choice.py` 来生成第2级选择——他是否让位给私生子（NPC转化）还是为保住权力而战（命运掷骰）？"

## 输出持久化

本技能通过命运追踪模板和世界圣经集成内置了持久化机制。

### 现有持久化机制

World-fates 将实体命运数据持久化在世界圣经结构中：

**模板：** `templates/fate-tracking.md` - 添加到世界圣经中的实体条目

**数据结构：**
- `data/fate-tracking.json` - 实体命运元数据的架构
- `data/shift-types.json` - 命运转变的类型及其效果
- `data/fate-choices.json` - 第2级选择模板

**持久化工具：**
- `fate-pressure.py` - 计算并记录压力状态
- `propose-shift.py` - 记录转变提案
- `exposure-log.py` - 追踪累积的暴露事件

### 与标准输出持久化的区别

World-fates 数据存在于**世界圣经实体条目内部**，而非单独的探索文件。这将命运追踪与 shared-world 技能集成。

**本技能不使用 `context/output-config.md`**，因为：
- 命运数据附属于世界圣经中的实体
- 位置由世界圣经结构决定
- 数据必须对所有贡献者可访问

### 对话 vs. 文件

| 写入文件 | 保留在对话中 |
|----------|-------------|
| 命运/运气状态更新 | 命运压力计算 |
| 转变提案（待批准） | 后果讨论 |
| 暴露事件 | 第2级选择的考量 |
| 命运掷骰结果 | 机制说明 |

## 你不做的事

- 不在未经人类批准的情况下应用命运转变
- 不保证结果（概率保持不确定性）
- 不忽略累积的压力（命运之轮必须转动）
- 不保护实体免受其选择的后果
- 不对主角和NPC适用不同规则
- 不凭空制造压力（必须追溯到选择/事件）
- 不使第2级选择变得轻而易举（两条路径都应有代价）

## 核心洞察

命运之轮创造了世界充满生机和后果的感觉。当玩家知道命运可以改变，强大人物可以衰落，他们自己的角色面临真实风险——赌注感觉是真实的。

但三级系统确保这永远不会感觉武断。玩家始终拥有能动性：他们可以优雅退出，他们可以面对戏剧性选择，或者他们可以掷骰子。系统不惩罚；它创造压力，而压力创造故事。

最好的命运时刻是那些玩家在明知风险的情况下选择面对赔率，而骰子对他们不利的时刻。或者他们接受了第2级提议，角色在世界中变成了新的存在。或者他们看到压力在积累，将英雄退役到当之无愧的安息。

所有这些都是叙事的胜利。命运之轮确保故事持续前进。

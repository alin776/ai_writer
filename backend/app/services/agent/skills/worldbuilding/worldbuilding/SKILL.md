# 网文世界观：诊断技能

诊断中国网络小说设定中的世界层面问题。识别修炼体系、势力架构、能量经济、种族设定和金手指中的缺陷与不自洽之处，并推荐具体的干预措施。

## 何时使用本技能

在以下情况使用本技能：
- 修炼境界划分混乱，突破条件前后矛盾
- 宗门/势力结构像空壳，缺乏运转逻辑
- 灵气、灵石、丹药等经济体系不自洽
- 非人种族（妖族、龙族等）只是换皮人类
- 主角金手指没有合理限制，读者质疑"为什么别人没有"
- 世界观随写随编，前后设定冲突

不要在以下情况使用本技能：
- 故事问题以角色为中心（使用 character-arc）
- 情节结构问题（使用 scene-sequencing）
- 需要从零开始系统性构建世界（使用 systemic-worldbuilding）
- 需要设计具体城池/聚落空间（使用 settlement-design）

## 核心原则

**当读者能感觉到"作者在现编"，世界观就失败了。**

好的网文世界观让读者相信：这个世界在主角出生之前就已经运转了千万年，在主角的故事结束之后也会继续存在。它有自己的历史、规则和不以任何角色意志为转移的运行逻辑。

## 世界状态诊断

### W1：修炼体系诊断
**症状：** 境界划分不清晰，突破条件随意，战力没有参照物
**典型表现：**
- 境界名称堆砌但没有实质区别（"筑基"和"金丹"到底差多少？）
- 突破条件一会儿是顿悟，一会儿是资源，毫无规律
- 同境界角色战力波动过大，没有基准线
**诊断问题：**
- 每个大境界的核心质变是什么？（不是量变，是质变）
- 突破需要满足哪几个硬性条件？
- 同境界内的战力差距由什么决定？（功法品质？天赋？战斗经验？）
**干预措施：** 建立"境界-质变-门槛-战力基准"四维表

### W2：宗门/势力诊断
**症状：** 势力只是背景板，缺乏运转逻辑
**典型表现：**
- 宗门收弟子但不知道靠什么盈利
- 势力层级（宗门→世家→散修）之间没有互动逻辑
- 宗门内部管理像现代公司或完全没有管理
**诊断问题：**
- 这个势力的经济来源是什么？（矿脉？丹药贸易？任务佣金？）
- 势力的人才选拔和晋升机制是什么？
- 势力之间的利益关系和制衡是什么？
**干预措施：** 建立"势力运转循环"——资源→人才→实力→地位→更多资源

### W3：灵气/能量体系诊断
**症状：** 天地灵气、灵石经济、丹药炼器等缺乏内在逻辑
**典型表现：**
- 灵石是万能货币但不知道从哪来、谁在挖
- 丹药效果随剧情需要随意变化
- 炼器材料珍稀程度前后不一
**诊断问题：**
- 灵气的来源和分布规律是什么？（灵脉？天地循环？）
- 灵石的产出速率和消耗速率是否平衡？
- 丹药/法器的品级体系是否与修炼境界对应？
**干预措施：** 建立"能量经济闭环"——产出→流通→消耗→再生

### W4：种族/血脉诊断
**症状：** 妖族、龙族等非人种族只是外形不同的人类
**典型表现：**
- 妖族除了能变身，思维方式和人族完全一样
- 龙族号称高贵但看不出高贵在哪
- 不同种族没有独特的社会结构和文化传统
**诊断问题：**
- 这个种族的寿命、繁殖方式如何影响其社会结构？
- 这个种族的天赋能力如何塑造其文化和价值观？
- 种族之间的历史恩怨和现实利益关系是什么？
**干预措施：** 从"生理特征→生存策略→社会结构→文化价值观"链条推演

### W5：金手指自洽性诊断
**症状：** 主角的外挂能力没有合理限制和代价
**典型表现：**
- 金手指随剧情升级，没有预设的成长轨迹
- 没有使用代价或限制条件
- 无法解释"为什么偏偏是主角得到了这个"
**诊断问题：**
- 金手指的能力上限在哪里？
- 使用金手指的代价/冷却/限制是什么？
- 金手指的来历是否有伏笔？为什么别人没发现过？
**干预措施：** 建立"金手指三要素"——能力边界、使用代价、获取合理性

## 世界构建十问（网文版）

这十个问题是世界观自洽性的"压力测试"。如果作者无法清晰回答其中五个以上，说明世界观需要补强。

### 1. 修炼到顶峰的人在做什么？（天花板设计）
- 最强者的日常是什么？闭关？争霸？飞升？
- 如果没有天花板，世界为什么没有被顶级强者摧毁？
- 如果有天花板，强者触及天花板后的出路是什么？

### 2. 普通人的日常生活是什么样？（基底设计）
- 不修炼的凡人占世界人口的百分比？
- 凡人和修士的关系是什么？共存？隔绝？剥削？
- 一个凡人农民的一天是怎么过的？

### 3. 灵石/能量从哪里来？谁控制？（经济基础）
- 灵气/灵石的产出地在哪里？
- 控制资源的势力如何维持垄断？
- 散修如何获取修炼资源？

### 4. 强者为什么不直接碾压一切？（权力制衡）
- 什么机制阻止了最强者为所欲为？（天道？同级制衡？规则？）
- 历史上有没有强者试图打破平衡的先例？结果如何？
- 弱者的生存空间来自哪里？

### 5. 宗门/势力靠什么维持运转？（组织逻辑）
- 宗门的收入来源和支出结构是什么？
- 弟子为什么愿意留在宗门而不是单干？
- 宗门内部的利益分配机制是什么？

### 6. 历史上发生过什么大事？（时间纵深）
- 有没有改变世界格局的远古大战/灾变？
- 现有的势力格局是什么时候形成的？
- 有哪些历史遗迹/禁地？它们的来历是什么？

### 7. 不同地区有什么差异？（空间广度）
- 东西南北有什么地理和文化差异？
- 高灵气区和低灵气区的发展差异是什么？
- 有没有被隔绝的特殊区域？（秘境、禁地、异界入口）

### 8. 禁忌是什么？违反了会怎样？（规则边界）
- 修炼界有哪些不可触碰的禁忌？（弑师？夺舍？魔修？）
- 禁忌的执行者是谁？（天道？正道联盟？某个组织？）
- 有没有人游走在禁忌边缘？

### 9. 天材地宝从哪来？为什么没被采光？（资源逻辑）
- 珍稀资源为什么还能被主角捡到？
- 资源的再生机制是什么？
- 危险区域中的资源为什么没有被强者清扫？

### 10. 主角的金手指为什么没被别人发现过？（独特性理由）
- 金手指的获取是否有前置条件？（特殊体质？机缘巧合？）
- 如果金手指是物品，它之前在哪里？为什么没人用过？
- 如果金手指是能力，为什么历史上没有第二个拥有者？

## 后果级联（网文版）

适用于分析任何设定元素引入后的连锁反应：

```
设定元素（如：灵气复苏）
├── 一阶：直接影响
│   ├── 谁最先受益？（有功法传承的世家/隐世宗门）
│   ├── 什么变得过时？（科技武器对修士无效？）
│   └── 最初的混乱是什么？（凡人觉醒、妖兽暴动）
├── 二阶：体系适应
│   ├── 权力结构如何重组？（政府 vs 修炼势力）
│   ├── 经济体系如何变化？（灵石取代货币？）
│   └── 什么抵抗力量出现？（反修炼组织？科技对抗派？）
└── 三阶：文化演变
    ├── 什么新的价值观出现？（实力为尊？弱肉强食？）
    ├── 什么伦理争议产生？（寿命不平等？强者特权？）
    └── 什么成为新的常态？（修炼成为义务教育？）
```

## 常见反模式

### 境界注水
整本书二十个小境界但没有质的区别。
**修复：** 大境界不超过 6-9 个，每个有明确的质变标志（如筑基=灵根激活，金丹=灵力实质化）。

### 宗门空壳
宗门只在主角需要的时候出场，没有自己的运行逻辑。
**修复：** 为重要宗门写一页"运转手册"——收入、支出、选拔、管理。

### 灵石通胀
前期一块灵石是巨款，后期百万灵石随便花。
**修复：** 建立货币层级（灵石→中品灵石→上品灵石→灵晶），对应不同经济层级。

### 打脸永动机
每到新地图就有人看不起主角，然后被打脸。
**修复：** 让主角的声望随实力增长而传播，高境界势力有情报网络。

### 换皮妖族
妖族只是长了耳朵/尾巴的人类。
**修复：** 从生理特征推演社会结构——长寿种族重传统、短寿种族重效率、群居种族重集体。

### 无限升级地图
每离开一个地方就去更大的地方，之前的设定全部作废。
**修复：** 让旧地图的人和事持续出现，建立跨区域的联系网络。

## 深度 vs 广度决策

**需要深入设计的：**
- 主角当前所在区域的势力格局
- 主线剧情涉及的修炼体系细节
- 核心冲突所依赖的世界规则
- 金手指的运作机制和限制

**可以保持模糊的：**
- 主角尚未到达的高级区域
- 次要角色的修炼细节
- 远古历史的具体过程（留伏笔空间）
- POV 角色不可能知道的信息

## 诊断执行流程

### 第一步：信息采集
1. 读取项目中的 `/knowledge/worldview.md`（如果存在）
2. 读取相关章节内容，了解已呈现的世界设定
3. 列出所有已出现的设定元素

### 第二步：十问压测
对照"世界构建十问"逐一检查：
- 已有明确答案 → 标记为"已设定"
- 答案模糊或矛盾 → 标记为"需补强"
- 完全没有涉及 → 标记为"空白"

### 第三步：状态诊断
对照 W1-W5 五个诊断状态：
- 逐一评估当前严重程度（轻微/中等/严重）
- 标记与主线剧情最相关的问题
- 按优先级排序

### 第四步：出具诊断报告
格式：
```markdown
## 世界观诊断报告

### 总体评级：[优秀/良好/需改进/严重不足]

### 各维度评估
| 维度 | 状态 | 严重程度 | 建议 |
|------|------|----------|------|
| W1 修炼体系 | ... | ... | ... |
| W2 势力架构 | ... | ... | ... |
| W3 能量经济 | ... | ... | ... |
| W4 种族血脉 | ... | ... | ... |
| W5 金手指 | ... | ... | ... |

### 十问回答情况
[已设定 X / 需补强 Y / 空白 Z]

### 优先修复建议
1. ...
2. ...
3. ...
```

### 第五步：输出持久化
将诊断结果和修复建议写入 `/knowledge/worldview.md`。
如涉及角色设定问题，同步更新 `/knowledge/characters.md`。

### 输出路径

分析和诊断结果直接在对话中呈现。如需持久化，写入平台标准路径：
- 世界观相关 → `/knowledge/worldview.md`
- 角色相关 → `/knowledge/characters.md`

### 主要输出

对于本技能，持久化以下内容：

## 验证（Oracle）

### 本技能可以验证的内容
- **体系自洽性** — 修炼境界与战力是否逻辑一致？（高置信度）
- **经济闭环** — 资源的产出与消耗是否平衡？（高置信度）
- **势力逻辑** — 势力的存在和运转是否合理？（中置信度）
- **规则冲突** — 不同设定之间是否有矛盾？（高置信度）

### 需要人工判断的内容
- **爽感平衡** — 设定是否在合理性和阅读爽感之间取得平衡？
- **创新程度** — 修炼体系是否有足够的新意？
- **读者预期** — 目标读者群对设定严谨度的要求是什么？
- **类型匹配** — 设定深度是否与小说类型匹配？（轻小说 vs 硬核设定）

### Oracle 局限
- **无法评估市场适配** — 设定可能自洽但不符合当前网文读者口味
- **无法预测爽感** — 逻辑严密的设定未必读起来爽
- **类型依赖** — 系统流和传统玄幻对自洽性的要求不同

## 反馈循环

### 会话持久化
- **输出位置：** `/knowledge/worldview.md`
- **保存内容：** 诊断报告、修炼体系、势力架构、能量经济、金手指规则
- **更新策略：** 每次诊断后追加或覆盖对应章节

### 跨会话学习
- **开始前：** 检查是否有之前的世界观文件
- **如果存在之前的输出：** 对照已有设定做增量诊断，保持一致性
- **什么反馈能改进本技能：**
  - 被读者质疑的设定漏洞 → 添加到诊断检查项
  - 效果好的设定模式 → 添加到正面案例
  - 新的网文类型趋势 → 更新诊断维度

### 会话间流程
1. 首次会话：全面诊断、建立基线、输出到文件
2. 后续会话：增量诊断、聚焦新增或变化的设定
3. 模式：采集 → 压测 → 诊断 → 修复建议 → 持久化 → 增量更新

## 设计约束

### 本技能假设
- 项目是中国网络小说或类网文体裁
- 世界观至少有部分内容已写出或构思
- 作者追求设定的内在自洽性

### 本技能不处理
- **从零构建世界** — 转至：systemic-worldbuilding
- **城池/聚落空间设计** — 转至：settlement-design
- **角色弧线问题** — 转至：character-arc
- **情节结构问题** — 转至：scene-sequencing
- **文风和行文问题** — 转至：prose-style

### 退化信号
本技能被误用的迹象：
- 没有任何已有设定就开始诊断（应先用 systemic-worldbuilding 构建）
- 问题集中在角色而非世界（应转 character-arc）
- 作者明确表示不需要严谨设定（轻喜剧/无厘头类型可降低标准）
- 反复诊断同一维度但不采纳建议

## 推理要求

### 标准推理
- 单一维度的诊断（如只看修炼体系）
- 回答十问中的单个问题
- 检查两个设定之间是否矛盾

### 扩展推理（ultrathink）
用于：
- **全面诊断（五维度 + 十问）** — [原因：需要同时在脑中持有整个世界的多个层面]
- **体系设计（修炼体系/经济闭环）** — [原因：需要保证多层级之间的逻辑自洽]
- **跨维度一致性检查** — [原因：需要追踪修炼体系、势力、经济之间的联动影响]
- **后果级联分析** — [原因：需要保持多个中间状态并追踪连锁反应]

**触发短语：** "全面诊断"、"世界观体检"、"检查所有设定"、"体系自洽性验证"

## 执行策略

### 顺序执行（默认）
- 先采集已有信息再诊断
- 先完成十问压测再做维度诊断
- 先诊断再给修复建议

### 可并行化
- W1-W5 五个维度的诊断可以并行
- 多个区域/势力的独立分析可以并行
- 不同章节的设定一致性检查可以并行

### 子代理候选
| 任务 | 代理类型 | 何时生成 |
|------|----------|----------|
| 读取多章节设定信息 | Explore | 当项目内容较多需要全面扫描时 |
| 修炼体系深度设计 | general-purpose | 当需要构建完整的境界体系时 |
| 势力关系梳理 | general-purpose | 当势力超过 5 个需要梳理关系网时 |

## 上下文管理

### 近似 Token 占用
- **技能基础：** ~3k tokens（框架 + 诊断维度）
- **含十问展开：** ~4k tokens
- **含完整诊断流程：** ~5k tokens

### 上下文优化
- 按名称引用其他技能，而非内联其内容

## 集成

### 入站（输入到本技能）
| 技能 | 提供的内容 |
|------|-----------|
| story-sense | 诊断出世界感觉单薄，路由至本技能 |
| story-analysis | 从文本分析中发现的设定矛盾 |
| genre-conventions | 当前类型对世界观深度的要求 |

### 出站（本技能赋能）
| 技能 | 本技能提供的内容 |
|------|-----------------|
| systemic-worldbuilding | 诊断出的薄弱点，供深度构建 |
| settlement-design | 世界观框架，供城池设计参考 |
| drafting | 世界规则，供写作时保持一致 |
| revision | 设定矛盾清单，供修订时对照 |

### 互补
| 技能 | 关系 |
|------|------|
| systemic-worldbuilding | worldbuilding 负责诊断；systemic-worldbuilding 负责从零构建 |
| settlement-design | worldbuilding 提供宏观框架；settlement-design 聚焦城池空间 |
| story-coach | worldbuilding 关注设定层面；story-coach 关注叙事层面 |

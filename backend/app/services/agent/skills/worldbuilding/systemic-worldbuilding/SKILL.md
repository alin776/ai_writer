# 系统性世界构建：级联后果技能

你帮助作者通过系统地追踪初始设定如何在多个领域和时间尺度上波及社会来构建网文世界。这种方法不是简单地引入新奇元素，而是探索它们如何现实地改变所触及的一切——让"修炼体系"不仅仅是战斗工具，而是塑造整个文明的底层逻辑。

## 核心原则

**好的网文世界观应该能预测的不是"修炼境界"，而是"修炼者如何改变了整个社会"。**

思辨性世界构建的力量不在于设定的新奇性，而在于其后果的真实性。

## 何时使用本技能

**使用：**
- 从零开始设计一个新的世界体系（修炼体系、系统规则、末世法则）
- 引入一个核心设定变化，需要推演其对社会各方面的影响
- 已有基本设定但世界感觉"空"，需要填充细节

**不使用：**
- 已有世界需要诊断问题 → worldbuilding
- 需要设计具体聚落空间 → settlement-design
- 角色层面的问题 → character-arc

## 后果框架（网文版）

### 第1层：核心分歧点

什么具体设定使你的网文世界与现实不同？

| 类型 | 网文常见示例 |
|------|------------|
| **修炼体系引入** | 灵气复苏、功法传世、血脉觉醒 |
| **系统降临** | 天道系统、游戏面板、任务系统 |
| **灾变/末世** | 灵气枯竭、异兽入侵、位面融合 |
| **穿越/重生** | 现代人穿古代、重生回过去、异世界召唤 |
| **科技突破** | 星际航行、基因改造、虚拟现实 |
| **历史分歧** | 秦朝未灭、三国统一、近代有修炼者 |

### 第2层：直接后果（一阶）

设定引入后的即时实际影响：

**需要问的问题：**
- 谁最先获得了力量或优势？（有传承的世家？觉醒的普通人？）
- 什么现有体系变得过时？（科技武器？法律体系？经济结构？）
- 最初的混乱是什么？（觉醒失控？妖兽暴动？社会秩序崩溃？）
- 出现了什么技术限制？（修炼需要资源？系统有规则？）
- 最初的意外影响是什么？（普通人的生活如何被波及？）

### 第3层：体系适应（二阶）

主要社会系统如何响应：

**权力结构**：修炼者/能力者 vs 普通人的关系。是实力为尊？还是政府管控？宗门/势力如何形成？

**经济体系**：灵石/能量成为新货币？旧经济崩溃还是共存？谁控制资源？

**社会分层**：有天赋者 vs 无天赋者。新的阶级如何固化？底层是否有上升通道？

**抵抗力量**：谁反对新秩序？（反修炼组织？科技对抗派？旧势力残余？）

**基础设施**：交通（飞剑/传送阵 vs 马车/汽车）、通信、城市布局如何变化？

**教育**：修炼学院替代学校？知识如何传承？

### 第4层：文化演变（三阶）

深层社会变化：

**语言演变**：修炼术语如何渗透日常语言？（"你这是找死"在修炼世界里可能是字面意思）

**伦理问题**：强者特权？寿命不平等？杀戮的道德标准？

**信仰体系**：天道是真实存在的？传统宗教如何回应？

**常态化**：什么曾经令人震惊的事变成了日常？（飞天遁地？百年寿命？）

**代际差异**：灵气复苏前出生的人 vs 之后出生的人

### 第5层：差异化影响

同一个设定变化如何不同地影响不同群体：

| 维度 | 网文中的体现 |
|------|------------|
| **天赋差异** | 有灵根 vs 无灵根、S级觉醒 vs F级觉醒 |
| **地理差异** | 灵气浓郁区 vs 灵气荒漠、安全区 vs 危险区 |
| **代际差异** | 灵气复苏前的老人 vs 天生能修炼的新一代 |
| **阶层差异** | 有传承的世家 vs 白手起家的散修 |
| **种族差异** | 人族 vs 妖族 vs 异族的不同处境 |

## 网文常见分歧点详解

### 示例 1：灵气复苏

**核心分歧：** 现代地球突然出现灵气，部分人类可以修炼。

```
灵气复苏
├── 一阶：直接影响
│   ├── 觉醒者出现（最先是体质特殊者/有传承者）
│   ├── 异兽/灵植出现（生态剧变）
│   └── 科技设备部分失效（电磁干扰？）
├── 二阶：体系适应
│   ├── 政府成立超凡管理局（权力重组）
│   ├── 灵石/灵材成为新资源（经济重构）
│   ├── 觉醒者学院取代部分学校（教育变革）
│   └── 反觉醒组织出现（抵抗力量）
├── 三阶：文化演变
│   ├── "实力为尊"成为新价值观
│   ├── 寿命不平等引发伦理争论
│   ├── 传统武术/宗教获得新含义
│   └── "普通人"成为一种新的身份焦虑
└── 四阶：深层变化
    ├── 国际格局重组（谁的觉醒者多？）
    ├── 城市为灵脉而战（新的领土争端）
    └── 人类文明分化（修炼文明 vs 科技文明）
```

### 示例 2：修炼世界的底层逻辑

**核心分歧：** 一个天生就有灵气和修炼体系的古代世界。

**关键推演：**
- 如果修炼者能活几百年 → 老一辈永远占据资源 → 年轻人上升通道极窄 → 宗门内部矛盾
- 如果灵石是修炼必需品 → 灵矿成为战略资源 → 控制灵矿的势力最强 → 经济基础决定势力格局
- 如果武力决定一切 → 弱国被强国吞并 → 最终只剩少数超级势力 → 恐怖平衡
- 如果有飞行能力 → 地形不再是天然屏障 → 防御体系完全不同 → 城市设计围绕阵法而非城墙

## 管理递归复杂性

### 深度与广度的决策

**深度探索**：选定一个领域（如经济体系），追踪到三阶四阶后果。适合写作前的重点设计。

**广度映射**：在所有主要领域做浅层覆盖。适合开书前的整体规划。

**示踪故事**：通过一个普通人的生活来追踪设定变化的影响。最能检验世界观是否"活"。

### 时间跨度

| 跨度 | 时间范围 | 网文中的体现 |
|------|----------|------------|
| **短期** | 灵气复苏后数月 | 混乱期、适应期、第一批觉醒者 |
| **中期** | 数年到数十年 | 新秩序建立、势力格局形成 |
| **长期** | 数百年 | 修炼文明成熟、文化彻底改变 |

### 矛盾效应

最有趣的世界构建来自张力——对网文来说尤其如此，因为张力就是冲突，冲突就是故事：

- 修炼者需要自由探索 vs 政府需要管控 → 冲突源
- 灵石经济的效率 vs 公平分配 → 社会矛盾
- 实力为尊的新价值观 vs 法律面前人人平等的旧价值观 → 主题张力

## 可见性标记

设定变化如何在日常生活中变得可感知——这些是让世界"活"起来的细节：

| 类型 | 网文示例 |
|------|---------|
| **身体标记** | 修炼者的气场压制、瞳色变化、体质特征 |
| **行为标记** | 修炼者不需要睡觉、不吃凡间食物、速度异常 |
| **社会标记** | 觉醒者ID卡、宗门弟子服饰、散修标识 |
| **语言标记** | 修炼术语日常化、"前辈""道友"称呼体系 |
| **环境标记** | 灵气浓郁区的植物异变、灵兽出没区的警告标志 |

## 实践应用步骤

1. **明确定义核心分歧点**——一句话说清楚你的世界与现实的区别
2. **在所有主要领域映射一阶影响**——权力、经济、社会、军事、教育
3. **识别内在矛盾**——找到 2-3 个最大的张力点
4. **追踪不同群体的响应**——至少 3 个不同处境的群体
5. **沿最有趣的后果链追踪到更深层级**——选择对故事最有用的
6. **寻找领域之间的意外交叉**——经济变化如何影响教育？教育如何影响军事？
7. **在最大张力点识别故事潜力**——冲突在哪里？主角的机会在哪里？
8. **添加可见性标记**——让世界设定在细节中被读者感知

## 反模式

### 1. 设定展示橱窗

**模式：** 精心设计了修炼体系的每个细节，但这些设定对剧情和角色没有任何影响——它们只是展示用的。
**修复：** 每个重要设定必须至少与一个角色困境或剧情冲突直接相关。

### 2. 单一后果思维

**模式：** 灵气复苏 = 人人可以修炼。只看到了表面的"超能力"，没有推演经济、政治、社会影响。
**修复：** 对每个一阶后果追问"然后呢？"至少三次。

### 3. 同质化响应

**模式：** 世界上所有人对灵气复苏的反应都一样——都兴奋地去修炼。
**修复：** 至少在 3 个维度上映射不同响应：阶层（富人/穷人）、年龄（老年/青年）、天赋（有灵根/无灵根）。

### 4. 领域隔离

**模式：** 详细设计了修炼体系，但没考虑它对经济的影响；设计了势力格局，但没考虑经济基础。
**修复：** 每个领域探索后，明确追问"这如何影响其他领域？"

### 5. 缺失底层生活

**模式：** 世界里只有修炼者和战斗。普通人在哪里？菜从哪来？路怎么修？
**修复：** 用"示踪故事"方法：一个普通农民/商人在这个世界的一天是怎么过的？

## 诊断执行流程

### 第一步：定义分歧点
与作者确认核心设定变化是什么。一个好的分歧点应该是：
- 清晰可表述的（一句话能说明）
- 有广泛影响的（不止影响一个领域）
- 有内在张力的（有正面也有负面后果）

### 第二步：广度映射
在以下领域做快速一阶影响扫描：
- 权力结构 | 经济体系 | 社会分层 | 军事防御
- 教育传承 | 日常生活 | 信仰文化 | 国际/势力关系

### 第三步：深度追踪
选择 2-3 个最相关的后果链，追踪到三阶或更深。

### 第四步：张力识别
标记所有矛盾点，评估哪些最适合作为故事冲突。

### 第五步：输出持久化
将推演结果写入 `/knowledge/worldview.md`。

- 世界观相关 → `/knowledge/worldview.md`

### 主要输出

对于本技能，持久化：
- **分歧点定义** — 核心设定变化
- **后果链** — 各层级的级联影响
- **领域影响** — 每个领域如何受到影响
- **矛盾图** — 后果之间的张力
- **故事潜力点** — 最大张力点和冲突源

## 验证（Oracle）

### 本技能可以验证的内容
- **后果链逻辑** — B是否由A合理推出？（高置信度）
- **领域覆盖** — 是否考虑了所有主要领域？（高置信度）
- **矛盾识别** — 是否发现了内在张力？（中置信度）

### 需要人工判断的内容
- **故事相关性** — 哪些后果对此叙事重要？
- **创作兴趣** — 哪些暗示最引人注目？
- **爽感平衡** — 设定严谨性 vs 阅读爽感的取舍

### Oracle 局限
- 无法评估设定在目标读者群中的接受度
- 无法预测某个后果链是否能写得有趣

### 标准推理
- 追踪单领域后果链
- 识别一阶影响
- 记录可见性标记

### 扩展推理（ultrathink）
用于：
- **多领域交叉映射** — [原因：追踪 3 个以上领域的后果如何互动]

- **矛盾解决** — [原因：找到社会如何应对竞争性压力]

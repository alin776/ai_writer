# 故事分析：网文诊断技能

## 目的

系统性地评估已完成的网文章节，识别优势、不足和改进机会。在完成草稿后使用，评估作品是否达成了其叙事目标——特别是在网文读者期待的维度上。

## 快速参考

| 模式 | 适用场景 | 重点关注 |
|------|---------|---------|
| 单章分析 | 单个章节评估 | 爽点、钩子、节奏、信息密度 |
| 多章连评 | 连续 3-5 章 | 升级曲线、追读力、线索编织 |
| 卷级分析 | 一整卷 | 卷弧线、高潮质量、转折力度 |
| 黄金三章 | 前三章专项 | 开篇吸引力、设定交付、读者留存 |

## 网文专项评估维度

### NA1：爽点密度与分布

**评估要点：**
- 每章是否有至少一个"爽"的瞬间（大爽点或小爽点）
- 爽点是否有铺垫-释放-反应的完整结构
- 连续多章没有爽点的"干旱期"是否存在
- 爽点类型是否有变化（打脸/升级/获宝/逆转/社交胜利）

**提问：**
1. 这一章最"爽"的瞬间是什么？读者会在哪里拍桌叫好？
2. 这个爽点有足够的铺垫吗？还是突如其来？
3. 周围角色对爽点事件有足够的反应吗？（围观震惊？对手崩溃？）
4. 最近 5 章的爽点密度如何？是否在衰减？

**爽点节奏参考：**
| 爽点级别 | 频率 | 说明 |
|---------|------|------|
| 微爽点 | 每章 1-2 个 | 一句机智回应、一个小发现 |
| 小爽点 | 每 2-3 章 | 打脸小人物、小突破 |
| 中爽点 | 每 5-10 章 | 关键战斗胜利、重要突破 |
| 大爽点 | 每卷 1-2 个 | 大逆转、大报复、跨级击杀 |

---

### NA2：升级曲线与成长感

**评估要点：**
- 主角是否有可感知的成长（实力/地位/认知）
- 升级节奏是否合理（太快→没有代入感，太慢→读者跑了）
- 每次升级是否有"仪式感"（不只是数字变化）
- 新能力是否很快就有展示机会

**提问：**
1. 最近 10 章，主角变强了多少？读者能感知到吗？
2. 升级是通过努力/智慧获得的，还是天降机缘？
3. 新获得的能力/资源在后续 5 章内有展示机会吗？
4. 配角的成长是否与主角形成对比（突出主角的特殊性）？

**危险信号：**
- 连续 20+ 章没有任何实力提升
- 升级太频繁导致麻木（每章突破一个小境界）
- 升级只有数字变化，没有质变感

---

### NA3：追读钩子与章末设计

**评估要点：**
- 章末是否有吸引读者继续阅读的钩子
- 钩子类型是否多样化（悬念/危机/期待/反转）
- 章首是否与上一章钩子衔接
- 是否在付费节点前放置了强力钩子

**提问：**
1. 读者读完这一章会不会立刻想看下一章？
2. 如果这是免费区最后一章，读者会不会付费？
3. 钩子是否被过度使用（每次都是"就在此时"）？
4. 章首是否及时兑现了上一章的悬念？

**钩子类型清单：**
- **悬念型：** 关键信息未揭示（"这个神秘人是谁？"）
- **危机型：** 主角陷入险境（"毒已入骨，只剩一天"）
- **期待型：** 即将发生好事（"明天就是拍卖会"）
- **反转型：** 出乎意料的变化（"他居然是..."）
- **情感型：** 情感冲突待解决（"她转身离去"）

---

### NA4：金手指平衡

**评估要点：**
- 金手指在关键时刻的表现是否合理
- 是否存在"万能钥匙"问题（任何困难都靠金手指解决）
- 金手指的使用是否有代价/限制
- 读者是否能理解金手指的规则

**提问：**
1. 主角最近解决问题时，金手指贡献了多大比例？
2. 金手指有没有"不能做"的事？
3. 如果去掉金手指，主角自身的能力/智慧够用吗？
4. 读者能预测金手指在下一个困境中能帮到什么程度吗？

## 通用分析维度

### SA1：叙事根基

**评估要点：**
- 核心冲突是否清晰
- 利害关系是否足够（读者在乎结果吗？）
- 主线是否稳定推进（没有偏离太远）

---

### SA2：角色表现

**评估要点：**
- 主角是否有明确的目标和个性
- 配角是否有存在的意义（不是工具人）
- 反派是否有合理的动机（不是纯粹的脑残）
- 角色对话是否有区分度

**网文特别关注：**
- 女性角色是否沦为花瓶？
- 反派是否只为送人头而存在？
- 配角是否在主角变强后被彻底遗忘？

---

### SA3：信息流管理

**评估要点：**
- 设定信息是否融入剧情而非直接倾泻
- 读者在每个节点知道多少信息？是否足够理解正在发生的事？
- 新信息引入的节奏是否合适

**网文特别关注：**
- 修炼体系说明是否太长/太无聊？
- 是否通过角色互动来传递世界观信息？
- 信息量是否适合"扫读"模式？

---

### SA4：节奏与密度

**评估要点：**
- 紧张与放松的交替是否合理
- 是否有"水"的感觉（内容少但字数多）
- 场景长度是否与其重要性匹配
- 时间跳跃的使用是否恰当

**网文密度参考：**
| 评级 | 说明 |
|------|------|
| **过密** | 每段都有重要事件，读者来不及消化 |
| **适中** | 有事件有铺垫有呼吸，节奏舒服 |
| **略水** | 能感觉到在凑字数，但还能读 |
| **严重水** | 三章可以压缩成一章，读者跳着看 |

## 黄金三章专项分析

前三章是网文生死线。专项评估：

### 第一章检查清单
- [ ] 前 500 字内建立了核心冲突或悬念
- [ ] 主角有明确的困境或目标
- [ ] 金手指/核心设定在第一章内展示
- [ ] 章末有强力钩子

### 第二章检查清单
- [ ] 兑现第一章的悬念（至少部分）
- [ ] 展示金手指的核心能力
- [ ] 至少一个小爽点
- [ ] 建立更大的期待

### 第三章检查清单
- [ ] 首个中等爽点（打脸/突破/逆转）
- [ ] 主角的成长路径变得清晰
- [ ] 核心矛盾/对手浮出水面
- [ ] 读者有理由继续读第四章

## 诊断流程

### 第一步：确定分析范围
- 单章？多章？一整卷？黄金三章？
- 读取对应的 `/chapters/` 文件

### 第二步：快速通读
- 标记爽点位置
- 标记钩子位置
- 标记节奏异常点
- 标记信息倾泻点

### 第三步：维度评估
- 先做网文专项维度（NA1-NA4）
- 再做通用维度（SA1-SA4）

### 第四步：生成报告
- 使用评估报告模板
- 优势和建议按影响力排序
- 建议具体可操作

## 反模式

### 1. 清单暴政

**模式：** 将清单上所有项目视为同等重要，把每个未达标项都标记为需要修复。
**修正：** 按影响力排序。先问"这真的伤害了故事吗？"有些规则是可以被有效打破的。

### 2. 类型盲区

**模式：** 用文学小说的标准评价网文——要求深刻的心理描写、诗意的散文、反英雄的复杂性。
**修正：** 先识别类型和目标读者。评估作品是否达成了它试图成为的样子。

### 3. 全面问题倾泻

**模式：** 一次性列出 50 个问题，没有优先级。
**修正：** 找出 3-5 个影响最大的问题。指出哪些地方做得好。提供可操作的、有优先级的指导。

### 4. 忽视商业维度

**模式：** 只从叙事质量角度分析，忽视追读、留存、付费节点等商业因素。
**修正：** 网文是商业写作。将追读和留存纳入评估体系。

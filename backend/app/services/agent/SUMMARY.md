## 💡 核心技术亮点

### 1. 三层记忆架构
```
短期记忆 (对话历史)
     ↓
长期记忆 (用户偏好 + Redis)
     ↓
知识库 (作品设定 + pgvector)
```

### 2. 人机协同工作流
```
Agent生成计划 → 暂停请求批准 → 用户操作 → 恢复执行
```

### 3. 反思迭代机制
```
生成 → 评估 → 未达标？ → 改进 → 再评估
                ↓
              达标 → 输出
```

### 4. 并行加速算法
```
串行: Task1(10s) → Task2(10s) → Task3(10s) = 30s
并行: max(Task1, Task2, Task3) = 10s ⚡️ 3倍加速
```

## 步骤5: 常见问题排查

### 问题1: 导入路径错误

**现象**: TypeScript报错 `Cannot find module '@/types/humanize'`

**解决**:
```typescript
// 确保 tsconfig.json 包含路径别名
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}

// 或使用相对路径
import type { HumanizeIntensity } from '../../../types/humanize';
```

### 问题2: API请求失败

**现象**: 控制台显示 `Network Error` 或 `404`

**排查步骤**:
1. 检查 `.env` 文件中的 `VITE_API_BASE_URL`
2. 确认后端服务正在运行
3. 检查浏览器控制台的Network标签
4. 验证API路径是否正确

### 问题3: 流式输出不工作

**现象**: 点击按钮后没有实时显示改写内容

**排查步骤**:
1. 检查浏览器是否支持SSE
2. 查看Network标签中的请求类型是否为`text/event-stream`
3. 检查后端是否正确实现SSE
4. 验证`handleStreamEvent`函数是否被调用

### 问题4: 样式不正确

**现象**: 布局混乱或样式缺失

**解决**:
```bash
# 确保Tailwind CSS配置正确
npx tailwindcss init -p

# 确认 tailwind.config.js 包含正确的content路径
module.exports = {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  // ...
}
```

### 问题5: 组件不刷新

**现象**: 历史记录不更新

**解决**:
```typescript
// 确保使用了refreshKey机制
const [historyRefreshKey, setHistoryRefreshKey] = useState(0);

// 在改写完成时增加key
setHistoryRefreshKey((prev) => prev + 1);

// 子组件监听key
useEffect(() => {
  loadHistory();
}, [refreshKey]);
```

  }

};

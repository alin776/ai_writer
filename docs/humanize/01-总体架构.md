# AI指纹消融 - 总体架构文档

## 文档概述
本文档描述AI指纹消融（去AI痕迹化）功能的完整前端架构设计，采用**独立页面模式**。

---

## 功能定位
**AI指纹消融**是一个将AI生成文本转化为自然表达的工具，帮助用户去除明显的AI痕迹。

### 核心特性
- 三阶段处理流程：检测 → 改写 → 验证
- 流式输出体验：实时显示改写进度
- 三种改写强度：轻度(5%) / 中度(20%) / 强度(40%)
- 历史记录管理：查看使用历史和统计数据
- 用户画像系统：自适应配置和偏好学习

## 数据流设计

### 处理流程

```
用户输入文本
    ↓
选择改写强度 (light/medium/strong)
    ↓
点击"开始去痕迹化"
    ↓
[后端] 三阶段处理 (SSE流式返回)
    ├─ 阶段1: 检测AI痕迹 (快速模型)
    ├─ 阶段2: 智能改写 (标准模型，流式输出)
    └─ 阶段3: 效果验证 (快速模型)
    ↓
前端实时更新 (逐字显示)
    ↓
显示改进结果
    ↓
用户反馈 (接受/拒绝)
    ↓
保存到历史记录
```

### 状态管理

```typescript
// 主要状态
- inputText: string           // 输入文本
- outputText: string          // 输出文本
- intensity: HumanizeIntensity // 改写强度
- isProcessing: boolean       // 处理中
- currentStage: string        // 当前阶段
- detectionScore: number      // 检测分数
- improvement: number         // 改进幅度
- sessionId: string           // 会话ID
- error: string               // 错误信息
```

## 核心功能

### 1. 流式改写

- 使用 **SSE (Server-Sent Events)** 协议
- 实时接收改写内容
- 逐字显示，提升用户体验

### 2. 三阶段处理

| 阶段 | 模型 | 功能 | 耗时 |
|-----|------|------|-----|
| 检测 | gemini-2.5-flash-lite | AI痕迹评分 | ~1s |
| 改写 | gemini-2.5-pro | 人性化改写 | ~3-5s |
| 验证 | gemini-2.5-flash-lite | 效果验证 | ~1s |

### 3. 智能跳过

- 检测分数 < 60分：自动跳过改写
- 节省成本，提升效率

### 4. 用户画像

- 记录使用习惯
- 自动调整偏好强度
- 计算接受率

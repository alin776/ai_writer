## 🚦 使用说明

### 启动开发服务器
```bash
npm run dev
# 访问: http://localhost:5174/humanize
```

### 功能入口
1. **侧边栏导航**: 点击 "AI 指纹消融"
2. **URL直接访问**: `/humanize`

### 基本流程
1. 输入待去痕迹的文本 (≤50000字符)
2. 选择改写强度 (轻度/中度/强度)
3. 点击 "开始去痕迹化"
4. 实时查看改写进度和结果
5. 提交反馈 (接受/拒绝)
6. 查看历史记录和统计数据

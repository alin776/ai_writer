```python
# 混合检索 = 向量检索 + 关键词检索
async def search_by_hybrid(query: str, alpha=0.7):
    # 1. 向量检索（语义相似）
    vector_results = await vector_search(query, top_k=20)

    # 2. 关键词检索（精确匹配）
    keyword_results = await keyword_search(query, top_k=20)

    # 3. 加权融合
    combined = merge_results(
        vector_results,   # 权重: alpha (0.7)
        keyword_results,  # 权重: 1-alpha (0.3)
    )

    return combined[:10]
```

#### 核心功能
**"相关条目推荐"**: 查看一个知识条目时，自动推荐相关条目

#### 实现思路
```python
async def get_related_items(
    item_id: str,
    user_id: str,
    top_k: int = 5
) -> List[KnowledgeItem]:
    """获取相关知识条目"""
    # 1. 获取当前条目的向量
    current_item = await get_item(item_id, user_id)

    # 2. 向量相似度搜索
    similar_items = await vector_service.find_similar(
        query=current_item.title + " " + current_item.content,
        user_id=user_id,
        top_k=top_k + 1,  # +1因为会包含自己
    )

    # 3. 排除自己
    return [item for item in similar_items if item.id != item_id][:top_k]
```

### 6. txtai ⭐⭐⭐ （高亮优化）

**链接**: https://github.com/neuml/txtai

| 维度 | 评分 | 说明 |

| 集成成本 | 🟢 **1天** | 局部优化 |
| 实际价值 | 🟡 **中** | 搜索结果体验提升 |
| 技术风险 | 🟢 **低** | 成熟框架 |

#### 问题分析
**当前问题**: `knowledge_service.py:391` 的高亮方法太简单

```python
# 当前实现（简陋）
def _extract_highlight(self, content: str, query: str) -> str:
    pos = content_lower.find(query_lower)
    if pos == -1:
        return content[:100] + "..."
    # 提取前后文
    start = max(0, pos - 50)
    end = min(len(content), pos + len(query) + 50)
    return content[start:end]
```

#### 优化方案
```python
# 使用txtai的Extractor
from txtai.pipeline import Extractor

def _extract_highlight(self, content: str, query: str) -> str:
    """使用txtai提取最相关片段"""
    extractor = Extractor()
    snippet = extractor([(content, query)], topn=1)
    return snippet[0]['text'] if snippet else content[:100]
```

#### 推荐理由
- ✅ 显著改进搜索结果展示
- ✅ 集成简单（1天）
- ✅ txtai是成熟框架

### 问题 #3: 流式API隐私风险

**位置**: `humanize.py:595`

**问题描述**:
```python
# ❌ 原代码：返回完整原文
yield f"data: {json.dumps({'type': 'done', 'skipped': True, 'original_text': request.text}, ...)}\n\n"
```

**风险**:
- 用户的完整原文通过SSE返回
- 如果有日志或监控，可能泄露敏感信息

**修复**:
```python
# ✅ 修复：不返回原文
yield f"data: {json.dumps({'type': 'done', 'skipped': True}, ...)}\n\n"
```

**结论**: ✅ **隐私风险已消除**

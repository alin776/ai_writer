### 核心代码框架

#### 1. NLP预处理器（阶段1）

```python
# backend/app/services/ai/nlp_preprocessor.py
class NLPPreprocessor:
    """中文NLP预处理器"""

    # AI痕迹词库
    AI_PATTERNS = {
        "当然": "",
        "很高兴为您服务": "",
        "值得注意的是": "要注意",
        "首先，": "",
        # ... 50+词
    }

    def preprocess(self, text: str) -> tuple[str, list[str]]:
        """预处理文本"""
        removed_traces = []

        # 1. 去除AI套话
        for pattern, replacement in self.AI_PATTERNS.items():
            if pattern in text:
                text = text.replace(pattern, replacement)
                removed_traces.append(pattern)

        # 2. 清理多余空格
        text = self._clean_whitespace(text)

        return text, removed_traces
```

#### 2. 优化后的Prompt（阶段2）

```python
# backend/app/services/ai/humanize_prompts.py
DETECTION_PROMPT_V2 = """检测以下文本的AI特征，从7个维度评分(0-100):

**维度:**
1. pattern_repetition: 模式重复（首先/其次/最后）
2. word_choice: 词汇选择（书面语过多）
3. sentence_structure: 句式结构（过于工整）
4. tone_style: 语气风格（过于客观）
5. formatting: 格式规范（过度列表化）
6. emotional_expression: 情感表达（缺乏）
7. coherence_flow: 连贯性（过渡词泛滥）

**AI特征列表:**
- 套话: "当然"、"很高兴为您服务"
- 过渡词: "首先"、"其次"、"综上所述"
- 结构词: "值得注意的是"、"需要强调的是"

**评分标准:**
- 80-100分: 明显AI生成（3个以上特征）
- 60-80分: 疑似AI（1-2个特征）
- 0-60分: 人类写作

**Few-shot示例:**
示例1: "当然，首先我们需要..." → score: 85
示例2: "这事儿麻烦了，得想办法..." → score: 30

**待检测文本:**
{text}

严格返回JSON格式。
"""
```

#### 3. 音调调整器（阶段3）

```python
# backend/app/services/ai/tone_adjuster.py
class ToneAdjuster:
    """音调调整器"""

    async def adjust(
        self,
        text: str,
        tone: Literal["casual", "professional", "creative"]
    ) -> str:
        """根据音调调整文本"""
        tone_prompts = {
            "casual": "用轻松口语化的方式改写",
            "professional": "用专业正式的语气改写",
            "creative": "用富有创意的表达改写"
        }

        prompt = f"{tone_prompts[tone]}: {text}"
        return await self.ai_service.call(prompt)
```

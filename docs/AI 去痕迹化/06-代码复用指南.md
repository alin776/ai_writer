## 🚀 方案B: Meta-prompting (高级功能)

### 来源项目
**10Nates/Humanlike-AI-Chat** (MIT License)

### 复用方式
**核心思路借鉴**（完全重写实现）

### 实施步骤

#### 1. 理解核心概念
```
Meta-prompting = Prompt生成Prompt

传统方式:
  User → AI (固定prompt) → 回答

Meta-prompting:
  User → AI (生成定制prompt) → AI (使用定制prompt) → 回答
```

#### 2. 创建实现
```python
# backend/app/services/ai/meta_prompt_humanizer.py

class MetaPromptHumanizer:
    """使用Meta-prompting的去痕迹服务"""

    async def generate_optimized_prompt(self, text: str) -> str:
        """第一步：生成定制化的改写prompt"""

        meta_prompt = f"""
        分析以下文本的AI特征，生成一个专门的去痕迹prompt。

        文本：{text}

        请生成一个prompt，包含：
        1. 检测到的具体AI痕迹（如"首先...其次..."）
        2. 针对性的改写策略
        3. 需要保持的内容要求

        只返回prompt，不要解释。
        """

        optimized_prompt = await self.ai_service.call(meta_prompt)
        return optimized_prompt

    async def humanize_with_meta_prompt(self, text: str) -> str:
        """第二步：用定制prompt改写"""

        # 生成定制prompt
        optimized_prompt = await self.generate_optimized_prompt(text)

        # 用定制prompt改写
        result = await self.ai_service.call(optimized_prompt)
        return result
```

#### 3. 使用场景
```python
# 作为"高级模式"提供
@router.post("/humanize/advanced")
async def humanize_advanced(request: HumanizeRequest):
    """高级改写（Meta-prompting，成本2倍）"""

    meta_humanizer = MetaPromptHumanizer()
    result = await meta_humanizer.humanize_with_meta_prompt(
        request.text
    )

    return {"humanized_text": result}
```

## 🎯 用户画像系统 (UserProfile)

### 功能概述

用户画像系统是一个**自动学习**的智能推荐系统，无需用户配置，会根据使用行为自动优化体验。

### 数据模型

**文件**: `backend/app/models/user_profile.py`

```python
class UserProfile(Base):
    """用户画像模型"""

    # === 统计数据（自动计算）===
    total_uses: int                    # 总使用次数
    avg_text_length: int               # 平均文本长度
    most_used_function: str            # 最常用功能

    # === 偏好设置（自动推荐）===
    preferred_intensity: str           # 推荐强度 (light/medium/strong)
    preferred_speed_over_quality: bool # 速度优先？
    is_novel_writer: bool              # 是否小说作者（自动检测）

    # === 反馈统计（用于优化）===
    total_accepted: int                # 接受次数
    total_rejected: int                # 拒绝次数
    accept_rate: float                 # 接受率

    # === 开关控制 ===
    humanize_enabled_global: bool      # 全局开关
    humanize_enabled_by_function: dict # 分功能开关（JSONB）

    # === 显示模式（自动计算）===
    display_mode: str                  # detailed/simplified/silent
```

## 🤖 自动学习机制

### 1. 小说作者自动检测

**规则**:
```python
if total_uses > 50 and avg_text_length > 500:
    is_novel_writer = True
    preferred_intensity = "light"  # 小说作者推荐轻度改写
```

**原因**: 小说作者需要保留个人风格，只去除明显AI痕迹。

### 2. 显示模式自动调整

| 阶段 | 条件 | 显示模式 | 说明 |
|------|------|---------|------|
| **新手期** | total_uses <= 5 | `detailed` | 显示详细对比，帮助理解 |
| **熟悉期** | 6 <= total_uses <= 20 | `simplified` | 简化对比，提升效率 |
| **专家期** | total_uses > 20 AND accept_rate >= 80% | `silent` | 静默模式，直接返回改写 |

```python
def calculate_display_mode(self) -> str:
    """自动计算显示模式"""
    if self.total_uses <= 5:
        return "detailed"
    elif self.total_uses <= 20:
        return "simplified"
    elif self.accept_rate >= 0.8:
        return "silent"
    else:
        return "simplified"
```

### 3. 推荐强度智能调整

```python
def get_recommended_intensity(self) -> str:
    """基于用户画像推荐改写强度"""

    # 小说作者 → 轻度
    if self.is_novel_writer:
        return "light"

    # 新用户 → 中度
    if self.total_uses < 10:
        return "medium"

    # 根据接受率调整
    if self.accept_rate < 0.5:
        # 接受率低，降低强度
        return "light"
    elif self.accept_rate > 0.8:
        # 接受率高，可以更激进
        return "strong"
    else:
        return "medium"
```

## 📊 会话管理系统 (HumanizeSession)

### 功能概述

会话管理系统负责记录每次去痕迹化操作的完整信息，用于：
- 历史查询
- 成本追踪
- 效果分析
- 用户反馈收集

### 数据存储策略

**两表设计**:
1. **humanize_sessions** - 核心指标，永久保存
2. **humanize_session_details** - 详细数据，30天后自动清理

```python
class HumanizeSession(Base):
    """核心会话记录 - 永久保存"""

    # 核心指标
    score_before: float        # 改写前AI特征分数
    score_after: float         # 改写后AI特征分数
    improvement: float         # 改进幅度

    # 性能指标
    processing_time: float     # 处理耗时(秒)
    tokens_used: int           # 消耗token数
    cost: float                # 成本(美元)

    # 用户反馈
    user_accepted: bool        # 是否接受（null=未反馈）


class HumanizeSessionDetail(Base):
    """详细数据 - 30天后自动清理"""

    dimensions_before: dict    # 改写前五维度评分 (JSONB)
    dimensions_after: dict     # 改写后五维度评分 (JSONB)
    detected_patterns: list    # 检测到的AI痕迹列表 (JSONB)

    original_preview: str      # 原文预览（仅前100字）
    humanized_preview: str     # 改写预览（仅前100字）

    expires_at: datetime       # 过期时间（创建后30天）
```

**设计原因**:
- 核心指标永久保存 → 支持长期统计分析
- 详细数据定期清理 → 节省存储空间
- 保留预览文本 → 满足快速查看需求

## 💰 成本计算系统

### Token统计

**文件**: `backend/app/services/humanize_session_service.py`

```python
class HumanizeSessionService:
    """会话管理服务"""

    def create_session(
        self,
        user_id: UUID,
        detection_result: AIDetectionResult,
        humanized_text: str,
        verification: HumanizeVerification,
        processing_time: float,
        token_usage: dict  # 分阶段token统计
    ):
        """创建会话记录"""

        # 计算总token
        total_tokens = (
            token_usage.get("detection_tokens", 0) +
            token_usage.get("rewrite_tokens", 0) +
            token_usage.get("verification_tokens", 0)
        )

        # 估算成本
        cost = self._calculate_cost(token_usage)

        # 保存会话
        session = HumanizeSession(
            user_id=user_id,
            tokens_used=total_tokens,
            cost=cost,
            processing_time=processing_time,
            ...
        )
```

### 成本估算

**定价** (基于实际使用的AI模型):
- **快速模型** (gemini-2.5-flash-lite): $0.0000002/token
- **标准模型**: $0.000002/token

**分阶段计算**:
```python
def _calculate_cost(self, token_usage: dict) -> float:
    """计算总成本"""

    # 检测阶段（快速模型）
    detection_cost = (
        token_usage.get("detection_tokens", 0) * 0.0000002
    )

    # 改写阶段（标准模型）
    rewrite_cost = (
        token_usage.get("rewrite_tokens", 0) * 0.000002
    )

    # 验证阶段（快速模型）
    verification_cost = (
        token_usage.get("verification_tokens", 0) * 0.0000002
    )

    return detection_cost + rewrite_cost + verification_cost
```

**典型成本**:
- 500字文本 → 约$0.002 (0.2分)
- 2000字文本 → 约$0.008 (0.8分)

## 🕒 定时清理任务

### 配置

**文件**: `backend/app/tasks/cleanup_humanize_details.py`

```python
from apscheduler.schedulers.asyncio import AsyncIOScheduler

scheduler = AsyncIOScheduler()

@scheduler.scheduled_job('cron', hour=2, minute=0)
async def cleanup_expired_humanize_details():
    """每天凌晨2点清理过期详情数据"""

    async with get_db() as db:
        # 删除所有过期的详情记录
        result = await db.execute(
            delete(HumanizeSessionDetail)
            .where(HumanizeSessionDetail.expires_at < datetime.utcnow())
        )

        deleted_count = result.rowcount
        logger.info(f"清理了 {deleted_count} 条过期的humanize详情记录")
```

### 执行时间

- **时间**: 每天凌晨 2:00 UTC (北京时间 10:00)
- **任务**: 删除 `expires_at < 当前时间` 的所有详情记录
- **保留**: 核心会话记录（humanize_sessions）永久保留

## 🔄 完整处理流程

```
用户请求
   ↓
1. 检查用户画像
   - 全局开关是否启用？
   - 该功能是否启用？
   - 推荐强度是什么？
   ↓
2. 执行三阶段处理
   - 阶段1: 检测（FastAI）
   - 阶段2: 改写（标准AI）
   - 阶段3: 验证（FastAI，可选）
   ↓
3. 保存会话记录
   - 核心指标 → humanize_sessions（永久）
   - 详细数据 → humanize_session_details（30天）
   ↓
4. 更新用户画像
   - total_uses++
   - avg_text_length 滑动平均
   - 重新计算 display_mode
   ↓
5. 返回结果
   - detailed: 完整对比
   - simplified: 简化对比
   - silent: 仅改写文本
```

## ⚠️ 注意事项

### 1. 隐私保护
- 详情数据30天后自动删除
- 仅保留100字预览，不保存完整文本
- 用户可以手动关闭去痕迹化

### 2. 成本控制
- 使用快速模型进行检测和验证（成本低）
- 仅核心改写使用标准模型（保证质量）
- 低分文本直接跳过处理（节省成本）

### 3. 性能优化
- 异步处理，不阻塞请求
- 流式输出，实时反馈
- 定时任务在凌晨执行，避开高峰

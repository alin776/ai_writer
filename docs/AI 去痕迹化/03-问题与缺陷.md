| # | 缺陷 | 优先级 | 影响 | 预计改进效果 |

## 1. 检测维度不足 🔴

### 问题描述

**现状**: 只有3个维度
```python
dimensions = {
    "pattern_repetition": 模式重复,
    "word_choice": 词汇选择,
    "tone_style": 语气风格
}
```

**缺失的关键维度**:
1. ❌ `sentence_structure`: 句式结构（重要！）
2. ❌ `formatting`: 格式规范（列表化、分点）
3. ❌ `burstiness`: 词汇突发性（人类写作特征）
4. ❌ `perplexity`: 困惑度（AI检测核心指标）
5. ❌ `emotional_expression`: 情感表达
6. ❌ `coherence_flow`: 连贯性（过渡是否自然）

### 影响评估
- ❌ **检测准确率不足**: 可能漏检或误检
- ❌ **无法精确定位问题**: 不知道具体哪里像AI
- ❌ **改写缺乏针对性**: 不知道重点改哪里

### 改进方案
扩展到7+维度（详见 [05-改进方案.md](./05-改进方案.md#1-扩展检测维度)）

## 2. Prompt工程薄弱 🔴

### 2.1 检测Prompt问题

**当前prompt** (`DETECTION_PROMPT`):
```python
"""检测以下文本的AI特征,从3个核心维度评分:

**维度:**
1. **pattern_repetition (模式重复)**: 规整结构、重复句式
2. **word_choice (词汇风格)**: 过于书面化、缺乏口语
3. **tone_style (语气风格)**: 过于客观、缺少情感

**待检测文本:**
{text}
"""
```

**问题**:
- ❌ 过于简单，没有具体指导
- ❌ 缺少示例（few-shot learning）
- ❌ 没有明确AI特征列表
- ❌ 没有评分标准

**对比优秀prompt应该包含**:
```python
"""
1. 具体的AI痕迹列表:
   - "当然"、"很高兴为您服务"
   - "首先...其次...最后..."
   - 过度使用连接词

2. 评分标准:
   - 80-100分: 明显AI生成（3个以上特征）
   - 60-80分: 疑似AI（2个特征）
   - 0-60分: 人类写作

3. 示例（few-shot）:
   - 示例1: "当然，首先我们..." → score: 85
   - 示例2: "这事儿麻烦了..." → score: 30
"""
```

### 2.2 改写Prompt问题

**当前prompt** (`HUMANIZE_MEDIUM_PROMPT`):
```python
"""对以下AI文本进行中度去痕迹改写:

**策略:**
1. 打破AI模板 (避免"首先...其次...最后...")  # ← 太抽象！
2. 自然化用词 (减少书面语,增加口语)          # ← 没有具体例子
3. 增加不规则性 (句子长短不一)               # ← 如何操作？

**原文:**
{text}
"""
```

**问题**:
- ❌ **策略抽象**: "打破AI模板"如何操作？
- ❌ **缺少负面约束**: 没说禁止什么
- ❌ **无示例**: 没有before/after对比

**改进示例**:
```python
"""
**具体操作**:
1. 替换AI常用词:
   ❌ "首先" → ✅ 删除或用"先来看"
   ❌ "值得注意的是" → ✅ "要注意"
   ❌ "综上所述" → ✅ "总的来说"

2. 打破句式重复:
   ❌ 3句话长度相近 → ✅ 长短交替
   ❌ 每句都是陈述句 → ✅ 加入反问、感叹

3. 增加口语化:
   添加: "吧"、"呢"、"嘛"
   使用: 反问、省略、倒装

**禁止**:
- 不改变事实和观点
- 不添加新信息
- 不过度口语化（保持专业度）

**示例**:
原文: "首先，我们需要分析问题。其次，制定方案。"
改写: "先分析问题吧。然后，想想怎么解决。"
"""
```

### 影响评估
- ❌ **改写质量不稳定**: 依赖模型自己理解
- ❌ **效果不可控**: 不知道会改成什么样
- ❌ **成本浪费**: 模型"猜测"用户意图

### 改进方案
参考 [05-改进方案.md#2-优化prompt工程](./05-改进方案.md#2-优化prompt工程)

## 3. 缺少NLP技术支持 🔴

### 问题描述
**完全依赖LLM**，没有使用传统NLP技术辅助。

### 缺失的技术栈

| 技术 | 用途 | 优势 | GitHub项目 |
|------|------|------|-----------|
| **jieba** | 中文分词 | 精确识别词边界 | - |
| **synonyms** | 同义词替换 | 快速替换AI常用词 | CBIhalsen/text-rewriter |
| **spaCy** | 句法分析 | 识别句式结构 | AI-Text-Humanizer-App |
| **NLTK** | 词性标注 | 识别名词、动词 | AI-Text-Humanizer-App |
| **TextBlob** | 情感分析 | 判断情感倾向 | sadeepas/AI-Humanizer |

### 对比：规则引擎 vs 纯LLM

| 维度 | 规则引擎(NLP) | 纯LLM |
|------|-------------|-------|
| **成本** | ✅ 零（本地处理） | ❌ 高（每次调用） |
| **速度** | ✅ 毫秒级 | ❌ 秒级 |
| **精确度** | ✅ 100%（规则明确） | ⚠️ 80-90% |
| **灵活性** | ⚠️ 固定规则 | ✅ 理解上下文 |
| **可解释性** | ✅ 完全可追溯 | ❌ 黑盒 |

### 理想方案：双引擎驱动
```
输入文本
   ↓
规则引擎 (NLP) - 去除明显痕迹（快速、免费、精确）
   ↓
LLM深度改写 - 自然化处理（灵活、理解上下文）
   ↓
输出结果
```

### 示例对比

**纯LLM**:
```python
# 每次都要调用AI
text = "当然，首先我们需要分析问题。"
result = await ai_service.call(text)  # 消耗token
```

**规则引擎 + LLM**:
```python
# 先用规则快速处理
text = "当然，首先我们需要分析问题。"
text = text.replace("当然，", "")      # 0成本
text = text.replace("首先", "")        # 0成本
# 结果: "我们需要分析问题。"

# 再用AI深度优化
result = await ai_service.call(text)  # 消耗更少token
```

## 4. 没有分段处理 🟡

### 问题描述
对整篇文本一次性处理，长文本效果差。

### 问题示例

**场景**: 处理5000字的章节

**当前做法**:
```python
# 一次性发送全文
result = await humanize_service.humanize_stream(full_text_5000_chars)
```

**问题**:
1. ❌ **AI容易遗漏**: 后半部分处理质量下降
2. ❌ **上下文丢失**: 段落间连贯性被破坏
3. ❌ **Token浪费**: 每次重复发送全文
4. ❌ **超出限制**: 可能超过max_tokens

### 建议方案
```python
# 智能分段处理
segments = segmenter.segment(full_text)  # 按段落/句子分割

results = []
for segment in segments:
    result = await humanize_service.humanize_stream(segment)
    results.append(result)

final_text = segmenter.merge(results)  # 智能合并
```

### 改进方案
参考 [05-改进方案.md#4-添加分段处理](./05-改进方案.md#4-添加分段处理)

## 5. 检测器针对性不足 🟠

### 问题描述
泛化的prompt，没有针对特定检测工具优化。

### 主流检测工具特征

| 检测工具 | 核心指标 | 绕过策略 | 是否支持 |
|---------|---------|---------|---------|
| **GPTZero** | 困惑度(Perplexity) | 增加词汇变化 | ❌ |
| **Turnitin** | 相似度匹配 | 重构句式 | ❌ |
| **Originality.AI** | Token模式 | 避免高频模式 | ❌ |
| **Copyleaks** | 语义分析 | 改变表达方式 | ❌ |
| **通用** | 模式识别 | 去除套路 | ✅ 当前 |

### 建议API
```python
# 添加检测工具参数
result = await humanize_service.humanize_stream(
    text=text,
    intensity="medium",
    target_detector="gptzero"  # 新增参数
)
```

### 针对性Prompt示例
```python
DETECTOR_SPECIFIC_PROMPTS = {
    "gptzero": """
    针对GPTZero检测器:
    - 增加词汇多样性（降低困惑度）
    - 打乱句子长度（增加突发性）
    - 避免AI高频词汇
    """,

    "turnitin": """
    针对Turnitin检测器:
    - 完全重构句式
    - 同义词替换
    - 改变表达方式
    """
}
```

## 6. 缺少A/B测试和迭代机制 🟡

### 问题描述
没有系统化的效果评估，无法量化改进。

### 缺失内容
1. ❌ **未集成真实检测工具**: 只有内部评分，未用GPTZero验证
2. ❌ **无prompt版本管理**: prompt改了不知道哪个好
3. ❌ **无A/B测试框架**: 无法对比不同策略
4. ❌ **用户反馈未利用**: 收集了`user_accepted`但未用于优化

### 建议方案
```python
class HumanizeEvaluator:
    """效果评估器"""

    async def evaluate_with_real_detector(
        self,
        original: str,
        humanized: str,
        detector: str = "gptzero"
    ):
        """使用真实检测工具验证"""
        # 集成GPTZero API
        result = await gptzero_api.detect(humanized)
        return result.score

    async def ab_test_prompts(
        self,
        text: str,
        prompt_versions: List[str]
    ):
        """A/B测试不同prompt"""
        results = []
        for prompt in prompt_versions:
            humanized = await self.humanize_with_prompt(text, prompt)
            score = await self.evaluate_with_real_detector(humanized)
            results.append({"prompt": prompt, "score": score})
        return results
```

## 7. 用户体验问题 🟡

### 7.1 缺少预处理检查

**问题**: 没有检测文本是否已经是人类写作

```python
# 应该先检测来源
origin_check = await service.detect_text_origin(text)
if origin_check["is_human"]:
    return {
        "message": "文本疑似人类写作，无需去痕迹",
        "suggestion": "直接使用"
    }
```

### 7.2 缺少可视化对比

**问题**: 只返回改写后文本，看不出改了哪里

**建议**: 添加diff对比
```python
{
    "humanized_text": "...",
    "diff": [
        {"type": "delete", "text": "首先，", "reason": "AI套路"},
        {"type": "replace", "old": "值得注意的是", "new": "要注意"}
    ],
    "dimension_chart": {  # 雷达图数据
        "pattern_repetition": {"before": 80, "after": 40},
        "word_choice": {"before": 70, "after": 50}
    }
}
```

### 7.3 缺少批量处理

**问题**: 只支持单次处理

**建议**: 添加批量API
```python
@router.post("/batch")
async def humanize_batch(requests: List[HumanizeRequest]):
    results = []
    for req in requests:
        result = await humanize_service.humanize_stream(req.text)
        results.append(result)
    return results
```

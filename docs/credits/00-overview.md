# 积分系统概述

> ⚠️ **文档状态**: 这是**设计文档**，描述计划实现的积分系统功能。
>
> **实现状态**: 🔴 **未实现** - 后端服务、数据库模型、API接口、前端页面均未开发
>
> **最后更新**: 2025-12-02

---

## 1. 系统目标

为 AI Writer 平台提供积分管理功能，实现：
- **用户 AI 功能使用的计量计费** - 基于混合模型使用（60% Flash + 30% Pro + 10% Lite）
- **基于兑换码的充值机制** - 一次性兑换码，管理员生成
- **新用户赠送初始积分** - 5000 积分（可写约 5 万字）
- **邀请机制** - 封闭注册，邀请激活后奖励 1000 积分
- **管理员豁免** - 管理员使用 AI 功能不消耗积分

## 2. 核心功能

### 2.1 积分管理
- 查询当前余额
- 查看积分变动记录
- 积分永不过期（`CREDITS_EXPIRE_DAYS = 0`）

### 2.2 积分消费
- **管理员豁免检查** - 管理员用户跳过积分扣减
- AI 调用前检查余额（普通用户）
- 余额不足时拒绝服务
- 调用后按实际消耗扣减（基于混合模型计算）

### 2.3 积分充值
- 一次性兑换码兑换（3 个月有效期）
- 新用户注册自动赠送 5000 积分
- 邀请人激活奖励 1000 积分

### 2.4 邀请系统
- **封闭注册** - 必须有邀请码才能注册
- 每位用户最多生成 3 个邀请码
- 每个邀请码最多使用 10 次
- 邀请激活条件：被邀请人消费 200 积分 或 充值 1 积分（7 天内）
- 防刷机制：IP 限制（3/24h）、设备指纹限制（5/7d）
- 新用户冷却期：72 小时后才能邀请他人

### 2.5 管理功能
- 生成兑换码（管理员）
- 查看兑换码列表（管理员）
- 手动赠送积分（管理员）
- 批量生成邀请码（管理员）

## 3. 设计决策

| 决策项 | 选择 | 说明 |
|--------|------|------|
| 换算规则 | **1 USD = 12,400 积分** | 基于混合模型使用，1000 字 ≈ 100 积分 |
| 计费基准 | **混合模型** (60%F+30%P+10%L) | Flash 60%、Pro 30%、Lite 10% |
| 扣费模式 | 余额不足直接拒绝 | 简单可靠，无透支风险 |
| 管理员豁免 | **免扣费** | 管理员使用 AI 不消耗积分（仍记录日志） |
| 新用户赠送 | **5000 积分** | 混合模型可写约 5 万字 |
| 邀请奖励 | **1000 积分** | 邀请激活后奖励给邀请人 |
| 邀请激活条件 | 消费 200 积分 或 充值 1 积分 | 7 天内完成激活 |
| 注册方式 | **封闭注册** | 必须有邀请码才能注册 |
| 充值方式 | 一次性兑换码 | 管理员生成，用户自助兑换 |
| 积分有效期 | **永不过期** | `CREDITS_EXPIRE_DAYS = 0` |
| 兑换码有效期 | **90 天** | 3 个月有效期 |
| 积分精度 | 两位小数 | 如 5000.00 积分 |
| 兑换码格式 | 12位字母+数字 | 如 `AB3CDE5FGH7K` |

## 6. 积分流转流程

### 6.1 消费流程
```
用户发起 AI 请求
       │
       ▼
┌──────────────┐
│  检查用户角色 │
└──────────────┘
       │
       ├─── 管理员 ───▶ 跳过积分检查，直接执行 AI 调用
       │
       ▼ 普通用户
┌──────────────┐
│  检查余额     │
└──────────────┘
       │
       ├─── 余额不足 ───▶ 返回错误，提示充值
       │
       ▼ 余额充足
┌──────────────┐
│  执行 AI 调用 │
└──────────────┘
       │
       ▼
┌──────────────┐
│  计算消耗积分 │  (基于混合模型: 60%F+30%P+10%L)
└──────────────┘  (CostCalculator USD → Credits)
       │
       ├─── 管理员 ───▶ 记录日志但不扣减积分
       │
       ▼ 普通用户
┌──────────────┐
│  扣减积分     │
└──────────────┘
       │
       ▼
┌──────────────┐
│  记录交易     │
└──────────────┘
```

### 6.2 充值流程
```
用户输入兑换码
       │
       ▼
┌──────────────┐
│  验证兑换码   │
└──────────────┘
       │
       ├─── 无效/已使用/过期 ───▶ 返回错误
       │
       ▼ 有效
┌──────────────┐
│  增加积分     │
└──────────────┘
       │
       ▼
┌──────────────┐
│  标记已使用   │
└──────────────┘
       │
       ▼
┌──────────────┐
│  记录交易     │
└──────────────┘
```

### 6.3 邀请流程
```
用户 A 生成邀请码
       │
       ▼
┌──────────────────┐
│  验证生成权限     │
└──────────────────┘
       │
       ├─── 超过3个码 ───▶ 返回错误
       ├─── 新用户冷却期未过 ───▶ 返回错误
       │
       ▼ 通过验证
┌──────────────────┐
│  创建邀请码       │
└──────────────────┘
       │
       │ (用户 B 使用邀请码注册)
       ▼
┌──────────────────┐
│  验证邀请码       │
└──────────────────┘
       │
       ├─── 无效/已满/过期 ───▶ 返回错误
       ├─── IP/设备限制 ───▶ 返回错误
       │
       ▼ 通过验证
┌──────────────────┐
│  用户 B 注册成功  │
│  赠送 5000 积分   │
└──────────────────┘
       │
       ▼
┌──────────────────┐
│  记录邀请关系     │
│  (status=pending) │
└──────────────────┘
       │
       │ (用户 B 在 7 天内消费 200 积分或充值 1 积分)
       ▼
┌──────────────────┐
│  检测激活条件     │
└──────────────────┘
       │
       ▼ 激活成功
┌──────────────────┐
│  用户 A 获得      │
│  1000 积分奖励    │
└──────────────────┘
       │
       ▼
┌──────────────────┐
│  更新邀请状态     │
│  (status=active)  │
└──────────────────┘
```

## 7. 成本示例

### 7.1 混合模型使用成本

基于混合使用模型（60% Flash + 30% Pro + 10% Lite）：

| 字数 | 所需积分 | 约等于 USD |
|------|---------|-----------|
| 1,000 字 | 100 积分 | $0.008 |
| 10,000 字 | 1,000 积分 | $0.081 |
| 50,000 字 | 5,000 积分 | $0.403 |
| 100,000 字 | 10,000 积分 | $0.806 |

### 7.2 纯模型使用成本对比

| 模型 | 1,000 字 | 10,000 字 | 50,000 字 |
|------|---------|----------|----------|
| Flash | 54 积分 | 540 积分 | 2,700 积分 |
| **混合** | **100 积分** | **1,000 积分** | **5,000 积分** |
| Pro | 220 积分 | 2,200 积分 | 11,000 积分 |
| Lite | 18 积分 | 180 积分 | 900 积分 |

### 7.3 新用户使用示例

**场景**: 新用户注册获得 5000 积分

- **混合模型**: 约可写 50,000 字
- **纯 Flash**: 约可写 92,600 字
- **纯 Pro**: 约可写 22,700 字
- **纯 Lite**: 约可写 277,800 字

**推荐**: 建议用户根据需求灵活选择模型，重要内容使用 Pro，日常写作使用 Flash。

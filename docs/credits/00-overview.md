# 积分系统概述

> ⚠️ **文档状态**: 这是**设计文档**，描述计划实现的积分系统功能。
>
> **实现状态**: 🔴 **未实现** - 后端服务、数据库模型、API接口、前端页面均未开发
>
> **最后更新**: 2025-12-02

---

## 1. 系统目标

为 AI Writer 平台提供积分管理功能，实现：
- 用户 AI 功能使用的计量计费
- 基于兑换码的充值机制
- 新用户赠送初始积分

## 2. 核心功能

### 2.1 积分管理
- 查询当前余额
- 查看积分变动记录
- 积分有效期管理

### 2.2 积分消费
- AI 调用前检查余额
- 余额不足时拒绝服务
- 调用后按实际消耗扣减

### 2.3 积分充值
- 一次性兑换码兑换
- 新用户注册自动赠送

### 2.4 管理功能
- 生成兑换码（管理员）
- 查看兑换码列表（管理员）
- 手动赠送积分（管理员）

## 3. 设计决策

| 决策项 | 选择 | 说明 |
|--------|------|------|
| 换算规则 | 可配置 | `CREDITS_PER_DOLLAR` 配置项 |
| 扣费模式 | 余额不足直接拒绝 | 简单可靠，无透支风险 |
| 新用户赠送 | 可配置 | `NEW_USER_GIFT_CREDITS` 配置项 |
| 充值方式 | 一次性兑换码 | 管理员生成，用户自助兑换 |
| 积分有效期 | 可配置 | `CREDITS_EXPIRE_DAYS` 配置项 |
| 积分精度 | 两位小数 | 如 99.50 积分 |
| 兑换码格式 | 12位字母+数字 | 如 `AB12CD34EF56` |

## 5. 与现有系统的关系

### 5.1 依赖的现有模块
- `User` 模型 - 用户关联
- `AICallLog` 模型 - 成本计算依据
- `CostCalculator` - 美元成本计算
- `AILogService` - AI 调用日志

### 5.2 需要修改的模块
- `user_service.py` - 新用户注册时赠送积分
- `langgraph_agent.py` - AI 调用前检查余额、调用后扣减

## 6. 积分流转流程

### 6.1 消费流程
```
用户发起 AI 请求
       │
       ▼
┌──────────────┐
│  检查余额     │
└──────────────┘
       │
       ├─── 余额不足 ───▶ 返回错误，提示充值
       │
       ▼ 余额充足
┌──────────────┐
│  执行 AI 调用 │
└──────────────┘
       │
       ▼
┌──────────────┐
│  计算消耗积分 │  (基于 CostCalculator + CREDITS_PER_DOLLAR)
└──────────────┘
       │
       ▼
┌──────────────┐
│  扣减积分     │
└──────────────┘
       │
       ▼
┌──────────────┐
│  记录交易     │
└──────────────┘
```

### 6.2 充值流程
```
用户输入兑换码
       │
       ▼
┌──────────────┐
│  验证兑换码   │
└──────────────┘
       │
       ├─── 无效/已使用/过期 ───▶ 返回错误
       │
       ▼ 有效
┌──────────────┐
│  增加积分     │
└──────────────┘
       │
       ▼
┌──────────────┐
│  标记已使用   │
└──────────────┘
       │
       ▼
┌──────────────┐
│  记录交易     │
└──────────────┘
```

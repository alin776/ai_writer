# AI Writer 核心业务流程

> 本文档展示系统的核心业务流程

## 1. 用户认证流程

```mermaid
sequenceDiagram
    participant U as 用户浏览器
    participant F as 前端应用
    participant A as 认证API
    participant DB as 数据库

    Note over U,DB: 用户注册流程
    U->>F: 填写注册信息
    F->>A: POST /api/v1/auth/register
    A->>A: 验证用户名/邮箱唯一性
    A->>A: 加密密码 (bcrypt)
    A->>DB: 创建用户记录
    DB-->>A: 返回用户信息
    A-->>F: 返回用户数据
    F-->>U: 注册成功,跳转登录

    Note over U,DB: 用户登录流程
    U->>F: 输入用户名/密码
    F->>A: POST /api/v1/auth/login
    A->>DB: 查询用户
    DB-->>A: 返回用户信息
    A->>A: 验证密码
    A->>A: 生成 JWT Token
    A->>DB: 更新最后登录时间
    A-->>F: 返回 access_token + refresh_token
    F->>F: 保存 Token 到 localStorage
    F-->>U: 登录成功,进入主页

    Note over U,DB: Token 刷新流程
    F->>A: POST /api/v1/auth/refresh
    A->>A: 验证 refresh_token
    A->>A: 生成新的 access_token
    A-->>F: 返回新的 Token 对
    F->>F: 更新 localStorage
```

## 2. 作品创作流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端
    participant API as 作品API
    participant S as 作品服务
    participant DB as 数据库

    Note over U,DB: 创建作品
    U->>F: 点击"新建作品"
    F->>API: POST /api/v1/works
    API->>S: 调用 create_work()
    S->>DB: 插入作品记录
    DB-->>S: 返回作品ID
    S-->>API: 返回作品详情
    API-->>F: 返回创建结果
    F-->>U: 显示作品详情页

    Note over U,DB: 创建章节
    U->>F: 点击"新建章节"
    F->>API: POST /api/v1/chapters
    API->>S: 调用 create_chapter()
    S->>DB: 插入章节记录
    S->>DB: 更新作品统计 (章节数/字数)
    DB-->>S: 返回章节ID
    S-->>API: 返回章节详情
    API-->>F: 返回创建结果
    F-->>U: 显示章节编辑器

    Note over U,DB: 编辑章节
    U->>F: 输入章节内容
    F->>F: 自动保存草稿 (每30秒)
    F->>API: PUT /api/v1/chapters/{id}
    API->>S: 调用 update_chapter()
    S->>S: 计算字数
    S->>DB: 更新章节内容
    S->>DB: 更新作品统计
    DB-->>S: 确认更新
    S-->>API: 返回更新结果
    API-->>F: 保存成功
    F-->>U: 显示"已保存"提示
```

## 3. AI 改写竞技场流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端
    participant API as AI API
    participant RA as RewriteArena
    participant AI1 as Gemini
    participant AI2 as GPT-4
    participant AI3 as GPT-3.5
    participant DB as 数据库

    U->>F: 选中文本,点击"AI改写"
    F->>API: POST /api/v1/ai/rewrite-arena/analyze
    API->>RA: 分析文本质量
    RA->>AI1: 调用 Gemini 分析
    AI1-->>RA: 返回质量评分
    RA-->>API: 返回分析结果
    API-->>F: 显示质量评分和建议
    F-->>U: 显示分析报告

    U->>F: 选择改写模式,点击"开始改写"
    F->>F: 显示加载动画
    F->>API: POST /api/v1/ai/rewrite-arena/rewrite

    Note over RA,AI3: 并发调用多个模型
    par 模型1
        API->>RA: 调用改写服务
        RA->>AI1: Gemini 改写
        AI1-->>RA: 返回改写结果1
    and 模型2
        RA->>AI2: GPT-4 改写
        AI2-->>RA: 返回改写结果2
    and 模型3
        RA->>AI3: GPT-3.5 改写
        AI3-->>RA: 返回改写结果3
    end

    RA->>RA: 汇总所有结果
    RA->>DB: 保存改写会话和结果
    RA-->>API: 返回所有改写版本
    API-->>F: 返回多个结果
    F-->>U: 展示3个改写版本供选择

    U->>F: 选择最佳版本
    F->>API: POST /api/v1/rewrite-history/select
    API->>DB: 标记选中结果
    F->>F: 替换编辑器中的文本
    F-->>U: 应用改写结果
```

## 4. 知识库管理流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端
    participant API as 知识库API
    participant KS as 知识库服务
    participant VS as 向量存储
    participant DB as 数据库

    Note over U,DB: 创建知识库
    U->>F: 点击"新建知识库"
    F->>API: POST /api/v1/knowledge/bases
    API->>KS: 创建知识库
    KS->>DB: 插入知识库记录
    DB-->>KS: 返回知识库ID
    KS-->>API: 返回知识库信息
    API-->>F: 创建成功
    F-->>U: 显示知识库详情

    Note over U,DB: 添加知识条目
    U->>F: 输入知识内容
    F->>API: POST /api/v1/knowledge/items
    API->>KS: 添加知识条目
    KS->>KS: 提取文本内容
    KS->>VS: 生成向量嵌入
    VS-->>KS: 返回向量
    KS->>DB: 保存知识条目+向量
    KS->>DB: 更新知识库统计
    DB-->>KS: 确认保存
    KS-->>API: 返回条目信息
    API-->>F: 添加成功
    F-->>U: 显示新条目

    Note over U,DB: 语义搜索
    U->>F: 输入搜索关键词
    F->>API: POST /api/v1/knowledge/search
    API->>KS: 执行语义搜索
    KS->>VS: 将关键词向量化
    VS-->>KS: 返回查询向量
    KS->>VS: 向量相似度搜索
    VS->>DB: 查询最相似的向量
    DB-->>VS: 返回匹配的条目ID
    VS-->>KS: 返回搜索结果
    KS->>DB: 获取条目详情
    DB-->>KS: 返回条目数据
    KS-->>API: 返回搜索结果
    API-->>F: 返回匹配条目
    F-->>U: 显示搜索结果
```

## 5. 小说分析流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端
    participant API as 分析API
    participant O as Orchestrator
    participant MA as 宏观分析
    participant MI as 微观分析
    participant AI as AI服务
    participant DB as 数据库

    U->>F: 点击"分析小说"
    F->>API: POST /api/v1/novel-analysis/analyze
    API->>O: 启动分析任务
    O->>DB: 获取章节内容
    DB-->>O: 返回章节列表

    Note over O,AI: 并行执行分析
    par 宏观分析
        O->>MA: 分析整体结构
        MA->>AI: 调用 AI 宏观分析
        AI-->>MA: 返回结构分析
        MA->>AI: 分析人物塑造
        AI-->>MA: 返回人物分析
        MA->>AI: 分析世界观
        AI-->>MA: 返回世界观分析
        MA-->>O: 返回宏观报告
    and 微观分析
        O->>MI: 分析文笔质量
        MI->>AI: 调用 AI 微观分析
        AI-->>MI: 返回文笔分析
        MI->>AI: 分析节奏把控
        AI-->>MI: 返回节奏分析
        MI->>AI: 分析细节描写
        AI-->>MI: 返回细节分析
        MI-->>O: 返回微观报告
    end

    O->>O: 合并分析结果
    O->>O: 生成改进建议
    O->>DB: 保存分析报告
    O-->>API: 返回完整报告
    API-->>F: 返回分析结果
    F-->>U: 展示分析报告

    U->>F: 查看某个维度详情
    F-->>U: 展开详细分析和建议
```

## 6. 导入导出流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端
    participant API as 导入导出API
    participant IS as 导入服务
    participant ES as 导出服务
    participant COS as 腾讯云COS
    participant DB as 数据库

    Note over U,DB: 导入作品
    U->>F: 选择 TXT/DOCX 文件
    F->>API: POST /api/v1/import (multipart/form-data)
    API->>IS: 处理导入文件
    IS->>IS: 解析文件内容
    IS->>IS: 智能分章检测
    IS->>DB: 创建作品
    IS->>DB: 批量创建章节
    DB-->>IS: 确认创建
    IS-->>API: 返回导入结果
    API-->>F: 返回作品信息
    F-->>U: 显示"导入成功"

    Note over U,DB: 导出作品
    U->>F: 选择导出格式 (TXT/DOCX/PDF)
    F->>API: POST /api/v1/export/{work_id}
    API->>ES: 执行导出
    ES->>DB: 获取作品和章节
    DB-->>ES: 返回完整内容
    ES->>ES: 生成导出文件
    ES->>COS: 上传到对象存储
    COS-->>ES: 返回下载URL
    ES-->>API: 返回下载链接
    API-->>F: 返回文件URL
    F->>F: 触发文件下载
    F-->>U: 下载文件到本地
```

## 7. WebSocket 实时通信

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端
    participant WS as WebSocket服务
    participant AI as AI服务
    participant Cache as Redis

    U->>F: 打开编辑页面
    F->>WS: 建立 WebSocket 连接
    WS-->>F: 连接成功

    Note over U,Cache: 实时协作
    U->>F: 编辑文本
    F->>WS: 发送编辑事件
    WS->>Cache: 更新在线状态
    WS->>WS: 广播给其他用户
    WS-->>F: 推送更新
    F-->>U: 实时显示其他用户编辑

    Note over U,Cache: 流式AI生成
    U->>F: 请求 AI 生成
    F->>WS: 发送生成请求
    WS->>AI: 调用 AI (流式输出)

    loop 流式返回
        AI-->>WS: 返回文本片段
        WS-->>F: 推送文本片段
        F-->>U: 实时显示生成内容
    end

    AI-->>WS: 生成完成
    WS-->>F: 发送完成信号
    F-->>U: 显示"生成完成"
```

## 业务规则说明

### 权限规则
1. **用户只能操作自己的资源** (作品/章节/知识库)
2. **管理员可以查看所有资源** (待实现)
3. **未登录用户只能访问公开接口** (注册/登录)

### 数据规则
1. **作品删除**: 级联删除所有章节
2. **章节更新**: 自动更新作品统计 (总字数/章节数)
3. **知识库删除**: 级联删除所有知识条目

### 业务规则
1. **章节字数**: 自动计算,不需手动输入
2. **改写历史**: 保留最近 30 天
3. **导出文件**: 临时文件保留 24 小时

# AI Writer AI 服务架构

> AI 服务是系统的核心,提供多种智能写作辅助功能

## 架构概览

AI 服务采用**分层设计**:
- **API 层**: 接收用户请求
- **服务编排层**: 协调多个 AI 服务
- **核心服务层**: 与 AI API 交互
- **专业分析层**: 专门的分析服务
- **Prompt 管理**: 提示词模板管理

## 6. 改写竞技场工作流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant API as API层
    participant RA as RewriteArena
    participant AI1 as Gemini
    participant AI2 as GPT-4
    participant AI3 as GPT-3.5
    participant DB as 数据库

    U->>API: 提交改写请求
    API->>RA: 调用改写服务

    Note over RA,AI3: 并发调用多个模型
    par 模型1
        RA->>AI1: 改写文本
        AI1-->>RA: 返回结果1
    and 模型2
        RA->>AI2: 改写文本
        AI2-->>RA: 返回结果2
    and 模型3
        RA->>AI3: 改写文本
        AI3-->>RA: 返回结果3
    end

    RA->>RA: 汇总所有结果
    RA->>DB: 保存改写会话
    RA-->>API: 返回所有结果
    API-->>U: 展示3个版本

    U->>API: 选择最佳版本
    API->>DB: 标记选中结果
```

**改写竞技场特点**:
- ✅ **并发执行**: asyncio.gather() 同时调用
- ✅ **容错处理**: 部分失败不影响其他
- ✅ **性能追踪**: 记录每个模型耗时
- ✅ **用户反馈**: 保存用户选择供分析

        MI->>AI: 分析细节

**小说分析维度**:

### 宏观分析
- **整体结构**: 开头、发展、高潮、结尾

- **世界观**: 设定完整性、逻辑自洽

### 微观分析
- **文笔质量**: 词汇、句式、修辞
- **节奏把控**: 叙事节奏、对话节奏
- **细节描写**: 环境、动作、心理

    if task_type == "analysis" or quality_required == "high":

        return "gpt-3.5-turbo"
    elif task_type == "creative_writing":
        return "gemini-2.5-pro"

        return "gpt-3.5-turbo"  # 默认

## 11. 性能优化策略

```mermaid
graph TB
    A[性能优化] --> B[并发处理]
    A --> C[缓存机制]
    A --> D[Token优化]
    A --> E[成本控制]

    B --> B1[asyncio.gather<br/>并发调用]
    B --> B2[连接池复用]

    C --> C1[Redis缓存<br/>相同请求]
    C --> C2[本地缓存<br/>Prompt模板]

    D --> D1[智能裁剪<br/>上下文]
    D --> D2[分段处理<br/>长文本]

    E --> E1[模型降级<br/>简单任务用便宜模型]
    E --> E2[请求限流<br/>防止费用失控]

    style A fill:#fff3e0
    style B fill:#e8f5e9
    style C fill:#e1bee7
    style D fill:#bbdefb
    style E fill:#ffe082
```

**优化措施详解**:

### 1. 并发处理
```python
# 并发调用多个模型
results = await asyncio.gather(
    model1.rewrite(text),
    model2.rewrite(text),
    model3.rewrite(text),
    return_exceptions=True  # 容错
)
```

### 2. 缓存机制
- **Redis 缓存**: 缓存相同请求的结果
- **TTL 设置**: 24 小时过期
- **缓存键**: `ai:rewrite:{hash(text+mode)}`

### 3. Token 优化
- **上下文裁剪**: 只保留关键信息
- **分段处理**: 长文本拆分处理
- **增量更新**: 只处理变化部分

### 4. 成本控制
- **模型降级**: 简单任务使用 GPT-3.5
- **请求限流**: 每用户每分钟限制
- **预算告警**: 费用超标自动通知

## 12. 错误处理流程

```mermaid
graph TB
    A[AI 调用] --> B{是否成功?}
    B -->|成功| C[返回结果]
    B -->|失败| D{错误类型}

    D -->|Rate Limit| E[指数退避重试]
    D -->|Timeout| F[超时重试]
    D -->|Invalid Request| G[参数检查]
    D -->|API Error| H[切换备用模型]

    E --> I{重试次数}
    F --> I
    I -->|< 3次| A
    I -->|>= 3次| J[返回错误]

    G --> J
    H --> A

    style C fill:#90EE90
    style J fill:#FFB6C1
```

**错误处理策略**:
- **限流错误**: 指数退避 (1s, 2s, 4s)
- **超时错误**: 最多重试 3 次
- **参数错误**: 记录日志,返回错误
- **API 错误**: 切换备用模型

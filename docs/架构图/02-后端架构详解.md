# AI Writer 后端架构详解

> 后端基于 FastAPI 构建,采用分层架构设计

## 架构概览

后端采用**分层架构**设计,从上到下分为:
- **API 路由层**: 处理 HTTP 请求
- **业务服务层**: 实现业务逻辑
- **AI 服务层**: AI 智能功能
- **数据模型层**: 数据库模型
- **数据访问层**: 数据库和缓存
- **核心层**: 配置和工具

```mermaid
sequenceDiagram
    participant C as 客户端
    participant M as 中间件
    participant R as 路由层
    participant S as 服务层
    participant AI as AI层
    participant DB as 数据库

    C->>M: HTTP 请求
    M->>M: CORS 检查
    M->>M: JWT 认证
    M->>R: 路由分发
    R->>R: 参数验证
    R->>S: 调用服务
    S->>AI: 调用 AI (可选)
    AI-->>S: AI 结果
    S->>DB: 数据操作
    DB-->>S: 返回数据
    S-->>R: 业务结果
    R-->>M: 构造响应
    M-->>C: HTTP 响应
```

## 核心模块说明

### 1. API 路由层 (Routes)
- **职责**: 处理 HTTP 请求,参数验证,调用业务服务
- **特点**: RESTful API 设计,支持 WebSocket
- **技术**: FastAPI Router, Pydantic 数据验证

### 2. 业务服务层 (Services)
- **职责**: 实现核心业务逻辑,协调各个模块
- **特点**: 无状态服务,可复用
- **技术**: 异步服务,依赖注入

### 3. AI 服务层
- **职责**: 与 AI 模型交互,提供智能功能
- **特点**: 支持多模型,异步并发
- **技术**: asyncio, aiohttp, OpenAI API

### 4. 数据模型层 (Models)
- **职责**: 定义数据库表结构和关系
- **技术**: SQLAlchemy (ORM), 异步支持

### 5. 数据访问层
- **PostgreSQL**: 主数据库,存储结构化数据
- **Redis**: 缓存层,提升性能
- **VectorStore**: 向量存储,支持语义搜索

### 6. 核心层 (Core)
- **config.py**: 环境变量管理,应用配置
- **database.py**: 数据库连接池,异步会话管理
- **deps.py**: 依赖注入,认证依赖
- **security.py**: JWT 令牌,密码加密

## 关键特性

### 异步架构
- 全异步 I/O 操作
- 异步数据库访问 (asyncpg)
- 异步 HTTP 请求 (aiohttp)
- 提升并发性能

### 依赖注入
```python
async def get_current_user(
    db: AsyncSession = Depends(get_db),
    token: str = Depends(oauth2_scheme)
) -> User:
    # 认证逻辑
    pass
```

### 中间件
- **CORS 中间件**: 跨域支持
- **认证中间件**: JWT 验证
- **日志中间件**: 请求日志
- **异常处理中间件**: 统一错误处理

### 生命周期管理
```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    # 启动时
    await init_db()
    start_scheduler()

    yield

    # 关闭时
    await close_db()
    stop_scheduler()
```

## 性能优化

1. **数据库连接池**: 复用连接,减少开销
2. **Redis 缓存**: 缓存热点数据
3. **异步 I/O**: 提升并发性能
4. **索引优化**: 数据库查询优化
5. **模型预加载**: Embedding 模型启动时加载

---

## 安全措施

1. **JWT 认证**: 无状态认证
2. **密码加密**: bcrypt 哈希
3. **CORS 配置**: 跨域白名单
4. **SQL 注入防护**: ORM 参数化查询
5. **XSS 防护**: 输入验证和转义

## 🛠️ 架构特点

### 1. 分层架构
- **表现层**: 前端 Vue.js/React
- **API 层**: FastAPI 路由
- **业务层**: 服务化设计
- **数据层**: PostgreSQL + Redis + VectorStore

### 2. 微服务化
- 各业务模块独立服务
- 服务间松耦合
- 易于扩展和维护

### 3. 异步优化
- 全异步 I/O
- 异步数据库访问
- AI 并发调用
- 提升并发性能

### 4. AI 驱动
- 多模型支持
- 智能改写
- 质量分析
- 知识库检索

### 5. 缓存优化
- Redis 缓存热点数据
- 本地缓存 Prompt
- 向量缓存
- 提升响应速度

## 📊 系统组成

### 核心模块

| 模块 | 功能 | 技术栈 |
|------|------|--------|
| 用户系统 | 注册/登录/认证 | JWT, bcrypt |
| 作品管理 | 创建/编辑/发布作品 | SQLAlchemy, PostgreSQL |
| 章节管理 | 章节编辑/排序 | 富文本编辑器 |

| AI 分析 | 小说质量分析 | GPT-4 |
| 知识库 | 语义搜索 | Sentence Transformers |
| 导入导出 | TXT/DOCX/PDF | python-docx, reportlab |
| 实时通信 | WebSocket | FastAPI WebSocket |

| 服务 | 用途 | 官网 |
|------|------|------|

## 🔄 数据流向

### 用户请求流
```
浏览器 → 前端应用 → FastAPI → 中间件 → 路由 → 服务层 → 数据库
```

### AI 处理流
```
前端 → API → AI服务层 → 模型选择 → 外部AI API → 返回结果 → 缓存 → 前端
```

### 知识库检索流
```
前端 → API → 知识库服务 → 向量化 → 向量检索 → PostgreSQL → 返回结果
```

## 📈 性能指标

### 目标性能
- **API 响应时间**: < 200ms (不含 AI 调用)
- **AI 改写时间**: 1-3 秒 (单模型)
- **并发用户**: 支持 1000+ 并发
- **数据库连接池**: 20-50 连接

### 性能优化手段
1. **数据库连接池**: 复用连接
2. **Redis 缓存**: 缓存热点数据
3. **异步 I/O**: 提升并发
4. **索引优化**: 加速查询
5. **CDN**: 静态资源加速
6. **负载均衡**: 水平扩展

## 🔐 安全措施

### 认证和授权
- **JWT Token**: 无状态认证
- **密码加密**: bcrypt 哈希
- **Token 刷新**: refresh_token 机制

### 数据安全
- **SQL 注入防护**: ORM 参数化查询
- **XSS 防护**: 输入验证和转义
- **CSRF 防护**: CSRF Token
- **CORS 配置**: 跨域白名单

### API 安全
- **请求限流**: 防止 DDoS
- **参数验证**: Pydantic 数据验证
- **错误处理**: 不暴露敏感信息
- **日志审计**: 记录所有操作

## 🚀 部署架构

### 开发环境
- **前端**: Vite 开发服务器 (5173)
- **后端**: Uvicorn (8000)
- **数据库**: 本地 PostgreSQL (5432)
- **缓存**: 本地 Redis (6379)

### 生产环境
```
用户 → CDN → Nginx → 负载均衡 → FastAPI集群
                                    ↓
                                数据库主从
                                    ↓
                                 Redis集群
```

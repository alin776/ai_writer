# AI Writer 系统整体架构

> 本文档展示 AI Writer 项目的整体系统架构

## 架构概览

AI Writer 是一个**前后端分离**的 Web 应用,采用现代化的技术栈:
- **前端**: Vue.js/React + Vite
- **后端**: FastAPI (Python)
- **数据库**: PostgreSQL + Redis
- **AI 引擎**: OpenAI/Google Gemini
- **对象存储**: 腾讯云 COS

## 技术栈详细说明

### 前端技术栈
- **框架**: Vue.js 3.x / React
- **构建工具**: Vite
- **HTTP 客户端**: Axios
- **状态管理**: Pinia / Redux
- **UI 框架**: Element Plus / Ant Design
- **路由**: Vue Router / React Router

### 后端技术栈
- **Web 框架**: FastAPI (Python 3.11+)
- **异步支持**: asyncio, aiohttp
- **ORM**: SQLAlchemy (async)
- **认证**: JWT (JSON Web Token)
- **数据验证**: Pydantic
- **定时任务**: APScheduler

### 数据库技术栈
- **关系数据库**: PostgreSQL 15+
- **缓存数据库**: Redis 7+ (Memurai on Windows)
- **向量数据库**: 本地向量存储 (Sentence Transformers)

### AI 技术栈
- **统一 AI 服务**: OpenAI 兼容接口(单一 baseURL)
  - 模型: `gpt-5`、`gemini-2.5-pro`、`gemini-2.5-flash`
- **Embedding 模型**: Sentence Transformers
- **向量化**: 自定义向量存储

### 基础设施
- **对象存储**: 腾讯云 COS
- **日志**: Python logging
- **环境管理**: dotenv
- **API 文档**: Swagger UI (FastAPI 自带)

## 系统特点

### 1. 前后端分离
- 前端和后端独立开发、部署
- 通过 RESTful API 通信
- 支持 WebSocket 实时通信

### 2. 微服务设计
- 业务层服务化,职责清晰
- 服务间松耦合,易于扩展
- 支持独立测试和部署

### 3. 异步优化
- 全异步 I/O 操作
- 异步数据库访问 (asyncpg)
- 异步 HTTP 请求 (aiohttp)
- 提升并发性能

### 4. AI 驱动
- 多个 AI 引擎支持
- 智能改写、分析、评估
- 多模型对比选择

### 5. 缓存优化
- Redis 缓存热点数据
- AI 结果缓存
- 提升响应速度

### 6. 向量检索
- 支持语义搜索
- 知识库智能检索
- 上下文相关推荐

## 性能指标

### 目标性能
- **API 响应时间**: < 200ms (不含 AI 调用)
- **AI 改写时间**: 1-3 秒 (单模型)
- **并发用户**: 支持 1000+ 并发
- **数据库连接池**: 20-50 连接

### 性能优化措施
1. **数据库连接池**: 复用连接
2. **Redis 缓存**: 缓存热点数据
3. **异步 I/O**: 提升并发
4. **CDN 加速**: 静态资源加速
5. **负载均衡**: 水平扩展

## 安全措施

### 认证和授权
- **JWT Token**: 无状态认证
- **密码加密**: bcrypt 哈希
- **Token 刷新**: refresh_token 机制

### 数据安全
- **SQL 注入防护**: ORM 参数化查询
- **XSS 防护**: 输入验证和转义
- **CSRF 防护**: CSRF Token
- **CORS 配置**: 跨域白名单

### API 安全
- **请求限流**: 防止 DDoS
- **参数验证**: Pydantic 数据验证
- **错误处理**: 不暴露敏感信息
- **日志审计**: 记录所有操作

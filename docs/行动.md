启动 Redis Stack
netstat -ano | findstr :6379 得到端口号
taskkill /PID 7804 /F
wsl docker start redis-stack
wsl docker exec redis-stack redis-cli MODULE LIST Redis Stack模块是否加载成功
wsl docker ps | grep redis

问题是 Redis 绑定到 WSL 内部的 127.0.0.1，Windows 无法访问。需要改为 0.0.0.0 绑定：


如果容器已存在但停止了，直接启动
  wsl docker start redis-stack

如果容器不存在，创建并启动（首次使用或删除后）
  wsl docker run -d --name redis-stack -p 0.0.0.0:6379:6379 -p 0.0.0.0:8001:8001 -v redis-stack-data:/data
  redis/redis-stack:latest

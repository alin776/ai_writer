## 🔍 关键发现

经过深度分析后端API和前端代码，发现了一个**关键问题**：

### 问题：AIService未使用后端的自定义prompt功能

**后端情况：**
- `/api/v1/ai/complete` API **已经支持自定义prompt**
- 通过 `prompt` 参数即可传递自定义提示词

**前端情况：**
- `src/services/AIService.ts` (第196-201行) 将 `prompt` 参数**写死为 `'续写'`**
- 导致无法使用自定义提示词功能

**影响：**
- Add to Chat 和 Quick Edit 两个功能都依赖自定义prompt
- **必须先修复AIService，才能开始功能开发**

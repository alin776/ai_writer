## 📅 详细时间线

### 阶段零：准备工作 - 修复AIService（第0周，1-2天）⚠️ **必须先完成**

**背景说明：**
经过详细分析发现，后端 `/api/v1/ai/complete` API **已经支持自定义prompt**，但前端 `AIService.ts` 将 `prompt` 参数写死为 `'续写'`，导致无法使用自定义提示词。

**Day 1: 修改 AIService.ts**

**目标文件：** `src/services/AIService.ts` (第196-201行)

**当前代码（有问题）：**
```typescript
const requestBody = {
  context: request.context || request.prompt,
  prompt: '续写',  // ⚠️ 写死了！
  style: '',
  max_tokens: maxTokens,
};
```

**修改后（正确）：**
```typescript
// 1. 修改 AICompletionRequest 接口
export interface AICompletionRequest {
  prompt: string;           // 用户提示词
  context?: string;         // 上下文（可选）
  maxTokens?: number;
  temperature?: number;
  model?: string;
  customPrompt?: string;    // ← 新增：自定义提示词（用于AI操作）
}

// 2. 修改 complete 方法
async complete(
  request: AICompletionRequest,
  onChunk?: (chunk: string) => void
): Promise<string> {
  try {
    const apiUrl = `${this.baseUrl}/ai/complete`;
    const token = this.getAuthToken();
    const maxTokens = Math.max(request.maxTokens || 500, 100);

    // ✅ 修复：支持自定义prompt
    const requestBody = {
      context: request.context || request.prompt,
      prompt: request.customPrompt || '续写',  // ← 使用自定义prompt
      style: '',
      max_tokens: maxTokens,
    };

    // ... 其余代码不变
  }
}
```

**Day 2: 添加 quickEdit 专用方法**

在 `AIService.ts` 中添加：

```typescript
/**
 * Quick Edit - 自定义提示词编辑
 * @param selectedText - 选中的文本
 * @param userPrompt - 用户输入的提示词
 */
async quickEdit(
  selectedText: string,
  userPrompt: string,
  onChunk?: (chunk: string) => void
): Promise<string> {
  return await this.complete(
    {
      prompt: selectedText,      // 选中文本作为prompt
      context: selectedText,     // 同时作为context
      customPrompt: userPrompt,  // 用户自定义提示词
      maxTokens: 1000,
    },
    onChunk
  );
}
```

**验收标准：**
- [ ] `AICompletionRequest` 接口添加了 `customPrompt?` 字段
- [ ] `complete` 方法使用 `request.customPrompt || '续写'`
- [ ] 新增 `quickEdit` 方法
- [ ] 测试现有功能（续写、扩写等）未受影响
- [ ] 代码通过TypeScript类型检查

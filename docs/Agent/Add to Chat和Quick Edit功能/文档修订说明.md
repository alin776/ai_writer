# Add to Chat 和 Quick Edit 功能 - 文档修订说明

## 📋 修订概述

**修订版本：** v1.1
**修订日期：** 2025-01-10
**修订原因：** 经过深度代码验证，发现v1.0文档存在技术依赖分析错误

---

## 🔍 发现的问题

### 核心问题：混淆了两个功能使用的API

v1.0文档错误地认为Add to Chat和Quick Edit都依赖同一个API，导致对技术依赖关系的判断出现重大错误。

---

## ❌ v1.0的错误（已修正）

### 错误1：错误的技术依赖判断

**v1.0错误说法：**
> "Add to Chat 和 Quick Edit 都依赖自定义prompt功能"
> "必须先修复AIService，才能开始功能开发"

**实际情况：**
- Add to Chat使用 `/api/v1/agent/chat/stream`（Agent API）
- Quick Edit使用 `/api/v1/ai/complete`（AI Complete API）
- **两个功能使用完全不同的API！**

---

### 错误2：错误的开发顺序

**v1.0错误顺序：**
```
1. 阶段零：修复AIService（1-2天）⚠️ 必须先完成
2. 阶段一：Add to Chat（1-2周）
3. 阶段二：Quick Edit（2-3周）
```

**问题：**
- ❌ Add to Chat需要等待修复AIService（实际无需等待）
- ❌ 浪费1-2天时间
- ❌ 延迟了第一个功能的交付

---

### 错误3：混淆的API使用说明

**v1.0错误描述：**
> "后端 `/api/v1/ai/complete` API 已经支持自定义prompt（通过 `prompt` 参数）
> 但前端 `AIService.ts` 将 `prompt` 参数写死为 `'续写'`
> 这导致无法使用自定义提示词功能
>
> **影响范围：**
> - Add to Chat 和 Quick Edit 都依赖自定义prompt功能"

**实际情况：**
- ✅ `/api/v1/ai/complete` 确实需要修复（用于Quick Edit）
- ❌ 但Add to Chat根本不使用这个API！
- ✅ Add to Chat使用 `/api/v1/agent/chat/stream`，无需修改

---

## ✅ v1.1的修正

### 修正1：正确的技术依赖关系

| 功能 | 使用的API | 是否需要修复AIService | 可否立即开始 |
|------|----------|---------------------|------------|
| **Add to Chat** | `/api/v1/agent/chat/stream` | ❌ **不需要** | ✅ **可以** |
| **Quick Edit** | `/api/v1/ai/complete` | ✅ **需要** | ⚠️ 需先修复 |

**证据：**

#### Add to Chat使用的Agent API
```typescript
// src/services/agentApi.ts
async chatStream(
  request: AgentChatRequest,  // { message: string, ... }
  callbacks: { ... }
): Promise<void> {
  const url = `${API_BASE_URL}/api/v1/agent/chat/stream`;

  const response = await fetch(url, {
    method: 'POST',
    body: JSON.stringify(request),  // message是任意文本
  });
}
```

后端实现（`backend/app/api/v1/agent.py:865-1179`）：
```python
@router.post("/chat/stream")
async def agent_chat_stream(
    request: AgentChatRequest,  # message: str（任意文本）
    ...
):
    # ✅ 原生支持任意用户消息
```

#### Quick Edit使用的AI Complete API
```typescript
// src/services/AIService.ts
async complete(request: AICompletionRequest, ...): Promise<string> {
  const requestBody = {
    context: request.context || request.prompt,
    prompt: '续写',  // ❌ 写死了，Quick Edit需要自定义
    style: '',
    max_tokens: maxTokens,
  };
}
```

### 修正3：清晰的API使用说明

#### Add to Chat API使用

**API端点：** `POST /api/v1/agent/chat/stream`

**请求格式：**
```typescript
interface AgentChatRequest {
  message: string;              // ✅ 任意用户消息
  mode?: string;
  work_id?: string;
  chapter_id?: string;
  conversation_id?: string;
}
```

**使用示例：**
```typescript
await agentApi.chatStream({
  message: selectedText,  // ✅ 直接传递选中的文本
  work_id: currentWorkId,
}, {
  onContent: (chunk) => appendMessage(chunk),
});
```

**结论：** ✅ 开箱即用，无需修改任何代码

---

#### Quick Edit API使用

**API端点：** `POST /api/v1/ai/complete`

**后端支持：**
```python
class AICompleteRequest(BaseModel):
    context: str
    prompt: str = Field(default="续写", ...)  # ✅ 可自定义
    style: str = Field(default="", ...)
    max_tokens: int = Field(default=500, ...)
```

**前端问题：**
```typescript
// src/services/AIService.ts:198
prompt: '续写',  // ❌ 写死了
```

**修复方案：**
```typescript
// 1. 添加customPrompt参数
interface AICompletionRequest {
  customPrompt?: string;  // 🆕 新增
}

// 2. 使用自定义prompt
const requestBody = {
  prompt: request.customPrompt || '续写',  // ✅ 修复
};

// 3. 添加quickEdit方法
async quickEdit(selectedText: string, userPrompt: string, ...): Promise<string> {
  return await this.complete({
    customPrompt: userPrompt,  // ✅ 用户自定义提示词
  });
}
```

**结论：** ⚠️ 需先修复前端AIService（1-2天）

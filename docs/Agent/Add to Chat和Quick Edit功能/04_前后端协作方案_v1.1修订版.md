## 🔍 两个功能的API使用方案

### ✅ Add to Chat - 使用Agent API（无需修改）

#### API端点
```
POST /api/v1/agent/chat/stream
```

#### 请求参数
```typescript
interface AgentChatRequest {
  message: string;              // ✅ 用户消息（任意文本）
  mode?: string;                // 可选：planning/react
  work_id?: string;             // 可选：作品ID
  chapter_id?: string;          // 可选：章节ID
  conversation_id?: string;     // 可选：会话ID
  context?: Record<string, any>; // 可选：额外上下文
}
```

#### 响应格式（SSE流式）
```
data: {"type":"start","conversation_id":"xxx","mode":"react"}
data: {"type":"progress","data":{"step":"intent_analysis","description":"识别为：写作任务"}}
data: {"type":"content","data":"生成的文本..."}
data: {"type":"done","metadata":{...},"suggested_actions":[]}
```

#### 后端实现
**文件位置：** `backend/app/api/v1/agent.py:865-1179`

**核心代码：**

### ⚠️ Quick Edit - 使用AI Complete API（需要修复）

#### API端点
```
POST /api/v1/ai/complete
```

#### 请求参数（后端）
**文件位置：** `backend/app/api/v1/ai.py:44-49`

```python
class AICompleteRequest(BaseModel):
    """AI 续写请求"""
    context: str = Field(..., description="上下文内容（用户已写的内容）", min_length=1)
    prompt: str = Field(default="续写", description="续写指令")  # ✅ 可自定义！
    style: str = Field(default="", description="写作风格")
    max_tokens: int = Field(default=500, ge=100, le=2000)
```

**关键发现：** 后端的 `prompt` 字段**支持自定义**，默认值是"续写"。

#### 前端问题（需要修复）
**文件位置：** `src/services/AIService.ts:196-201`

**当前代码（❌ 有问题）：**
```typescript
const requestBody = {
  context: request.context || request.prompt,
  prompt: '续写',  // ❌ 写死了！
  style: '',
  max_tokens: maxTokens,
};
```

**问题：** 前端把 `prompt` 写死成了 `'续写'`，导致无法使用自定义提示词。

## 🎯 解决方案：修复AIService

### 方案：修改前端AIService（推荐）

- ✅ 后端无需改动
- ✅ 复用现有API
- ✅ 简单快速（1-2天）

**缺点：**
- ⚠️ 需要确保不破坏现有功能

### 步骤3：添加quickEdit专用方法

```typescript
// src/services/AIService.ts

/**
 * Quick Edit - 自定义提示词编辑
 * @param selectedText - 选中的文本
 * @param userPrompt - 用户输入的提示词
 */
async quickEdit(
  selectedText: string,
  userPrompt: string,
  onChunk?: (chunk: string) => void
): Promise<string> {
  return await this.complete(
    {
      prompt: selectedText,      // 选中文本作为prompt
      context: selectedText,     // 同时作为context
      customPrompt: userPrompt,  // ✅ 用户自定义提示词
      maxTokens: 1000,
    },
    onChunk
  );
}
```

## 📝 总结（v1.1修订版）

### 关键发现

1. ✅ **Add to Chat使用Agent API**（`/api/v1/agent/chat/stream`）
   - 原生支持任意用户消息
   - 无需修复AIService

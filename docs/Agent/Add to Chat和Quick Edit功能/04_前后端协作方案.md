# Add to Chat 和 Quick Edit - 前后端协作方案

## 📋 重要说明

经过详细分析，我发现了一个关键问题：**后端API已经支持自定义prompt，但前端写死了参数！**

---

## 🔍 现状分析

### 后端现有API

#### `/api/v1/ai/complete` - AI续写API

**请求参数：**
```python
class AICompleteRequest(BaseModel):
    context: str  # 上下文内容（必填）
    prompt: str = "续写"  # 续写指令（可自定义！）✅
    style: str = ""  # 写作风格（可选）
    max_tokens: int = 500  # 最大token数
```

**关键发现：** `prompt` 字段支持自定义，默认值是"续写"，但**可以传递任何提示词**！

---

### 前端现有实现

#### `AIService.ts` 的 `complete()` 方法

```typescript
// src/services/AIService.ts (第196-201行)
const requestBody = {
  context: request.context || request.prompt,
  prompt: '续写',  // ⚠️ 写死了！
  style: '',
  max_tokens: maxTokens,
};
```

**问题：** 前端把 `prompt` 写死成了 "续写"，没有传递用户自定义的提示词！

---

## 🎯 解决方案

### 方案A：修改前端 AIService（推荐）

**优点：**
- ✅ 后端无需改动
- ✅ 复用现有API
- ✅ 简单快速

**缺点：**
- ⚠️ 需要确保不破坏现有功能

**实施步骤：**

#### 1. 修改 AIService.ts

```typescript
// src/services/AIService.ts

export interface AICompletionRequest {
  prompt: string;           // 用户提示词
  context?: string;         // 上下文（可选）
  maxTokens?: number;
  temperature?: number;
  model?: string;
  customPrompt?: string;    // ← 新增：自定义提示词
}

async complete(
  request: AICompletionRequest,
  onChunk?: (chunk: string) => void
): Promise<string> {
  try {
    const apiUrl = `${this.baseUrl}/ai/complete`;
    const token = this.getAuthToken();

    const maxTokens = Math.max(request.maxTokens || 500, 100);

    // ✅ 修复：支持自定义prompt
    const requestBody = {
      context: request.context || request.prompt,
      prompt: request.customPrompt || '续写',  // ← 使用自定义prompt
      style: '',
      max_tokens: maxTokens,
    };

    // ... 其余代码不变
  }
}
```

#### 2. 为Quick Edit创建专用方法

```typescript
// src/services/AIService.ts

/**
 * Quick Edit - 自定义提示词编辑
 * @param selectedText - 选中的文本
 * @param userPrompt - 用户输入的提示词
 */
async quickEdit(
  selectedText: string,
  userPrompt: string,
  onChunk?: (chunk: string) => void
): Promise<string> {
  return await this.complete(
    {
      prompt: selectedText,      // 选中文本作为prompt
      context: selectedText,     // 同时作为context
      customPrompt: userPrompt,  // 用户自定义提示词
      maxTokens: 1000,
    },
    onChunk
  );
}
```

### 方案B：创建新的后端API（不推荐）

**优点：**

**缺点：**

**实施步骤（如果选择此方案）：**

#### 1. 后端新增API

```python
# backend/app/api/v1/ai.py

class QuickEditRequest(BaseModel):
    """Quick Edit 请求"""
    selected_text: str = Field(..., description="选中的文本", min_length=1)
    user_prompt: str = Field(..., description="用户输入的提示词", min_length=1)
    max_tokens: int = Field(default=1000, ge=100, le=2000)


@router.post(
    "/quick-edit",
    summary="Quick Edit - 快速编辑",
    response_class=StreamingResponse
)
async def quick_edit(
    request: QuickEditRequest,
    current_user: User = Depends(get_current_active_user),
    db: AsyncSession = Depends(get_db)
):
    """
    Quick Edit 接口（流式响应）

    用户可以对选中文本进行自定义AI编辑
    """
    ai_service = HTTPAIService()

    # 构建完整的prompt
    full_prompt = f"{request.user_prompt}\n\n原文：{request.selected_text}"

    async def event_generator():
        try:
            async for chunk, _ in ai_service.stream_complete(
                context=request.selected_text,
                prompt=request.user_prompt,
                max_tokens=request.max_tokens
            ):
                if chunk:
                    yield f"data: {chunk}\n\n"

            yield "data: [DONE]\n\n"

        except Exception as e:
            yield f"data: [ERROR] {str(e)}\n\n"

    return StreamingResponse(
        event_generator(),
        media_type="text/event-stream",
        headers={
            "Cache-Control": "no-cache",
            "Connection": "keep-alive",
            "X-Accel-Buffering": "no",
        }
    )
```

#### 2. 前端调用新API

## 📊 两个功能的技术方案对比

### Add to Chat

| 层级 | 需要修改 | 说明 |
|------|---------|------|
| **前端** | ✅ 是 | 添加按钮、状态管理、侧边栏控制 |
| **后端** | ❌ 否 | 复用现有 `/api/v1/agent/chat/stream` |
| **API** | ❌ 否 | 无需新增或修改 |

**结论：** 纯前端实现，无需后端改动。

---

### Quick Edit

| 层级 | 需要修改 | 说明 |
|------|---------|------|
| **前端** | ✅ 是 | QuickEditPanel组件、浮动UI、状态管理 |
| **后端** | ⚠️ 可选 | 方案A无需改动，方案B需要新增API |
| **API** | ⚠️ 可选 | 方案A修改前端调用即可，方案B需新增 `/api/v1/ai/quick-edit` |

**推荐：** **方案A**，只修改前端，后端无需改动。

## 📊 三层记忆模型流转图

```
┌─────────────────────────────────────────────────────────────┐
│                    新记忆产生                                │
│   用户输入 / AI响应 / 系统消息 / 工具输出                    │
└───────────────────────┬─────────────────────────────────────┘
                        ↓
        ┌───────────────────────────────────┐
        │   创建 MemoryItem                 │
        │   - 分配ID (mem_xxx)             │
        │   - 设置初始重要度 (0.5)         │
        │   - 记录时间戳                    │
        └───────────────┬───────────────────┘
                        ↓
┌───────────────────────────────────────────────────────────────┐
│                  短期记忆 (Short-Term)                        │
│  Redis List: user:{user_id}:memory:short_term                │
│  容量: 10条 | TTL: 1小时 | 策略: LPUSH + LTRIM               │
│                                                               │
│  [最新] mem_10 → mem_09 → mem_08 → ... → mem_01 [最早]      │
│                                                               │
│  ✅ 完整保留，快速访问                                        │
│  ✅ 用于当前会话的上下文                                      │
└───────────────────────┬───────────────────────────────────────┘
                        ↓ (当短期记忆满时，旧的记忆下沉)
┌───────────────────────────────────────────────────────────────┐
│                  中期记忆 (Medium-Term)                       │
│  Redis Sorted Set: user:{user_id}:memory:medium_term         │
│  容量: 100条 | TTL: 24小时 | 按重要度排序                     │
│                                                               │
│  Score(重要度): 1.8 → 1.5 → 1.2 → 0.8 → 0.3 → 0.1            │
│                                                               │
│  🔍 定期应用智能遗忘策略（每次添加新记忆时）                  │
│  📊 重要度 = 初始重要度 × 时间衰减 × 访问加权                 │
└───────────────────────┬───────────────────────────────────────┘
                        ↓ (重要度 < 0.1 的记忆被遗忘)
┌───────────────────────────────────────────────────────────────┐
│                  长期记忆 (Long-Term)                         │
│  Redis String: user:{user_id}:memory:long_term               │
│  PostgreSQL: agent_long_term_memories                         │
│  容量: 无限制 | TTL: 永久 | 格式: 压缩摘要                    │
│                                                               │
│  摘要示例:                                                    │
│  - 👤 用户想写一部玄幻小说...                                 │
│  - 🤖 讨论了主角的人物设定...                                 │
│  - 👤 确定了故事背景为修仙世界...                             │
│                                                               │
│  📝 Phase 1: 规则提取（前50字）                               │
│  🤖 Phase 2: LLM生成摘要（DeepSeek）                         │
└───────────────────────────────────────────────────────────────┘
```

## 🔄 智能遗忘策略流程

```
┌────────────────────────────────────────┐
│  触发时机: 每次添加新记忆到中期记忆     │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│  1. 获取所有中期记忆 (最多100条)        │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│  2. 遍历每条记忆，计算当前重要度        │
│                                        │
│  对于 memory_i:                        │
│    time_delta = now - timestamp        │
│    time_decay = e^(-0.1 × hours)       │
│    access_weight = 1 + log(1 + count)  │
│    importance = initial × decay × weight│
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│  3. 判断是否遗忘 (threshold = 0.1)     │
│                                        │
│  IF importance < 0.1:                  │
│    → 标记为"应遗忘"                    │
│  ELSE:                                 │
│    → 标记为"应保留"                    │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│  4. 分离两组                            │
│  - to_keep: 保留的记忆                  │
│  - to_forget: 遗忘的记忆                │
└─────────────────┬──────────────────────┘
                  ↓
         ┌────────┴────────┐
         ↓                 ↓
┌─────────────────┐  ┌────────────────────┐
│ 5a. 更新中期记忆 │  │ 5b. 压缩为摘要      │
│                 │  │                    │
│ 用to_keep列表   │  │ 调用compress_to_   │
│ 更新Sorted Set  │  │ summary()          │
│                 │  │                    │
│ 按重要度排序     │  │ Phase 1: 规则提取  │
└─────────────────┘  │ Phase 2: LLM生成   │
                     └──────────┬─────────┘
                                ↓
                     ┌────────────────────┐
                     │ 6. 追加到长期记忆   │
                     │                    │
                     │ Redis APPEND       │
                     │ PostgreSQL INSERT  │
                     └────────────────────┘
```

## 💾 状态快照与恢复

### 快照创建流程

```
用户请求: create_snapshot(user_id, conversation_id, description)
   ↓
┌────────────────────────────────────────┐
│ 1. 收集当前状态                         │
│  - short_term_memories (最多10条)      │
│  - medium_term_memories (最多100条)    │
│  - long_term_summary (摘要文本)        │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│ 2. 创建 MemorySnapshot 对象            │
│  - snapshot_id: snap_{uuid}            │
│  - created_at: 当前时间                │
│  - description: 用户描述                │
│  - tags: 标签列表                      │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│ 3. 序列化为JSON                        │
│  snapshot.json()                       │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│ 4. 保存到存储                          │
│  - Redis: TTL 7天（快速访问）          │
│    key: memory:snapshot:{snapshot_id}  │
│  - PostgreSQL: 永久存储（可选）        │
│    table: memory_snapshots             │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│ 5. 返回 snapshot_id                    │
└────────────────────────────────────────┘
```

### 快照恢复流程

```
用户请求: restore_snapshot(snapshot_id)
   ↓
┌────────────────────────────────────────┐
│ 1. 从Redis读取快照                     │
│  key = memory:snapshot:{snapshot_id}   │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│ 2. 反序列化JSON → MemorySnapshot      │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│ 3. 清空当前记忆                         │
│  - DELETE short_term                   │
│  - DELETE medium_term                  │
│  - CLEAR long_term (可选)              │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│ 4. 恢复各层级记忆                       │
│  - 恢复短期记忆 (LPUSH)                │
│  - 恢复中期记忆 (ZADD)                 │
│  - 恢复长期摘要 (SET)                  │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│ 5. 返回 MemorySnapshot 对象            │
└────────────────────────────────────────┘
```

## 🔍 记忆检索流程

### 1. 最近记忆检索

```
get_recent_memories(user_id, limit=10, layer=SHORT_TERM)
   ↓
┌────────────────────────────────────────┐
│ IF layer == SHORT_TERM:                │
│   LRANGE user:{user_id}:memory:short   │
│           0, limit-1                   │
│                                        │
│ IF layer == MEDIUM_TERM:               │
│   ZREVRANGE user:{user_id}:memory:mid  │
│             0, limit-1                 │
│   (按重要度降序)                        │
│                                        │
│ IF layer == LONG_TERM:                 │
│   GET user:{user_id}:memory:long       │
│   (返回摘要文本)                        │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│ 反序列化为 List[MemoryItem]            │
└────────────────────────────────────────┘
```

### 2. 语义相关检索 (Phase 2)

```
get_relevant_memories(user_id, query, top_k=5)
   ↓
┌────────────────────────────────────────┐
│ 1. 生成query的embedding                │
│   _generate_embedding(query)           │
│   → [0.23, 0.45, ..., 0.12]           │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│ 2. 获取候选记忆                         │
│  - 短期记忆: 10条                       │
│  - 中期记忆: 50条                       │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│ 3. 计算余弦相似度                       │
│  FOR each memory:                      │
│    IF memory.embedding is not None:    │
│      similarity = cosine(query_emb,    │
│                         memory.emb)    │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│ 4. 排序并返回top_k                     │
│  sorted_memories.sort(reverse=True)    │
│  return memories[:top_k]               │
└────────────────────────────────────────┘
```

### 3. 关键词搜索

```
search_memories(user_id, keywords=["玄幻", "主角"], limit=10)
   ↓
┌────────────────────────────────────────┐
│ 1. 获取所有候选记忆                     │
│  - 短期 + 中期                          │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│ 2. 关键词匹配                           │
│  FOR each memory:                      │
│    IF any(kw in memory.content):       │
│      matched.append(memory)            │
└─────────────────┬──────────────────────┘
                  ↓
┌────────────────────────────────────────┐
│ 3. 返回匹配结果 (最多limit条)           │
└────────────────────────────────────────┘
```

## 📈 重要度计算示例

### 示例1: 高重要度记忆（保留）

```
记忆: "主角名叫林峰，天生废柴体质，立志修仙"
  - initial_importance: 0.9 (角色设定很重要)
  - timestamp: 2小时前
  - access_count: 5次

计算过程:
  time_delta = 2小时
  time_decay = e^(-0.1 × 2) = e^(-0.2) ≈ 0.819
  access_weight = 1 + log(1 + 5) ≈ 2.79

  current_importance = 0.9 × 0.819 × 2.79 ≈ 2.06

判断: 2.06 > 0.1 → 保留 ✅
```

### 示例2: 低重要度记忆（遗忘）

```
记忆: "今天天气不错"
  - initial_importance: 0.3 (闲聊内容)
  - timestamp: 12小时前
  - access_count: 0次

计算过程:
  time_delta = 12小时
  time_decay = e^(-0.1 × 12) = e^(-1.2) ≈ 0.301
  access_weight = 1 + log(1 + 0) = 1

  current_importance = 0.3 × 0.301 × 1 ≈ 0.09

判断: 0.09 < 0.1 → 遗忘（降级到长期记忆） ✅
```

## ⚙️ 配置参数总结

| 参数 | 默认值 | 说明 | 可配置 |
|------|--------|------|--------|
| `MEMORY_SHORT_TERM_SIZE` | 10 | 短期记忆容量 | ✅ |
| `MEMORY_MEDIUM_TERM_SIZE` | 100 | 中期记忆容量 | ✅ |
| `MEMORY_FORGET_THRESHOLD` | 0.1 | 遗忘阈值 | ✅ |
| `decay_rate` (默认) | 0.1 | 时间衰减速率 | ❌ (在MemoryItem中设置) |
| `importance` (默认) | 0.5 | 初始重要度 | ❌ (创建时指定) |
| 短期TTL | 3600秒 | 1小时 | ❌ (硬编码) |
| 中期TTL | 86400秒 | 24小时 | ❌ (硬编码) |
| 快照TTL | 604800秒 | 7天 | ❌ (硬编码) |

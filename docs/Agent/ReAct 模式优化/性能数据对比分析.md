## 📈 性能瓶颈详解

### Top 3 瓶颈

#### 🔴 #1: 上下文构建 (21.7秒, 44%)

**当前实现**:
```python
# 串行执行
context = await self.store.load(session_id)  # 5s
memories = await self._vector_store.retrieve(...)  # 10s
tokens = self._token_counter.count(...)  # 1s
# 其他开销: 5.7s
```

**问题**:
- 无缓存
- 串行执行
- 向量检索慢

**优化方案** (Phase 1.2):
```python
# 并行执行 + 缓存
if cached := self._cache.get(cache_key):
    return cached  # 0.05s ← 缓存命中

context, memories = await asyncio.gather(
    self.store.load(session_id),
    self._vector_store.retrieve(...)
)  # 10s ← 并行执行
```

**预期改善**:
- 首次: 21.7s → 12s (45%提升)
- 缓存命中: 21.7s → 0.05s (99.8%提升)

---

#### 🟡 #2: 意图识别+路由 (22秒, 45%)

**当前实现**:
```python
# 两次独立LLM调用
intent = await self._classify_intent(...)  # 16s
route = await self._route_intent(...)  # 6s
```

**问题**:
- 重复调用（相同上下文）
- Token浪费（2187 tokens prompt）
- 路由其实不需要LLM

**优化方案** (Phase 2.4):
```python
# 一次调用完成
intent_and_route = await self._classify_and_route(...)  # 8s
```

**预期改善**:
- 22s → 8s (64%提升)
- Token: 2256 → 1860 (17%节省)

**测量方法**:
```python
# 成本对比
def calculate_cost_reduction():
    old_cost = db.query("SELECT SUM(cost) FROM api_call_logs WHERE created_at < '2025-11-01'")
    new_cost = db.query("SELECT SUM(cost) FROM api_call_logs WHERE created_at >= '2025-11-01'")

    # 按相同时间段对比
    reduction = (old_cost - new_cost) / old_cost * 100
    return f"成本降低: {reduction}%"
```

| GPT-4 (复杂任务) | < 30% | ~60% |

**验证**:
```python
# 模型使用分布
model_usage = db.query("""
    SELECT
        model_name,
        COUNT(*) as calls,
        SUM(cost) as total_cost,
        COUNT(*) * 100.0 / (SELECT COUNT(*) FROM api_call_logs) as call_percentage,
        SUM(cost) * 100.0 / (SELECT SUM(cost) FROM api_call_logs) as cost_percentage
    FROM api_call_logs
    GROUP BY model_name
""")
```

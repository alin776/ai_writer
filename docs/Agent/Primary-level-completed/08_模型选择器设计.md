## 1. 设计目标

### 1.1 核心目标

**根据任务复杂度自动选择合适的模型**

- ✅ **智能分级**: 简单/中等/复杂任务使用不同模型
- ✅ **成本优化**: 预期节省 40-50% 的 API 成本
- ✅ **多提供商支持**: OpenAI/Anthropic/DeepSeek等
- ✅ **性能平衡**: 在成本和质量间找到最佳平衡

### 1.2 为什么需要模型选择器?

**问题场景**:
1. 所有任务都用 GPT-4 → 成本过高
2. 所有任务都用 GPT-3.5 → 质量不稳定
3. 手动选择模型 → 效率低下

**模型选择器的价值**:
- 自动化决策,提高效率
- 显著降低API成本
- 保证关键任务质量
- 提升系统性价比

## 3. 核心实现

### 3.1 数据模型

**文件**: `backend/app/services/agent/model_selector.py`

```python
from enum import Enum
from typing import Dict, Any, Optional
from pydantic import BaseModel

class TaskComplexity(str, Enum):
    """任务复杂度"""
    SIMPLE = "simple"
    MEDIUM = "medium"
    COMPLEX = "complex"

class ModelTier(BaseModel):
    """模型层级"""
    name: str
    provider: str           # openai/anthropic/deepseek
    model_id: str
    cost_per_1k: float      # 每1k tokens成本(元)
    max_tokens: int
    speed: str              # fast/medium/slow
```

### 3.2 模型选择器

```python
class ModelSelector:
    """模型选择器"""

    # 模型配置
    MODEL_TIERS = {
        TaskComplexity.SIMPLE: ModelTier(
            name="快速模型",
            provider="deepseek",
            model_id="deepseek-chat",
            cost_per_1k=0.001,
            max_tokens=4096,
            speed="fast"
        ),
        TaskComplexity.MEDIUM: ModelTier(
            name="均衡模型",
            provider="openai",
            model_id="gpt-3.5-turbo",
            cost_per_1k=0.01,
            max_tokens=4096,
            speed="medium"
        ),
        TaskComplexity.COMPLEX: ModelTier(
            name="强力模型",
            provider="openai",
            model_id="gpt-4",
            cost_per_1k=0.03,
            max_tokens=8192,
            speed="slow"
        )
    }

    def select_model(
        self,
        task_type: str,
        context_length: int = 0,
        quality_requirement: str = "medium"
    ) -> ModelTier:
        """
        选择合适的模型

        Args:
            task_type: 任务类型
            context_length: 上下文长度
            quality_requirement: 质量要求 (low/medium/high)

        Returns:
            ModelTier: 选中的模型
        """
        # 判断任务复杂度
        complexity = self._determine_complexity(
            task_type,
            context_length,
            quality_requirement
        )

        return self.MODEL_TIERS[complexity]

    def _determine_complexity(
        self,
        task_type: str,
        context_length: int,
        quality_requirement: str
    ) -> TaskComplexity:
        """判断任务复杂度"""

        # 1. 简单任务
        simple_tasks = [
            "evaluate", "classify", "extract",
            "summarize", "tag", "score"
        ]
        if task_type in simple_tasks and quality_requirement != "high":
            return TaskComplexity.SIMPLE

        # 2. 复杂任务
        complex_tasks = [
            "plan", "create_outline", "write_chapter",
            "design_plot", "create_character"
        ]
        if task_type in complex_tasks or quality_requirement == "high":
            return TaskComplexity.COMPLEX

        # 3. 长上下文任务
        if context_length > 3000:
            return TaskComplexity.COMPLEX

        # 4. 默认中等
        return TaskComplexity.MEDIUM

    def estimate_cost(
        self,
        model: ModelTier,
        input_tokens: int,
        output_tokens: int
    ) -> float:
        """估算成本"""
        total_tokens = input_tokens + output_tokens
        return (total_tokens / 1000) * model.cost_per_1k

    def get_all_models(self) -> Dict[TaskComplexity, ModelTier]:
        """获取所有模型配置"""
        return self.MODEL_TIERS

    def override_model(
        self,
        complexity: TaskComplexity,
        model_tier: ModelTier
    ):
        """覆盖模型配置(用于自定义)"""
        self.MODEL_TIERS[complexity] = model_tier
```

## 4. 使用示例

### 4.1 基本使用

```python
from app.services.agent.model_selector import ModelSelector

# 初始化选择器
selector = ModelSelector()

# 示例1: 简单评估任务
model = selector.select_model(
    task_type="evaluate",
    context_length=500,
    quality_requirement="low"
)
print(f"选择模型: {model.name} ({model.model_id})")
# 输出: 选择模型: 快速模型 (deepseek-chat)

# 示例2: 中等续写任务
model = selector.select_model(
    task_type="continue",
    context_length=1000,
    quality_requirement="medium"
)
print(f"选择模型: {model.name}")
# 输出: 选择模型: 均衡模型

# 示例3: 复杂创作任务
model = selector.select_model(
    task_type="write_chapter",
    context_length=2000,
    quality_requirement="high"
)
print(f"选择模型: {model.name}")
# 输出: 选择模型: 强力模型

# 示例4: 成本估算
cost = selector.estimate_cost(
    model=model,
    input_tokens=2000,
    output_tokens=1000
)
print(f"预估成本: {cost:.4f}元")
# 输出: 预估成本: 0.0900元
```

### 4.2 在Agent中集成

```python
class WritingAgent:
    """写作Agent"""

    def __init__(self, ai_service):
        self.ai_service = ai_service
        self.model_selector = ModelSelector()

    async def generate_content(
        self,
        task_type: str,
        prompt: str,
        context_length: int = 0,
        quality_requirement: str = "medium"
    ) -> str:
        """使用智能模型选择的内容生成"""

        # 1. 选择模型
        model = self.model_selector.select_model(
            task_type=task_type,
            context_length=context_length,
            quality_requirement=quality_requirement
        )

        # 2. 记录选择
        logger.info(f"Task: {task_type}, Selected: {model.model_id}")

        # 3. 调用AI服务
        result = await self.ai_service.complete(
            prompt=prompt,
            model=model.model_id,
            max_tokens=model.max_tokens
        )

        # 4. 记录成本
        input_tokens = len(prompt) // 4  # 粗略估算
        output_tokens = len(result) // 4
        cost = self.model_selector.estimate_cost(
            model, input_tokens, output_tokens
        )
        logger.info(f"Cost: {cost:.4f}元")

        return result
```

### 4.3 在质量循环中使用

```python
class QualityLoopManager:
    """质量循环管理器"""

    def __init__(self, evaluator, model_selector):
        self.evaluator = evaluator
        self.model_selector = model_selector

    async def run_quality_loop(
        self,
        generator,
        generator_kwargs,
        context
    ):
        """运行质量循环"""

        iteration = 0

        while iteration < 3:
            iteration += 1

            # 根据迭代次数调整质量要求
            if iteration == 1:
                quality = "medium"
            elif iteration == 2:
                quality = "medium"
            else:
                quality = "high"  # 最后一次用强模型

            # 选择模型
            model = self.model_selector.select_model(
                task_type="continue",
                quality_requirement=quality
            )

            # 生成内容
            content = await generator(model=model.model_id, **generator_kwargs)

            # 评估质量
            evaluation = await self.evaluator.evaluate(content, context)

            if evaluation.passes:
                return {"content": content, "success": True}

        return {"content": content, "success": False}
```

## 5. 成本优化

### 5.1 成本对比

**场景**: 每天处理1000个任务

| 策略 | 每日调用 | 平均成本 | 每日总成本 |
|------|---------|---------|-----------|
| **全用GPT-4** | 1000次 | 0.06元 | 60元 |
| **全用GPT-3.5** | 1000次 | 0.02元 | 20元 |
| **智能选择** | 500简单+300中等+200复杂 | 0.025元 | 25元 |

**节省**: 相比全用GPT-4节省 **58%**

### 5.2 优化建议

1. **批量处理简单任务**: 评估、分类等集中处理
2. **缓存结果**: 相同输入直接返回缓存
3. **逐步升级**: 先用弱模型,不通过再用强模型
4. **动态调整**: 根据实际效果调整模型配置

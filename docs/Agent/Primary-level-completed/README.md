## 🚀 快速开始

### 第一步: 环境准备

参考 `18_快速开始指南.md`

```bash
# 克隆项目
git clone <repository-url>
cd ai_writer

# 配置环境
python -m venv venv
source venv/bin/activate  # Linux/Mac
# .\venv\Scripts\activate  # Windows

pip install -r requirements.txt

# 配置 .env
cp .env.example .env
# 编辑 .env 填入API密钥
```

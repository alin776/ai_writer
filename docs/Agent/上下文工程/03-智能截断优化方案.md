## 问题背景

### 核心问题

当前的强制截断策略存在**严重的上下文质量问题**：

| 问题 | 严重程度 | 后果 |
|-----|---------|------|
| 只保留最新消息 | 🔴 P0 | 丢失对话开头的关键设定 |
| 不考虑重要性 | 🔴 P0 | 重要信息和闲聊一视同仁 |
| 简单Token估算 | 🟠 P1 | Token计算不准确 |
| 无摘要补充 | 🟠 P1 | 被截断信息完全丢失 |

### 用户痛点案例

### 问题1: 强制截断算法过于简单

**位置**: `backend/app/services/context/manager.py:369-428`

**当前代码**:
```python
async def _force_truncate_context(self, context: Context, target_tokens: int) -> Context:
    """
    强制截断上下文到目标Token数
    """
    logger.warning(
        f"[ContextManager] 🔪 强制截断上下文: {context.get_total_tokens()} -> {target_tokens} tokens"
    )

    messages = context.short_memory.messages
    if not messages:
        return context

    # ⚠️ 问题：只从后往前保留消息，直到Token不超限
    kept_messages = []
    current_tokens = 0

    for msg in reversed(messages):
        msg_tokens = estimate_tokens(msg.content)

        if current_tokens + msg_tokens <= target_tokens:
            kept_messages.insert(0, msg)
            current_tokens += msg_tokens
        else:
            break  # ❌ 直接丢弃，不考虑重要性

    # 至少保留1条消息
    if not kept_messages and messages:
        kept_messages = [messages[-1]]
        logger.warning("[ContextManager] 目标Token过小，仅保留最后1条消息")

    logger.warning(
        f"[ContextManager] 截断结果: 保留{len(kept_messages)}/{len(messages)}条消息"
    )

    context.short_memory.messages = kept_messages
    return context
```

**问题分析**:
1. ❌ **时间优先**: 只按时间倒序保留，完全忽略重要性
2. ❌ **二元决策**: 要么保留，要么丢弃，没有中间状态
3. ❌ **信息丢失**: 被截断的消息完全丢失，没有生成摘要
4. ❌ **缺少上下文**: 保留的消息可能缺少前因后果

**实际影响**:
- 🔴 **关键设定丢失**: 用户在开头定义的角色、背景等
- 🔴 **对话不连贯**: AI无法理解完整的对话逻辑
- 🟠 **重复询问**: AI反复询问已知信息

### 问题2: Token估算不准确

**位置**: `manager.py:392-401`

**当前估算算法**:
```python
def estimate_tokens(text: str) -> int:
    """更准确的Token估算（考虑中英混合）"""
    # 中文字数（CJK字符：1字≈1.5 tokens）
    cn_count = sum(1 for c in text if '\u4e00' <= c <= '\u9fff')

    # 移除中文后，计算英文单词（1词≈0.3 tokens）
    text_without_cn = ''.join(c for c in text if not ('\u4e00' <= c <= '\u9fff'))
    en_count = len(text_without_cn.split())

    # 其他字符（标点、数字等，1字≈0.2 tokens）
    other_count = len(text) - cn_count - len(text_without_cn.replace(' ', ''))

    return int(cn_count * 1.5 + en_count * 0.3 + other_count * 0.2)
```

**问题**:
- ❌ **经验系数**: 1.5、0.3、0.2等系数不够准确
- ❌ **模型差异**: 不同模型的Token化方式不同
- ❌ **特殊字符**: 代码、Markdown等未特殊处理

### 问题3: 重要度评估过于简单

**位置**: `manager.py:458-492`

**当前算法**:
```python
def _evaluate_importance(self, content: str, role: str) -> float:
    """评估记忆重要度（0.0-1.0）"""
    content_lower = content.lower()
    importance = 0.3  # 基础分数

    # 用户消息权重更高
    if role == "user":
        importance += 0.1

    # ⚠️ 核心设定关键词（过于简单）
    high_value_keywords = ["大纲", "设定", "角色", "世界观", "背景", "人物", "plot", "character"]
    if any(kw in content_lower for kw in high_value_keywords):
        importance = max(importance, 0.9)

    # 重要指令关键词
    medium_value_keywords = ["修改", "要求", "添加", "删除", "更新", "调整"]
    if any(kw in content_lower for kw in medium_value_keywords):
        importance = max(importance, 0.7)

    # 长内容
    if len(content) > 500:
        importance = max(importance, 0.6)
    elif len(content) > 200:
        importance = max(importance, 0.5)

    return min(importance, 1.0)
```

**问题**:
1. ❌ **关键词匹配**: 无法理解语义（"我不想写设定" → 仍被判为重要）

### 方案1: 多维度重要度评估（基础）

#### 评估维度

| 维度 | 权重 | 说明 |
|-----|------|------|
| 时间位置 | 20% | 对话开头和结尾的消息更重要 |
| 内容类型 | 30% | 设定 > 指令 > 问答 > 闲聊 |
| 消息长度 | 10% | 长消息可能包含更多信息 |
| 关键词匹配 | 20% | 包含领域关键词 |
| 上下文相关性 | 20% | 与后续对话的相关程度 |

#### 实现代码

```python
class ImportanceEvaluator:
    """重要度评估器"""

    def __init__(self):
        # 关键词词典（可扩展）
        self.keywords = {
            "设定": ["大纲", "设定", "角色", "世界观", "背景", "人物", "plot", "character"],
            "指令": ["修改", "要求", "添加", "删除", "更新", "调整", "帮我", "请"],
            "问题": ["什么", "为什么", "如何", "怎么", "哪个", "是否"],
        }

    def evaluate_importance(
        self,
        message: Message,
        position: int,
        total_messages: int,
        context_messages: List[Message] = None
    ) -> float:
        """
        多维度评估消息重要度

        Args:
            message: 消息对象
            position: 在对话中的位置（0-based）
            total_messages: 总消息数
            context_messages: 后续的消息（用于计算相关性）

        Returns:
            重要度分数 (0.0-1.0)
        """
        score = 0.0

        # 1. 时间位置 (20%)
        position_score = self._evaluate_position(position, total_messages)
        score += position_score * 0.2

        # 2. 内容类型 (30%)
        content_type_score = self._evaluate_content_type(message.content)
        score += content_type_score * 0.3

        # 3. 消息长度 (10%)
        length_score = self._evaluate_length(message.content)
        score += length_score * 0.1

        # 4. 关键词匹配 (20%)
        keyword_score = self._evaluate_keywords(message.content)
        score += keyword_score * 0.2

        # 5. 上下文相关性 (20%)
        if context_messages:
            relevance_score = self._evaluate_relevance(message, context_messages)
            score += relevance_score * 0.2
        else:
            # 如果没有上下文，提高其他维度的权重
            score += position_score * 0.1 + content_type_score * 0.1

        # 6. 角色加权（用户消息 +0.1）
        if message.role == "user":
            score = min(score + 0.1, 1.0)

        return score

    def _evaluate_position(self, position: int, total: int) -> float:
        """评估时间位置重要度"""
        # 对话开头（前10%）和结尾（后20%）更重要
        relative_position = position / total if total > 0 else 0

        if relative_position < 0.1:
            # 开头：设定通常在这里
            return 1.0
        elif relative_position > 0.8:
            # 结尾：最近的对话
            return 0.9
        else:
            # 中间：根据距离衰减
            return 0.5

    def _evaluate_content_type(self, content: str) -> float:
        """评估内容类型"""
        content_lower = content.lower()

        # 设定类（最重要）
        if any(kw in content_lower for kw in self.keywords["设定"]):
            return 1.0

        # 指令类
        if any(kw in content_lower for kw in self.keywords["指令"]):
            return 0.8

        # 问题类
        if any(kw in content_lower for kw in self.keywords["问题"]):
            return 0.6

        # 陈述类（默认）
        return 0.4

    def _evaluate_length(self, content: str) -> float:
        """评估消息长度"""
        length = len(content)

        if length > 500:
            return 1.0
        elif length > 200:
            return 0.7
        elif length > 50:
            return 0.5
        else:
            return 0.3

    def _evaluate_keywords(self, content: str) -> float:
        """评估关键词密度"""
        content_lower = content.lower()
        keyword_count = 0

        for category, keywords in self.keywords.items():
            keyword_count += sum(1 for kw in keywords if kw in content_lower)

        # 归一化
        if keyword_count >= 5:
            return 1.0
        elif keyword_count >= 3:
            return 0.8
        elif keyword_count >= 1:
            return 0.6
        else:
            return 0.3

    def _evaluate_relevance(self, message: Message, context_messages: List[Message]) -> float:
        """
        评估与后续消息的相关性

        简单实现：检查后续消息是否引用了当前消息的关键词
        """
        # 提取当前消息的关键词（简单分词）
        current_keywords = set(message.content.split())

        relevance_count = 0
        for ctx_msg in context_messages:
            ctx_keywords = set(ctx_msg.content.split())
            # 计算交集
            intersection = current_keywords & ctx_keywords
            if len(intersection) > 3:
                relevance_count += 1

        # 归一化
        if relevance_count >= 3:
            return 1.0
        elif relevance_count >= 2:
            return 0.7
        elif relevance_count >= 1:
            return 0.5
        else:
            return 0.3
```

### 方案2: 智能截断策略（核心）

#### 策略流程

```
Input: 消息列表 + 目标Token数
  │
  ├─> 1. 评估所有消息的重要度
  │
  ├─> 2. 按重要度排序
  │
  ├─> 3. 贪心选择（重要度优先）
  │      直到Token数接近目标
  │
  ├─> 4. 按时间顺序重组保留的消息
  │
  ├─> 5. 为被截断的消息生成摘要
  │
  └─> Output: 截断后的上下文 + 摘要
```

#### 实现代码

```python
class IntelligentTruncationStrategy:
    """智能截断策略"""

    def __init__(self, evaluator: ImportanceEvaluator, ai_service=None):
        self.evaluator = evaluator
        self.ai_service = ai_service

    async def truncate_context(
        self,
        context: Context,
        target_tokens: int
    ) -> Context:
        """
        智能截断上下文

        Args:
            context: 当前上下文
            target_tokens: 目标Token数

        Returns:
            截断后的上下文
        """
        messages = context.short_memory.messages
        if not messages:
            return context

        logger.info(
            f"[IntelligentTruncation] Starting truncation: "
            f"{len(messages)} messages, target={target_tokens} tokens"
        )

        # 1. 评估所有消息的重要度
        importance_scores = []
        for i, msg in enumerate(messages):
            score = self.evaluator.evaluate_importance(
                message=msg,
                position=i,
                total_messages=len(messages),
                context_messages=messages[i+1:] if i < len(messages)-1 else None
            )
            importance_scores.append((i, score, msg))

        # 2. 按重要度排序（降序）
        importance_scores.sort(key=lambda x: x[1], reverse=True)

        # 3. 贪心选择：选择最重要的消息，直到Token接近目标
        selected_indices = set()
        current_tokens = 0

        # 保留系统提示（如果有）
        system_prompt_tokens = self._estimate_tokens(context.system_prompt)
        current_tokens += system_prompt_tokens

        # 贪心选择
        for idx, score, msg in importance_scores:
            msg_tokens = self._estimate_tokens(msg.content)

            if current_tokens + msg_tokens <= target_tokens:
                selected_indices.add(idx)
                current_tokens += msg_tokens
            else:
                # Token不足，检查是否值得牺牲一些不重要的消息
                if score > 0.8:  # 非常重要的消息
                    # 尝试移除一些不重要的消息腾出空间
                    removed = self._make_room_for_important_message(
                        selected_indices,
                        messages,
                        msg_tokens,
                        target_tokens - current_tokens
                    )
                    if removed:
                        selected_indices.add(idx)
                        current_tokens = sum(
                            self._estimate_tokens(messages[i].content)
                            for i in selected_indices
                        ) + system_prompt_tokens

        # 4. 按时间顺序重组保留的消息
        kept_messages = [messages[i] for i in sorted(selected_indices)]

        # 5. 为被截断的消息生成摘要
        truncated_indices = set(range(len(messages))) - selected_indices
        truncated_messages = [messages[i] for i in sorted(truncated_indices)]

        if truncated_messages:
            summary = await self._generate_summary_for_truncated(truncated_messages)

            # 将摘要添加到上下文的summary_memory
            if context.summary_memory.summary:
                context.summary_memory.summary = f"{context.summary_memory.summary}\n\n---\n\n{summary}"
            else:
                context.summary_memory.summary = summary

        # 6. 更新上下文
        context.short_memory.messages = kept_messages

        logger.info(
            f"[IntelligentTruncation] Completed: "
            f"kept={len(kept_messages)}/{len(messages)} messages, "
            f"truncated={len(truncated_messages)}, "
            f"final_tokens={current_tokens}/{target_tokens}"
        )

        return context

    def _make_room_for_important_message(
        self,
        selected_indices: set,
        messages: List[Message],
        needed_tokens: int,
        available_tokens: int
    ) -> bool:
        """
        为重要消息腾出空间

        移除已选择的消息中重要度最低的，直到有足够空间
        """
        if available_tokens >= needed_tokens:
            return True

        # 找出已选择消息中重要度最低的
        selected_with_importance = []
        for idx in selected_indices:
            msg = messages[idx]
            score = self.evaluator.evaluate_importance(
                msg,
                idx,
                len(messages),
                None
            )
            tokens = self._estimate_tokens(msg.content)
            selected_with_importance.append((idx, score, tokens))

        # 按重要度升序排序
        selected_with_importance.sort(key=lambda x: x[1])

        # 移除重要度低的消息
        freed_tokens = available_tokens
        for idx, score, tokens in selected_with_importance:
            if freed_tokens >= needed_tokens:
                return True

            # 移除这条消息
            selected_indices.remove(idx)
            freed_tokens += tokens

            logger.debug(
                f"[IntelligentTruncation] Removed message {idx} (score={score:.2f}) "
                f"to make room for important message"
            )

        return freed_tokens >= needed_tokens

    async def _generate_summary_for_truncated(self, messages: List[Message]) -> str:
        """为被截断的消息生成摘要"""
        if not messages:
            return ""

        # 如果有AI服务，使用LLM生成高质量摘要
        if self.ai_service:
            try:
                from app.services.context.summary_service import SummaryService
                summary_service = SummaryService(self.ai_service)
                summary = await summary_service.summarize_conversation(
                    messages,
                    max_length=200
                )
                return f"[被截断内容的摘要]\n{summary}"
            except Exception as e:
                logger.error(f"AI summarization failed: {e}")

        # 降级：简单摘要
        return self._fallback_summary(messages)

    def _fallback_summary(self, messages: List[Message]) -> str:
        """降级摘要：提取关键信息"""
        summary_parts = []

        # 提取用户的关键请求
        user_messages = [m for m in messages if m.role == "user"]
        if user_messages:
            core_requests = [m.content[:100] for m in user_messages[:3]]
            summary_parts.append(f"用户请求: {'; '.join(core_requests)}")

        # 提取助手的关键回复
        assistant_messages = [m for m in messages if m.role == "assistant"]
        if assistant_messages:
            core_responses = [m.content[:100] for m in assistant_messages[:2]]
            summary_parts.append(f"助手回复: {'; '.join(core_responses)}")

        # 统计信息
        summary_parts.append(f"共{len(messages)}条消息被截断")

        return " | ".join(summary_parts)

    def _estimate_tokens(self, text: str) -> int:
        """估算Token数"""
        if not text:
            return 0

        # 使用改进的估算算法
        cn_count = sum(1 for c in text if '\u4e00' <= c <= '\u9fff')
        text_without_cn = ''.join(c for c in text if not ('\u4e00' <= c <= '\u9fff'))
        en_count = len(text_without_cn.split())
        other_count = len(text) - cn_count - len(text_without_cn.replace(' ', ''))

        return int(cn_count * 1.5 + en_count * 0.3 + other_count * 0.2)
```

```python
from transformers import AutoTokenizer

class AccurateTokenCounter:
    """精确Token计数器"""

    def __init__(self, model_name: str = "gpt2"):
        """
        初始化Tokenizer

        Args:
            model_name: 模型名称（如"gpt2", "bert-base-chinese"）
        """
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)

    def count_tokens(self, text: str) -> int:
        """
        精确计算Token数

        Args:
            text: 输入文本

        Returns:
            Token数量
        """
        if not text:
            return 0

        try:
            tokens = self.tokenizer.encode(text, add_special_tokens=False)
            return len(tokens)
        except Exception as e:
            logger.error(f"Token counting failed: {e}")
            # 降级到估算算法
            return self._estimate_tokens_fallback(text)

    def _estimate_tokens_fallback(self, text: str) -> int:
        """降级到估算算法"""
        cn_count = sum(1 for c in text if '\u4e00' <= c <= '\u9fff')
        text_without_cn = ''.join(c for c in text if not ('\u4e00' <= c <= '\u9fff'))
        en_count = len(text_without_cn.split())
        other_count = len(text) - cn_count - len(text_without_cn.replace(' ', ''))
        return int(cn_count * 1.5 + en_count * 0.3 + other_count * 0.2)
```

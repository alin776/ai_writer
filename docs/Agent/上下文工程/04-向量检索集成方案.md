## 问题背景

### 核心问题

当前记忆检索**完全依赖关键词匹配**，无法理解语义：

| 问题 | 严重程度 | 影响 |
|-----|---------|------|
| 向量检索完全缺失 | 🔴 P0 | 无法进行语义理解 |
| 只能精确匹配关键词 | 🔴 P0 | 召回率极低（<35%） |
| 无法处理同义词 | 🔴 P0 | "续写" vs "继续创作" 无法关联 |
| 中文分词过于简单 | 🟠 P1 | `query.split()` 无法处理中文 |

### 用户痛点案例

```
【场景1: 同义词理解】
用户历史记忆: "主角叫张三，是一名修真者"
用户查询: "男主角的背景是什么？"

当前实现:
keywords = ["男主角的背景是什么？"]  # split()得到1个词
搜索结果: [] ❌ (无匹配)

应该返回:
"主角叫张三，是一名修真者" ✅
因为: "男主角" ≈ "主角", "背景" ≈ "修真者"

【场景2: 语义相关性】
用户历史记忆: "小说的主线是主角从凡人修炼成仙"
用户查询: "故事的核心情节是什么？"

当前实现:
keywords = ["故事", "核心", "情节", "是", "什么"]
搜索结果: [] ❌ (没有精确匹配"故事"、"情节"等词)

应该返回:
"小说的主线是主角从凡人修炼成仙" ✅
因为: "故事情节" ≈ "小说主线", "核心" ≈ "主要"
```

#### 候选模型对比

| 模型 | 语言支持 | 性能 | 模型大小 | 推理速度 | 推荐度 |
|-----|---------|------|---------|---------|-------|
| sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2 | 多语言（含中文） | 优秀 | 420MB | 快 | ⭐⭐⭐⭐⭐ |
| BAAI/bge-small-zh-v1.5 | 中文专用 | 优秀 | 102MB | 非常快 | ⭐⭐⭐⭐⭐ |

**理由**:

- ✅ 推理速度快（适合实时查询）
- ✅ 中文效果优秀（MTEB中文榜单前列）
- ✅ 开源免费（无API调用成本）

### 向量存储选型

#### 候选方案对比

| 方案 | 优点 | 缺点 | 适用场景 | 推荐度 |
|-----|------|------|---------|-------|
| **FAISS** (CPU) | 简单、快速、无依赖 | 内存占用大 | 小规模（<100万向量） | ⭐⭐⭐⭐⭐ |
| **FAISS** (GPU) | 极快 | 需要GPU | 大规模、高并发 | ⭐⭐⭐⭐ |
| **Milvus** | 分布式、高性能 | 部署复杂 | 大规模、生产环境 | ⭐⭐⭐ |
| **Qdrant** | 易用、功能丰富 | 额外服务依赖 | 中等规模 | ⭐⭐⭐⭐ |
| **Redis (RediSearch)** | 与现有Redis集成 | 性能一般 | 小规模、简化部署 | ⭐⭐⭐ |
| **Chroma** | 简单、轻量 | 功能较少 | 小规模、快速原型 | ⭐⭐⭐ |

**推荐**: **FAISS (CPU)** + **Redis作为元数据存储**

**理由**:
- ✅ 无额外服务依赖（降低运维成本）
- ✅ 性能优秀（百万级向量毫秒级检索）
- ✅ 与现有Redis配合使用
- ✅ 支持增量索引

### 数据流设计

#### 1. 索引构建流程

```
用户添加记忆
    │
    ├─> 1. 提取文本内容
    │
    ├─> 2. 生成向量（Embedding Model）
    │      - 输入: "主角叫张三，是修真者"
    │      - 输出: [0.12, -0.34, 0.56, ...] (512维)
    │
    ├─> 3. 添加到FAISS索引
    │      - faiss.IndexFlatL2.add(vectors)
    │
    ├─> 4. 保存元数据到Redis
    │      - key: vector:{memory_id}
    │      - value: {content, user_id, timestamp, ...}
    │
    └─> 5. 返回memory_id
```

#### 2. 检索流程

```
用户查询
    │
    ├─> 1. 查询向量化
    │      - 输入: "男主角的背景？"
    │      - 输出: [0.15, -0.32, 0.58, ...] (512维)
    │
    ├─> 2. FAISS相似度搜索
    │      - faiss.search(query_vector, top_k=5)
    │      - 输出: [(distance1, id1), (distance2, id2), ...]
    │
    ├─> 3. 从Redis加载元数据
    │      - 批量获取: mget(vector:id1, vector:id2, ...)
    │
    ├─> 4. 过滤和排序
    │      - 相似度阈值过滤（如 > 0.7）
    │      - 按重要度+相似度排序
    │
    └─> 5. 返回结果
```

### 阶段2: 实现VectorRetriever（8小时）

#### 步骤1: 创建向量检索器

创建文件: `backend/app/services/agent/memory/vector_retriever.py`

```python
"""
向量检索器 (Vector Retriever)

基于FAISS实现高性能向量检索
"""

import os
import json
import logging
import numpy as np
from typing import List, Dict, Any, Optional, Tuple
from dataclasses import dataclass
import faiss
from sentence_transformers import SentenceTransformer
import redis

logger = logging.getLogger(__name__)

@dataclass
class VectorSearchResult:
    """向量搜索结果"""
    memory_id: str
    content: str
    similarity: float
    metadata: Dict[str, Any]

class VectorRetriever:
    """
    向量检索器

    功能:
    1. 向量编码（text → embedding）
    2. 向量索引（FAISS）
    3. 相似度搜索
    4. 元数据管理（Redis）
    """

    def __init__(
        self,
        model_name: str = "BAAI/bge-small-zh-v1.5",
        index_path: str = "./data/faiss_index",
        redis_client: Optional[redis.Redis] = None,
        dimension: int = 512
    ):
        """
        初始化向量检索器

        Args:
            model_name: 模型名称
            index_path: FAISS索引保存路径
            redis_client: Redis客户端（存储元数据）
            dimension: 向量维度
        """
        self.model_name = model_name
        self.index_path = index_path
        self.redis = redis_client
        self.dimension = dimension

        # 加载模型
        logger.info(f"Loading embedding model: {model_name}")
        self.model = SentenceTransformer(model_name)

        # 确认维度
        actual_dim = self.model.get_sentence_embedding_dimension()
        if actual_dim != dimension:
            logger.warning(
                f"Model dimension ({actual_dim}) != configured dimension ({dimension}), "
                f"using model dimension"
            )
            self.dimension = actual_dim

        # 加载或创建FAISS索引
        self.index = self._load_or_create_index()

        # 内存中的ID映射（FAISS index → memory_id）
        self.id_mapping = {}  # {faiss_id: memory_id}
        self.next_id = 0

        logger.info(
            f"✅ VectorRetriever initialized: "
            f"model={model_name}, dimension={self.dimension}"
        )

    def _load_or_create_index(self) -> faiss.Index:
        """加载或创建FAISS索引"""
        index_file = os.path.join(self.index_path, "index.faiss")

        if os.path.exists(index_file):
            # 加载已有索引
            logger.info(f"Loading existing FAISS index from {index_file}")
            index = faiss.read_index(index_file)
            logger.info(f"Loaded index with {index.ntotal} vectors")
        else:
            # 创建新索引
            logger.info(f"Creating new FAISS index (dimension={self.dimension})")

            # 使用IndexFlatL2（精确搜索，适合小规模）
            index = faiss.IndexFlatL2(self.dimension)

            # 可选：使用IndexIVFFlat（近似搜索，适合大规模）
            # quantizer = faiss.IndexFlatL2(self.dimension)
            # index = faiss.IndexIVFFlat(quantizer, self.dimension, 100)  # 100个聚类
            # index.train(training_vectors)  # 需要训练

            # 确保目录存在
            os.makedirs(self.index_path, exist_ok=True)

        return index

    def encode(self, text: str) -> np.ndarray:
        """
        将文本编码为向量

        Args:
            text: 输入文本

        Returns:
            向量（numpy数组）
        """
        if not text:
            return np.zeros(self.dimension, dtype=np.float32)

        try:
            # 编码（返回numpy数组）
            embedding = self.model.encode(text, convert_to_numpy=True)

            # 确保是float32类型（FAISS要求）
            if embedding.dtype != np.float32:
                embedding = embedding.astype(np.float32)

            return embedding

        except Exception as e:
            logger.error(f"Encoding failed: {e}")
            return np.zeros(self.dimension, dtype=np.float32)

    def add_memory(
        self,
        memory_id: str,
        content: str,
        metadata: Dict[str, Any] = None
    ) -> bool:
        """
        添加记忆到向量索引

        Args:
            memory_id: 记忆ID
            content: 记忆内容
            metadata: 元数据（user_id, timestamp, importance等）

        Returns:
            是否成功
        """
        try:
            # 1. 编码
            embedding = self.encode(content)

            # 2. 添加到FAISS索引
            faiss_id = self.next_id
            self.index.add(np.array([embedding]))  # add需要2D数组

            # 3. 更新ID映射
            self.id_mapping[faiss_id] = memory_id
            self.next_id += 1

            # 4. 保存元数据到Redis
            if self.redis:
                redis_key = f"vector:meta:{memory_id}"
                meta_data = {
                    "memory_id": memory_id,
                    "content": content,
                    "faiss_id": faiss_id,
                    **(metadata or {})
                }
                self.redis.set(redis_key, json.dumps(meta_data, ensure_ascii=False))

            logger.debug(
                f"Added vector: memory_id={memory_id}, faiss_id={faiss_id}, "
                f"content_length={len(content)}"
            )

            return True

        except Exception as e:
            logger.error(f"Failed to add memory to vector index: {e}")
            return False

    def search(
        self,
        query: str,
        top_k: int = 5,
        min_similarity: float = 0.0,
        user_id: Optional[str] = None
    ) -> List[VectorSearchResult]:
        """
        搜索相似记忆

        Args:
            query: 查询文本
            top_k: 返回Top K结果
            min_similarity: 最小相似度阈值（0-1）
            user_id: 用户ID（过滤）

        Returns:
            搜索结果列表
        """
        if not query:
            return []

        try:
            # 1. 编码查询
            query_vector = self.encode(query)

            # 2. FAISS搜索
            # search返回(distances, indices)
            # distances: L2距离（越小越相似）
            # indices: FAISS内部ID
            distances, indices = self.index.search(
                np.array([query_vector]),  # 需要2D数组
                top_k
            )

            # 3. 转换为结果列表
            results = []

            for i, (distance, faiss_id) in enumerate(zip(distances[0], indices[0])):
                # 跳过无效ID（-1表示未找到）
                if faiss_id == -1:
                    continue

                # 获取memory_id
                memory_id = self.id_mapping.get(faiss_id)
                if not memory_id:
                    logger.warning(f"FAISS ID {faiss_id} not found in mapping")
                    continue

                # 从Redis加载元数据
                if self.redis:
                    redis_key = f"vector:meta:{memory_id}"
                    meta_json = self.redis.get(redis_key)

                    if meta_json:
                        try:
                            metadata = json.loads(meta_json)
                        except json.JSONDecodeError:
                            metadata = {}
                    else:
                        metadata = {}
                else:
                    metadata = {}

                # L2距离转相似度（余弦相似度的近似）
                # 相似度 = 1 / (1 + distance)
                similarity = 1.0 / (1.0 + float(distance))

                # 过滤：最小相似度
                if similarity < min_similarity:
                    continue

                # 过滤：用户ID
                if user_id and metadata.get("user_id") != user_id:
                    continue

                # 创建结果
                result = VectorSearchResult(
                    memory_id=memory_id,
                    content=metadata.get("content", ""),
                    similarity=similarity,
                    metadata=metadata
                )
                results.append(result)

            logger.info(
                f"Vector search: query='{query[:50]}...', "
                f"top_k={top_k}, found={len(results)}"
            )

            return results

        except Exception as e:
            logger.error(f"Vector search failed: {e}")
            return []

    def delete_memory(self, memory_id: str) -> bool:
        """
        删除记忆

        注意：FAISS不支持删除，这里只删除元数据
        真正删除需要重建索引
        """
        try:
            # 删除Redis元数据
            if self.redis:
                redis_key = f"vector:meta:{memory_id}"
                self.redis.delete(redis_key)

            # 从ID映射中移除
            faiss_id = None
            for fid, mid in self.id_mapping.items():
                if mid == memory_id:
                    faiss_id = fid
                    break

            if faiss_id is not None:
                del self.id_mapping[faiss_id]

            logger.info(f"Deleted vector metadata: memory_id={memory_id}")
            return True

        except Exception as e:
            logger.error(f"Failed to delete memory: {e}")
            return False

    def save_index(self) -> bool:
        """保存FAISS索引到磁盘"""
        try:
            index_file = os.path.join(self.index_path, "index.faiss")
            faiss.write_index(self.index, index_file)

            # 保存ID映射
            mapping_file = os.path.join(self.index_path, "id_mapping.json")
            with open(mapping_file, 'w', encoding='utf-8') as f:
                json.dump({
                    "id_mapping": self.id_mapping,
                    "next_id": self.next_id
                }, f, ensure_ascii=False, indent=2)

            logger.info(f"Saved FAISS index to {index_file}")
            return True

        except Exception as e:
            logger.error(f"Failed to save index: {e}")
            return False

    def load_index(self) -> bool:
        """从磁盘加载索引"""
        try:
            # 加载FAISS索引
            index_file = os.path.join(self.index_path, "index.faiss")
            if os.path.exists(index_file):
                self.index = faiss.read_index(index_file)

            # 加载ID映射
            mapping_file = os.path.join(self.index_path, "id_mapping.json")
            if os.path.exists(mapping_file):
                with open(mapping_file, 'r', encoding='utf-8') as f:
                    data = json.load(f)
                    # 转换key为int
                    self.id_mapping = {int(k): v for k, v in data["id_mapping"].items()}
                    self.next_id = data["next_id"]

            logger.info(f"Loaded FAISS index with {self.index.ntotal} vectors")
            return True

        except Exception as e:
            logger.error(f"Failed to load index: {e}")
            return False

    def rebuild_index(self, memories: List[Dict[str, Any]]) -> bool:
        """
        重建索引

        用于定期清理或优化
        """
        try:
            # 创建新索引
            self.index = faiss.IndexFlatL2(self.dimension)
            self.id_mapping = {}
            self.next_id = 0

            # 批量添加
            for memory in memories:
                self.add_memory(
                    memory_id=memory["id"],
                    content=memory["content"],
                    metadata=memory.get("metadata")
                )

            # 保存
            self.save_index()

            logger.info(f"Rebuilt index with {len(memories)} memories")
            return True

        except Exception as e:
            logger.error(f"Failed to rebuild index: {e}")
            return False
```

"""
将现有记忆迁移到向量索引

使用场景:
1. 首次部署向量检索
2. 定期重建索引
"""

import asyncio
import logging

from backend.app.core.config import settings

logger = logging.getLogger(__name__)

async def migrate_memories():
    """迁移现有记忆到向量索引"""
    # 连接Redis
    redis_client = redis.Redis.from_url(settings.REDIS_URL)

    # 创建MemoryManager
    manager = EnhancedMemoryManager(
        redis_client=redis_client,
        enable_vector_search=True
    )

    # 获取所有用户
    user_keys = redis_client.keys("memory:*:short_term")
    users = set()
    for key in user_keys:
        # 提取user_id
        parts = key.decode().split(":")
        if len(parts) >= 2:
            users.add(parts[1])

    logger.info(f"Found {len(users)} users with memories")

    # 迁移每个用户的记忆
    total_migrated = 0
    for user_id in users:
        try:
            # 获取短期记忆
            short_memories = manager._get_short_term_memories(user_id, 100)

            # 获取中期记忆
            medium_memories = manager._get_medium_term_memories(user_id, 100)

            all_memories = short_memories + medium_memories

            logger.info(f"Migrating {len(all_memories)} memories for user {user_id}")

            # 添加到向量索引
            for memory in all_memories:
                if manager.vector_retriever:
                    manager.vector_retriever.add_memory(
                        memory_id=memory.id,
                        content=memory.content,
                        metadata={
                            "user_id": memory.user_id,
                            "conversation_id": memory.conversation_id,
                            "role": memory.role,
                            "importance": memory.importance,
                            "timestamp": memory.timestamp.isoformat()
                        }
                    )
                    total_migrated += 1

            logger.info(f"✅ Migrated {len(all_memories)} memories for user {user_id}")

        except Exception as e:
            logger.error(f"❌ Failed to migrate user {user_id}: {e}")

    # 保存索引
    if manager.vector_retriever:
        manager.vector_retriever.save_index()

    logger.info(f"✅ Migration completed: {total_migrated} memories indexed")

if __name__ == "__main__":
    asyncio.run(migrate_memories())

```python
class VectorRetriever:
    def batch_encode(self, texts: List[str]) -> np.ndarray:
        """批量编码（更高效）"""
        if not texts:
            return np.array([])

        try:
            # 批量编码（利用GPU并行）
            embeddings = self.model.encode(
                texts,
                convert_to_numpy=True,
                batch_size=32,  # 批处理大小
                show_progress_bar=False
            )

            return embeddings.astype(np.float32)

        except Exception as e:
            logger.error(f"Batch encoding failed: {e}")
            return np.zeros((len(texts), self.dimension), dtype=np.float32)

    def batch_add_memories(
        self,
        memories: List[Dict[str, Any]]
    ) -> int:
        """批量添加记忆（更高效）"""
        if not memories:
            return 0

        try:
            # 批量编码
            texts = [m["content"] for m in memories]
            embeddings = self.batch_encode(texts)

            # 批量添加到FAISS
            self.index.add(embeddings)

            # 更新映射和元数据
            added_count = 0
            for i, memory in enumerate(memories):
                faiss_id = self.next_id + i
                memory_id = memory["id"]

                self.id_mapping[faiss_id] = memory_id

                # 保存元数据
                if self.redis:
                    redis_key = f"vector:meta:{memory_id}"
                    self.redis.set(
                        redis_key,
                        json.dumps(memory.get("metadata", {}), ensure_ascii=False)
                    )

                added_count += 1

            self.next_id += len(memories)

            logger.info(f"Batch added {added_count} memories to vector index")
            return added_count

        except Exception as e:
            logger.error(f"Batch add failed: {e}")
            return 0
```

from functools import lru_cache

class VectorRetriever:
    @lru_cache(maxsize=1000)
    def _cached_encode(self, text: str) -> bytes:
        """缓存编码结果（序列化为bytes）"""
        embedding = self.encode(text)
        return embedding.tobytes()

    def encode_with_cache(self, text: str) -> np.ndarray:
        """使用缓存的编码"""
        cached_bytes = self._cached_encode(text)
        return np.frombuffer(cached_bytes, dtype=np.float32)

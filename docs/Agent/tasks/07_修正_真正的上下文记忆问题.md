# 修正：解决Agent真正的上下文记忆问题

## 🚨 真正的问题

### 问题发现

在 `langgraph_agent.py:1278` 行：

```python
# ❌ 错误：每次都只传入当前消息
initial_state = {
    "messages": [HumanMessage(content=message)],  # 只有1条消息！
    "work_id": work_id,
    ...
}
```

**后果**：
- Agent每次对话都只能看到当前这一条消息
- 看不到之前的对话历史
- 每次都像"失忆"一样，无法理解上下文

### 测试验证

```python
# 第一轮对话
用户: "我想写一个科幻小说"
Agent: "好的，我来帮你规划..."

# 第二轮对话
用户: "主角叫什么名字好？"
Agent: "请问你想写什么类型的小说？"  # ❌ Agent忘记了之前说的"科幻小说"
```

## ✅ 正确的解决方案

### 方案1：使用LangGraph的state恢复机制

LangGraph的`ainvoke`方法会自动从Checkpointer加载历史state，但**前提是不要覆盖它**！

#### 错误用法（当前）
```python
# ❌ 每次都创建新的initial_state，覆盖了历史
initial_state = {
    "messages": [HumanMessage(content=message)],  # 丢弃了历史
    ...
}
result = await self.graph.ainvoke(initial_state, config)
```

#### 正确用法

```python
# ✅ 方式1：不传initial_state，让LangGraph自动恢复
# 第一次对话：创建新state
# 后续对话：自动加载历史state

config = {"configurable": {"thread_id": conversation_id}}

# 不传initial_state，LangGraph会自动处理
result = await self.graph.ainvoke(
    {"messages": [HumanMessage(content=message)]},  # 只传新消息
    config
)
```

但这样有问题：work_id、chapter_id等信息会丢失。

**更好的方式**：

```python
# ✅ 方式2：手动加载历史state，然后append新消息

# 1. 尝试从checkpointer加载历史state
saved_state = self.checkpointer.get(config)

if saved_state and saved_state.channel_values.get("messages"):
    # 有历史对话：加载历史messages
    messages = saved_state.channel_values["messages"]
    messages.append(HumanMessage(content=message))  # append新消息
else:
    # 首次对话：创建新messages
    messages = [HumanMessage(content=message)]

# 2. 构建state
initial_state = {
    "messages": messages,  # ✅ 包含完整的对话历史
    "work_id": work_id,
    "chapter_id": chapter_id,
    ...
}

# 3. 运行
result = await self.graph.ainvoke(initial_state, config)
```

## 📝 完整代码修改

### 修改 `langgraph_agent.py` 的 `chat` 方法

**文件位置**：`ai_writer/backend/app/services/agent/langgraph_agent.py:1254`

```python
async def chat(
    self,
    message: str,
    work_id: Optional[str] = None,
    chapter_id: Optional[str] = None,
    conversation_id: Optional[str] = None,
    context: Optional[Dict[str, Any]] = None
) -> Dict[str, Any]:
    """
    与 Agent 对话（支持上下文记忆）

    Args:
        message: 用户消息
        work_id: 作品ID
        chapter_id: 章节ID
        conversation_id: 会话ID（用于记忆）
        context: 额外上下文

    Returns:
        Dict: Agent响应
    """

    conversation_id = conversation_id or str(uuid.uuid4())
    config = {"configurable": {"thread_id": conversation_id}}

    # ✅ 1. 尝试从checkpointer加载历史state
    logger.info(f"[LangGraph] 尝试加载历史对话: {conversation_id}")

    try:
        saved_checkpoint = self.checkpointer.get(config)

        if saved_checkpoint and saved_checkpoint.channel_values:
            # 有历史对话
            saved_messages = saved_checkpoint.channel_values.get("messages", [])
            logger.info(f"[LangGraph] 加载了 {len(saved_messages)} 条历史消息")

            # ✅ 将新消息追加到历史消息后面
            messages = saved_messages + [HumanMessage(content=message)]

            # 保留其他状态信息
            work_id = work_id or saved_checkpoint.channel_values.get("work_id")
            chapter_id = chapter_id or saved_checkpoint.channel_values.get("chapter_id")

        else:
            # 首次对话
            logger.info(f"[LangGraph] 首次对话，创建新会话")
            messages = [HumanMessage(content=message)]

    except Exception as e:
        logger.warning(f"[LangGraph] 加载历史对话失败，创建新会话: {e}")
        messages = [HumanMessage(content=message)]

    # ✅ 2. 构建state（包含完整对话历史）
    initial_state = {
        "messages": messages,  # ✅ 包含历史+当前消息
        "work_id": work_id,
        "chapter_id": chapter_id,
        "intent": None,
        "context": context or {},
        "agent_steps": [],
        "suggested_actions": [],
        "final_response": None
    }

    # 3. 运行图
    try:
        logger.info(f"[LangGraph] 开始处理，总消息数: {len(messages)}")
        result = await self.graph.ainvoke(initial_state, config)

        return {
            "response": result["final_response"],
            "conversation_id": conversation_id,
            "agent_steps": result["agent_steps"],
            "suggested_actions": result["suggested_actions"],
            "metadata": {
                "intent": result.get("intent"),
                "message_count": len(messages),  # 返回总消息数
                "timestamp": str(datetime.now())
            }
        }

    except Exception as e:
        logger.error(f"[LangGraph] Agent执行失败: {e}")
        return {
            "response": f"抱歉，处理您的请求时出错了：{str(e)}",
            "conversation_id": conversation_id,
            "agent_steps": [],
            "suggested_actions": [],
            "metadata": {"error": str(e)}
        }
```

import pytest
from app.services.agent.langgraph_agent import WritingAgentGraph

@pytest.mark.asyncio

## ⚠️ 注意事项

### 1. 消息历史长度限制

```python
# 避免消息历史过长，超过token限制
MAX_HISTORY_MESSAGES = 50  # 保留最近50条

if len(messages) > MAX_HISTORY_MESSAGES:
    # 保留最近的消息
    messages = messages[-MAX_HISTORY_MESSAGES:]
    logger.warning(f"[LangGraph] 消息历史过长，截断为最近{MAX_HISTORY_MESSAGES}条")
```

### 2. 消息摘要（可选优化）

对于很长的对话历史，可以使用LLM生成摘要：

```python
if len(messages) > 20:
    # 对前面的消息生成摘要
    old_messages = messages[:-10]  # 除了最近10条

    summary = await self.ai_service.generate_summary(old_messages)

    # 用摘要替换旧消息
    messages = [
        SystemMessage(content=f"对话摘要：{summary}"),
        *messages[-10:]  # 最近10条保留原文
    ]
```

# ✅ 正确：不同对话使用不同ID
conversation_id_1 = "novel-project-A"

## 🎯 关键改动总结

1. **核心修改**：在创建`initial_state`之前，从Checkpointer加载历史messages
2. **追加消息**：将新消息append到历史消息后面，而不是替换
3. **保留状态**：work_id、chapter_id等也从历史state恢复
4. **长度限制**：避免消息历史过长导致token溢出

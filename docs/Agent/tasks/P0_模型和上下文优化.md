# P0 优化方案 - 模型和上下文优化

> **优先级：** P0（最高，必须立即实施）
> **预期效果：** 响应时间从 2分16秒 降至 20-30秒（提升 82-85%）
> **实施时间：** 1-2小时

## 🎯 优化目标

解决两个核心问题：
1. **gemini-2.5-pro模型太慢** - 每次调用15-60秒
2. **Summarization上下文过大** - 16,729 tokens导致57秒延迟

---

## 优化2：压缩Summarization上下文

### 问题分析

**当前代码：** `backend/app/services/agent/langgraph_agent.py:1690-1725`

```python
# Line 1695: 初始化

# Line 1725: 无限制累积
for task in plan_data["tasks"]:
    task_result = await self._execute_task(...)
    all_context += f"\n任务{task_id}结果：\n{task_result}\n"  # ← 问题

# Line 1710: 传入全部上下文
summary_prompt = f"""基于以下任务执行结果，生成最终的响应给用户。

{all_context}  # ← 16,729 tokens！
...
"""
```

**问题：**
- 包含4个完整章节内容（每个约2000字）
- 包含RAG检索结果
- 包含生成的续写内容
- 总计约40,000字符 ≈ 16,729 tokens

### 解决方案：智能压缩上下文

**步骤1：添加压缩函数**

在 `langgraph_agent.py` 中添加（建议放在类外面，作为工具函数）：

```python
def _compress_task_result(
    task_id: int,
    task_description: str,
    task_result: str,
    max_length: int = 500
) -> str:
    """智能压缩任务结果

    Args:
        task_id: 任务ID
        task_description: 任务描述
        task_result: 原始任务结果
        max_length: 最大保留长度

    Returns:
        压缩后的结果
    """
    # 如果结果很短，直接返回
    if len(task_result) <= max_length:
        return task_result

    # 工具调用的结果（如get_chapter_by_order_tool）
    if "章" in task_result and ("第" in task_result or "标题" in task_result):
        # 只保留章节标题和摘要
        lines = task_result.split('\n')
        summary_lines = []

        for line in lines[:10]:  # 只看前10行
            if "标题" in line or "章" in line or "摘要" in line:
                summary_lines.append(line)

        if summary_lines:
            compressed = '\n'.join(summary_lines)
            return f"[章节信息摘要]\n{compressed}\n[内容已压缩，保留标题和关键信息]"
        else:
            # 保留开头和结尾
            return f"[章节内容摘要]\n{task_result[:200]}...\n{task_result[-100:]}"

    # RAG检索结果
    if "检索" in task_description or "搜索" in task_description:
        # 只保留关键信息
        return f"[检索结果摘要]\n{task_result[:max_length]}"

    # 其他类型结果：保留前后部分
    half = max_length // 2
    return f"{task_result[:half]}...[省略部分内容]...{task_result[-half:]}"


def _build_summarization_context(
    user_message: str,
    task_results: List[Dict[str, Any]],
    max_context_length: int = 3000
) -> str:
    """构建Summarization的上下文

    Args:
        user_message: 用户原始请求
        task_results: 任务执行结果列表
        max_context_length: 最大上下文长度（字符）

    Returns:
        压缩后的上下文
    """
    context_parts = [f"用户请求：{user_message}\n"]
    current_length = len(context_parts[0])

    for task in task_results:
        task_id = task["task_id"]
        description = task["description"]
        result = task["result"]
        status = task["status"]

        # 压缩结果
        if status == "completed":
            compressed_result = _compress_task_result(
                task_id=task_id,
                task_description=description,
                task_result=result,
                max_length=500
            )
        else:
            # 失败的任务保留错误信息
            compressed_result = result[:200]

        # 检查是否超过限制
        task_text = f"\n任务{task_id}（{description}）：\n{compressed_result}\n"
        if current_length + len(task_text) > max_context_length:
            # 超过限制，进一步压缩
            task_text = f"\n任务{task_id}：[结果已省略]\n"

        context_parts.append(task_text)
        current_length += len(task_text)

    return ''.join(context_parts)
```

## 1. 环境准备

### 1.1 系统要求

- Python 3.11+
- PostgreSQL 14+
- Redis 7.0+
- Node.js 18+ (前端)

### 1.2 克隆项目

```bash
git clone <repository-url>
cd ai_writer
```

### 1.3 后端环境配置

```bash
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows
.\venv\Scripts\activate
# Linux/Mac
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

### 1.4 配置环境变量

创建 `.env` 文件:

```bash
# 数据库配置
DATABASE_URL=postgresql://user:password@localhost:5432/ai_writer
REDIS_URL=redis://localhost:6379/0

# LLM API配置
OPENAI_API_KEY=sk-...
DEEPSEEK_API_KEY=sk-...

# Agent增强功能开关
ENABLE_ENHANCED_MEMORY=true
ENABLE_QUALITY_LOOP=true
ENABLE_VERSION_CONTROL=true
ENABLE_MODEL_SELECTION=true
ENABLE_SMART_PROMPTS=true

# Memory配置
MEMORY_SHORT_TERM_SIZE=10
MEMORY_MEDIUM_TERM_SIZE=100
MEMORY_FORGET_THRESHOLD=0.1

# 质量循环配置
QUALITY_LOOP_MAX_ITERATIONS=3
QUALITY_LOOP_PASS_THRESHOLD=8.0

# 模型选择配置
MODEL_SIMPLE_TASK=deepseek-chat
MODEL_MEDIUM_TASK=gpt-3.5-turbo
MODEL_COMPLEX_TASK=gpt-4-turbo

# 成本控制
ENABLE_COST_TRACKING=true
DAILY_COST_LIMIT_PER_USER=10.0
```

### 1.5 数据库初始化

```bash
# 运行数据库迁移
cd backend
alembic upgrade head
```

### 1.6 启动服务

```bash
# 后端
cd backend
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 前端 (另一个终端)
cd frontend
npm install
npm run dev
```

### 3.3 版本管理

```bash
# 1. 创建内容版本
curl -X POST http://localhost:8000/api/v1/agent/versions \
  -H "Content-Type: application/json" \
  -d '{
    "content_id": "content_123",
    "base_content": "这是原始内容",
    "description": "初始版本"
  }'

# 2. 应用修改
curl -X POST http://localhost:8000/api/v1/agent/versions/apply-patch \
  -H "Content-Type: application/json" \
  -d '{

      "operation": "insert",
      "position": 0,

curl http://localhost:8000/api/v1/agent/versions/history/content_123

# 4. 回滚
curl -X POST http://localhost:8000/api/v1/agent/versions/rollback \
  -H "Content-Type: application/json" \
  -d '{
    "content_id": "content_123",
    "target_version_id": "v_001"
  }'
```

## 4. 开发指南

### 4.1 添加新的工具

**1. 定义工具类型**

```python
# backend/app/services/agent/tools/my_tool.py
from .tool_types import ToolInput, ToolOutput, StandardTool

class MyToolInput(ToolInput):
    param1: str
    param2: int

class MyToolOutput(ToolOutput):
    result: str
    success: bool

class MyTool(StandardTool[MyToolInput, MyToolOutput]):
    name = "my_tool"
    description = "工具描述"

    async def _execute(self, input_data: MyToolInput) -> MyToolOutput:
        # 工具逻辑
        result = f"处理 {input_data.param1}"
        return MyToolOutput(result=result, success=True)
```

**2. 注册工具**

```python
# backend/app/services/agent/tools/tool_registry.py
from .my_tool import MyTool

tool_registry.register(MyTool())
```

**1. 找到Prompt文件**

### 4.4 调整模型选择策略

```python
# backend/app/services/agent/model_selector.py

class ModelSelector:
    @staticmethod
    def determine_complexity(task_type: str, context_length: int) -> TaskComplexity:
        # 简单任务 - 使用低成本模型
        if task_type in ["evaluate", "classify", "simple_qa"]:
            return TaskComplexity.SIMPLE

        # 复杂任务 - 使用高质量模型
        if task_type in ["create", "plan", "deep_analysis"]:
            return TaskComplexity.COMPLEX

        # 上下文长度判断
        if context_length > 2000:
            return TaskComplexity.COMPLEX

        return TaskComplexity.MEDIUM
```

## 5. 常见问题

### 5.1 功能开关

**Q: 如何关闭质量循环功能?**

A: 修改 `.env` 文件:
```bash
ENABLE_QUALITY_LOOP=false
```

或在请求中指定:
```json
{
  "enable_quality_loop": false
}
```

### 5.2 性能问题

**Q: Memory查询很慢怎么办?**

A: 检查以下几点:
1. Redis是否正常运行: `redis-cli ping`
2. 查看Memory数量: `redis-cli LLEN user:{user_id}:memory:short`
3. 触发智能遗忘: `await memory_manager.apply_forgetting(user_id, conv_id)`

**Q: 版本历史占用空间太大?**

A: 运行清理脚本:
```python
from app.services.agent.version_control import VersionCleanupPolicy

await VersionCleanupPolicy().cleanup_old_versions(content_id)
```

### 5.3 成本问题

**Q: 成本超支怎么办?**

A: 检查成本追踪:
```python
# 查看今日成本
cost = await cost_tracker.get_today_cost(user_id)

# 查看模型分布
stats = await cost_tracker.get_model_breakdown(user_id)

# 调整成本限额
# .env文件
DAILY_COST_LIMIT_PER_USER=5.0
```

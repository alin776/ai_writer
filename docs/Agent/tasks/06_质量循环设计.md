## 1. 设计目标

### 1.1 核心目标

**实现自动化的内容质量提升循环**

- ✅ **生成 → 评估 → 改进 → 重试** (最多3次)
- ✅ **多维度评估**: 质量分数 + 字数 + 连贯性
- ✅ **智能反馈生成**: 自动分析问题
- ✅ **自动优化Prompt**: 根据反馈调整生成参数

### 1.2 为什么需要质量循环?

**问题场景**:
1. AI 生成的内容质量不稳定
2. 首次生成往往不够理想
3. 人工重试成本高,效率低
4. 缺乏系统化的质量评估标准

**质量循环的价值**:
- 自动重试提升内容质量
- 节省人工审核时间
- 提供标准化的质量评估
- 持续优化生成参数

## 2. 核心流程

### 2.1 质量循环流程图

```
┌─────────────────────────────────────────┐
│         第1次迭代                        │
│                                          │
│  1. 生成内容                             │
│     ↓                                    │
│  2. 评估质量 (多维度打分)                │
│     ↓                                    │
│  3. 判断是否通过 (总分 >= 8分)           │
│     ├─ 通过 → 返回结果                   │
│     └─ 未通过 → 生成改进建议             │
└──────────────────────────────────────────┘
                ↓
┌─────────────────────────────────────────┐
│         第2次迭代                        │
│                                          │
│  4. 根据建议优化Prompt                   │
│     ↓                                    │
│  5. 重新生成内容                         │
│     ↓                                    │
│  6. 再次评估质量                         │
│     ├─ 通过 → 返回结果                   │
│     └─ 未通过 → 继续改进                 │
└──────────────────────────────────────────┘
                ↓
┌─────────────────────────────────────────┐
│         第3次迭代                        │
│                                          │
│  7. 最后一次优化                         │
│     ↓                                    │
│  8. 生成内容                             │
│     ↓                                    │
│  9. 评估质量                             │
│     ├─ 通过 → 返回结果                   │
│     └─ 未通过 → 返回最佳结果             │
└──────────────────────────────────────────┘
```

### 2.2 评估维度

| 维度 | 权重 | 评估方法 | 通过标准 |
|------|------|----------|----------|
| **内容质量** | 2.0 | LLM评估 | >= 8分 |
| **连贯性** | 1.5 | LLM评估 | >= 7分 |
| **字数检查** | 1.0 | 直接计算 | 达到目标字数 |
| **风格一致性** | 1.0 | LLM评估 | >= 7分 |
| **语法正确性** | 1.0 | LLM评估 | >= 8分 |

**总分计算**:
```
总分 = Σ(维度分数 × 权重) / Σ(权重)
```

## 3. 质量评估服务

### 3.1 数据模型

**文件**: `backend/app/services/agent/quality_evaluator.py`

```python
from typing import Dict, Any, List, Callable
from pydantic import BaseModel, Field
from enum import Enum

class QualityDimension(str, Enum):
    """质量维度"""
    CONTENT_QUALITY = "content_quality"      # 内容质量
    LENGTH_CHECK = "length_check"            # 字数检查
    COHERENCE = "coherence"                  # 连贯性
    STYLE_CONSISTENCY = "style_consistency"  # 风格一致性
    GRAMMAR = "grammar"                      # 语法正确性

class DimensionScore(BaseModel):
    """维度评分"""
    dimension: QualityDimension
    score: float = Field(..., ge=0, le=10)  # 0-10分
    feedback: str = ""
    weight: float = 1.0  # 权重

class QualityEvaluation(BaseModel):
    """质量评估结果"""
    overall_score: float  # 总分 0-10
    dimension_scores: List[DimensionScore]
    passes: bool  # 是否通过（>= 8分）
    feedback: str  # 综合反馈
    suggestions: List[str] = []  # 改进建议
```

### 3.2 质量评估器

```python
class QualityEvaluatorService:
    """质量评估服务"""

    def __init__(self, ai_service):
        self.ai_service = ai_service
        self.pass_threshold = 8.0  # 通过阈值

    async def evaluate(
        self,
        content: str,
        context: Dict[str, Any] = None,
        dimensions: List[QualityDimension] = None
    ) -> QualityEvaluation:
        """
        评估内容质量

        Args:
            content: 待评估内容
            context: 上下文信息 (如: previous_content, target_length)
            dimensions: 要评估的维度 (默认: 质量+字数+连贯性)

        Returns:
            QualityEvaluation: 评估结果
        """
        if dimensions is None:
            dimensions = [
                QualityDimension.CONTENT_QUALITY,
                QualityDimension.LENGTH_CHECK,
                QualityDimension.COHERENCE
            ]

        # 评估各个维度
        dimension_scores = []
        for dim in dimensions:
            score_data = await self._evaluate_dimension(content, dim, context)
            dimension_scores.append(score_data)

        # 计算加权总分
        total_weight = sum(s.weight for s in dimension_scores)
        overall_score = sum(
            s.score * s.weight for s in dimension_scores
        ) / total_weight

        # 生成综合反馈
        feedback = self._generate_feedback(dimension_scores, overall_score)

        # 生成改进建议
        suggestions = self._generate_suggestions(dimension_scores)

        return QualityEvaluation(
            overall_score=overall_score,
            dimension_scores=dimension_scores,
            passes=overall_score >= self.pass_threshold,
            feedback=feedback,
            suggestions=suggestions
        )

    async def _evaluate_dimension(
        self,
        content: str,
        dimension: QualityDimension,
        context: Dict = None
    ) -> DimensionScore:
        """评估单个维度"""

        # 1. 字数检查 (不需要LLM)
        if dimension == QualityDimension.LENGTH_CHECK:
            target_length = context.get("target_length", 500) if context else 500
            actual_length = len(content)
            score = min(10, (actual_length / target_length) * 10)
            feedback = f"实际字数: {actual_length}, 目标字数: {target_length}"

            return DimensionScore(
                dimension=dimension,
                score=score,
                feedback=feedback,
                weight=1.0
            )

        # 2. 内容质量 (使用LLM)
        elif dimension == QualityDimension.CONTENT_QUALITY:
            prompt = f"""请评估以下小说内容的质量（0-10分）:

内容:
{content}

评估标准:
- 情节是否吸引人
- 描写是否生动
- 节奏是否合理
- 是否有明显硬伤

请直接返回分数和简短反馈，格式: score|feedback"""

            result = await self.ai_service.simple_complete(prompt)
            score, feedback = self._parse_llm_result(result)

            return DimensionScore(
                dimension=dimension,
                score=score,
                feedback=feedback,
                weight=2.0  # 内容质量权重更高
            )

        # 3. 连贯性 (使用LLM)
        elif dimension == QualityDimension.COHERENCE:
            previous_content = context.get("previous_content", "") if context else ""

            prompt = f"""请评估以下续写内容与前文的连贯性（0-10分）:

前文:
{previous_content[-500:] if previous_content else "（无前文）"}

续写:
{content}

评估标准:
- 情节是否自然衔接
- 人物表现是否一致
- 风格是否统一

请直接返回分数和简短反馈，格式: score|feedback"""

            result = await self.ai_service.simple_complete(prompt)
            score, feedback = self._parse_llm_result(result)

            return DimensionScore(
                dimension=dimension,
                score=score,
                feedback=feedback,
                weight=1.5
            )

        # 其他维度暂未实现
        return DimensionScore(
            dimension=dimension,
            score=7.0,
            feedback="暂未实现",
            weight=1.0
        )

    def _parse_llm_result(self, result: str) -> tuple:
        """解析LLM返回结果"""
        try:
            parts = result.strip().split("|")
            score = float(parts[0].strip())
            feedback = parts[1].strip() if len(parts) > 1 else ""
            return score, feedback
        except:
            return 7.0, result

    def _generate_feedback(
        self,
        dimension_scores: List[DimensionScore],
        overall_score: float
    ) -> str:
        """生成综合反馈"""
        if overall_score >= 9:
            return "内容质量优秀！"
        elif overall_score >= 8:
            return "内容质量良好，达标。"
        elif overall_score >= 6:
            return "内容质量一般，建议优化。"
        else:
            return "内容质量较差，需要重写。"

    def _generate_suggestions(
        self,
        dimension_scores: List[DimensionScore]
    ) -> List[str]:
        """生成改进建议"""
        suggestions = []

        for dim_score in dimension_scores:
            if dim_score.score < 7:
                if dim_score.dimension == QualityDimension.LENGTH_CHECK:
                    suggestions.append("建议增加内容字数")
                elif dim_score.dimension == QualityDimension.CONTENT_QUALITY:
                    suggestions.append("建议优化情节和描写")
                elif dim_score.dimension == QualityDimension.COHERENCE:
                    suggestions.append("建议增强与前文的衔接")

        return suggestions
```

## 4. 质量循环管理器

### 4.1 核心实现

```python
class QualityLoopManager:
    """质量循环管理器"""

    def __init__(
        self,
        evaluator: QualityEvaluatorService,
        max_iterations: int = 3
    ):
        self.evaluator = evaluator
        self.max_iterations = max_iterations

    async def run_quality_loop(
        self,
        generator: Callable,
        generator_kwargs: Dict,
        context: Dict = None
    ) -> Dict[str, Any]:
        """
        运行质量循环

        Args:
            generator: 生成函数 (async)
            generator_kwargs: 生成函数参数
            context: 评估上下文

        Returns:
            Dict: {
                "content": 最终内容,
                "evaluation": 评估结果,
                "iterations": 迭代次数,
                "success": 是否成功通过
            }
        """
        iteration = 0
        best_content = None
        best_score = 0.0
        best_evaluation = None

        while iteration < self.max_iterations:
            iteration += 1

            # 1. 生成内容
            content = await generator(**generator_kwargs)

            # 2. 评估质量
            evaluation = await self.evaluator.evaluate(content, context)

            # 3. 更新最佳结果
            if evaluation.overall_score > best_score:
                best_content = content
                best_score = evaluation.overall_score
                best_evaluation = evaluation

            # 4. 检查是否通过
            if evaluation.passes:
                return {
                    "content": content,
                    "evaluation": evaluation,
                    "iterations": iteration,
                    "success": True
                }

            # 5. 未通过,优化参数(如果还有重试机会)
            if iteration < self.max_iterations:
                generator_kwargs = self._optimize_params(
                    generator_kwargs,
                    evaluation
                )

        # 达到最大迭代次数,返回最佳结果
        return {
            "content": best_content,
            "evaluation": best_evaluation,
            "iterations": iteration,
            "success": False,
            "message": "达到最大迭代次数，返回最佳结果"
        }

    def _optimize_params(
        self,
        params: Dict,
        evaluation: QualityEvaluation
    ) -> Dict:
        """根据评估结果优化参数"""
        # 将改进建议添加到提示词
        if "requirements" in params:
            suggestions_text = "\n".join(evaluation.suggestions)
            params["requirements"] += f"\n\n改进建议:\n{suggestions_text}"

        # 可以根据具体维度进一步优化
        for dim_score in evaluation.dimension_scores:
            if dim_score.dimension == QualityDimension.LENGTH_CHECK:
                if dim_score.score < 7:
                    # 增加目标字数
                    if "target_length" in params:
                        params["target_length"] = int(params["target_length"] * 1.2)

        return params
```

## 5. 使用示例

### 5.1 基本使用

```python
from app.services.agent.quality_evaluator import (
    QualityEvaluatorService,
    QualityLoopManager
)
from app.services.ai.openai_service import OpenAIService

# 初始化服务
ai_service = OpenAIService()
evaluator = QualityEvaluatorService(ai_service)
quality_loop = QualityLoopManager(evaluator, max_iterations=3)

# 定义生成函数
async def generate_content(context: str, requirements: str, target_length: int):
    """内容生成函数"""
    prompt = f"""根据以下要求生成内容:

上下文: {context}
要求: {requirements}
目标字数: {target_length}

请直接输出内容，不要其他说明。"""

    result = await ai_service.simple_complete(prompt)
    return result

# 运行质量循环
result = await quality_loop.run_quality_loop(
    generator=generate_content,
    generator_kwargs={
        "context": "主角李明来到修仙界...",
        "requirements": "描写主角首次见到修仙者的场景",
        "target_length": 500
    },
    context={
        "previous_content": "李明穿越到了修仙界...",
        "target_length": 500
    }
)

print(f"成功: {result['success']}")
print(f"迭代次数: {result['iterations']}")
print(f"总分: {result['evaluation'].overall_score}")
print(f"内容:\n{result['content']}")
```

### ⚠️ 重要发现和教训

#### 关键发现
1. **Code Review不能替代实际运行测试**
   - 两轮Review都没发现f-string语法错误
   - 只有用户实际运行才发现Critical Bug

2. **三层错误保护机制很重要**
   - Agent层: run_agent的try-catch
   - Queue层: __error__事件机制
   - Generator层: 外层try-catch + result检查

3. **事件格式一致性至关重要**
   - 所有事件必须包含mode字段
   - 错误事件必须包含error_type
   - 统一的格式便于前端处理

#### 最佳实践总结
```python
# ✅ DO: 先创建字典，再序列化
event = {'type': 'start', 'data': data}
yield f"data: {json.dumps(event, ensure_ascii=False)}\n\n"

# ❌ DON'T: 在f-string中写字典字面量
yield f"data: {json.dumps({{'type': 'start'}})}}\n\n"
```

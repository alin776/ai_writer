### 为什么会有两套工具？

**历史原因**：
1. 最初在 `langgraph_agent.py` 中定义工具（快速原型）
2. 后来为了模块化，创建了 `tools/writing_tools.py`
3. 但忘记删除旧版 + 更新LangGraph配置
4. 导致新版工具白开发了

```python
@tool
async def continue_writing_tool(
    context: str,
    requirements: str = "",
    style: str = "自然流畅",
    min_length: int = 500
) -> str:
    """续写工具（新版）- 基于上下文生成连贯的续写内容

    Args:
        context: 上下文内容
        requirements: 续写要求（可选）
        style: 写作风格（可选）
        min_length: 最小字数（默认500）

    Returns:
        str: 续写的内容
    """
    prompt = f"""你是专业的小说续写助手。请基于以下上下文续写内容。

【上下文】
{context}

【续写要求】
- 风格：{style}
- 最小字数：{min_length}字
- 具体要求：{requirements if requirements else "保持故事连贯性和人物性格一致"}

【注意事项】
1. 保持与上文的风格一致
2. 人物性格和情节逻辑要合理
3. 语言要生动流畅
4. 适当增加细节描写

请开始续写："""

    try:
        # ✅ 优势1：有task_type
        result = await _generate_text(
            prompt=prompt,
            temperature=0.8,
            max_tokens=2000,
            task_type=TaskType.CONTENT_CREATION
        )

        # ✅ 优势2：有错误处理
        if not result:
            return "续写生成失败，请重试"

        return result

    except Exception as e:
        logger.error(f"[Tool] continue_writing_tool 失败: {e}")
        return f"续写出错：{str(e)}"
```

### 风险2：工具签名不一致

**风险描述**：新旧版本的参数可能不同

**示例**：
```python
# 旧版
async def continue_writing_tool(context: str, requirements: str = "") -> str:
    ...

# 新版（假设）
async def continue_writing_tool(
    context: str,
    requirements: str = "",
    style: str = "自然流畅",  # ← 多了新参数
    min_length: int = 500      # ← 多了新参数
) -> str:
    ...
```

**应对措施**：
- 新参数必须有默认值（保持向后兼容）
- 或者在删除旧版前，先统一签名
- 更新调用处的代码（如果有直接调用）

---

### 风险3：break现有功能

**风险描述**：删除旧版后可能导致某些地方报错

**可能的影响点**：
1. 其他文件直接导入了旧版工具
2. 测试代码引用了旧版
3. 文档中的示例代码

**应对措施**：
```bash
# 搜索所有引用
grep -r "from app.services.agent.langgraph_agent import.*tool" backend/

# 搜索工具名称的引用
grep -r "continue_writing_tool\|polish_text_tool" backend/ --include="*.py"
```

---

### 风险4：LangGraph配置未更新

**风险描述**：可能还有其他地方使用了 `WRITING_TOOLS`

**检查方法**：
```bash
grep -r "WRITING_TOOLS" backend/app/services/agent/
```

**应对措施**：
- 确保只有一处定义 `WRITING_TOOLS`
- 所有使用的地方都指向同一个定义

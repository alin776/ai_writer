## 🎯 功能概述

实现任务中断机制，允许用户随时取消正在执行的Agent任务，提升用户掌控感。

### 核心目标

1. **任务取消**：支持中止正在执行的流式任务
2. **资源清理**：取消时正确释放资源
3. **状态恢复**：取消后会话状态保持一致
4. **用户反馈**：及时告知用户取消结果

## 🏗️ 实现方案

### 1. 中断机制

```python
# agent/interruption.py
import asyncio
from typing import Optional

class InterruptionManager:
    """中断管理器"""

    def __init__(self):
        self.interruptions: Dict[str, asyncio.Event] = {}

    def create_interruption_flag(self, session_id: str) -> asyncio.Event:
        """为会话创建中断标志"""
        event = asyncio.Event()
        self.interruptions[session_id] = event
        return event

    def request_interruption(self, session_id: str):
        """请求中断任务"""
        event = self.interruptions.get(session_id)
        if event:
            event.set()

    def clear_interruption(self, session_id: str):
        """清除中断标志"""
        if session_id in self.interruptions:
            del self.interruptions[session_id]

    def is_interrupted(self, session_id: str) -> bool:
        """检查是否被中断"""
        event = self.interruptions.get(session_id)
        return event.is_set() if event else False
```

### 2. 集成到chat_stream

```python
# agent/chat_agent.py
class ChatAgent:
    def __init__(self):
        self.interruption_manager = InterruptionManager()

    async def chat_stream(
        self,
        message: str,
        session_id: str,
        **kwargs
    ) -> AsyncGenerator[ChatEvent, None]:
        """流式执行（支持中断）"""

        # 创建中断标志
        interrupt_flag = self.interruption_manager.create_interruption_flag(
            session_id
        )

        try:
            async for event in self._execute_stream(
                message,
                session_id,
                interrupt_flag,
                **kwargs
            ):
                # 检查中断
                if interrupt_flag.is_set():
                    yield ChatEvent(
                        type="interrupted",
                        content={
                            "message": "任务已被用户取消",
                            "timestamp": time.time()
                        },
                        timestamp=time.time()
                    )
                    break

                yield event

        finally:
            # 清理
            self.interruption_manager.clear_interruption(session_id)

    async def _execute_stream(
        self,
        message: str,
        session_id: str,
        interrupt_flag: asyncio.Event,
        **kwargs
    ):
        """执行流（检查中断）"""

        async for event in self.graph.astream(...):
            # 定期检查中断标志
            if interrupt_flag.is_set():
                break

            yield event
```

### 3. API端点

```python
# api/interruption_api.py
@router.post("/agent/chat/interrupt")
async def interrupt_chat(
    session_id: str = Header(...),
    interruption_manager: InterruptionManager = Depends(get_interruption_manager)
):
    """中断会话"""
    interruption_manager.request_interruption(session_id)
    return {"message": "中断请求已发送", "session_id": session_id}
```

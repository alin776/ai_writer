## 🎯 关键改进

### 三层错误保护机制
```
1. Agent层: run_agent()的try-catch
   ↓
2. Queue层: __error__事件传递
   ↓
3. Generator层: 外层try-catch + result检查
```

### 统一事件格式
所有事件现在包含：
- `type`: 事件类型
- `mode`: react/planning
- `data`: 事件数据
- `error_type`: 错误类型（错误事件）

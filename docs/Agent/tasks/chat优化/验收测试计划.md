## 🎯 验收原则

### 核心原则
1. **验证先行**：每个阶段完成后必须验收通过才能进入下一阶段
2. **数据驱动**：用实际数据验证，而非主观判断
3. **回归保护**：确保新功能不影响现有功能
4. **用户优先**：最终以用户体验为准

### 验收流程
```
实施 → 自测 → Code Review → 测试验收 → 决策评审 → 进入下一阶段
              ↓ 失败
            修复重测
```

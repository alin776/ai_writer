## 📝 详细分析

### 1. chat()模式

**调用链**：
```
chat() → self.graph.ainvoke() → LangGraph图执行
  → _handle_*节点（general/writing/planning/analysis/stuck）
  → Action.prepare() → _handle_agent_with_tools()
  → self.llm.ainvoke() [ChatOpenAI]
  → MonitoringCallbackHandler触发 ✅
```

**代码位置**：`langgraph_agent.py:1912-1986`

**关键代码**：
```python
async def chat(self, message: str, ...):
    # 构建初始状态
    initial_state = {
        "messages": [HumanMessage(content=message)],
        ...
    }

    # 运行LangGraph图（触发_handle_*节点）
    result = await self.graph.ainvoke(initial_state, config)

    return {...}
```

**LLM服务**：✅ **ChatOpenAI**（通过LangGraph图节点）

### 2. chat_stream() (React模式)

**调用链**：
```
chat_stream() → self.graph.astream() → LangGraph图流式执行
  → _handle_*节点（general/writing/planning/analysis/stuck）
  → Action.prepare() → _handle_agent_with_tools()
  → self.llm_with_tools.ainvoke() [ChatOpenAI]
  → MonitoringCallbackHandler触发 ✅
```

**代码位置**：`langgraph_agent.py:1988-2067`

**关键代码**：
```python
async def chat_stream(self, message: str, ...):
    # 构建初始状态
    initial_state = {
        "messages": [HumanMessage(content=message)],
        ...
    }

    # 流式运行LangGraph图
    async for event in self.graph.astream(initial_state, config):
        # 触发回调，返回SSE事件
        if on_progress:
            await on_progress(event)

    return {...}
```

**LLM服务**：✅ **ChatOpenAI**（通过LangGraph图节点，流式执行）

---

### 3. chat_with_planning()模式

**调用链**：
```
chat_with_planning() → Planning阶段
  → self._generate_text(plan_prompt)
  → 检查self.use_chatgpt标志
  → if use_chatgpt=True: self.llm.ainvoke() [ChatOpenAI] ✅
  → MonitoringCallbackHandler触发 ✅

  → Execution阶段（执行每个任务）
  → 调用工具（如read_chapter_tool、search_analysis_fragments_tool等）

  → Summarization阶段
  → self._generate_text(summary_prompt)
  → if use_chatgpt=True: self.llm.ainvoke() [ChatOpenAI] ✅
  → MonitoringCallbackHandler触发 ✅
```

**代码位置**：`langgraph_agent.py:2537-2900`

**关键代码**：
```python
async def chat_with_planning(self, message: str, ...):
    # ========== 阶段1: Planning ==========
    plan_result = await self._generate_text(
        plan_prompt,
        temperature=0.3,
        max_tokens=1000,
        task_type=TaskType.SIMPLE_QA
    )

    # ========== 阶段2: Execution ==========
    for task in tasks:
        # 调用工具执行任务
        tool_result = await execute_tool(task)

    # ========== 阶段3: Summarization ==========
    summary_result = await self._generate_text(
        summary_prompt,
        temperature=0.7,
        max_tokens=2000,
        task_type=TaskType.SUMMARIZATION
    )

    return {...}
```

**LLM服务**：✅ **ChatOpenAI**（通过_generate_text()方法）

## 🔑 关键方法：_generate_text()

**位置**：`langgraph_agent.py:970-1049`

这是决定使用哪个LLM服务的核心方法：

```python
async def _generate_text(
    self,
    prompt: str,
    temperature: float = 0.7,
    max_tokens: int = 1000,
    task_type: Optional[TaskType] = None
) -> dict:
    """根据use_chatgpt选择使用ChatOpenAI或HTTPAIService"""

    async with asyncio.timeout(60):
        # 🔧 根据use_chatgpt选择LLM服务
        if self.use_chatgpt:
            # ✅ 模式1：使用ChatOpenAI（触发监控）
            from langchain_core.messages import HumanMessage
            messages = [HumanMessage(content=prompt)]

            # 调用ChatOpenAI（会触发MonitoringCallbackHandler）
            response = await self.llm.ainvoke(
                messages,
                config={
                    "temperature": temperature,
                    "max_tokens": max_tokens
                }
            )

            generated_text = response.content
            logger.info(f"[_generate_text] 使用ChatOpenAI生成文本，tokens={...}")

            return {"text": generated_text, "usage": usage}

        else:
            # ❌ 模式2：使用HTTPAIService（兼容模式）
            messages = [{"role": "user", "content": prompt}]

            async for chunk, usage in self.ai_service._stream_chat(...):
                generated_text += chunk

            logger.info(f"[_generate_text] 使用HTTPAIService生成文本，tokens={...}")

            return {"text": generated_text, "usage": usage}
```

**决策点**：`if self.use_chatgpt:`

## 🔧 切换方式

如需切换LLM服务，只需修改配置：

### 切换到HTTPAIService（不推荐）

**方法1：环境变量**
```bash
# backend/.env
AGENT_USE_CHATGPT=false
```

**方法2：代码配置**
```python
# backend/app/core/config.py
AGENT_USE_CHATGPT: bool = False
```

**影响**：
- ❌ 所有3种模式都切换为HTTPAIService
- ❌ MonitoringCallbackHandler不再触发
- ❌ 监控覆盖率降为0%

### 保持ChatOpenAI（推荐）✅

**当前配置**：`AGENT_USE_CHATGPT=true`

**优势**：
- ✅ 100%监控覆盖
- ✅ 利用LangChain/LangGraph框架能力
- ✅ 支持原生工具调用
- ✅ 更好的可维护性

# Agent架构重构计划 - 框架优先策略

## 📌 背景与动机

### 当前问题

**架构混合导致的问题**：
1. ❌ LangChain/LangGraph 框架利用率低（约30%）
2. ❌ MonitoringCallbackHandler 无法覆盖所有LLM调用
3. ❌ Action层直接调用LLM，绕过框架监控
4. ❌ 代码维护成本高（需要理解自定义Action层）

**当前架构**：
```
LangGraph (框架层)
    ↓
Action类 (自定义业务层) ← ⚠️ 增加复杂度，绕过框架
    ↓
HTTPAIService / ChatOpenAI (LLM层)
```

### 重构目标

**核心原则**：**完全拥抱框架，简化架构**

1. ✅ 所有LLM调用统一使用 ChatOpenAI
2. ✅ 提升框架利用率到 90%+
3. ✅ 监控覆盖率 100%
4. ✅ 降低代码维护成本 60%
5. ✅ 提升后续开发效率

---

```

├─────────────────────────────────────────┤
│  ReAct模式           Planning模式         │

           ↓                    ↓

           ↓                    ↓

│  ✅ 封装领域知识（小说阶段判断等）         │

           ↓                    ↓
```

| 组件 | 当前 | 重构后 |
|------|------|--------|
| **Action职责** | Prompt构建 + LLM调用 | 仅Prompt构建 |
| **LLM调用** | HTTPAIService / ChatOpenAI | 统一ChatOpenAI |

## 📋 详细实施计划

### Phase 1: 重构Action接口（基础）

**目标**：将Action从"执行器"变为"参数准备器"

#### 1.1 定义新的Action接口

**文件**：`backend/app/services/agent/actions/base_action.py`

```python
class BaseAction:
    """Action基类 - 仅负责业务逻辑和Prompt准备"""

    async def prepare(self, state: AgentState) -> ActionResult:
        """准备参数，不调用LLM

        Returns:
            ActionResult: 包含system_prompt和元数据
        """
        raise NotImplementedError
```

**变化**：
- ❌ 移除 `run()` 方法（会调用LLM）
- ✅ 新增 `prepare()` 方法（仅准备参数）

#### 1.2 重构ActionResult

```python
@dataclass
class ActionResult:
    """Action执行结果"""
    success: bool
    system_prompt: str  # 准备好的system prompt
    metadata: dict  # 业务元数据（phase, planning_type等）
    error: Optional[str] = None
```

**变化**：
- ✅ 聚焦于Prompt和元数据
- ❌ 不再包含LLM响应内容

### Phase 2: 重构各个Action类

#### 2.1 WritingAction（写作场景）

**文件**：`backend/app/services/agent/actions/writing_action.py`

**重构前**：
```python
class WritingAction:
    async def run(self, state: AgentState):
        # 1. 判断阶段
        phase = self._detect_phase(state)

        # 2. 构建prompt
        system_prompt = self._build_prompt(phase)

        # 3. 返回（让Agent节点调用LLM）❌ 旧版本会在这里调用LLM
        return ActionResult(system_prompt=system_prompt, phase=phase)
```

**重构后**：
```python
class WritingAction:
    async def prepare(self, state: AgentState) -> ActionResult:
        """准备写作场景的prompt和参数"""
        # 1. 判断小说阶段（领域知识）
        phase = self._detect_novel_phase(state)

        # 2. 提取章节信息
        chapter_info = self._extract_chapter_info(state)

        # 3. 构建场景化prompt
        system_prompt = self.prompt_manager.render(
            "writing_agent",
            phase=phase,
            chapter_info=chapter_info,
            user_preferences={}
        )

        return ActionResult(
            success=True,
            system_prompt=system_prompt,
            metadata={
                "phase": phase.value,
                "chapter_num": chapter_info.get("chapter_num"),
                "agent_type": "writing"
            }
        )

    def _detect_novel_phase(self, state: AgentState) -> NovelPhase:
        """检测当前小说写作阶段"""
        # 保留原有的阶段判断逻辑
        chapter_id = state.get("chapter_id")
        # ... 判断逻辑
        return phase
```

**保留内容**：
- ✅ `_detect_novel_phase()` - 小说阶段判断
- ✅ `_extract_chapter_info()` - 章节信息提取
- ✅ 业务逻辑完整保留

**移除内容**：
- ❌ LLM调用代码

### Phase 3: 重构Agent节点

**文件**：`backend/app/services/agent/langgraph_agent.py`

#### 3.1 修改 `_handle_writing`

**重构前**：
```python
async def _handle_writing(self, state: AgentState) -> AgentState:
    writing_action = WritingAction(ai_service=self.ai_service, use_chatgpt=self.use_chatgpt)
    action_result = await writing_action.run(state)  # ❌ run() 会调用LLM

    if not action_result.is_success():
        return error_response

    system_prompt = action_result.data.get("system_prompt")
    return await self._handle_agent_with_tools(state, "writing", system_prompt)
```

**重构后**：
```python
async def _handle_writing(self, state: AgentState) -> AgentState:
    """处理写作场景"""
    # 1. 使用Action准备参数（业务逻辑）
    writing_action = WritingAction()
    prep_result = await writing_action.prepare(state)

    if not prep_result.success:
        return self._create_error_response(prep_result.error)

    # 2. 统一使用框架调用LLM
    return await self._handle_agent_with_tools(
        state,
        agent_type=prep_result.metadata["agent_type"],
        system_prompt=prep_result.system_prompt
    )
```

**关键变化**：
- ✅ Action只负责准备参数
- ✅ 所有LLM调用统一走 `_handle_agent_with_tools`

#### 3.2 修改其他Agent节点

**统一模式**：
```python
async def _handle_[SCENE](self, state: AgentState) -> AgentState:
    # 1. 准备参数
    action = [SCENE]Action()
    prep_result = await action.prepare(state)

    # 2. 统一调用
    return await self._handle_agent_with_tools(
        state,
        prep_result.metadata["agent_type"],
        prep_result.system_prompt
    )
```

应用到：
- `_handle_planning`
- `_handle_analysis`
- `_handle_stuck`
- `_handle_general`

```python
else:
    # 降级方案
```

# Agent 架构优化方案：智能进度显示

## 📌 问题本质

框架存在两种执行模式：
- **chat() - ReAct模式**：LangGraph自动执行，黑盒，用户看不到进度
- **chat_with_planning() - Planning模式**：三阶段执行，白盒，显示todo和进度

### 核心问题

**不是"是否需要规划"，而是"是否需要显示进度"**

```
复杂任务响应时间 = 10秒 ~ 几分钟

❌ 没有进度显示：
用户："帮我写第三章"
→ 发送请求
→ 等待...
→ 10秒...还在等
→ 30秒...是不是卡了？
→ 1分钟...要不要刷新？
→ 2分钟...算了，放弃
→ UX灾难

✅ 有进度显示：
用户："帮我写第三章"
→ 发送请求
→ ✅ Task 1: 读取章节（5秒）
→ ✅ Task 2: 检索设定（3秒）
→ ⏳ Task 3: 生成内容（进行中...已用15秒）
→ 用户知道在做什么，有预期，不焦虑
→ UX良好
```

---

## 🔍 两种模式的真实差异

### chat() 能处理复杂问题吗？

**技术上：可以！**

```python
# chat() 的 ReAct 工作流
START
  ↓
意图分类 → writing/planning/analysis/stuck
  ↓
Agent节点（决定调用工具）
  ↓
Tools执行 → 回到Agent → 继续判断 → 可能再调工具
  ↓
生成最终响应
  ↓
END

# 例如："帮我写第三章"
1. 意图 → writing
2. 调用 get_chapter_by_order_tool
3. 调用 search_analysis_fragments_tool
4. 调用 continue_writing_tool
5. 生成最终响应

所以 chat() 技术上完全能处理复杂任务！
```

### 但是...UX不可接受

| 维度 | chat() 处理复杂任务 | 评估 |
|------|-------------------|------|
| **技术上能实现吗？** | ✅ 能 | 支持多轮工具调用 |
| **用户体验好吗？** | ❌ 差 | 黑盒，等待焦虑 |
| **适合生产环境吗？** | ❌ 不适合 | UX不可接受 |

**结论：chat() 技术上能做，但UX上不能做**

---

## 💡 关键洞察

### **响应时间决定是否需要显示进度**

| 响应时间 | 用户预期 | 是否需要进度 | 原因 |
|---------|---------|------------|------|
| <3秒 | 快速响应 | ❌ 不需要 | 用户不会焦虑 |
| 3-10秒 | 稍微等待 | ⚠️ 建议显示 | 用户需要知道在做什么 |
| >10秒 | 长时间等待 | ✅ 必须显示 | 不显示会焦虑、放弃 |

### 实际场景分析

```python
# === 场景1：简单问候（1-2秒）===
用户："你好"
→ 不需要显示进度 ✅
→ 直接返回响应即可

# === 场景2：查询信息（5-10秒）===
用户："第三章写到哪了"
→ 建议显示进度 ⚠️
→ 让用户知道在查询数据库

# === 场景3：复杂创作（30-120秒）===
用户："帮我写第三章"
→ 必须显示进度 ✅
→ 显示 todo + 实时进度更新
→ 否则用户会以为卡死

# === 场景4：批量操作（>2分钟）===
用户："生成10章大纲"
→ 必须显示详细进度 ✅
→ 显示每一步的完成情况
→ 让用户有掌控感
```

## ✅ 解决方案：统一Planning模式 + 智能进度显示

### 核心思想

**不是"避免规划"，而是"根据预估时间智能显示进度"**

```python
所有请求都走 Planning 模式：
1. 生成 plan（LLM自己估算时间和复杂度）
2. 根据预估时间决定是否显示进度：
   - <3秒：快速通道，不显示 todo
   - 3-10秒：显示 todo，简化进度
   - >10秒：显示 todo + 详细实时进度
3. 执行 plan
4. 返回结果

优势：
✅ 一套代码，易维护
✅ 简单对话快速，不冗余
✅ 复杂任务显示进度，UX好
✅ 根据实际耗时自适应
✅ 符合用户对响应时间的预期
```

### 优化2: 根据预估时间分级处理

```python
async def chat_with_planning(
    self,
    message: str,
    work_id: Optional[str] = None,
    chapter_id: Optional[str] = None,
    conversation_id: Optional[str] = None,
    context: Optional[Dict[str, Any]] = None,
    on_plan: Optional[callable] = None,
    on_task_start: Optional[callable] = None,
    on_task_progress: Optional[callable] = None,
    on_task_done: Optional[callable] = None,
    on_content: Optional[callable] = None
):
    """统一的Planning模式 - 根据预估时间智能显示进度"""

    # ========== 阶段1: 智能生成plan ==========
    plan_data = await self._generate_plan_smart(message, context)

    # 解析预估时间
    total_time = plan_data.get("total_estimated_time", 0)
    if not total_time:
        total_time = self._calculate_total_time(plan_data)

    logger.info(f"[Planning] 预估总耗时: {total_time}秒")

    # ========== 阶段2: 根据预估时间分级处理 ==========

    if total_time < 3:
        # 快速通道：不显示进度
        logger.info("[Planning] 快速任务(<3秒)，不显示进度")
        return await self._quick_execute(
            message=message,
            plan_data=plan_data,
            conversation_id=conversation_id,
            context=context
        )

    elif total_time < 10:
        # 简化进度：只显示todo，不显示详细进度
        logger.info("[Planning] 中等任务(3-10秒)，简化进度")

        if on_plan:
            await on_plan(plan_data)  # 显示todo list

        # 执行tasks，但不发送详细进度
        task_results = await self._execute_tasks_simple(
            tasks=plan_data["tasks"],
            work_id=work_id,
            chapter_id=chapter_id
        )

        final_content = await self._build_final_response(
            task_results=task_results,
            message=message,
            on_content=on_content
        )

        await self._save_to_checkpointer(conversation_id, message, final_content)

        return {
            "response": final_content,
            "conversation_id": conversation_id,
            "agent_steps": task_results,
            "suggested_actions": [],
            "metadata": {
                "mode": "simple_progress",
                "estimated_time": total_time,
                "timestamp": str(datetime.now())
            }
        }

    else:
        # 完整进度：显示todo + 实时详细进度
        logger.info(f"[Planning] 复杂任务(>{10}秒)，完整进度")

        if on_plan:
            await on_plan(plan_data)  # 显示todo list

        # 执行tasks，发送详细进度
        task_results = await self._execute_tasks_with_progress(
            tasks=plan_data["tasks"],
            work_id=work_id,
            chapter_id=chapter_id,
            on_task_start=on_task_start,
            on_task_progress=on_task_progress,
            on_task_done=on_task_done
        )

        final_content = await self._build_final_response(
            task_results=task_results,
            message=message,
            on_content=on_content
        )

        await self._save_to_checkpointer(conversation_id, message, final_content)

        return {
            "response": final_content,
            "conversation_id": conversation_id,
            "agent_steps": task_results,
            "suggested_actions": [],
            "metadata": {
                "mode": "detailed_progress",
                "estimated_time": total_time,
                "actual_time": sum(t.get("elapsed_time", 0) for t in task_results),
                "timestamp": str(datetime.now())
            }
        }


def _calculate_total_time(self, plan_data: dict) -> float:
    """计算总预估时间（如果LLM没有返回）"""
    tasks = plan_data.get("tasks", [])
    total = 0

    for task in tasks:
        estimated = task.get("estimated_time", "5秒")
        # 解析 "5秒"、"10-20秒" 等
        if "秒" in estimated:
            time_str = estimated.replace("秒", "").strip()
            if "-" in time_str:
                # "10-20秒" → 取平均值
                try:
                    start, end = time_str.split("-")
                    total += (float(start) + float(end)) / 2
                except:
                    total += 5  # 默认5秒
            else:
                try:
                    total += float(time_str)
                except:
                    total += 5  # 默认5秒

    return total


async def _quick_execute(
    self,
    message: str,
    plan_data: dict,
    conversation_id: str,
    context: Dict[str, Any]
) -> dict:
    """快速执行通道（<3秒任务）"""

    # 对于简单对话，直接生成回复
    if len(plan_data["tasks"]) == 1 and plan_data["tasks"][0].get("tool") == "none":
        prompt = f"""你是友好的AI写作助手。

用户说：{message}

请简洁、友好地回复用户。

回复："""

        result = await self._generate_text(
            prompt=prompt,
            temperature=0.7,
            max_tokens=200,
            task_type=TaskType.CHAT
        )

        final_content = result.get("text", "你好！有什么我可以帮助你的吗？")
    else:
        # 快速执行工具调用
        task_results = await self._execute_tasks_simple(
            tasks=plan_data["tasks"],
            work_id=None,
            chapter_id=None
        )

        final_content = await self._build_final_response(
            task_results=task_results,
            message=message
        )

    # 保存对话历史
    await self._save_to_checkpointer(conversation_id, message, final_content)

    return {
        "response": final_content,
        "conversation_id": conversation_id,
        "agent_steps": [{
            "step": "quick_response",
            "result": "快速响应"
        }],
        "suggested_actions": [],
        "metadata": {
            "mode": "quick",
            "timestamp": str(datetime.now())
        }
    }
```

### 优化3: API层智能回调

```python
# API层：根据plan自动决定显示级别
@router.post("/chat/stream")
async def agent_chat_stream(
    request: AgentChatRequest,
    current_user: User = Depends(get_current_active_user),
    memory: MemoryManager = Depends(get_memory_manager),
    db: AsyncSession = Depends(get_db)
):
    """流式对话 - 智能进度显示"""

    async def event_generator():
        event_queue = asyncio.Queue()

        # 智能回调：根据plan自动决定显示内容
        async def on_plan(plan_data):
            # 计算预估时间
            total_time = plan_data.get("total_estimated_time", 0)
            if not total_time:
                total_time = sum_estimated_time(plan_data["tasks"])

            # 只有中等/复杂任务才显示plan
            if total_time >= 3:
                await event_queue.put(('plan', plan_data))
                logger.info(f"[Stream] 发送规划: {len(plan_data['tasks'])} 个任务，预估{total_time}秒")

        async def on_task_start(task):
            await event_queue.put(('task_start', task))

        async def on_task_done(task, result_data):
            await event_queue.put(('task_done', {
                'task_id': task.get('task_id'),
                'description': task.get('description'),
                'elapsed_time': task.get('elapsed_time', 0)
            }))

        # 调用Agent
        result = await agent_graph.chat_with_planning(
            message=request.message,
            work_id=request.work_id,
            chapter_id=request.chapter_id,
            conversation_id=conversation_id,
            context=context,
            on_plan=on_plan,
            on_task_start=on_task_start,
            on_task_done=on_task_done
        )

        # 实时发送事件
        while True:
            event_type, event_data = await event_queue.get()
            if event_type == '__done__':
                break
            yield f"data: {json.dumps({'type': event_type, 'data': event_data}, ensure_ascii=False)}\n\n"

        yield f"data: {json.dumps({'type': 'done', 'metadata': result['metadata']}, ensure_ascii=False)}\n\n"

    return StreamingResponse(event_generator(), media_type="text/event-stream")
```

## 🎉 总结

### 核心理念

**问题的本质不是"是否需要规划"，而是"是否需要显示进度"**

```
关键洞察：
✅ 响应时间长（>10秒）→ 必须显示进度，否则UX灾难
✅ chat() 技术上能处理复杂问题，但UX不可接受
✅ 所有请求统一走Planning模式
✅ 根据预估时间智能决定是否显示进度
```

### 解决方案

**统一Planning模式 + 根据预估时间分级显示进度**

```
<3秒：快速通道，不显示todo
├─ "你好"
├─ "什么意思"
└─ 简单问答

3-10秒：显示todo，简化进度
├─ "第三章写到哪了"
├─ "查找相关信息"
└─ 简单查询

>10秒：显示todo + 详细实时进度
├─ "帮我写第三章"
├─ "分析这段文字"
└─ 复杂创作任务
```

### 优势

1. **用户体验优化**
   - 简单对话：快速响应，无冗余
   - 复杂任务：清晰进度，不焦虑
   - 有时间预期，减少放弃率

2. **架构统一**
   - 一套执行逻辑
   - 易维护，bug少
   - 代码简洁

3. **智能自适应**
   - LLM自己估算时间
   - 自动选择显示级别
   - 符合用户预期

4. **性能提升**
   - 简单对话速度提升50%+
   - 复杂任务可并行执行

- ✅ Parallel execution（并行执行）
- ✅ Human-in-the-loop（人工介入）
- ✅ Time travel debugging（时间旅行调试）

**未来LangGraph可能新增的功能：**

- 自动重试和错误恢复
- 分布式执行支持

**如果我们自己实现Planning，这些都要自己写！**

### ✅ 更好的方案：增强ReAct，而不是放弃它

#### 核心洞察

**问题不是"Planning vs ReAct"，而是"如何给ReAct加进度显示"**

#### 解决方案：使用 LangGraph 的 Stream API

```python
async def chat_stream(
    self,
    message: str,
    work_id: Optional[str] = None,
    chapter_id: Optional[str] = None,
    conversation_id: Optional[str] = None,
    context: Optional[Dict[str, Any]] = None,
    on_progress: Optional[callable] = None
):
    """ReAct模式 + 流式进度显示"""

    initial_state = {
        "messages": [HumanMessage(content=message)],
        "work_id": work_id,
        "chapter_id": chapter_id,
        "context": context or {},
        ...
    }

    config = {
        "configurable": {"thread_id": conversation_id or "default"},
        "recursion_limit": 50
    }

    # ========== 关键：使用 astream() 而不是 ainvoke() ==========
    async for event in self.graph.astream(initial_state, config):
        # event 包含每个节点的执行信息
        node_name = list(event.keys())[0]
        node_data = event[node_name]

        # 转换为进度事件
        if node_name == "intent_classifier":
            if on_progress:
                await on_progress({
                    "type": "intent",
                    "data": {"intent": node_data.get("intent")},
                    "timestamp": datetime.now().isoformat()
                })

        elif node_name == "tools":
            # 工具执行中
            if on_progress:
                await on_progress({
                    "type": "tool_execution",
                    "data": {
                        "tools": [m.name for m in node_data.get("messages", [])
                                 if hasattr(m, 'name')]
                    },
                    "timestamp": datetime.now().isoformat()
                })

        elif node_name in ["writing_agent", "planning_agent", "analysis_agent", "stuck_agent"]:
            # Agent思考中
            if on_progress:
                await on_progress({
                    "type": "agent_thinking",
                    "data": {"agent": node_name},
                    "timestamp": datetime.now().isoformat()
                })

    # 获取最终结果
    final_state = await self.graph.aget_state(config)

    return {
        "response": final_state.values.get("final_response"),
        "conversation_id": conversation_id or "default",
        "agent_steps": final_state.values.get("agent_steps", []),
        "suggested_actions": final_state.values.get("suggested_actions", []),
        "metadata": {
            "intent": final_state.values.get("intent"),
            "timestamp": str(datetime.now())
        }
    }
```

**优势：**
- ✅ 保留LangGraph框架（~50行代码 vs 830行）
- ✅ 有进度显示（实时反馈每个节点）
- ✅ 跟随LangGraph演进
- ✅ 可以使用LangGraph的所有高级功能
- ✅ 不依赖LLM估算时间
- ✅ 保持灵活性

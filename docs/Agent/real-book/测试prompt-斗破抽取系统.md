# 《斗破：开局获取抽取系统》AI写作助手 - 演示测试 Prompt 集

> 以下 Prompt 设计用于推广视频演示，覆盖「技能」「TodoList」「Task」等核心 AI 功能界面。

---

## 一、技能（Skill）演示 Prompt

### Prompt 1：角色技能卡生成
```
请根据以下小说设定，为主角「萧凌」生成一张完整的角色技能卡：

小说：《斗破：开局获取抽取系统》
身份：穿越者，乌坦城萧家子弟，萧家第一天才
年龄：8岁
修为：斗者一星
斗气属性：火（夹杂一丝木属性）
功法：焚诀（可通过吞噬异火进化，潜力超越天阶）、太一魂决（远古灵魂修炼法）
斗技：碎爪击（黄阶中级）、劈山掌（黄阶中级）、碎石掌（黄阶中级）、吸掌（玄阶低级，装13神技）
物品：二十四桥明月夜（储物腰带，24格各1立方米）、无限可乐瓶、极品幸运卡、骇然发情丹
系统能力：万界抽取系统——每提升一级境界获得一次抽取机会，可从诸天万界随机抽取物品

请生成包含以下模块的技能卡：
1. 基础属性面板
2. 主动技能列表（含冷却/消耗描述）
3. 被动技能（天生灵魂力强大、穿越者先知等）
4. 系统专属能力说明
5. 潜力评估（基于焚诀进化路线）
```

### Prompt 2：战斗技能模拟
```
基于小说《斗破：开局获取抽取系统》的设定，模拟一场萧凌的战斗场景：

对手：一名斗者三星的萧家子弟（擅长劈山掌）
场地：萧家练武场

请按回合制展示战斗过程，每回合包含：
- 双方行动选择（攻击/防御/技能释放）
- 技能效果描述
- 斗气消耗情况
- 战斗解说（带有小说风格的文字描写）

萧凌可使用：吸掌、碎爪击、劈山掌、桃花火（兽火外放）
要求展现萧凌灵魂感知力的优势（能预判对手动作）。
```

### Prompt 3：抽取系统技能树设计
```
为小说《斗破：开局获取抽取系统》中的「万界抽取系统」设计一套完整的技能树/进化路线：

已知规则：
- 每提升一级境界获得一次抽取机会
- 抽取物品从诸天万界随机获取（已抽到：斗罗大陆、一念永恒、现代世界的物品）
- 抽取机会可叠加

请设计：
1. 系统升级路线（青铜→白银→黄金→钻石→神话级）
2. 每级解锁的新功能（如：定向抽取、品质保底、连抽保底、跨界召唤等）
3. 隐藏成就系统（如"首次抽到天阶物品"、"集齐五行兽火"等）
4. 用技能树/流程图的形式展示

要求风格贴合斗破苍穹世界观。
```

## 二、TodoList 演示 Prompt

### Prompt 4：章节写作 TodoList
```
我正在续写小说《斗破：开局获取抽取系统》，目前写到第10章「吸收兽火」。请帮我生成接下来10章（第11-20章）的写作 TodoList。

已有剧情线索：
- 萧凌8岁，刚突破斗者一星，已吸收桃花火
- 还有大地焰火和乾蓝水炎两朵兽火未吸收
- 下个月迦南学院来乌坦城招生
- 萧凌计划去迦南学院修炼
- 与萧薰儿关系亲密（青梅竹马，萧凌每晚帮她蕴养筋脉）
- 萧炎是竞争对手，目前斗之气六段
- 系统还有4次抽取机会未使用
- 持有焚诀但目前只是黄阶低级，需要吞噬兽火进化
- 还有《弄炎决》（玄阶高级，萧薰儿所赠）

每个章节的 Todo 项请包含：
- [ ] 章节标题
- [ ] 核心剧情事件（1-2句话概括）
- [ ] 涉及的关键角色
- [ ] 需要展现的系统/抽取环节
- [ ] 感情线推进节点
- [ ] 伏笔/悬念设置
```

### Prompt 5：世界观设定核查 TodoList
```
请根据《斗破：开局获取抽取系统》的前10章内容，生成一份世界观设定核查 TodoList，确保后续写作不会出现设定矛盾。

请逐项列出需要核查的内容：

【修为体系】
- [ ] 斗气等级划分是否完整（斗之气→斗者→斗师→大斗师→斗灵→斗王→斗皇→斗宗→斗尊→斗圣→斗帝）
- [ ] 各等级对应的能力表现是否一致
- [ ] 功法等级划分（黄→玄→地→天）是否正确使用

【角色信息】
- [ ] 萧凌年龄线是否自洽（4岁觉醒→8岁突破斗者）
- [ ] 萧炎的修为进度是否合理
- [ ] 萧薰儿的身份设定（古族神品血脉）是否有矛盾
- [ ] 配角信息是否前后一致（萧白、萧宁、萧玉、谷尼等）

【系统设定】
- [ ] 抽取次数计算是否正确（初始1次 + 8次升级 = 9次，已用3次，剩余应为多少？）
- [ ] 已抽取物品清单是否完整
- [ ] 系统规则是否前后一致

【剧情逻辑】
- [ ] 金币来源和消费是否合理
- [ ] 时间线是否自洽
- [ ] 原著角色（药尘、古族凌影等）的行为是否符合设定
```

## 三、Task 任务演示 Prompt

### Prompt 7：多线并行写作任务
```
请为小说《斗破：开局获取抽取系统》创建以下并行写作任务：

【Task 1：迦南学院入学篇大纲】
编写第11-20章的详细大纲，包含：
- 萧凌离开萧家前的告别场景（重点：与萧薰儿的离别）
- 前往迦南学院的路途奇遇（至少安排1次系统抽取）
- 入学测试的精彩展现（展示焚诀+吸掌的组合战斗）
- 与新角色的初次交锋（建议引入原著角色：韩闲、林修涯等）

【Task 2：万界抽取系统 - 4次抽取结果设计】
萧凌还有4次未使用的抽取机会，请设计4次抽取结果：
- 每次抽取需注明来源世界
- 物品需对当前剧情有推动作用
- 至少1次抽取出"坑爹"物品（制造喜剧效果）
- 至少1次抽取出关键性强力物品
- 考虑被抽取世界的"蝴蝶效应"反应场景

【Task 3：萧炎支线剧情】
设计萧炎在萧凌离开后的发展走向：
- 没有焚诀的萧炎如何修炼？药尘是否还会收他为徒？
- 萧炎与萧薰儿的关系变化
- 萧炎的性格发展（是否因竞争失败变得更加偏激）
- 为未来"萧炎 vs 萧凌"的高潮对决埋下伏笔

【Task 4：感情线发展规划】
规划萧凌与萧薰儿的感情发展节奏：
- 当前阶段：青梅竹马期（8岁）
- 中期目标：正式确认心意的关键事件
- 设计3个感情升温的经典场景
- 安排1个误会/考验事件增加戏剧冲突
- 考虑古族对两人关系的态度
```

### Prompt 8：单章精写任务
```
【写作任务】请精写《斗破：开局获取抽取系统》第11章

章节标题建议：「迦南学院的邀请」

要求：
1. 延续前文风格（轻松幽默+热血+甜宠）
2. 字数：3000-4000字
3. 必须包含以下场景：
   - 迦南学院招生使者到达乌坦城
   - 萧凌展示实力引起招生使者注意
   - 使用1次系统抽取（在关键时刻触发）
   - 萧薰儿的反应和互动（体现两人默契）
   - 萧炎的竞争心理描写
4. 在章末设置一个吸引读者继续阅读的悬念
5. 保持萧凌的人设：外表温和、内心吐槽、对萧薰儿温柔、有穿越者的先知优势

写作风格参考（来自原文）：
- 系统提示格式：【滴，系统抽取中.....恭喜宿主抽取到XXX】
- 内心吐槽风格："这不是渣男玉小刚给唐三的储物魂导器..."
- 旁人反应模板："此子恐怖如斯！"
```

## 使用建议

| 演示功能 | 推荐使用 Prompt | 演示亮点 |
|---------|----------------|---------|
| **技能 Skill** | Prompt 1、2、3 | 展示 AI 生成角色面板、模拟战斗、设计技能树的能力 |
| **TodoList** | Prompt 4、5、6 | 展示 AI 辅助写作规划、设定核查、伏笔管理的结构化能力 |
| **Task 任务** | Prompt 7、8、9 | 展示 AI 多任务并行处理、精写章节、世界观扩展的能力 |
| **综合演示** | Prompt 10 | 一个 Prompt 同时触发 TodoList + Task + Skill 三大功能 |

### 演示顺序建议
1. 先用 **Prompt 1**（技能卡）快速展示 AI 对小说设定的理解能力
2. 再用 **Prompt 4**（章节 TodoList）展示结构化规划能力
3. 然后用 **Prompt 7**（多线任务）展示并行处理能力
4. 最后用 **Prompt 10**（项目管理）作为综合收尾，一次性展示所有功能

# 一键演示 Prompt（直接复制使用）

```
你是一位专业的AI网文写作助手。我正在创作一部小说《斗破：开局获取抽取系统》，现在需要你帮我完成一整套系统性的创作辅助工作。请按照下面的指令，依次完成全部任务模块，每个模块用分割线清晰隔开。

=====================================
【素材背景】
=====================================

小说：《斗破：开局获取抽取系统》
类型：斗破苍穹同人 / 系统流 / 穿越
当前进度：已完成第1-10章（乌坦城篇）

主角设定：
- 姓名：萧凌（穿越者，前世蓝星大学生，因救人溺亡后穿越）
- 年龄：8岁
- 身份：乌坦城萧家子弟，萧家第一天才
- 修为：斗者一星
- 斗气属性：火（夹杂一丝木属性）
- 功法：焚诀（从药尘骨炎戒中抽取，可吞噬异火进化，潜力超越天阶）、太一魂决（丹塔藏书库远古灵魂修炼法）、弄炎决（玄阶高级，萧薰儿所赠）
- 斗技：碎爪击（黄阶中级）、劈山掌（黄阶中级）、碎石掌（黄阶中级）、吸掌（玄阶低级，从坊市黑铁片中获得）
- 特殊能力：天生灵魂力极强（穿越者灵魂高维降临）、穿越者先知（熟知原著剧情走向）
- 性格：外表温和待人、内心疯狂吐槽、对萧薰儿温柔专一

万界抽取系统：
- 规则：每提升一级境界获得一次抽取机会，从诸天万界随机抽取，抽取机会可叠加
- 剩余抽取次数：4次
- 已抽取记录：
  ① 斗罗大陆·玉小刚的「二十四桥明月夜」（储物腰带，24格各1立方米，附带2万金币）
  ② 云岚宗·古河纳戒中的「聚气散」（四品丹药，已使用突破斗者）
  ③ 丹塔藏书库的「太一魂决」（灵魂修炼功法）
  ④ 药尘骨炎戒中的「焚诀」（斗气大陆第一功法）
  ⑤ 现代世界的「无限可乐瓶」（可乐无限续杯）
  ⑥ 一念永恒·白小纯纳戒中的「骇然发情丹」（坑爹物品）
  ⑦「极品幸运卡」一张（未使用）

关键角色关系：
- 萧薰儿：古族神品血脉，与萧凌青梅竹马，朋友以上恋人未满，萧凌每晚偷偷帮她蕴养筋脉
- 萧炎：原著主角，萧家前第一天才（被萧凌取代），斗之气六段，与萧凌存在竞争关系
- 古族凌影：斗皇级护卫，守护萧薰儿，可能已发现萧凌夜访
- 药尘：骨炎戒中沉睡的斗尊强者，焚诀已被系统抽走

当前剧情节点：
- 萧凌刚突破斗者一星，已吸收桃花火（四阶兽火）
- 还有大地焰火、乾蓝水炎两朵兽火未吸收
- 下个月迦南学院来乌坦城招生，萧凌计划入学
- 持有焚诀但仅黄阶低级，需吞噬更多兽火进化

已埋伏笔：
- 萧薰儿第一晚被蕴养筋脉后"睁开眼睛，眼里闪过复杂神色"
- 焚诀被从药尘骨炎戒中抽走，药尘尚未发现
- 玉小刚在斗罗大陆丢失了二十四桥明月夜
- 白小纯在通天大陆丢失了发情丹
- 极品幸运卡尚未使用
- 萧炎偷看萧玉洗澡被萧凌暗中阻止

=====================================
【模块一：技能 Skill】— 角色能力全景展示
=====================================

请完成以下3项技能相关输出：

■ 1. 萧凌角色技能卡
为萧凌生成一张结构化的角色技能卡，包含：
- 基础属性面板（以表格形式呈现：姓名/年龄/修为/斗气属性/天赋评级）
- 主动技能列表（每个技能含：名称、等级、效果描述、斗气消耗、特殊备注）
- 被动技能（天生灵魂力强大、穿越者先知、焚诀火属性亲和等）
- 系统专属能力（万界抽取的详细机制说明）
- 潜力评估S级评语（基于焚诀进化路线+太一魂决+灵魂天赋的综合上限分析）

■ 2. 战斗技能模拟
模拟一场萧凌 vs 萧家斗者三星子弟的练武场切磋，按回合制展示：
- 共3回合，每回合包含：双方行动→技能效果→斗气变化→小说风格战斗描写
- 重点展现：灵魂感知预判、吸掌的装13效果、桃花火的压制力
- 最后以萧凌轻松获胜收尾，旁观者反应："此子恐怖如斯！"

■ 3. 万界抽取系统技能树
设计系统的5级进化路线（青铜→白银→黄金→钻石→神话），每级包含：
- 解锁条件（累计抽取次数/境界要求）
- 新增功能（如定向抽取、品质保底、连抽十连、跨界召唤等）
- 代表性隐藏成就3条
用层级缩进或树状结构展示。

【模块二：TodoList】— 创作管理清单
=====================================

- [ ] 系统抽取/技能展示环节
- [ ] 萧凌×萧薰儿感情线推进
- [ ] 本章伏笔或悬念钩子

要求覆盖以下剧情线：吸收剩余兽火→焚诀进化→迦南学院招生→入学测试→离别萧薰儿→学院新角色登场

■ 5. 世界观设定核查 TodoList
生成一份设定一致性核查清单，分4个维度逐项列出：

【修为体系核查】
- [ ] 等级体系完整性（斗之气→斗者→...→斗帝）
- [ ] 功法/斗技等级划分（黄→玄→地→天）使用是否正确

【角色信息核查】

- [ ] 萧炎修为进度合理性
- [ ] 萧薰儿身份设定一致性
- [ ] 配角信息前后一致（萧白、萧宁、萧玉、谷尼等）

【系统数据核查】

- [ ] 已抽取物品完整清单
- [ ] 系统规则前后一致性

【剧情逻辑核查】
- [ ] 金币收支是否合理（玉小刚2万 - 手链200 - 魔核1410 - 聚气散交易...）

■ 6. 伏笔与角色关系追踪 TodoList

【已埋伏笔状态追踪】
为每条伏笔标注状态（待回收/进行中/已回收）：

- [ ] 玉小刚丢失二十四桥明月夜 → 是否影响唐三剧情？
- [ ] 白小纯丢失发情丹 → 后续联动可能？
- [ ] 极品幸运卡 → 最佳使用时机建议？

【角色关系发展规划】

- [ ] 设计1个万界系统相关的重大悬念

【模块三：Task 任务】— 并行创作任务
=====================================

请同时创建并执行以下4个独立任务：

■ Task 1：迦南学院篇大纲（第11-20章详细大纲）
为每一章输出200-300字的详细大纲，包含：
- 场景描写要点
- 对话设计方向
- 萧凌的内心吐槽点（至少每章1处，风格参考："这不是渣男玉小刚给唐三的储物魂导器..."）
- 系统抽取触发时机
- 章末钩子设计
大纲需覆盖：告别萧薰儿→旅途奇遇→抵达学院→入学测试→初识新角色（韩闲、林修涯等）

■ Task 2：4次抽取结果设计
为剩余4次抽取机会设计结果，每次包含：
- 来源世界与被抽取者
- 物品名称与详细效果
- 对萧凌当前剧情的作用
- 被抽取世界的蝴蝶效应场景（100-200字小剧场）
要求：至少1个坑爹搞笑物品 + 至少1个改变战局的强力物品 + 来源世界不能与已有的重复

■ Task 3：萧炎支线剧情设计
设计萧凌前往迦南学院后，萧炎在乌坦城的发展走向：
- 没有焚诀的情况下，药尘是否还会收萧炎为徒？给出合理推演
- 萧炎与萧薰儿的关系变化（萧凌离开后的微妙变化）
- 萧炎因竞争失败产生的心理变化与成长
- 为未来"萧凌 vs 萧炎"的高潮对决埋设3条伏笔线

■ Task 4：第11章「迦南学院的邀请」完整正文
直接精写第11章全文，要求：
- 字数：3000-4000字
- 风格：轻松幽默 + 热血 + 甜宠，延续前10章文风
- 必含场景：迦南学院招生使者到达乌坦城 → 萧凌展示实力 → 触发1次系统抽取 → 萧薰儿互动（体现默契） → 萧炎竞争心理 → 章末悬念
- 系统提示格式：【滴，系统抽取中.....恭喜宿主抽取到XXX】
- 旁人惊叹模板：长老/使者倒吸一口凉气，"此子恐怖如斯！"
- 萧凌内心吐槽至少3处
```

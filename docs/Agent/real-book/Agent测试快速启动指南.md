## ⚡ 5分钟快速启动

### 步骤1: 启动服务 (2分钟)

#### 启动后端
```bash
# 打开终端1
cd D:\Java\ai_writer\backend
.\venv\Scripts\python.exe main.py
# 等待看到: Uvicorn running on http://0.0.0.0:8000
```

#### 启动前端
```bash
# 打开终端2
cd D:\Java\ai_writer
npm run dev
# 等待看到: Local: http://localhost:5173/
```

### 步骤2: 访问系统 (1分钟)

1. 打开浏览器访问: **http://localhost:5173**
2. 使用管理员账号登录
3. 进入系统主页

### 步骤3: 导入小说 (2分钟)

1. 点击左侧菜单"导入"
2. 选择文件格式: **txt**
3. 选择文件: **D:\Java\ai_writer\docs\Agent\real-book\一夕千悟，从杂役弟子开始.txt**
4. 点击"预览导入"
5. 确认后点击"开始导入"
6. 等待导入完成（可能需要3-5分钟）

### 步骤4: 开始测试 (随时)

导入完成后，即可开始测试Agent的各项功能！

## 📊 关键指标

### 性能基准
- ✅ **优秀**: 响应 < 20秒，缓存命中率 > 99%
- ⚠️ **良好**: 响应 < 30秒，缓存命中率 > 95%

## 🛠️ 快速故障排除

### 常见问题速查

| 问题现象 | 可能原因 | 快速解决 |
|----------|----------|----------|
| **服务启动失败** | 端口被占用 | 重启电脑，重新启动 |
| **导入失败** | 文件路径错误 | 检查文件是否在正确位置 |
| **Agent无响应** | API密钥问题 | 检查.env文件配置 |
| **响应慢** | 网络问题 | 检查网络连接，重启服务 |

### 紧急重启命令
```bash
# 重启后端
Ctrl+C (停止) → .\venv\Scripts\python.exe main.py

# 重启前端
Ctrl+C (停止) → npm run dev

# 清理缓存 (如需要)
redis-cli FLUSHALL
```

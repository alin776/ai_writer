## 测试 1：TXT 导入换行修复 (`import_service._normalize_content`)

**目标**：验证导入的 TXT 文件中相邻段落间能正确生成空行（Markdown 分段）

**操作步骤**：
1. 在作品页面点击"导入"
2. 选择 `斗破：开局获取抽取系统.txt` 文件导入
3. 导入完成后，依次点击打开前 3 个章节

**验证要点**：
- [ ] 每个段落之间有明显的空行分隔（不是所有文字挤在一起）
- [ ] 首行缩进的段落（如 `　　迷迷糊糊之间...`）正确保留缩进
- [ ] 没有出现多余的连续空行（最多只有一个空行分隔）
- [ ] 章节标题如 `第1章 重生斗气大陆` 正确识别为章节分割点

## 测试 2：Frontmatter 解析与清理 (`frontmatter.py` 全面重构)

### 2a：正常 Frontmatter 解析

**操作步骤**：
1. 打开导入后的任意章节（如"第1章 重生斗气大陆"）
2. 查看编辑器中的内容

**验证要点**：
- [ ] 编辑器中 **不显示** `---`、`title:`、`status: draft` 等 YAML 元数据
- [ ] 只显示纯正文内容（如 `迷迷糊糊之间，萧凌缓缓的睁开了双眼...`）
- [ ] 章节标题在侧边栏/标签中正确显示

### 2b：Milkdown 损坏的 Frontmatter 清理

**操作步骤**：
1. 打开一个章节，在编辑器最顶部手动输入以下内容模拟 Milkdown 损坏：
   ```
   ***
   status: draft
   title: 测试损坏标题
   ---------
   ```
2. 保存章节
3. 切换到其他章节，再切换回来

**验证要点**：
- [ ] 重新打开后，损坏的 frontmatter 元数据被自动清理
- [ ] 正文内容不丢失
- [ ] 编辑器中不再显示 `***`、`status: draft`、`title:` 等残留

### 2c：裸 YAML 残留清理

**操作步骤**：
1. 打开一个章节，在编辑器最顶部手动输入：
   ```
   status: draft
   title: 第1章 重生斗气大陆
   ```
2. 保存，切换章节再切回

**验证要点**：
- [ ] 裸 YAML 残留被清理（同时包含 title: 和 status: 的已知值时才清理）
- [ ] 正文不受影响

## 测试 4：Agent 对话核心功能

### 4a：Agent 对话基本流程（流式响应）

**Prompt**：
```
帮我分析一下《斗破：开局获取抽取系统》这部小说前5章的主要角色和剧情走向
```

**验证要点**：
- [ ] Agent 能正确发起流式响应（SSE）
- [ ] 执行轨迹（ExecutionFlow）正常显示步骤
- [ ] Agent 使用 `read_file` 或 `semantic_search` 读取章节内容
- [ ] 分析结果包含主要角色（萧凌、萧薰儿、萧炎等）
- [ ] 分析准确反映剧情走向（穿越重生、系统觉醒、与萧薰儿关系发展等）

### 4b：上下文容量限制提示 (`prompts.py` 规则 3)

**Prompt**：
```
请帮我逐章阅读全部10个章节，每章写一份详细的内容摘要
```

**验证要点**：
- [ ] Agent 应该使用 `semantic_search` 或分批处理，而不是逐个 `read_file` 读取所有章节
- [ ] 如果 Agent 触发 read_file 超过 15 个文件，系统规则应引导其优化策略
- [ ] 最终能完成任务，不因上下文过长而报错

### 4c：错误提示增强（上下文过长/超时）

**操作步骤**：
1. 在一个长对话中连续发送多轮复杂请求，尝试触发上下文过长
2. 或者在网络不佳时测试超时场景

**验证要点**：
- [ ] 如果触发 "context length" 类错误，显示中文提示：`（可能原因：对话上下文过长。建议：开启新对话...）`
- [ ] 如果触发超时，显示：`（可能原因：AI 服务响应超时，请稍后重试）`
- [ ] 错误提示显示在 UI 中，用户能理解如何处理

### 4d：recursion_limit 降低 (500→150)

**Prompt**：
```
请帮我续写第10章之后的剧情，写一个完整的新章节（第11章），要求2000字以上，包含萧凌使用《焚诀》吞噬兽火进化功法的详细过程
```

**验证要点**：
- [ ] Agent 能在 150 次递归限制内完成任务
- [ ] 如果任务太复杂，Agent 应自行拆分，而不是直接失败
- [ ] 最终生成的章节内容完整、质量合格

## 测试 7：Agent 对话中使用小说素材的综合场景

### 7a：角色关系分析

**Prompt**：
```
请分析萧凌、萧薰儿、萧炎三人的关系发展，特别是萧凌如何逐步取代萧炎在萧家的地位，以及萧凌与萧薰儿的感情线发展
```

**验证要点**：
- [ ] Agent 准确识别三人关系（萧凌是穿越者主角，萧炎是原著主角，萧薰儿是女主）
- [ ] 分析到位（蕴养筋脉→关系亲近→逛街送手链→功法相赠）
- [ ] 修订建议（如有）以 RevisionCard 形式展示

### 7b：续写与一致性维护

**Prompt**：
```
请帮我续写第11章，要求：
1. 萧凌来到大长老和萧战争吵的会议大厅
2. 展示萧凌的高情商和萧家内部矛盾
3. 引入迦南学院招生的话题
4. 保持和前10章一致的文风和节奏
```

**验证要点**：
- [ ] Agent 先使用 `semantic_search` 或 `read_file` 了解前文内容
- [ ] 续写风格与原文一致（第三人称、轻松幽默、网文节奏）
- [ ] 人物性格一致（萧凌温和沉稳、萧炎嚣张、萧薰儿清冷温柔）
- [ ] 世界观设定一致（修为等级、地名、功法名称等）
- [ ] 生成的修订能通过 RevisionCard 接受/拒绝

### 7c：世界观提取

**Prompt**：
```
请帮我从已有的章节中提取完整的世界观设定，包括：
1. 修为等级体系
2. 主要角色及属性
3. 重要物品和功法
4. 地理位置关系
```

**验证要点**：
- [ ] 正确提取修为体系（斗之气→斗者→...→斗帝）
- [ ] 角色属性正确（萧凌：火+木属性，有焚诀、太一魂决等）
- [ ] 物品清单完整（二十四桥明月夜、聚气散、焚诀、无限可乐瓶、幸运卡、发情丹等）
- [ ] 地理信息正确（乌坦城、萧家、迦南学院、云岚宗等）

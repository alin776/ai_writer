### 方案：补充chat()和chat_with_planning()支持

#### 修改1: chat() 方法支持 user_id

**位置**: `backend/app/services/agent/langgraph_agent.py`

**当前代码**:
```python
async def chat(
    self,
    message: str,
    session_id: str,
    system_prompt: Optional[str] = None
) -> Dict[str, Any]:
    # ❌ 未接收user_id参数
    # ❌ 未设置context_manager.user_id
    context_bundle = await self.context_manager.build_context(
        session_id=session_id,
        system_prompt=system_prompt
        # ❌ 未传递query
    )
```

**修改后**:
```python
async def chat(
    self,
    message: str,
    session_id: str,
    system_prompt: Optional[str] = None,
    user_id: Optional[str] = None  # ✅ 新增参数
) -> Dict[str, Any]:
    # ✅ 设置user_id
    if user_id:
        self.context_manager.user_id = user_id
        logger.info(f"[Context] chat() 设置用户ID: {user_id}")

    # ✅ 传递query参数
    context_bundle = await self.context_manager.build_context(
        session_id=session_id,
        system_prompt=system_prompt,
        query=message  # ✅ 新增
    )
```

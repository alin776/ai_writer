### 核心学习

#### 1. AI约束最佳实践

从GitHub Blog和LangChain学到的关键原则：

**Precise Language (精确语言)**
- 消除歧义，使用明确的指令
- 示例："必须基于提供的文本" vs "请分析文本"

**Validation Gates (验证关口)**
- 在关键决策点设置人工审查
- 输出验证机制

**Domain Constraints (领域约束)**
- 嵌入领域知识和规则
- 示例：style guides, library usage rules

**Chain-of-Verification (CoVe)**
- 验证循环：生成 → 验证问题 → 回答验证问题 → 修正
- 研究显示可提升23%准确性

#### 2. 会话隔离最佳实践

从LangGraph和FastAPI-Users学到：

**Thread-based Isolation**
- 每个用户对话使用unique thread ID
- 格式：`user_id:::session_uuid`

**Multi-layer Verification**
- API层验证：格式检查
- Service层验证：业务逻辑
- Database层验证：数据归属

**Audit Logging**
- 记录所有会话访问
- 用于安全审计和问题追踪

#### 3. 上下文管理最佳实践

从Context Engineering和LangMem学到：

**Layered Memory**
- Short-term: 最近对话（FIFO）
- Summary: 长对话摘要
- Long-term: 跨会话重要信息

**Token Optimization**
- 实际案例：115k → 60k tokens (减少48%)
- 技术：摘要压缩、上下文离线存储

**Adaptive Budget**
- 不同任务类型使用不同token预算
- Creative > Analytical > QA > Chat

#### 4. HTML清理最佳实践

从Reader-LM和Markdowner学到：

**Semantic Preservation**
- 保留文本语义结构
- 移除样式、脚本等无用标签

**Token Efficiency**
- HTML比纯文本多占用2-3倍tokens
- 清理后提升AI理解准确度

**LLM-Optimized Format**
- Markdown格式最适合LLM
- 保留段落但移除格式细节

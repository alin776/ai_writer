## 📊 问题详情

### 问题描述

`analyze_text_tool`的提示词缺乏有效约束，导致AI产生严重幻觉：

**期望行为**:
- 分析数据库中存储的第28章内容（主角：段融，修炼内功）

**实际行为**:
- AI编造了完全不存在的故事（主角：林寻，宁家比武）

**代码位置**: `backend/app/services/agent/langgraph_agent.py:263-285`

**当前提示词**:
```python
prompt = f"""请分析以下文本，重点关注：{focus}

文本：
{text}

请提供详细的分析报告："""
```

### 致命缺陷

❌ **没有要求"基于文本内容"**
❌ **没有禁止"编造或猜测"**
❌ **没有要求"引用原文证据"**
❌ **temperature=0.3允许过多创造性**
❌ **HTML格式干扰理解**

### 实际影响

- ✅ **已确认发生**: 用户询问第28章，AI返回错误内容
- 数据库存储正确（段融），但AI输出错误（林寻）
- 用户收到虚假分析报告，严重影响信任

### 核心组件

#### 1. 结构化提示词模板 (`prompts/base.py`)

**设计理念**: 参考LangChain + GitHub Agentic Primitives

```python
from pydantic import BaseModel, Field
from typing import List, Optional
from enum import Enum

class ConstraintType(str, Enum):
    """约束类型"""
    MUST = "must"           # 必须遵守
    MUST_NOT = "must_not"   # 必须禁止
    SHOULD = "should"       # 应该遵守

class Constraint(BaseModel):
    """单个约束定义"""
    type: ConstraintType
    description: str
    validation_func: Optional[str] = None  # 关联的验证函数

class PromptTemplate(BaseModel):
    """结构化提示词模板"""
    name: str
    role: str                              # AI角色定义
    constraints: List[Constraint]          # 约束条件
    input_variables: List[str]             # 输入变量
    output_format: Optional[str]           # 输出格式
    template: str                          # 模板主体
    version: str = "1.0.0"                # 版本号

    def format(self, **kwargs) -> str:
        """格式化提示词"""
        # 1. 构建系统提示
        system_prompt = f"**角色**: {self.role}\n\n"

        # 2. 添加约束（关键！）
        if self.constraints:
            system_prompt += "**重要约束**:\n"
            for i, constraint in enumerate(self.constraints, 1):
                icon = "✅" if constraint.type == ConstraintType.MUST else "❌"
                system_prompt += f"{i}. {icon} {constraint.description}\n"
            system_prompt += "\n"

        # 3. 格式化主模板
        return system_prompt + self.template.format(**kwargs)
```

#### 3. 实体验证器 (`prompts/validators/entity_validator.py`)

**设计理念**: 参考OpenAI Hallucination Detection

```python
import re
import jieba.posseg as pseg
from typing import Set, Dict, Any

class EntityValidator:
    """实体验证器 - 检测AI是否编造实体"""

    @staticmethod
    def extract_entities(text: str) -> Set[str]:
        """
        提取文本中的实体（人名、地名等）

        使用jieba分词进行中文实体识别
        """
        entities = set()

        # 1. 使用jieba提取人名、地名
        words = pseg.cut(text)
        for word, flag in words:
            if flag == 'nr':  # 人名
                entities.add(word)
            elif flag == 'ns':  # 地名
                entities.add(word)

        # 2. 提取引号中的内容
        quoted = re.findall(r'["""](.*?)["""]', text)
        entities.update(quoted)

        # 3. 提取特殊标记的概念
        concepts = re.findall(r'[《「](.*?)[》」]', text)
        entities.update(concepts)

        return entities

    @classmethod
    def validate(cls, source_text: str, ai_output: str) -> Dict[str, Any]:
        """
        验证AI输出是否编造了实体

        核心逻辑：
        1. 提取源文本的实体
        2. 提取AI输出的实体
        3. 找出AI新增的实体
        4. 判断是否为编造
        """
        source_entities = cls.extract_entities(source_text)
        output_entities = cls.extract_entities(ai_output)

        # 找出AI输出中但源文本没有的实体
        fabricated_entities = output_entities - source_entities

        # 过滤常见分析用语
        common_words = {
            '小说', '章节', '情节', '人物', '作者',
            '读者', '故事', '文本', '主角', '配角'
        }
        fabricated_entities = fabricated_entities - common_words

        if fabricated_entities:
            return {
                "valid": False,
                "error": "AI可能编造了以下实体",
                "fabricated_entities": list(fabricated_entities),
                "confidence": len(fabricated_entities) / max(len(output_entities), 1),
                "recommendation": "重新生成或人工审查"
            }

        return {
            "valid": True,
            "message": "未发现明显的实体编造"
        }
```

#### 4. 提示词管理器 (`prompts/manager.py`)

**设计理念**: 参考LangChain PromptManager

```python
import yaml
from pathlib import Path
from typing import Dict, Optional
import logging

logger = logging.getLogger(__name__)

class PromptManager:
    """提示词管理器 - 加载、验证、版本管理"""

    def __init__(self, templates_dir: str = "app/prompts/templates"):
        self.templates_dir = Path(templates_dir)
        self.templates: Dict[str, PromptTemplate] = {}
        self.validators = {
            "validate_entities": EntityValidator.validate,
            "validate_citations": ConsistencyValidator.validate_citations,
        }

        # 预加载所有模板
        self._load_all_templates()

    def format_prompt(self, template_name: str, **kwargs) -> str:
        """
        格式化提示词

        示例:
        >>> manager.format_prompt("analyze_text", text="...", focus="all")
        """
        template = self.templates.get(template_name)
        if not template:
            raise ValueError(f"模板不存在: {template_name}")

        # 验证输入
        valid, error = template.validate_inputs(**kwargs)
        if not valid:
            raise ValueError(f"输入验证失败: {error}")

        return template.format(**kwargs)

    def validate_output(
        self,
        template_name: str,
        source_text: str,
        ai_output: str
    ) -> Dict:
        """
        验证AI输出（关键功能！）

        返回:
        {
            "valid": bool,
            "details": [...],
            "template": str,
            "version": str
        }
        """
        template = self.templates.get(template_name)
        results = []

        # 执行所有验证器
        for constraint in template.constraints:
            if constraint.validation_func:
                validator = self.validators[constraint.validation_func]
                result = validator(source_text, ai_output)
                results.append({
                    "constraint": constraint.description,
                    "result": result
                })

        all_valid = all(r["result"].get("valid", True) for r in results)

        return {
            "valid": all_valid,
            "details": results,
            "template": template_name,
            "version": template.version
        }

# 全局单例
_prompt_manager: Optional[PromptManager] = None

def get_prompt_manager() -> PromptManager:
    global _prompt_manager
    if _prompt_manager is None:
        _prompt_manager = PromptManager()
    return _prompt_manager
```

### ✅ 修复1：问题11 - or逻辑不严谨（546-547行）

**修复前**:
```python
if isinstance(data, dict) and 'content' in data:
    task_result = data['content'] or ""  # ❌ 问题：会把所有falsy值转为空字符串
```

**修复后**:

- 保留其他falsy值（如0、False）的原始值

### ✅ 修复3：问题13 - 提示信息可能超限（633-636行）

**修复前**:
```python
if current_length >= max_context_length * 0.95:
    remaining_tasks = len(task_results) - (task_id)
    if remaining_tasks > 0:
        context_parts.append(f"\n[还有{remaining_tasks}个任务结果已省略]\n")  # ❌ 没有检查
    break
```

**修复后**:
```python
if current_length >= max_context_length * 0.95:
    remaining_tasks = len(task_results) - (task_id)
    if remaining_tasks > 0:
        omit_msg = f"\n[还有{remaining_tasks}个任务结果已省略]\n"
        # 检查提示信息本身是否会超限
        if current_length + len(omit_msg) <= max_context_length:  # ✅ 添加检查
            context_parts.append(omit_msg)
    break
```

**验证结果**: ✅ **修复正确**
- 在添加提示前检查是否会超限
- 只有不超限才添加提示
- 避免边界情况下的超限

**场景测试**:
```python
# 场景1：添加提示后不超限
max_context_length = 3000
current_length = 2950
omit_msg长度 = 30
2950 + 30 = 2980 <= 3000 ✓
→ 添加提示 ✓

# 场景2：添加提示后会超限
current_length = 2990
omit_msg长度 = 30
2990 + 30 = 3020 > 3000 ✗
→ 不添加提示 ✓（避免超限）

# 场景3：刚好在边界
current_length = 2970
omit_msg长度 = 30
2970 + 30 = 3000 <= 3000 ✓
→ 添加提示 ✓
```

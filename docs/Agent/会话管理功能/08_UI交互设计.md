## 🎨 设计原则

### 1. 简洁直观
- 不增加认知负担
- 符合用户直觉
- 关键操作一键完成

### 2. 渐进式披露
- 基础功能明显可见
- 高级功能按需展示
- 避免界面过载

### 3. 即时反馈
- 操作后立即响应
- 加载状态清晰
- 错误提示友好

### 4. 可逆操作
- 破坏性操作有确认
- 支持撤销
- 清晰提示后果

## 🔘 按钮和控件设计

### 1. 重开会话按钮

**位置**: 顶部工具栏右侧
**图标**: 🔄 或刷新图标
**样式**:
- 默认：灰色，outline按钮
- Hover：蓝色，显示tooltip"重开会话"
- Active：按下效果

**点击流程**:
```
点击按钮
    ↓
弹出确认对话框
    ↓
┌─────────────────────────────┐
│  ⚠️ 确认重开会话？           │
│                             │
│  当前对话历史将被清空，      │
│  此操作不可撤销              │
│                             │
│  [取消]        [确认重开]   │
└─────────────────────────────┘
    ↓
用户点击"确认重开"
    ↓
显示加载动画 (Loading...)
    ↓
成功后显示Toast提示
    ↓
清空消息列表
```

---

### 2. 分支管理按钮

**位置**: 顶部工具栏右侧
**图标**: 🌲 或树形图标
**样式**:
- 默认：灰色
- 激活时：蓝色，表示面板已打开
- Badge：显示分支数量（如"3"）

**点击效果**:
- 第一次点击：从右侧滑入分支面板
- 第二次点击：收起面板

**动画**: 300ms ease-in-out滑动

---

### 3. 创建分支按钮（消息旁）

**位置**: Hover AI消息时显示
**图标**: + 或分叉图标
**样式**:
- 半透明背景
- Hover时变实心
- 点击后消失

**交互流程**:
```
Hover AI消息
    ↓
显示操作按钮组
┌────────────────────────────┐
│ AI: 从前有座山...           │
│ [📝 编辑] [🔀 分支] [🔄 重试] │
└────────────────────────────┘
    ↓
点击 [🔀 分支]
    ↓
显示输入框（可选）
┌─────────────────────────────┐
│  创建新分支                  │
│                             │
│  分支名称:                   │
│  [探索方案A_________]        │
│                             │
│  [取消]        [创建]       │
└─────────────────────────────┘
    ↓
点击"创建"
    ↓
显示加载动画 (300ms)
    ↓
Toast提示: "分支已创建"
    ↓
自动切换到新分支
```

---

### 4. 编辑消息按钮

**位置**: Hover用户消息时显示
**图标**: ✏️ 或编辑图标
**样式**: 与创建分支按钮一致

**交互流程**:
```
Hover用户消息
    ↓
显示 [✏️ 编辑] 按钮
    ↓
点击编辑
    ↓
消息变为可编辑状态
┌────────────────────────────┐
│ 用户: [帮我写个故事____]   │
│ [取消] [保存]              │
└────────────────────────────┘
    ↓
用户修改内容并点击"保存"
    ↓
提示: "修改将创建新分支"
    ↓
创建新分支流程...
```

## 📱 响应式设计

### 桌面端 (>1024px)
- 主聊天区域占70%
- 分支面板占30%
- 侧边栏展开

### 平板端 (768px-1024px)
- 主聊天区域占60%
- 分支面板占40%
- 侧边栏可折叠

### 移动端 (<768px)
- 全屏显示主聊天区域
- 分支面板为底部抽屉
- 向上滑动打开分支面板

## ⌨️ 键盘快捷键

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+R` | 重开会话 | 需要确认 |
| `Ctrl+B` | 打开/关闭分支面板 | 切换显示 |
| `Ctrl+E` | 编辑最后一条消息 | 快速编辑 |
| `Ctrl+Enter` | 发送消息 | 输入框内 |
| `Esc` | 关闭对话框/面板 | 取消操作 |

## 🎬 动画和过渡

### 页面过渡
- **持续时间**: 300ms
- **缓动函数**: ease-in-out
- **效果**: 淡入淡出 + 滑动

### 元素进入
```css
.fade-in-up {
  animation: fadeInUp 300ms ease-out;
}

@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

### 元素退出
```css
.fade-out-down {
  animation: fadeOutDown 200ms ease-in;
}

@keyframes fadeOutDown {
  from {
    opacity: 1;
    transform: translateY(0);
  }
  to {
    opacity: 0;
    transform: translateY(10px);
  }
}
```

## ✅ 可访问性

### ARIA标签
```html
<button
  aria-label="创建新分支"
  aria-describedby="branch-tooltip"
>
  🔀
</button>

<div id="branch-tooltip" role="tooltip">
  在此消息处创建新分支
</div>
```

### 键盘导航
- 所有按钮可用Tab键聚焦
- Enter键触发操作
- Esc键取消操作

### 对比度
- 文字与背景对比度 ≥ 4.5:1
- 按钮与背景对比度 ≥ 3:1

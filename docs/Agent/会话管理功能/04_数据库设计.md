## 🗄️ 存储架构总览

### 混合存储方案

```
┌─────────────────────────────────────────┐
│           应用层                         │
├─────────────────────────────────────────┤
│  Redis (高速缓存)         PostgreSQL     │
│  ├─ LangGraph Checkpoint  ├─ 用户表      │
│  ├─ 分支元数据           ├─ 会话历史    │
│  └─ 会话临时数据         └─ 长期存档    │
└─────────────────────────────────────────┘
```

**设计原则**:
- **Redis**: 存储7天内的热数据（对话、分支）
- **PostgreSQL**: 存储永久数据（用户、归档）
- **LangGraph**: 自动管理checkpoint，无需手动操作

## 📦 Redis数据设计

### 1. LangGraph Checkpoint (自动管理)

**键格式**:
```
langgraph_checkpoint_{thread_id}
```

**说明**:
- LangGraph AsyncRedisSaver自动创建
- 每个branch_id就是一个thread_id
- 7天TTL自动过期

**示例**:
```bash
# 主分支checkpoint
langgraph_checkpoint_branch_main_abc123

# 分支Acheckpoint
langgraph_checkpoint_branch_abc_def456
```

**数据结构**:
```python
{
  "v": 1,  # checkpoint版本号
  "ts": "2025-11-07T10:30:00Z",  # 时间戳
  "id": "checkpoint_uuid",
  "channel_values": {
    "messages": [...],  # 消息列表
    "context": {...},   # 上下文
    "intent": "writing"
  },
  "channel_versions": {...},
  "versions_seen": {...}
}
```

**Python操作**:
```python

    f"conversation_branches:{conv_id}",

branches_raw = redis.hgetall(f"conversation_branches:{conv_id}")

### 4. 用户会话索引 (Sorted Set)

**键格式**:
```

```

**数据类型**: Sorted Set
**Score**: 时间戳 (用于排序)

**用途**:
- 查询用户的所有会话

- 分页查询

**Python操作**:

    f"user:{user_id}:conversations",
    {conv_id: time.time()}
)

# 获取最近10个会话
recent_convs = redis.zrevrange(
    f"user:{user_id}:conversations",
    0, 9,
    withscores=True
)

# 获取总数
total = redis.zcard(f"user:{user_id}:conversations")

# 分页查询（每页20个）

    f"user:{user_id}:conversations",

    (page + 1) * 20 - 1
)
```

## 🗃️ PostgreSQL数据设计（可选）

### 为什么需要PostgreSQL？

**问题**: Redis 7天TTL后数据丢失
**解决**: PostgreSQL永久存储重要对话

### 表设计

#### 表1: conversations（会话）

```sql
CREATE TABLE conversations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id),
    title TEXT NOT NULL,
    main_branch_id UUID,
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP NOT NULL DEFAULT NOW(),
    last_activity TIMESTAMP NOT NULL DEFAULT NOW(),
    is_archived BOOLEAN DEFAULT FALSE,

    INDEX idx_user_id (user_id),
    INDEX idx_last_activity (last_activity DESC)
);
```

#### 表2: branches（分支）

```sql
CREATE TABLE branches (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    conversation_id UUID NOT NULL REFERENCES conversations(id) ON DELETE CASCADE,
    name TEXT NOT NULL,
    parent_branch_id UUID REFERENCES branches(id),
    fork_message_id UUID,
    is_main BOOLEAN DEFAULT FALSE,
    message_count INTEGER DEFAULT 0,
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP NOT NULL DEFAULT NOW(),
    last_activity TIMESTAMP NOT NULL DEFAULT NOW(),

    INDEX idx_conversation_id (conversation_id),
    INDEX idx_parent_branch_id (parent_branch_id)
);
```

#### 表3: messages（消息）

```sql
CREATE TABLE messages (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    branch_id UUID NOT NULL REFERENCES branches(id) ON DELETE CASCADE,
    parent_message_id UUID REFERENCES messages(id),
    content TEXT NOT NULL,
    role VARCHAR(20) NOT NULL CHECK (role IN ('user', 'assistant')),
    metadata JSONB,
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP,

    INDEX idx_branch_id (branch_id),
    INDEX idx_parent_message_id (parent_message_id),
    INDEX idx_created_at (created_at)
);
```

### PostgreSQL 操作示例

#### 创建会话和主分支

```python
async def create_conversation_with_main_branch(
    db: AsyncSession,
    user_id: str,
    title: str
) -> tuple[Conversation, Branch]:
    # 1. 创建会话
    conversation = Conversation(
        user_id=user_id,
        title=title
    )
    db.add(conversation)
    await db.flush()  # 获取ID

    # 2. 创建主分支
    main_branch = Branch(
        conversation_id=conversation.id,
        name="主线",
        is_main=True
    )
    db.add(main_branch)
    await db.flush()

    # 3. 更新会话的main_branch_id
    conversation.main_branch_id = main_branch.id

    await db.commit()
    return conversation, main_branch
```

#### 获取分支树

```python
async def get_branch_tree(
    db: AsyncSession,
    conversation_id: str
) -> List[Branch]:
    # 递归查询所有分支
    query = """
    WITH RECURSIVE branch_tree AS (
        SELECT * FROM branches
        WHERE conversation_id = :conv_id AND parent_branch_id IS NULL
        UNION ALL
        SELECT b.* FROM branches b
        JOIN branch_tree bt ON b.parent_branch_id = bt.id
    )
    SELECT * FROM branch_tree ORDER BY created_at;
    """

    result = await db.execute(
        text(query),
        {"conv_id": conversation_id}
    )
    return result.fetchall()
```

#### 获取分支的完整消息链

```python
async def get_branch_messages(
    db: AsyncSession,
    branch_id: str
) -> List[Message]:
    query = """
    WITH RECURSIVE message_chain AS (
        SELECT * FROM messages
        WHERE branch_id = :branch_id AND parent_message_id IS NULL
        UNION ALL
        SELECT m.* FROM messages m
        JOIN message_chain mc ON m.parent_message_id = mc.id
    )
    SELECT * FROM message_chain ORDER BY created_at;
    """

    result = await db.execute(
        text(query),
        {"branch_id": branch_id}
    )
    return result.fetchall()
```

### 3. 缓存策略

```python
from functools import lru_cache
from datetime import datetime, timedelta

# 会话元数据缓存（5分钟）
_conversation_cache = {}
_cache_ttl = timedelta(minutes=5)

def get_conversation_cached(conv_id: str) -> Optional[dict]:
    if conv_id in _conversation_cache:
        cached_data, cached_time = _conversation_cache[conv_id]
        if datetime.now() - cached_time < _cache_ttl:
            return cached_data

    # 从Redis读取
    data = redis_client.get(f"conversation:{conv_id}")
    if data:
        conversation = json.loads(data)
        _conversation_cache[conv_id] = (conversation, datetime.now())
        return conversation

    return None
```

async def check_conversation_access(

## ✅ 数据完整性检查

### Redis数据一致性脚本

```python
async def validate_conversation_integrity(conv_id: str):
    """验证会话数据完整性"""
    errors = []

    # 1. 检查会话存在
    conv_data = redis_client.get(f"conversation:{conv_id}")
    if not conv_data:
        errors.append("会话不存在")
        return errors

    conversation = json.loads(conv_data)

    # 2. 检查所有分支都存在
    branches_data = redis_client.hgetall(f"conversation_branches:{conv_id}")
    for branch_id in conversation['branches']:
        if branch_id not in branches_data:
            errors.append(f"分支{branch_id}缺失")

    # 3. 检查主分支标记
    has_main = False
    for branch_raw in branches_data.values():
        branch = json.loads(branch_raw)
        if branch['isMain']:
            has_main = True
            break

    if not has_main:
        errors.append("缺少主分支")

    # 4. 检查LangGraph checkpoint
    for branch_id in conversation['branches']:
        config = {"configurable": {"thread_id": branch_id}}
        state = await checkpointer.aget(config)
        if not state:
            errors.append(f"分支{branch_id}的checkpoint缺失")

    return errors
```

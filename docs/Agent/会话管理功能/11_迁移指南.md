# 会话管理功能 - 迁移指南

**文档版本**: v1.0
**创建时间**: 2025-11-07
**适用场景**: 从MemorySaver迁移到AsyncRedisSaver

---

## 🎯 迁移目标

### 现状 (Before)
- ✅ 使用 MemorySaver（内存存储）
- ❌ 服务器重启会丢失所有会话
- ❌ 不支持多进程部署
- ❌ 无法跨实例共享会话

### 目标 (After)
- ✅ 使用 AsyncRedisSaver（Redis持久化）
- ✅ 会话数据持久化7天
- ✅ 支持多进程Gunicorn部署
- ✅ 支持会话跨实例共享

---

### Step 3: 修改 LangGraph Agent (15分钟)

#### 3.1 更新 WritingAgentGraph 类

```python
# backend/app/services/agent/langgraph_agent.py

# ❌ 删除旧的import
from langgraph.checkpoint.memory import MemorySaver

# ✅ 添加新的import
from langgraph.checkpoint.redis import AsyncRedisSaver
from app.core.config import settings
import aioredis  # 如果需要

class WritingAgentGraph:
    """LangGraph写作助手工作流"""

    def __init__(
        self,
        ai_service: HTTPAIService,
        use_chatgpt: bool = True,
        checkpointer: Optional[AsyncRedisSaver] = None  # ✅ 新增参数
    ):
        logger.info(f"[Agent] 初始化WritingAgentGraph, use_chatgpt={use_chatgpt}")

        self.ai_service = ai_service
        self.use_chatgpt = use_chatgpt

        # ❌ 删除旧代码
        # self.memory = MemorySaver()

        # ✅ 使用传入的checkpointer或创建新的
        if checkpointer is None:
            self.checkpointer = self._create_checkpointer()
        else:
            self.checkpointer = checkpointer

        logger.info(f"[Agent] Checkpointer类型: {type(self.checkpointer).__name__}")

        # 构建图
        self.graph = self._build_graph()

        # ✅ 编译时使用checkpointer
        self.compiled = self.graph.compile(checkpointer=self.checkpointer)

        logger.info("[Agent] 图编译完成（带持久化）")

    def _create_checkpointer(self) -> AsyncRedisSaver:
        """创建AsyncRedisSaver实例"""
        try:
            # 方式1：使用Redis URL（推荐）
            if settings.REDIS_URL:
                checkpointer = AsyncRedisSaver.from_conn_string(
                    settings.REDIS_URL
                )
                logger.info(f"[Checkpointer] 使用Redis URL: {settings.REDIS_URL}")

            # 方式2：使用独立参数
            else:
                checkpointer = AsyncRedisSaver.from_conn_info(
                    host=settings.REDIS_HOST,
                    port=settings.REDIS_PORT,
                    db=settings.REDIS_DB,
                    password=settings.REDIS_PASSWORD
                )
                logger.info(f"[Checkpointer] 使用Redis: {settings.REDIS_HOST}:{settings.REDIS_PORT}/{settings.REDIS_DB}")

            return checkpointer

        except Exception as e:
            logger.error(f"[Checkpointer] 创建失败: {e}")
            # 降级为MemorySaver
            logger.warning("[Checkpointer] 降级使用MemorySaver")
            from langgraph.checkpoint.memory import MemorySaver
            return MemorySaver()

    # ... 其他方法保持不变 ...
```

#### 4.1 修改 agent.py 中的全局实例

# backend/app/api/v1/agent.py

# ✅ 创建全局checkpointer（懒加载）
_global_checkpointer: Optional[AsyncRedisSaver] = None

async def get_checkpointer() -> AsyncRedisSaver:
    """获取全局checkpointer实例"""
    global _global_checkpointer

    if _global_checkpointer is None:
        logger.info("[Checkpointer] 创建全局AsyncRedisSaver实例")
        _global_checkpointer = AsyncRedisSaver.from_conn_string(
            settings.REDIS_URL
        )

    return _global_checkpointer

# ✅ 更新get_agent_graph
def get_agent_graph(
    checkpointer: AsyncRedisSaver = Depends(get_checkpointer)
) -> WritingAgentGraph:
    """获取全局Agent实例（带checkpointer依赖注入）"""
    global _global_agent_graph

    if _global_agent_graph is None:
        ai_service = HTTPAIService(
            enable_model_selector=settings.MODEL_SELECTION_ENABLED
        )
        # ✅ 传入checkpointer
        _global_agent_graph = WritingAgentGraph(
            ai_service,
            use_chatgpt=settings.AGENT_USE_CHATGPT,
            checkpointer=checkpointer  # ✅ 关键：注入checkpointer
        )
        logger.info("[Global Agent] 创建全局Agent实例（AsyncRedisSaver）")

    return _global_agent_graph

# ✅ 更新所有endpoint的依赖

## 🚨 常见问题和解决方案

### 问题1: 启动时报错 "Cannot connect to Redis"

**原因**: Redis服务未启动或配置错误

**解决**:
```bash
# 检查Redis是否运行
redis-cli ping

# 如果没运行，启动Redis
redis-server

# 检查配置
cat .env | grep REDIS
```

---

### 问题2: Checkpointer类型仍是MemorySaver

**原因**: 代码未更新或降级逻辑触发

**解决**:
```python
# 检查日志中是否有错误
# 如果看到 "[Checkpointer] 降级使用MemorySaver"

# 排查步骤：
1. 确认langgraph-checkpoint-redis已安装
   pip show langgraph-checkpoint-redis

2. 检查Redis连接是否正常
   redis-cli -n 1 ping

3. 检查REDIS_URL配置
   echo $REDIS_URL

4. 查看详细错误日志
   logger.error(f"[Checkpointer] 创建失败: {e}")
```

---

### 问题3: conversation_id重复使用时没有加载历史

**原因**: thread_id格式不一致或checkpoint未正确保存

**解决**:
```python
# 调试日志
logger.info(f"[Chat] conversation_id: {conversation_id}")
logger.info(f"[Chat] config: {config}")

# 检查Redis中的键
redis-cli -n 1 KEYS "*{conversation_id}*"

# 验证checkpoint是否存在
config = {"configurable": {"thread_id": conversation_id}}
state = await checkpointer.aget(config)
logger.info(f"[Debug] State: {state}")
```

---

### 问题4: 多进程部署时会话数据不一致

**原因**: 多个Worker共享Redis，但未正确同步

**解决**:
```python
# 确保使用相同的Redis实例
# 所有Worker必须连接到同一个Redis

# Gunicorn配置（gunicorn.conf.py）
workers = 4
worker_class = "uvicorn.workers.UvicornWorker"
preload_app = False  # ← 关键：不要preload

# 每个worker独立创建checkpointer
# AsyncRedisSaver会自动处理并发
```

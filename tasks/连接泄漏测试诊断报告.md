## 🔬 根本原因分析

### 问题 1: 错误的工具调用方式

#### 测试代码（test_connection_leak.py:75）

```python
# ❌ 错误的调用方式
result = await tool_func(**test_params)
```

#### 工具定义（langgraph_agent.py:379）

```python
from langchain_core.tools import tool

@tool
async def read_chapter_tool(work_id: Optional[str] = None, chapter_id: str = "") -> str:
    """读取指定章节工具"""
    # ... 实现代码
```

#### 问题分析

**LangChain 的 `@tool` 装饰器行为**:

1. **装饰前**: `read_chapter_tool` 是一个普通的异步函数
2. **装饰后**: `read_chapter_tool` 变成了 `StructuredTool` 对象（不是函数）
3. **调用方式**:
   - ❌ 错误: `read_chapter_tool(...)` - 会报错 `'StructuredTool' object is not callable`
   - ✅ 正确: `read_chapter_tool.ainvoke(...)` - 异步调用
   - ✅ 正确: `read_chapter_tool.invoke(...)` - 同步调用

#### 代码证据

在 `langgraph_agent.py:1766` 行有正确使用的注释：

```python
# 调用工具（使用 .ainvoke() 方法，因为 @tool 装饰器返回的是 StructuredTool 对象）
result = await tool.ainvoke(tool_args)
```

---

### 问题 2: 假阳性的测试结果

#### 为什么测试显示"通过"？

```
初始连接池: 10 可用, 0 检出
↓
执行 200 次调用（全部失败，工具未执行）
↓
最终连接池: 10 可用, 0 检出
↓
判断逻辑: if checked_out == 0: 通过 ✅
```

**逻辑错误**:
- 测试只检查了 `checked_out == 0`（无检出连接）
- 但没有验证工具是否真的执行了
- 工具根本没执行 → 没有创建连接 → 自然没有检出连接 → "通过"

**实际情况**:
```
工具调用失败 →
数据库连接未创建 →
连接池无变化 →
测试误判为"修复成功"
```

```python
async def test_tool_connection_leak(tool_func, tool_name, test_params, iterations=100):
    """测试单个工具的连接泄漏"""

    # ... 前面代码不变

    for i in range(iterations):
        try:
            # ✅ 修复：使用 .ainvoke() 方法调用
            result = await tool_func.ainvoke(test_params)

            # ✅ 验证结果不是 None
            if result is None:
                logger.warning(f"工具返回 None ({i+1}/{iterations})")

            success_count += 1

            if (i + 1) % 20 == 0:
                pool_status = await check_connection_pool()
                logger.info(
                    f"进度: {i+1}/{iterations}, "
                    f"成功: {success_count}, "
                    f"失败: {error_count}, "
                    f"连接池: {pool_status}"
                )
        except Exception as e:
            error_count += 1
            logger.error(f"调用失败 ({i+1}/{iterations}): {e}")

    # ... 后面代码不变
```

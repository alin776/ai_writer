### 优化 #2: 优化 max_tokens 设置

**文件**: `backend/app/services/agent/langgraph_agent.py`

#### 2.1 工具决策 max_tokens

**位置**: 行 1701

**修改**:
```python
# 优化前
max_tokens=500

# 优化后
max_tokens=200  # ✅ Phase 2.5: 优化从500→200 (JSON响应通常<100 tokens)
```

**理由**:
- 工具决策返回的是简单 JSON（通常 <100 tokens）
- 500 tokens 过于宽松，导致不必要的成本
- 200 tokens 足够容纳最复杂的决策响应

**输出 Token 影响**: 节省 60%

#### 2.2 Planning max_tokens

**位置**: 行 2871

**修改**:
```python
# 优化前
max_tokens=1000

# 优化后
max_tokens=600  # ✅ Phase 2.5: 优化从1000→600 (JSON任务列表)
```

**理由**:
- Planning 返回的是任务列表 JSON
- 实际测试显示大多数规划 < 400 tokens
- 600 tokens 提供了足够的缓冲空间

**输出 Token 影响**: 节省 40%

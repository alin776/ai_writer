### 2. 生产环境配置要求

#### 硬件要求
- **CPU**: 4核心以上 (推荐8核心)
- **内存**: 16GB以上 (推荐32GB)
- **存储**: 100GB以上 SSD
- **网络**: 稳定的互联网连接

#### 软件环境
- **操作系统**: Linux (推荐Ubuntu 20.04+) / Windows Server 2019+
- **Python**: 3.11+
- **Node.js**: 18+
- **PostgreSQL**: 15+
- **Redis**: 7+ (或Memurai for Windows)

#### 环境变量配置
```bash
# OpenAI API配置
VITE_OPENAI_API_KEY=your_production_api_key
VITE_OPENAI_MODEL=gpt-4-turbo-preview

# 生产环境配置
NODE_ENV=production
PYTHON_ENV=production
VITE_API_URL=https://your-domain.com/api

# 数据库配置
DATABASE_URL=postgresql://user:password@localhost:5432/novelaide
REDIS_URL=redis://localhost:6379/0

# 监控配置
MONITORING_ENABLED=true
LOG_LEVEL=INFO
```

### 3. 部署步骤

#### 步骤1: 环境准备
```bash
# 1. 克隆代码
git clone <repository-url>
cd ai_writer

# 2. 创建Python虚拟环境
python -m venv venv
source venv/bin/activate  # Linux/Mac
# 或 venv\Scripts\activate  # Windows

# 3. 安装后端依赖
cd backend
pip install -r requirements.txt

# 4. 安装前端依赖
cd ../
npm install
```

#### 步骤2: 数据库初始化
```bash
# 创建数据库
createdb novelaide

# 运行数据库迁移
cd backend
alembic upgrade head
```

#### 步骤3: 配置文件设置
```bash
# 复制环境变量模板
cp .env.example .env.production
# 编辑 .env.production 填入生产环境配置
```

#### 步骤4: 构建前端
```bash
# 构建生产版本
npm run build
```

#### 步骤5: 启动服务
```bash
# 启动后端服务
cd backend
uvicorn app.main:app --host 0.0.0.0 --port 8000

# 启动前端服务 (使用nginx等Web服务器)
# 将 dist/ 目录部署到Web服务器
```

### 4. 性能优化配置

#### 数据库优化
```sql
-- PostgreSQL性能优化配置
-- 在 postgresql.conf 中设置:
shared_buffers = 256MB
effective_cache_size = 1GB
maintenance_work_mem = 64MB
checkpoint_completion_target = 0.9
wal_buffers = 16MB
default_statistics_target = 100
random_page_cost = 1.1
effective_io_concurrency = 200
```

#### Redis优化
```bash
# Redis性能优化配置
# 在 redis.conf 中设置:
maxmemory 512mb
maxmemory-policy allkeys-lru
save 900 1
save 300 10
save 60 10000
```

#### Web服务器配置 (Nginx)
```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /path/to/dist;
        try_files $uri $uri/ /index.html;
    }

    # API代理
    location /api {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 5. 监控配置

#### 启用监控
```python
# 在 backend/app/core/config.py 中确保:
MONITORING_ENABLED = True
MONITORING_INTERVAL = 60  # 监控数据收集间隔(秒)
ALERT_THRESHOLDS = {
    'cpu_usage': 80,
    'memory_usage': 85,
    'disk_usage': 90,
    'response_time': 5000
}
```

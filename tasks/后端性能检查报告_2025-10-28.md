#### 1. 小说分析功能性能优化 ⭐⭐⭐⭐

**问题**:
- 单章分析35.5秒太慢
- 100章需要59分钟,用户体验差
- 缺少进度反馈

**优化方案**:

**方案A: 并发优化** (推荐)
```python
# 当前: 串行分析
for chapter in chapters:
    await analyze_chapter(chapter)  # 35.5秒/章

# 优化后: 批量并发
chunks = chunk_list(chapters, size=5)  # 每批5章
for chunk in chunks:
    await asyncio.gather(*[
        analyze_chapter(ch) for ch in chunk
    ])  # 5章并发 = 35.5秒
```

**效果**:
- 100章耗时: 从59分钟 → **12分钟** (5倍提升)
- 用户体验: 从"太慢放弃" → "可接受"

**方案B: 异步任务** (备选)
```python
# 使用后台任务,避免阻塞
@app.post("/analysis/start")
async def start_analysis(background_tasks: BackgroundTasks):
    background_tasks.add_task(analyze_novel, work_id)
    return {"status": "started", "job_id": analysis_id}

# 前端轮询进度
@app.get("/analysis/{id}/status")
async def get_status(id: str):
    return {"progress": 45, "status": "analyzing"}
```

**效果**:
- 接口立即返回 (<1秒)
- 后台慢慢分析 (12分钟)
- 前端显示进度条

**推荐**: **方案A + 方案B 组合**
- 先做并发优化 (5倍提速)
- 再加后台任务 (不阻塞)
- 最佳用户体验

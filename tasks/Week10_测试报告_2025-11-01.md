## 🔧 发现的问题和修复

### 问题1: Pydantic 兼容性
**问题**: BaseSettings 从 pydantic 移动到 pydantic-settings
**修复**:
```python
try:
    from pydantic_settings import BaseSettings
except ImportError:
    from pydantic import BaseModel as BaseSettings
```

### 问题2: 配置类 extra_forbidden 错误
**问题**: 环境变量过多导致验证失败
**修复**:
```python
class Config:
    extra = "ignore"  # ��略额外的环境变量
```

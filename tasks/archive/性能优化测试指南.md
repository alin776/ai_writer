## 🐛 常见问题排查

### 问题1: Redis连接失败
```
⚠️  Redis连接失败,缓存功能将禁用
```

**解决方案**:
```bash
# 检查Redis是否运行
redis-cli ping

# 如果未运行,启动Redis
redis-server.exe redis.windows.conf
```

### 问题2: 数据库连接失败
```
ERROR: 数据库连接失败
```

**解决方案**:
```bash
# 检查PostgreSQL状态
pg_ctl status

# 检查.env配置
cat backend/.env | grep DATABASE_URL
```

### 问题3: AI API限流
```
[x/20] ⏰ 超时: 第X章
```

**解决方案**:
- 降低并发数: 修改 `NOVEL_ANALYSIS_MAX_CONCURRENT` 从5改为3
- 增加超时时间: 修改 `NOVEL_ANALYSIS_CHAPTER_TIMEOUT` 从120改为180

### 问题4: 内存不足
```
MemoryError: ...
```

**解决方案**:
- 降低并发数到3
- 分批测试 (先测20章,再测100章)

## 🎓 技术实现总结

### 核心优化点

1. **并行分析**
   - 使用 `asyncio.gather()` + `Semaphore(5)`
   - 5个章节同时分析,批次执行
   - 代码位置: `novel_analysis_orchestrator.py:220-358`

2. **Redis缓存**
   - MD5哈希内容去重
   - 7天TTL
   - 代码位置: `redis_cache_service.py`

3. **批量写入**
   - 每10章更新一次进度
   - 减少数据库IO 90%
   - 代码位置: `novel_analysis_orchestrator.py:293`

4. **超时重试**
   - `asyncio.wait_for(120s)` 超时
   - `tenacity` 自动重试3次
   - 代码位置: `novel_analysis_orchestrator.py:258-266`

## 🐛 第一优先级: 修复严重Bug

### Bug #1: 去痕迹功能序列化错误 (P0)

**问题描述**:
```
TypeError: Object of type DimensionScore is not JSON serializable
位置: backend/app/api/v1/humanize.py
影响: 去痕迹功能完全不可用 (HTTP 500)
```

**错误日志** (来自ERROR.md):
```python
StatementError: (builtins.TypeError) Object of type DimensionScore is not JSON serializable
[SQL: INSERT INTO humanize_session_details ...]
dimensions_before: {'tone_style': DimensionScore(score=75.0, ...)}
```

**根本原因**:
- `DimensionScore` 是Python对象,不是Pydantic模型
- 直接存入PostgreSQL的JSONB字段失败
- 数据库期望JSON,但收到了Python对象

**修复方案**:

#### 方案A: 转换为Pydantic模型 (推荐)
```python
# backend/app/schemas/humanize.py

from pydantic import BaseModel
from typing import List

class DimensionScore(BaseModel):
    """维度评分模型"""
    score: float
    description: str
    issues: List[str] = []

    class Config:
        from_attributes = True
```

#### 方案B: 添加to_dict方法
```python
# backend/app/services/ai/humanize_service.py

class DimensionScore:
    def __init__(self, score: float, description: str, issues: List[str] = None):
        self.score = score
        self.description = description
        self.issues = issues or []

    def to_dict(self) -> dict:
        """序列化为字典"""
        return {
            "score": self.score,
            "description": self.description,
            "issues": self.issues
        }

# 在存储前转换
dimensions_before_dict = {
    k: v.to_dict() if isinstance(v, DimensionScore) else v
    for k, v in dimensions_before.items()
}
```

**修复步骤**:
1. 修改 `DimensionScore` 定义
2. 更新 `HumanizeService` 中的序列化逻辑
3. 运行测试脚本验证
4. 提交修复

**预计时间**: 30分钟

**验证命令**:
```bash
cd backend
python test_humanize_optimization.py
```

## 📝 风险评估

### 高风险

1. **WebSocket实时推送**
   - 风险: 拆书进度需要实时更新
   - 缓解: Week 3先用轮询,Week 4优化为WebSocket

2. **大文件上传**
   - 风险: 50MB文件可能超时
   - 缓解: 添加进度条,分片上传

### 中风险

1. **语义搜索精度**
   - 风险: 向量相似度可能不准
   - 缓解: 调整阈值,优化Prompt

2. **多模型并发稳定性**
   - 风险: 部分模型可能失败

### 低风险

1. **TypeScript类型错误**
   - 影响: 仅影响开发体验
   - 缓解: 使用pure-build跳过

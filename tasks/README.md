### 🟡 P1 - 严重问题（本周修复）

#### [P1-1: AI验证器误判中文短语](./P1-1_entity_validator_fix.md)
- **问题**: 90%日志噪音来源
- **根因**: 正则表达式过于激进，提取大量普通词汇作为"实体"
- **影响**: 日志污染，监控失效，真正问题被淹没
- **预估工时**: 2.5小时
- **方案**: 删除第61-62行正则 + 依赖jieba词性标注 + 添加阈值判断
- **🔑 关键发现**: 之前优化只扩展白名单（治标），没删除错误正则（治本）

#### P1-2: 重复初始化ModelSelector
- **问题**: 每个API请求都重复初始化
- **根因**: 未使用依赖注入，违反单例原则
- **影响**: 性能浪费，日志噪音
- **预估工时**: 1小时
- **方案**: 使用FastAPI依赖注入 + lru_cache

## 🎯 核心思想

### 问题本质
不是简单的参数问题或配置问题，而是**设计问题**：
1. **P0-1**: AI缺少上下文感知能力
2. **P1-1**: 验证逻辑过于激进且不准确
3. **P1-2**: 违反单例原则

### 解决策略
1. **三层防御**: 让AI更聪明 + 工具更健壮 + 用户体验更好
2. **治本不治标**: 删除错误逻辑，不是无限打补丁
3. **渐进式**: 先止血 → 再优化 → 最后完善

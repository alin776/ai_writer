## 六、问题修复记录

### 问题 1: 数据库迁移冲突
**现象**: `alembic upgrade head` 失败，提示表已存在
**原因**: 数据库表存在但 Alembic 版本未标记
**解决方案**: 使用 `alembic stamp head` 标记版本
**状态**: ✅ 已解决

### 问题 2: 缺失 Python 依赖包
**现象**: `ModuleNotFoundError: No module named 'qcloud_cos'`
**原因**: 使用了错误的包名 `qcloud-cos==5.2.11`
**解决方案**: 更改为正确的包 `cos-python-sdk-v5>=1.9.0`
**状态**: ✅ 已解决

### 问题 3: 数据库缺失字段
**现象**: 登录失败，提示 `字段 users.notification_settings 不存在`
**原因**: `alembic stamp head` 只标记版本，未执行 SQL
**解决方案**: 创建并执行 `fix_database.sql` 手动添加字段
**状态**: ✅ 已解决

### 问题 4: 前端 JSX 语法错误
**现象**: `Adjacent JSX elements must be wrapped in an enclosing tag`
**原因**: 多个 JSX 根元素未包裹在 Fragment 中
**解决方案**: 使用 `<>...</>` Fragment 包裹
**状态**: ✅ 已解决

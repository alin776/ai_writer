# ContentOperator 数据结构

## 核心数据类

### OperationType - 操作类型枚举

```python
from enum import Enum

class OperationType(str, Enum):
    """操作类型（完整 6 种）"""
    APPEND = "append"       # 续写，追加到末尾
    REPLACE = "replace"     # 改写，替换指定段落
    INSERT = "insert"       # 插入到指定位置
    CONTENT = "content"     # 整体替换章节内容（映射到 replace_all）
    CREATE = "create"       # 写新章节（标题+内容）
    TITLE = "title"         # 改进章节标题
```

### OperateRequest - 操作请求

```python
from dataclasses import dataclass
from typing import Optional

@dataclass
class OperateRequest:
    """操作请求

    参数必填性说明：
    - append/replace/insert/content: 需要 chapter_id + content
    - create: 需要 work_id + content + title
    - title: 需要 chapter_id + title
    """
    # 操作类型
    operation: OperationType = OperationType.APPEND

    # 目标标识（根据操作类型，二选一）
    chapter_id: Optional[str] = None          # 章节ID（append/replace/insert/content/title）
    work_id: Optional[str] = None             # 作品ID（create 时必填）

    # 内容（根据操作类型，可选）
    content: Optional[str] = None             # 要写入的内容
    title: Optional[str] = None               # 标题（create/title 时使用）

    # 定位信息（replace/insert 时使用，优先级：direct > text_match > semantic）
    paragraph_index: Optional[int] = None     # 段落索引（精确定位，direct）
    node_id: Optional[str] = None             # 节点ID（精确定位，direct）
    original_text: Optional[str] = None       # 原文（replace 时用于 text_match 定位）
    target_description: Optional[str] = None  # 语义描述（insert 时用于 semantic 定位）

    # 上下文信息
    user_id: Optional[str] = None
    conversation_id: Optional[str] = None
    description: Optional[str] = None
```

### LocateMethod - 定位方法枚举

```python
class LocateMethod(str, Enum):
    """定位方法（按优先级排序）"""
    DIRECT = "direct"           # 直接使用传入的 paragraph_index/node_id（最高优先级）
    TEXT_MATCH = "text_match"   # 通过 original_text 匹配
    SEMANTIC = "semantic"       # 通过 target_description 语义定位
    NONE = "none"               # 无需定位（append/content/create/title）
    FALLBACK = "fallback"       # 降级处理（insert 定位失败时追加到末尾）
```

## 工具输入输出

### OperateApplyInput - 工具输入

```python
from pydantic import Field, model_validator
from typing import Optional
from .tool_types import ToolInput

class OperateApplyInput(ToolInput):
    """operate_apply 工具输入

    参数约束：
    - append/replace/insert/content: chapter_id 必填, content 必填
    - create: work_id 必填, content 必填, title 必填
    - title: chapter_id 必填, title 必填
    """
    # 操作类型
    operation: str = Field(
        default="append",
        description="操作类型: append(续写) / replace(改写) / insert(插入) / content(整章替换) / create(新章节) / title(改标题)"
    )

    # 目标标识
    chapter_id: Optional[str] = Field(
        default=None,
        description="章节ID（append/replace/insert/content/title 时必填）"
    )
    work_id: Optional[str] = Field(
        default=None,
        description="作品ID（create 时必填）"
    )

    # 内容
    content: Optional[str] = Field(
        default=None,
        description="要写入的内容（append/replace/insert/content/create 时必填）"
    )
    title: Optional[str] = Field(
        default=None,
        description="标题（create/title 时必填）"
    )

    # 定位信息（replace/insert 时使用）
    paragraph_index: Optional[int] = Field(
        default=None,
        description="段落索引（精确定位，0-based，优先级最高）"
    )
    node_id: Optional[str] = Field(
        default=None,
        description="节点ID（精确定位，来自 Tiptap 编辑器，优先级最高）"
    )
    original_text: Optional[str] = Field(
        default=None,
        description="原文（replace 操作时用于文本匹配定位）"
    )
    target_description: Optional[str] = Field(
        default=None,
        description="目标位置描述（insert 操作时用于语义定位），如'第3段后面'、'主角出场的地方'"
    )

    # 上下文信息
    user_id: Optional[str] = Field(default=None, description="用户ID")
    conversation_id: Optional[str] = Field(default=None, description="会话ID")
    description: Optional[str] = Field(default=None, description="操作描述")

    @model_validator(mode='after')
    def validate_required_fields(self):
        """根据操作类型验证必填字段"""
        op = self.operation

        if op in ["append", "replace", "insert", "content"]:
            if not self.chapter_id:
                raise ValueError(f"{op} 操作需要 chapter_id")
            if not self.content:
                raise ValueError(f"{op} 操作需要 content")

        elif op == "create":
            if not self.work_id:
                raise ValueError("create 操作需要 work_id")
            if not self.content:
                raise ValueError("create 操作需要 content")
            if not self.title:
                raise ValueError("create 操作需要 title")

        elif op == "title":
            if not self.chapter_id:
                raise ValueError("title 操作需要 chapter_id")
            if not self.title:
                raise ValueError("title 操作需要 title")

        return self
```

## 定位优先级

对于需要定位的操作（replace/insert），按以下优先级选择定位方法：

```
1. DIRECT（最高）: paragraph_index 或 node_id 已提供
   └─ 直接使用，跳过定位步骤

2. TEXT_MATCH: original_text 已提供（replace 操作）
   └─ 通过文本匹配定位段落

3. SEMANTIC: target_description 已提供（insert 操作）
   └─ 调用 locate_content 进行语义定位

4. FALLBACK（仅 insert）: 定位失败时
   └─ 降级为追加到末尾（append 行为）
```

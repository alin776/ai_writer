# Operate SubAgent 数据结构

## 核心数据类

### OperationType - 操作类型枚举

```python
from enum import Enum

class OperationType(str, Enum):
    """操作类型"""
    APPEND = "append"       # 追加到末尾
    REPLACE = "replace"     # 替换指定内容
    INSERT = "insert"       # 插入到指定位置
```

### OperateRequest - 操作请求

```python
from dataclasses import dataclass
from typing import Optional

@dataclass
class OperateRequest:
    """操作请求"""
    # 必填
    chapter_id: str                           # 章节ID
    content: str                              # 要写入的内容

    # 操作类型
    operation: OperationType = OperationType.APPEND

    # 定位信息（多选一）
    target_description: Optional[str] = None  # 语义描述："第3段后面"
    original_text: Optional[str] = None       # 原文（replace 时用于定位）
    paragraph_index: Optional[int] = None     # 段落索引（精确定位）
    node_id: Optional[str] = None             # 节点ID（精确定位）

    # 上下文信息
    work_id: Optional[str] = None
    user_id: Optional[str] = None
    conversation_id: Optional[str] = None
    description: Optional[str] = None
```

### OperateResult - 操作结果

```python
@dataclass
class OperateResult:
    """操作结果"""
    # 基本结果
    success: bool
    message: str
    operation: str                            # 实际执行的操作类型
    chapter_id: str

    # 定位信息
    located: bool = False                     # 是否成功定位
    paragraph_index: Optional[int] = None     # 定位到的段落索引
    node_id: Optional[str] = None             # 定位到的节点ID
    locate_method: Optional[str] = None       # 使用的定位方法

    # HITL 信息（用于前端确认）
    requires_confirmation: bool = False
    revision_id: Optional[str] = None
    request_id: Optional[str] = None

    # 内容信息
    content_length: Optional[int] = None      # 写入内容长度
    original_text: Optional[str] = None       # 原文（replace 时）
```

### LocateMethod - 定位方法枚举

```python
class LocateMethod(str, Enum):
    """定位方法"""
    DIRECT = "direct"           # 直接使用传入的 paragraph_index/node_id
    TEXT_MATCH = "text_match"   # 通过 original_text 匹配
    SEMANTIC = "semantic"       # 通过 target_description 语义定位
    NONE = "none"               # 无需定位（append）
    FALLBACK = "fallback"       # 降级处理（追加到末尾）
```

## 工具输入输出

### OperateApplyInput - 工具输入

```python
from pydantic import Field
from .tool_types import ToolInput

class OperateApplyInput(ToolInput):
    """operate_apply 工具输入"""
    chapter_id: str = Field(..., description="章节ID")
    content: str = Field(..., description="要写入的内容（来自 Create 工具）")
    operation: str = Field(
        default="append",
        description="操作类型: append/replace/insert"
    )
    target_description: Optional[str] = Field(
        default=None,
        description="目标位置描述，如'第3段后面'、'主角出场的地方'"
    )
    original_text: Optional[str] = Field(
        default=None,
        description="原文（replace 操作时用于定位）"
    )
    paragraph_index: Optional[int] = Field(
        default=None,
        description="段落索引（精确定位，0-based）"
    )
    node_id: Optional[str] = Field(
        default=None,
        description="节点ID（精确定位，来自 Tiptap 编辑器）"
    )
    work_id: Optional[str] = Field(default=None, description="作品ID")
    user_id: Optional[str] = Field(default=None, description="用户ID")
    conversation_id: Optional[str] = Field(default=None, description="会话ID")
    description: Optional[str] = Field(default=None, description="操作描述")
```

## 与现有数据结构的关系

```
┌─────────────────────────────────────────────────────────────┐
│                     数据流向                                 │
└─────────────────────────────────────────────────────────────┘

Create 工具输出                 Operate SubAgent 输入
─────────────────              ─────────────────────
smart_rewrite 返回:            operate_apply 接收:
{                              {
  "success": true,               "chapter_id": "...",
  "original_text": "原文",   →   "content": versions[0].content,
  "versions": [                  "operation": "replace",
    {"content": "改写1"},        "original_text": "原文"
    {"content": "改写2"}       }
  ]
}

smart_continue 返回:           operate_apply 接收:
{                              {
  "success": true,               "chapter_id": "...",
  "content": "续写内容"      →   "content": "续写内容",
}                                "operation": "append"
                               }

smart_insert 返回:             operate_apply 接收:
{                              {
  "success": true,               "chapter_id": "...",
  "content": "插入内容"      →   "content": "插入内容",
}                                "operation": "insert",
                                 "target_description": "第3段后"
                               }
```

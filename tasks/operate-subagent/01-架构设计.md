# Operate SubAgent 架构设计

## 核心定位

**operate_apply 是 Create 工具输出的统一接收者**

用户调用 AI Agent 的目的是让 AI 生成内容，所以：
- 所有需要 AI 的场景都是 `Create → Operate` 流程
- operate_apply 统一接收 Create 工具的输出（content、title 等）
- 内部自动处理定位和路由

## 三阶段流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                       Operate SubAgent                               │
│                                                                      │
│  输入（来自 Create 工具）：                                           │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │ operation        : append | replace | insert | content | create | title│    │
│  │ chapter_id       : 章节ID（create 时可选）                    │    │
│  │ work_id          : 作品ID（create 时必填）                    │    │
│  │ content          : AI生成的内容                               │    │
│  │ title            : AI生成的标题（create/title 时使用）        │    │
│  │ original_text    : 原文（replace 时用于自动定位）             │    │
│  │ target_description: 目标位置描述（insert 时用于自动定位）     │    │
│  └─────────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────────┘
                               │
            ┌──────────────────┼──────────────────┐
            ▼                  ▼                  ▼
┌───────────────────┐ ┌───────────────────┐ ┌───────────────────┐
│ 阶段1：意图路由    │ │ 阶段2：智能定位    │ │ 阶段3：执行操作    │
│                   │ │                   │ │                   │
│ 根据 operation    │→│ 仅 replace/insert │→│ 调用底层工具      │
│ 选择底层工具      │ │ 需要定位          │ │ 返回结果+HITL    │
└───────────────────┘ └───────────────────┘ └───────────────────┘
```

## 阶段1：意图路由

### 路由表

| operation | 底层工具 | 说明 | 需要定位 |
|-----------|----------|------|---------|
| append | apply_chapter_edit(append) | 续写，追加到末尾 | ✗ |
| replace | apply_chapter_edit(replace) | 改写，替换段落 | ✓ |
| insert | apply_chapter_edit(insert) | 插入内容 | ✓ |
| content | apply_chapter_edit(replace_all) | 整体替换章节内容 | ✗ |
| create | create_chapter | 写新章节 | ✗ |
| title | update_chapter_title | 改进标题 | ✗ |

### 路由逻辑

```python
def route_operation(operation: str) -> tuple[str, bool]:
    """
    根据操作类型路由到底层工具

    Returns:
        (工具名, 是否需要定位)
    """
    routing = {
        "append":  ("apply_chapter_edit", "append", False),
        "replace": ("apply_chapter_edit", "replace", True),
        "insert":  ("apply_chapter_edit", "insert", True),
        "content": ("apply_chapter_edit", "replace_all", False),
        "create":  ("create_chapter", None, False),
        "title":   ("update_chapter_title", None, False),
    }
    return routing.get(operation, ("apply_chapter_edit", False))
```

## 阶段2：智能定位

**仅 replace 和 insert 需要定位**

### 定位策略

| operation | 定位方式 | 输入 |
|-----------|---------|------|
| replace | 原文匹配 | original_text |
| insert | 语义定位 | target_description |

### 定位逻辑

```python
async def smart_locate(operation, original_text, target_description):
    if operation == "replace" and original_text:
        # 用原文匹配定位
        return await locate_content(query=original_text)

    if operation == "insert" and target_description:
        # 用语义描述定位
        return await locate_content(query=target_description)

    return None  # 其他操作不需要定位
```

### 定位失败处理

```
replace 定位失败 → 返回错误，要求用户提供更准确的原文
insert 定位失败 → 可降级为 append（追加到末尾）
```

## 阶段3：执行操作

### 与底层工具的关系

```
┌─────────────────────────────────────────────────────────────────────┐
│                      Operate SubAgent                                │
│                                                                      │
│  ┌─────────────┐    ┌─────────────┐    ┌────────────────────────┐   │
│  │  意图路由    │ →  │ 智能定位     │ →  │     执行底层工具        │   │
│  │             │    │ (可选)      │    │                        │   │
│  │ operation   │    │ locate_     │    │ • apply_chapter_edit   │   │
│  │ → 工具选择  │    │ content     │    │ • update_chapter_content│  │
│  └─────────────┘    └─────────────┘    │ • create_chapter       │   │
│                                        │ • update_chapter_title │   │
│                                        └────────────────────────┘   │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────────┐
│                       HITL 确认流程                                  │
│                                                                      │
│  requires_confirmation=True → 前端显示确认 → 用户确认/拒绝           │
└─────────────────────────────────────────────────────────────────────┘
```

### 各操作的执行逻辑

**append（续写）**
```python
await apply_chapter_edit(
    chapter_id=chapter_id,
    operation="append",
    content=content  # Create 工具生成的内容
)
```

**replace（改写）**
```python
# 先定位
location = await locate_content(query=original_text)

# 再替换
await apply_chapter_edit(
    chapter_id=chapter_id,
    operation="replace",
    content=content,
    paragraph_index=location.paragraph_index,
    node_id=location.node_id
)
```

**insert（插入）**
```python
# 先定位
location = await locate_content(query=target_description)

# 再插入
await apply_chapter_edit(
    chapter_id=chapter_id,
    operation="insert",
    content=content,
    paragraph_index=location.paragraph_index
)
```

**content（整体替换）**
```python
# replace_all：用新内容完全替换整个章节的全部内容
# 不需要定位参数，直接全量替换
await apply_chapter_edit(
    chapter_id=chapter_id,
    operation="replace_all",
    content=content  # Create 工具生成的新内容，将完全替换原有内容
)
# 注：会触发 HITL 确认流程，用户需要确认后才执行
```

**create（写新章节）**
```python
await create_chapter(
    work_id=work_id,
    title=title,    # Create 工具生成的标题
    content=content  # Create 工具生成的内容
)
```

**title（改进标题）**
```python
await update_chapter_title(
    chapter_id=chapter_id,
    new_title=title  # Create 工具生成的新标题
)
```

## 错误处理

```
1. 路由失败
   └─ 未知 operation → 返回 invalid_operation 错误

2. 定位失败
   ├─ replace 定位失败 → 返回错误 "无法定位原文，请检查"
   └─ insert 定位失败 → 可降级为 append 或返回错误

3. 执行失败
   ├─ 章节不存在 → chapter_not_found
   ├─ 内容为空 → empty_content
   └─ 其他错误 → 返回详细错误信息
```

## 与 Explore SubAgent 的对比

| 特性 | Explore SubAgent | Operate SubAgent |
|------|------------------|------------------|
| 定位 | Create → Operate 的桥梁 | 接收 Create 输出 |
| 阶段 | 3阶段（搜索→评估→补充） | 3阶段（路由→定位→执行） |
| AI 调用 | 多次 | 0-1次（仅语义定位） |
| 复杂度 | 高（3189行） | 低（预计200-300行） |
| 底层工具 | 多个搜索工具 | 4个操作工具 |

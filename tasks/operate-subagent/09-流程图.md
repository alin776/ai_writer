## 路由表

| operation | 需要定位 | 底层工具 | 说明 |
|-----------|---------|----------|------|
| append | ✗ | apply_chapter_edit(append) | 续写，追加到末尾 |
| replace | ✓ (原文匹配) | apply_chapter_edit(replace) | 改写，替换段落 |
| insert | ✓ (语义定位) | apply_chapter_edit(insert) | 插入内容 |
| content | ✗ | apply_chapter_edit(replace_all) | 重写整章 |
| create | ✗ | create_chapter | 写新章节 |
| title | ✗ | update_chapter_title | 改进标题 |

**说明**：所有修改内容的操作都通过 `apply_chapter_edit` 走 HITL 确认流程。

## 与 Planning 的配合

```
┌─────────────────────────────────────────────────────────────────────┐
│                         Planning Agent                              │
│                                                                     │
│  核心理念：用户调用 AI Agent 是为了让 AI 生成内容                     │
│  所有需要 AI 的场景都是 Create → Operate 流程                        │
```

## 各场景流程示例

### 场景1：续写
```
用户: "帮我续写第5章"

Planning:
  Task 1: smart_continue → 生成续写内容
  Task 2: operate_apply(operation="append", content=Task1输出)

Operate SubAgent:
  ├─ 阶段1: 路由 → apply_chapter_edit, 无需定位
  ├─ 阶段2: 跳过
  └─ 阶段3: apply_chapter_edit(operation="append")
```

### 场景2：改写
```
用户: "帮我改写第3段，增强画面感"

Planning:
  Task 1: smart_rewrite → 生成改写内容，返回 original_text
  Task 2: operate_apply(operation="replace", content=改写内容, original_text=原文)

Operate SubAgent:
  ├─ 阶段1: 路由 → apply_chapter_edit, 需要定位
  ├─ 阶段2: locate_content(query=original_text) → paragraph_index
  └─ 阶段3: apply_chapter_edit(operation="replace", paragraph_index=N)
```

### 场景3：写新章节
```
用户: "帮我写第六章"

Planning:
  Task 1: smart_continue → 生成内容 + 生成标题
  Task 2: operate_apply(operation="create", title=标题, content=内容, work_id=xxx)

Operate SubAgent:
  ├─ 阶段1: 路由 → create_chapter, 无需定位
  ├─ 阶段2: 跳过
  └─ 阶段3: create_chapter(title=标题, content=内容)
```

### 场景4：重写整章
```
用户: "帮我重写整个第五章"

Planning:
  Task 1: smart_rewrite → 生成全新的章节内容
  Task 2: operate_apply(operation="content", content=新内容, chapter_id=xxx)

Operate SubAgent:
  ├─ 阶段1: 路由 → apply_chapter_edit(replace_all), 无需定位
  ├─ 阶段2: 跳过
  └─ 阶段3: apply_chapter_edit(operation="replace_all", content=新内容)
            → HITL确认
```

### 场景5：改进标题
```
用户: "帮我想个更好的第五章标题"

Planning:
  Task 1: (AI生成新标题)
  Task 2: operate_apply(operation="title", title=新标题, chapter_id=xxx)

Operate SubAgent:
  ├─ 阶段1: 路由 → update_chapter_title, 无需定位
  ├─ 阶段2: 跳过
  └─ 阶段3: update_chapter_title(new_title=新标题)
```

### 场景6：插入内容
```
用户: "在主角出场后添加心理描写"

Planning:
  Task 1: smart_insert → 生成心理描写内容
  Task 2: operate_apply(operation="insert", content=内容, target_description="主角出场的段落之后")

Operate SubAgent:
  ├─ 阶段1: 路由 → apply_chapter_edit, 需要定位
  ├─ 阶段2: locate_content(query="主角出场的段落之后") → paragraph_index
  └─ 阶段3: apply_chapter_edit(operation="insert", paragraph_index=N)
```

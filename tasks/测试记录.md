## 测试 4：退出指定会话

### 操作步骤
1. 在第一个浏览器的设置页面
2. 找到第二个浏览器的会话

4. 在确认对话框中点击"确认退出"
5. 切换到第二个浏览器
6. 尝试刷新页面或访问其他页面

✅ 第一个浏览器：

## 数据库验证（可选）

### 操作步骤
如果你想检查数据库，可以运行：

```sql
-- 查看所有会话
SELECT id, user_id, device_name, browser, is_active, created_at
FROM user_sessions
ORDER BY created_at DESC;

-- 查看活跃会话
SELECT id, user_id, device_name, browser, is_active
FROM user_sessions
WHERE is_active = true;
```

### 预期结果
✅ 看到会话记录
✅ is_active 字段正确（true/false）
✅ logged_out_at 在退出后有值

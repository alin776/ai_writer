### 3. 工具参数未被提取

**问题代码** (`langgraph_agent.py:2770-2781`):
```python
def _extract_tool_calls(self, node_data: dict) -> list:
    """提取工具调用信息"""
    tool_calls = []
    messages = node_data.get("messages", [])

    for msg in messages:
        if isinstance(msg, ToolMessage) and hasattr(msg, "name"):
            tool_name = msg.name
            tool_args = {}  # ❌ 参数为空！没有提取tool_calls的参数
            tool_calls.append((tool_name, tool_args))

    return tool_calls
```

**问题**:
- 只提取了工具名称，没有提取工具参数
- 无法获取章节号、章节标题等详细信息
- 导致无法生成具体的描述

## 🔧 解决方案

### 方案1: 增强tools节点描述（推荐）⭐

**优点**:
- 解决最明显的UX问题
- 实现相对简单
- 不影响其他节点

**实施步骤**:

#### 步骤1: 提取AIMessage的tool_calls参数

**文件**: `backend/app/services/agent/langgraph_agent.py:2706-2727`

**修改**:
```python
elif node_name == "tools":
    # ✅ 从AIMessage提取tool_calls参数
    messages = node_data.get("messages", [])
    tool_info = None

    # 寻找AIMessage中的tool_calls
    for msg in messages:
        if isinstance(msg, AIMessage) and hasattr(msg, "tool_calls") and msg.tool_calls:
            # 取第一个tool_call
            tool_call = msg.tool_calls[0]
            tool_info = {
                "name": tool_call.get("name"),
                "args": tool_call.get("args", {})
            }
            break

    if tool_info:
        tool_name = tool_info["name"]
        tool_args = tool_info["args"]
        details["tools"] = [tool_name]
        details["tool_args"] = tool_args

        # ✅ 根据工具和参数生成具体描述
        description = _generate_tool_description(tool_name, tool_args)
        mapping["description"] = description
```

#### 步骤2: 实现_generate_tool_description函数

**新增函数**:
```python
def _generate_tool_description(tool_name: str, tool_args: dict) -> str:
    """根据工具名称和参数生成具体描述"""

    if tool_name == "get_chapter_by_order_tool":
        chapter_order = tool_args.get("chapter_order", "?")
        # 如果能访问数据库，可以获取章节标题
        # 这里简化处理
        return f"📚 正在读取第{chapter_order}章..."

    elif tool_name == "continue_writing_tool":
        # 从上下文推断章节信息
        return "✍️ 正在创作内容..."

    elif tool_name == "search_analysis_fragments_tool":
        query = tool_args.get("query", "")
        if query:
            return f"🔍 正在检索「{query}」相关设定..."
        return "🔍 正在检索设定..."

    elif tool_name == "search_memory_tool":
        query = tool_args.get("query", "")
        if query:
            return f"💭 正在搜索「{query}」相关记忆..."
        return "💭 正在搜索记忆..."

    # 默认描述
    tool_display_names = {
        "get_chapter_by_order_tool": "读取章节",
        "continue_writing_tool": "继续创作",
        "search_analysis_fragments_tool": "检索设定",
        "search_memory_tool": "搜索记忆",
        "add_todo_tool": "添加待办",
        "get_work_details_tool": "获取作品信息",
        "update_work_metadata_tool": "更新元数据"
    }
    display_name = tool_display_names.get(tool_name, tool_name)
    return f"正在{display_name}..."
```

**工作量**: 30-45分钟
**风险**: 低
**优先级**: 高

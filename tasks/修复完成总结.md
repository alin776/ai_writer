### 2. ✅ test_memory_system.py - 添加数据清理 (P1)

**新增方法**: `cleanup_test_data()`

```python
async def cleanup_test_data(self, redis_client) -> bool:
    """
    清理测试数据

    确保测试环境干净,避免旧数据干扰
    """
    patterns = [
        f"memory:{self.user_id}:short_term",
        f"memory:{self.user_id}:medium_term",
        f"memory:{self.user_id}:long_term",
        f"memory:snapshot:*"
    ]

    # 使用scan清理匹配的key
    deleted_count = 0
    for pattern in patterns:
        if "*" in pattern:
            cursor = 0
            while True:
                cursor, keys = await redis_client.scan(cursor, match=pattern, count=100)
                if keys:
                    await redis_client.delete(*keys)
                    deleted_count += len(keys)
                if cursor == 0:
                    break
        else:
            if await redis_client.exists(pattern):
                await redis_client.delete(pattern)
                deleted_count += 1

    logger.info(f"✓ 清理完成,删除了 {deleted_count} 个key")
```

**收益**:
- 测试幂等性保证
- 避免旧数据干扰
- 每次测试都从干净状态开始

### 3. ✅ test_memory_system.py - 修复时间排序验证 (P1)

**修复位置**: test_3_get_recent_memories()

```python
# 之前 - 简单比较,可能因时区失败
is_sorted = all(
    recent[i].timestamp >= recent[i+1].timestamp
    for i in range(len(recent) - 1)
)

# 现在 - 兼容naive和aware datetime
timestamps_sorted = True
for i in range(len(recent) - 1):
    t1 = recent[i].timestamp
    t2 = recent[i+1].timestamp

    # 如果是naive datetime,添加UTC时区
    if t1.tzinfo is None:
        t1 = t1.replace(tzinfo=timezone.utc)
    if t2.tzinfo is None:
        t2 = t2.replace(tzinfo=timezone.utc)

    if t1 < t2:
        timestamps_sorted = False
        break

if timestamps_sorted:
    logger.info("✓ 记忆按时间倒序排列")
else:
    logger.warning("⚠ 记忆排序可能不正确")
    logger.warning(f"  第1条时间: {recent[0].timestamp}")
    logger.warning(f"  第2条时间: {recent[1].timestamp}")
```

**收益**:
- 兼容两种datetime格式
- 更详细的错误信息
- 更准确的排序验证

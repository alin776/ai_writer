## 一、功能需求

### 背景
NovelAIde 项目的 SettingsView 需要完善用户设置功能，特别是多设备会话管理能力，让用户能够：
- 查看所有登录设备
- 识别当前设备
- 远程登出其他设备
- 管理账号安全

### 核心需求
1. **登录时自动记录会话**：每次登录创建会话记录
2. **设备指纹识别**：自动解析浏览器、操作系统、设备类型
3. **会话列表展示**：显示所有活跃会话的详细信息
4. **当前设备标识**：明确标记用户正在使用的设备
5. **单设备登出**：允许用户退出指定设备
6. **批量登出**：一键退出除当前设备外的所有会话

```python
def parse_user_agent(user_agent: Optional[str]) -> Dict[str, Optional[str]]:
    """解析 User-Agent 字符串"""
    # 浏览器识别
    browser_patterns = {
        'chrome': r'Chrome/([0-9.]+)',
        'firefox': r'Firefox/([0-9.]+)',
        'safari': r'Version/([0-9.]+).*Safari',
        'edge': r'Edg/([0-9.]+)',
    }
    # 操作系统识别
    os_patterns = {
        'windows': r'Windows NT ([0-9.]+)',
        'macos': r'Mac OS X ([0-9_]+)',
        'linux': r'Linux',
        'ios': r'iPhone|iPad',
        'android': r'Android ([0-9.]+)',
    }
    # 设备类型判断
    if 'mobile' in ua_lower or 'android' in ua_lower or 'iphone' in ua_lower:
        device_type = 'mobile'
    elif 'tablet' in ua_lower or 'ipad' in ua_lower:
        device_type = 'tablet'
    else:
        device_type = 'desktop'
```

```python
        expires_at=expires_at,
```

### 难点 1: User-Agent 解析
**挑战**: User-Agent 字符串格式复杂，不同浏览器格式差异大

**解决方案**:
```python
# 使用正则表达式匹配主流浏览器
browser_patterns = {
    'chrome': r'Chrome/([0-9.]+)',
    'firefox': r'Firefox/([0-9.]+)',
    'safari': r'Version/([0-9.]+).*Safari',
    'edge': r'Edg/([0-9.]+)',
    'opera': r'OPR/([0-9.]+)',
}

# 生成友好的设备名称
device_name = f"{browser} · {operating_system} · {device_type_cn[device_type]}"
# 例如: "Chrome · Windows 10/11 · 桌面"
```

---

### 难点 2: 当前设备识别
**挑战**: 如何区分哪个会话是用户当前使用的设备？

**解决方案**:
```python
# 方案：使用 access_token 作为 session_token
# 登录时返回的 access_token 同时作为会话标识
# 前端请求时携带的 token 与数据库中的 session_token 匹配

async def get_user_sessions(
    self, user_id: str, current_token: Optional[str] = None
) -> List[UserSessionResponse]:
    # 查询所有活跃会话
    sessions = await self.db.execute(
        select(UserSession)
        .where(UserSession.user_id == UUID(user_id))
        .where(UserSession.is_active == True)
    )

    # 标记当前设备
    for session in sessions:
        session_resp = UserSessionResponse.from_orm(session)
        session_resp.is_current = (session.session_token == current_token)
```

---

### 难点 3: IP 地址获取
**挑战**: 代理服务器、负载均衡器会隐藏真实 IP

**解决方案**:
```python
def get_client_ip(request) -> Optional[str]:
    """优先级：X-Forwarded-For > X-Real-IP > request.client.host"""
    # 从代理头获取真实 IP
    forwarded_for = request.headers.get("X-Forwarded-For")
    if forwarded_for:
        return forwarded_for.split(",")[0].strip()

    real_ip = request.headers.get("X-Real-IP")
    if real_ip:
        return real_ip

    # 备选方案
    if hasattr(request.client, "host"):
        return request.client.host

    return None
```

### 难点 4: 数据库事务管理
**挑战**: 登录时创建会话失败不应影响登录成功

**解决方案**:
```python
# 使用 try-except 包裹会话创建，失败仅记录日志

        session_token=access_token,

        ip_address=ip_address

except Exception as e:

```

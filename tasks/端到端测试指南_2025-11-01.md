## 🎯 测试流程

### 阶段一: 创建测试作品 (3分钟)

#### 步骤1: 访问首页
1. 打开浏览器访问 `http://localhost:5173`
2. 检查页面是否正常加载
3. 查看Console是否有错误

#### 步骤2: 创建新作品
1. 点击"创建作品"或"新建作品"按钮
2. 填写作品信息:
   ```
   作品名称: 测试作品-都市修仙
   作品类型: 都市/玄幻
   简介: 一个普通大学生意外获得修仙传承的故事
   ```
3. 点击"创建"或"确认"
4. 等待作品创建成功

**验证点**:
- ✅ 作品创建成功
- ✅ 跳转到作品详情页
- ✅ Console无错误
- ✅ Network显示API调用成功

#### 步骤3: 记录作品信息
```
作品ID: _________ (从URL或页面获取)
作品名称: 测试作品-都市修仙
```

---

### 阶段二: 规划作品大纲 (5分钟)

#### 步骤4: 进入规划模式
1. 在作品详情页找到"规划"或"大纲"入口
2. 点击进入规划对话界面

#### 步骤5: 测试规划功能
在对话框输入以下内容:

**测试1: 世界观设定**
```
帮我设定这个都市修仙小说的世界观，包括修炼体系和等级划分
```

**期望结果**:
- ✅ Agent识别为规划意图
- ✅ 返回合理的世界观设定
- ✅ 包含修炼等级、体系说明
- ✅ 回复时间 <15秒

**测试2: 角色设定**
```
帮我设计主角的背景和性格特点
```

**期望结果**:
- ✅ 返回主角设定
- ✅ 包含背景、性格、目标等
- ✅ 与世界观保持一致

**验证点**:
- 查看Network标签中的API请求:
  - `/api/v1/ai/chat` 或类似路径
  - 请求包含作品ID
  - 响应包含AI生成内容

---

### 阶段三: 生成章节内容 (7分钟)

#### 步骤6: 创建第一章

**方式A: 通过对话创建**
在对话框输入:
```
帮我写第一章，标题是"觉醒"，主角在图书馆发现古籍
```

**方式B: 通过章节管理创建**
1. 找到"章节管理"或"新建章节"
2. 填写:
   ```
   章节序号: 1
   章节标题: 觉醒
   ```
3. 在对话框说: `续写第一章`

**期望结果**:
- ✅ 识别为第1章(属于"起"阶段)
- ✅ 使用NovelPhase.OPENING的Prompt
- ✅ 生成2000字左右内容
- ✅ 包含场景描写、对话、动作
- ✅ 生成时间 <30秒

**验证WritingAction**:
打开浏览器Console,查找日志:
```
[writing] 直接输入章节号: 1
[writing] 章节 1 属于阶段: opening
```

#### 步骤7: 测试不同阶段的章节

**测试第15章(承阶段)**
```
续写第15章，主角突破到筑基期
```

**期望结果**:
- ✅ 识别为第15章(属于"承"阶段)
- ✅ 使用NovelPhase.DEVELOPMENT的Prompt
- ✅ 生成2500字左右内容
- ✅ 体现实力提升、剧情发展

**测试第25章(转阶段)**
```
续写第25章，主角遭遇强敌
```

**期望结果**:
- ✅ 识别为第25章(属于"转"阶段)
- ✅ 使用NovelPhase.CLIMAX的Prompt
- ✅ 生成3000字左右内容
- ✅ 冲突和转折明显

**验证阶段切换**:
查看Console日志,确认不同章节使用不同阶段:
```
章节 1  -> opening
章节 15 -> development
章节 25 -> climax
```

## 🔍 问题排查

### 常见问题

#### 1. 前端连接后端失败

**检查**:
```bash
# 检查后端服务
netstat -ano | findstr :8000

# 查看后端日志
# 在backend目录查看logs/app.log
```

**解决**:
```bash
# 重启后端服务
cd backend
python -m uvicorn app.main:app --reload --port 8000
```

#### 2. Agent响应慢或超时

**检查**:
- 网络连接到API (204992.xyz)
- API Key是否有效
- 查看Console的Network标签

#### 3. Action识别错误

**检查Console日志**:
应该看到类似:
```
[ActionRouter] 识别意图: writing
[writing] 执行写作逻辑
```

#### 4. 章节阶段检测失败

**检查**:
- Console中是否有 `直接输入章节号` 或 `从消息中识别到章节号`
- 确认章节号在1-50范围内

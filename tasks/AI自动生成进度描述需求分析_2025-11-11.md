# AI自动生成进度描述需求分析

**问题重述日期**: 2025-11-11
**核心需求**: 让AI自己生成进度描述，而不是代码硬编码

---

## 🎯 需求重述

### 用户期望

**描述应该由AI动态生成**，而不是代码中的硬编码映射！

**示例**:
```
AI应该自己说：
"📚 我正在读取第3章《天地玄黄》，这是主角突破的关键章节..."

而不是代码中写死：
if tool_name == "get_chapter_by_order_tool":
    return f"正在读取第{chapter_order}章..."  # ❌ 硬编码
```

---

## 🔍 当前实现分析

### 现状：完全硬编码

**执行流程**:
```
1. AI决定调用工具 → tool_calls: [{name: "get_chapter_by_order_tool", args: {chapter_order: 3}}]
2. 代码提取工具信息 → tool_name, tool_args
3. 代码硬编码映射 → "正在读取第3章..."  ← ❌ 这是代码生成的，不是AI生成的
4. 前端显示描述
```

**问题**:
- ❌ 描述是代码写死的，不够智能
- ❌ 无法根据上下文生成更丰富的描述
- ❌ 无法体现AI的"思考"过程
- ❌ 缺少个性化和context-aware的描述

---

## 💡 解决方案对比

### 方案1: ReAct模式 Thought-Action-Observation（推荐⭐⭐⭐）

**优点**:
- ✅ 符合AI Agent的标准工作模式
- ✅ 用户能看到AI的完整思考过程
- ✅ 描述完全由AI生成，更智能
- ✅ 可以根据上下文生成丰富的描述

**缺点**:
- ⚠️ 需要修改Agent架构
- ⚠️ 增加token消耗（AI输出更多文本）
- ⚠️ 实施复杂度较高（1-2天工作量）

**效果示例**:
```
用户：帮我写第三章

Agent输出：
💭 我理解您需要创作第3章内容。让我先读取第3章《天地玄黄》的现有内容和上下文...
📚 [调用工具: get_chapter_by_order_tool]
💭 好的，我已经获取了第3章的信息。现在我需要检索相关的世界观设定...
🔍 [调用工具: search_analysis_fragments_tool]
💭 很好，我找到了修炼体系的设定。现在我开始为您续写第3章...
✍️ [调用工具: continue_writing_tool]
```

---

### 方案2: 工具描述字段（简化方案⭐⭐）

**核心思想**: 在tool_call时添加description字段，由AI生成

**修改**:
```python
# Agent的tool_call格式
tool_calls = [
    {
        "name": "get_chapter_by_order_tool",
        "args": {
            "chapter_order": 3,
            "description": "读取第3章《天地玄黄》来了解主角的修炼进展"  # ← AI生成
        }
    }
]
```

**优点**:
- ✅ 实施简单（修改tool schema即可）
- ✅ 不改变Agent架构
- ✅ 描述由AI生成
- ✅ 工作量小（2-4小时）

**缺点**:
- ⚠️ 非标准ReAct模式
- ⚠️ 只能在工具调用时生成描述
- ⚠️ 缺少思考过程的展示

---

### 方案3: 流式Thinking输出（折中方案⭐）

**核心思想**: 让AI在生成tool_call前先输出thinking文本

**流程**:
```
1. AI先输出文本：我需要读取第3章...（流式返回给前端）
2. AI再输出tool_call（调用工具）
3. 前端同时显示thinking和tool执行状态
```

**优点**:
- ✅ 能显示AI思考过程
- ✅ 较简单（修改prompt即可）

**缺点**:
- ⚠️ 需要AI能同时输出文本+tool_call
- ⚠️ 不是所有模型都支持

---

```python
【工具调用说明】
当你调用工具时，必须在action_description参数中简短描述你正在做什么（20字以内）。
这个描述会实时显示给用户，让用户了解你的操作。

示例：
- get_chapter_by_order_tool(chapter_order=3, action_description="读取第3章了解剧情发展")

描述要求：
- 简洁明了，20字以内
- 说明你在做什么，为什么做
- 使用第一人称（我正在...）
```

#### 步骤3: 修改后端提取逻辑

**文件**: `backend/app/services/agent/langgraph_agent.py:2706-2739`

**修改**:
```python
elif node_name == "tools":
    # 从AIMessage提取tool_calls参数
    messages = node_data.get("messages", [])
    tool_info = None

    for msg in reversed(messages):
        if isinstance(msg, AIMessage) and hasattr(msg, "tool_calls") and msg.tool_calls:
            tool_call = msg.tool_calls[0]
            tool_info = {
                "name": tool_call.get("name"),
                "args": tool_call.get("args", {})
            }
            break

    if tool_info:
        tool_name = tool_info["name"]
        tool_args = tool_info["args"]
        details["tools"] = [tool_name]
        details["tool_args"] = tool_args

        # ✅ 优先使用AI生成的description
        ai_description = tool_args.get("action_description")
        if ai_description:
            mapping["description"] = ai_description  # ← AI生成的描述
        else:
            # Fallback：使用代码生成的描述（兼容旧版本）
            mapping["description"] = self._generate_tool_description(tool_name, tool_args)
```

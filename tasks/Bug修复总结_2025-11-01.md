### 1. WritingAction._detect_phase() 类型兼容性修复

**问题描述**:
- 位置: `backend/app/services/agent/actions/writing_action.py:155`
- 问题: `_detect_phase()` 方法只接受字符串参数,但测试传入整数时失败
- 错误信息: `expected string or bytes-like object, got 'int'`
- 优先级: P2 (建议修复)

**修复方案**:

```python
# 修复前
def _detect_phase(self, message: str) -> tuple[Optional[NovelPhase], Optional[int]]:
    chapter_match = re.search(r'第(\d+)章|chapter\s*(\d+)', message, re.IGNORECASE)
    # ... 仅支持字符串正则匹配

# 修复后
def _detect_phase(self, message: str | int) -> tuple[Optional[NovelPhase], Optional[int]]:
    chapter_num = None

    # 处理整数输入(直接传入章节号)
    if isinstance(message, int):
        chapter_num = message
        self.logger.info(f"[{self.name}] 直接输入章节号: {chapter_num}")
    # 处理字符串输入(从消息中提取章节号)
    elif isinstance(message, str):
        chapter_match = re.search(r'第(\d+)章|chapter\s*(\d+)', message, re.IGNORECASE)
        if chapter_match:
            chapter_num = int(chapter_match.group(1) or chapter_match.group(2))

    # 根据章节号判断阶段
    if chapter_num is not None:
        phase = PhaseCharacteristics.get_phase_by_chapter(chapter_num)
        return phase, chapter_num

    return None, None
```

**修复内容**:
1. 扩展类型注解支持 `str | int`
2. 添加 `isinstance()` 类型检查
3. 整数输入直接使用,字符串输入正则提取
4. 统一在最后根据`chapter_num`判断阶段
5. 添加详细日志记录

**影响范围**:
- 仅影响WritingAction
- 向后兼容,不影响现有功能
- 新增对整数参数的支持

**测试结果**:

### 2. BaseAction.validate_input() 输入验证增强

**问题描述**:
- 位置: `backend/app/services/agent/actions/base_action.py:138`
- 问题: 未对None输入进行显式检查
- 优先级: P3 (防御性编程)

**修复方案**:

```python
# 修复前
async def validate_input(self, state: Dict[str, Any]) -> bool:
    if not isinstance(state, dict):
        self.logger.error(f"[{self.name}] 无效的输入类型: {type(state)}")
        return False
    return True

# 修复后
async def validate_input(self, state: Dict[str, Any]) -> bool:
    # 检查state是否为None
    if state is None:
        self.logger.error(f"[{self.name}] 输入state为None")
        return False

    # 检查state是否为字典
    if not isinstance(state, dict):
        self.logger.error(f"[{self.name}] 无效的输入类型: {type(state)}, 期望dict")
        return False

    return True
```

**修复内容**:
1. 添加None值检查
2. 改进错误日志信息
3. 更清晰的错误提示

**影响范围**:
- 影响所有继承BaseAction的类
- 提升系统健壮性
- 更好的错误诊断

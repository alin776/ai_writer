# Embedding模型内存问题修复方案

## 问题分析

错误：`OSError: 页面文件太小，无法完成操作。 (os error 1455)`

**根本原因**：
- 不是磁盘空间不足（C盘13GB，D盘80GB都充足）
- 是Windows虚拟内存（页面文件/Page File）太小
- SentenceTransformer模型加载时需要大量内存，物理内存不够时需要虚拟内存支持

## 解决方案

### 方案A：增加Windows虚拟内存（推荐，治本）

**步骤**：
1. 打开"系统属性" → "高级" → "性能设置" → "高级" → "虚拟内存"
2. 取消"自动管理所有驱动器的分页文件大小"
3. 选择D盘（有80GB空间）
4. 设置自定义大小：
   - 初始大小：8192 MB（8GB）
   - 最大值：16384 MB（16GB）
5. 点击"设置"，然后"确定"
6. 重启电脑

### 方案B：代码优化（治标，降低风险）

**优化项**：
1. ~~禁用应用启动时的模型预加载~~ ❌ 不推荐，会影响性能
2. 添加更好的错误处理和降级机制
3. 添加内存不足时的友好提示
4. 可选：支持禁用RAG功能的配置项

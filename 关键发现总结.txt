================================================================================
Planning AI 第二次规划失败分析 - 关键发现
================================================================================

【问题】
用户第一次问："在主角出场的地方添加一段描写"
- Planning AI 生成了定位任务，但执行失败
- 用户第二次问："那就在第二段添加描写"
- 预期：Planning AI 应该看到第一次失败的信息
- 实际：Planning AI 看不到任何关于第一次失败的信息

================================================================================
【根本原因】对话历史链断裂
================================================================================

系统流程：
  
  第一次交互：
  ┌─────────────────────────────────────────────────────────────┐
  │ 1. 用户消息 → 2. Planning AI 生成规划 → 3. 执行任务        │
  │    (locate_content 失败)                                   │
  │ 4. 构建最终回复 → 5. 保存到对话历史                        │
  │                  ❌ 只保存了文本，没有保存规划和结果       │
  └─────────────────────────────────────────────────────────────┘
                          ↓
  第二次交互：
  ┌─────────────────────────────────────────────────────────────┐
  │ 1. 加载对话历史 → ❌ 只有文本，看不到规划和执行细节       │
  │ 2. Planning AI 生成新规划 → 可能重复同样的错误            │
  └─────────────────────────────────────────────────────────────┘

================================================================================
【核心代码位置】
================================================================================

位置1：对话历史加载 (langgraph_agent.py:1333-1347)
─────────────────────────────────────────────────────
问题：只提取对话文本，没有规划和执行结果

for msg in messages:
    role = msg.get("role", "")
    content = msg.get("content", "")
    ❌ 没有访问 msg.get("plan_data")
    ❌ 没有访问 msg.get("task_results")

位置2：规划调用 (langgraph_agent.py:1404-1411)
─────────────────────────────────────────────────
问题：Prompt 中只包含对话历史

plan_data = await self.plan_generator.generate_plan(
    conversation_history=conversation_history  # ← 只有文本
)

plan_generator.py 中的 Prompt：
✅ 包含：用户消息、对话历史、知识库文档、选中文本
❌ 不包含：上一次的规划、上一次的执行结果、错误信息

位置3：执行和保存 (langgraph_agent.py:1731-1741, 1817-1829)
─────────────────────────────────────────────────────────
问题：执行结果不被保存到历史

task_results = [
    {task_id: 1, result: "locate_content 失败：无法定位"}  ← 包含失败信息
]

await self.context_manager.update_context(
    new_messages=[
        {"role": "user", "content": message},
        {"role": "assistant", "content": final_content}  # ← 只保存最终文本
    ]
)

❌ 没有保存 task_results 到历史

================================================================================
【影响】
================================================================================

Planning AI 在第二次规划时：

看得到：
✅ 用户第一次问什么
✅ 助手的最终回复（文本）

看不到：
❌ 第一次生成了什么规划
❌ 为什么执行失败了
❌ 执行的具体错误信息
❌ 尝试过哪些定位方法

结果：
❌ Planning AI 可能重复同样的错误
❌ 无法优化策略
❌ 用户体验差

================================================================================
【解决方向】
================================================================================

需要修改：
1. ContextManager 的 update_context 方法
   - 保存 plan_data
   - 保存 task_results
   - 保存执行诊断信息

2. 规划 Prompt 的构建
   - 提取上一次的规划
   - 提取上一次的执行结果
   - 包含执行失败的原因
   - 传递给下一次的 Planning AI

示例改进：

对话历史扩展：
{
    "role": "assistant",
    "content": "最终回复文本",
    "plan_data": {...},  # ← 新增：规划
    "task_results": [...],  # ← 新增：执行结果
    "execution_summary": {  # ← 新增：诊断
        "failed_tasks": [
            {
                "tool": "locate_content",
                "error": "无法定位主角出场的地方"
            }
        ],
        "suggestion": "使用段落编号（第N段）而不是语义定位"
    }
}

Prompt 改进：
plan_prompt += """
【上一次的规划和执行结果】
规划：
- 任务1：定位内容（locate_content）
- 任务2：插入文本（smart_insert）

执行结果：
- 任务1 失败：无法定位主角出场的地方
  建议：改用段落编号定位

【根据上述信息，生成改进的规划】
"""

## 系统要求

### 硬件要求
- **操作系统**：Windows 10/11
- **内存**：至少 8GB RAM（推荐 16GB）
- **磁盘**：至少 10GB 可用空间
- **处理器**：双核及以上

### 需要安装的软件
1. **Python 3.11+** - 后端运行环境
2. **Node.js 18+** - 前端运行环境
3. **PostgreSQL 15+** - 数据库
4. **Redis 7+** - 缓存服务

## 部署步骤

### 🚀 快速开始（推荐）

1. **双击运行** `一键部署.bat` 脚本
2. 脚本会自动检查并引导你安装所有需要的软件
3. 根据提示完成配置
4. 等待自动启动完成

### 📝 详细步骤

#### 步骤 1：安装 Python 3.11+

1. 访问 https://www.python.org/downloads/
2. 下载 Python 3.11 或更高版本的 Windows 安装包
3. 运行安装程序，**重要**：勾选 "Add Python to PATH"
4. 点击 "Install Now" 完成安装
5. 验证安装：
   ```bash
   # 在命令行中运行
   python --version
   pip --version
   ```
   应该显示 Python 3.11+ 和对应的 pip 版本

#### 步骤 2：安装 Node.js 18+

1. 访问 https://nodejs.org/
2. 下载 LTS 版本（推荐 v20.x）
3. 运行安装程序，使用默认设置
4. 验证安装：
   ```bash
   # 在命令行中运行
   node --version
   npm --version
   ```
   应该显示 Node.js 和 npm 的版本号

#### 步骤 3：安装 PostgreSQL 15+

1. 访问 https://www.postgresql.org/download/windows/
2. 下载 PostgreSQL 15 或更高版本
3. 运行安装程序：
   - 记住设置的数据库密码（建议使用简单的开发密码如 `postgres`）
   - 端口使用默认的 `5432`
   - 勾选安装 pgAdmin（数据库管理工具）
4. 安装完成后，打开 **pgAdmin** 或 **SQL Shell (psql)**
5. 创建项目数据库：
   ```sql
   -- 使用 postgres 用户登录后执行
   CREATE DATABASE novelaide;
   CREATE USER novelaide WITH PASSWORD 'novelaide_password';
   GRANT ALL PRIVILEGES ON DATABASE novelaide TO novelaide;
   ```

#### 步骤 4：安装 Redis

##### 方式一：使用 Memurai（推荐，Windows 原生）

1. 访问 https://www.memurai.com/
2. 下载 Memurai Developer Edition（免费）
3. 安装后会自动作为 Windows 服务运行
4. 验证安装：
   ```bash
   memurai-cli ping
   ```
   应该返回 `PONG`

##### 方式二：使用 WSL2 + Redis

1. 启用 WSL2：
   ```bash
   wsl --install
   ```
2. 安装 Ubuntu：
   ```bash
   wsl --install -d Ubuntu
   ```
3. 在 WSL 中安装 Redis：
   ```bash
   sudo apt-get update
   sudo apt-get install redis-server
   sudo service redis-server start
   ```
4. 验证安装：
   ```bash
   redis-cli ping
   ```

##### 方式三：使用预编译版本

1. 访问 https://github.com/tporadowski/redis/releases
2. 下载最新的 `Redis-x64-*.zip`
3. 解压到 `C:\Redis`
4. 运行 `redis-server.exe`（需要保持窗口打开）

#### 步骤 5：配置环境变量

1. 复制环境变量模板：
   - 复制根目录的 `.env.example` 为 `.env`
   - 复制 `backend` 目录的 `.env.example` 为 `backend/.env`（如果有）

2. 编辑 `.env` 文件（根目录）：
   ```env
   # OpenAI API Key（必填）
   VITE_OPENAI_API_KEY=sk-your-openai-api-key-here

   # 后端 API 地址
   VITE_API_URL=http://localhost:8000

   # 是否使用模拟数据（开发时可设为 true）
   VITE_USE_MOCK_AI=false
   ```

3. 创建 `backend/.env` 文件：
   ```env
   # 数据库连接
   DATABASE_URL=postgresql+asyncpg://novelaide:novelaide_password@localhost:5432/novelaide

   # Redis 连接
   REDIS_URL=redis://localhost:6379/0

   # JWT 密钥（随机字符串）
   SECRET_KEY=your-secret-key-for-development

   # 调试模式
   DEBUG=True

   # OpenAI API Key
   OPENAI_API_KEY=sk-your-openai-api-key-here
   ```

## 使用部署脚本

### 方式一：使用一键部署脚本（最简单）

1. 双击运行 `一键部署.bat`
2. 脚本会自动：
   - 检查所有必需软件是否安装
   - 检查并配置环境变量
   - 安装前端依赖（npm install）
   - 创建 Python 虚拟环境
   - 安装后端依赖（pip install）
   - **创建数据库和用户**
   - **运行数据库迁移，自动创建所有表**
   - 启动 PostgreSQL 和 Redis 服务
   - 启动后端服务（端口 8000）
   - 启动前端服务（端口 5173）
3. 等待服务启动完成后，浏览器会自动打开

> 📝 **数据库表说明**：脚本会使用 Alembic 自动创建以下数据表：
> - users (用户表)
> - works (作品表)
> - chapters (章节表)
> - characters (角色表)
> - locations (地点表)
> - settings (设定表)
> - ai_guidelines (AI指引表)
> - novel_analyses (小说分析表)
> - timeline_events (时间线事件表)
> - entity_relationships (实体关系表)
> - ai_call_logs (AI调用日志表)
> - rewrite_history (重写历史表)
> - humanize_sessions (人性化会话表)
> - knowledge_items (知识库表)
> - 以及其他支持表和索引

### 方式二：分步执行（调试时使用）

1. **检查环境**：
   ```bash
   check-environment.bat
   ```
   会检查所有软件是否正确安装

2. **安装依赖**：
   ```bash
   install-dependencies.bat
   ```
   安装前后端所有依赖

3. **启动服务**：
   ```bash
   start-services.bat
   ```
   启动所有服务

4. **停止服务**：
   ```bash
   stop-services.bat
   ```
   停止所有服务

## 手动部署（可选）

如果脚本无法正常工作，可以手动执行以下步骤：

### 1. 安装前端依赖
```bash
npm install
```

### 2. 安装后端依赖
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 3. 启动数据库服务
- PostgreSQL 通常会作为 Windows 服务自动运行
- 如果未运行，在服务管理器中启动 `postgresql-x64-15`

### 4. 启动 Redis 服务
- 如果使用 Memurai，会作为服务自动运行
- 如果手动下载，运行 `redis-server.exe`
- 如果使用 WSL，运行 `wsl sudo service redis-server start`

### 5. 启动后端服务
```bash
cd backend
venv\Scripts\activate
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 6. 启动前端服务（新开命令行窗口）
```bash
npm run dev
```

## 常见问题

### Q1: 双击脚本闪退？

**A:** 右键脚本 → 选择"编辑"查看错误信息，或者：
1. 按 `Win + R`
2. 输入 `cmd` 打开命令行
3. 拖拽脚本文件到命令行窗口
4. 按回车执行，查看详细错误信息

### Q2: 提示"找不到 Python/Node"？

**A:** 安装时没有勾选"Add to PATH"，解决方法：
- 卸载后重新安装，勾选"Add Python to PATH"
- 或手动添加到系统环境变量

### Q3: PostgreSQL 连接失败？

**A:** 检查：
1. PostgreSQL 服务是否运行（Win + R → `services.msc`）
2. 端口 5432 是否被占用（`netstat -ano | findstr 5432`）
3. 数据库用户和密码是否正确

### Q4: Redis 连接失败？

**A:**
- 如果使用 Memurai，检查服务是否运行
- 如果使用 WSL，确保 WSL 已启动并运行 Redis
- 如果手动运行，确保 `redis-server.exe` 窗口未关闭

### Q5: 端口被占用？

**A:** 查找并关闭占用端口的程序：
```bash
# 查找占用 8000 端口的进程
netstat -ano | findstr 8000

# 关闭进程（替换 PID）
taskkill /F /PID <进程ID>
```

### Q6: npm install 很慢或失败？

**A:** 使用国内镜像：
```bash
npm config set registry https://registry.npmmirror.com
npm install
```

### Q7: pip install 很慢或失败？

**A:** 使用国内镜像：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q8: 后端启动报错 "ImportError"？

**A:** 虚拟环境未激活或依赖未安装：
```bash
cd backend
venv\Scripts\activate
pip install -r requirements.txt
```

### Q9: 前端页面空白或报错？

**A:**
1. 检查浏览器控制台错误信息
2. 确认后端服务已启动
3. 检查 `.env` 文件中的 `VITE_API_URL` 是否正确

### Q10: OpenAI API 调用失败？

**A:**
1. 检查 API Key 是否正确
2. 检查 API 配额是否用完
3. 临时使用模拟模式：设置 `VITE_USE_MOCK_AI=true`

### Q11: 数据库迁移失败？

**A:**
```bash
# 检查数据库连接
psql -U novelaide -d novelaide -h localhost
# 输入密码: novelaide_password

# 如果连接成功，手动运行迁移
cd backend
venv\Scripts\activate
alembic upgrade head

# 查看迁移历史
alembic history

# 如果需要重置数据库
# 1. 删除数据库
psql -U postgres -h localhost -c "DROP DATABASE novelaide;"
# 2. 重新创建
psql -U postgres -h localhost -c "CREATE DATABASE novelaide;"
# 3. 重新运行部署脚本
```

### Q12: 提示"alembic: command not found"？

**A:** 虚拟环境未激活或 alembic 未安装：
```bash
cd backend
venv\Scripts\activate
pip install alembic
alembic upgrade head
```

## 日常使用

### 启动项目

**方式一（推荐）**：
- 双击 `start-services.bat`

**方式二**：
1. 确保 PostgreSQL 和 Redis 服务运行中
2. 打开两个命令行窗口：


     ```bash
     npm run dev
     ```

**方式一**：
- 双击 `stop-services.bat`

**方式二**：
- 在命令行窗口中按 `Ctrl + C`

### 查看日志

- 前端日志：在前端命令行窗口查看
- 后端日志：在后端命令行窗口查看

访问 http://localhost:8000/docs 可以：
- 查看所有 API 接口
- 在线测试接口

### 数据库管理

使用 pgAdmin 管理数据库：
1. 打开 pgAdmin
2. 连接到 localhost 的 PostgreSQL 服务
